<objective>
Ship `EdenSkeletonScope` — a wrapper widget that cross-fades a skeleton subtree to its real content subtree when an `isLoading` flag toggles. Per `VERTICAL_UX_RESEARCH_2026-05-16.md` §2.2 row 4: "New `EdenSkeletonScope` that cross-fades skeleton → content over 250ms. Currently swap is instant."

This is **distinct from `EdenLoadingIndicator.crossFade`** (TRD 010-05) — that one is a lightweight inline swap helper for identical-shape items. `EdenSkeletonScope` is for SCOPE-of-a-larger-subtree fades (entire card, entire list section, entire dashboard panel) where skeleton and content may have different internal shapes.

Composes existing `EdenSkeleton` (no replacement; consumers still use `EdenSkeleton.text/circle/block` as skeleton children).
</objective>

**Alternative (manual implementation, NOT using AnimatedCrossFade)** — if you need both children in tree simultaneously for Hero/Focus preservation:
```dart
class EdenSkeletonScope extends StatefulWidget { ... }

class _EdenSkeletonScopeState extends State<EdenSkeletonScope> with SingleTickerProviderStateMixin {
  late final AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(duration: widget.fadeDuration, vsync: this, value: widget.isLoading ? 1.0 : 0.0);
  }

  @override
  void didUpdateWidget(EdenSkeletonScope oldWidget) {
    super.didUpdateWidget(oldWidget);
    if (oldWidget.isLoading != widget.isLoading) {
      widget.isLoading ? _controller.forward() : _controller.reverse();
    }
  }

  @override
  void dispose() { _controller.dispose(); super.dispose(); }

  @override
  Widget build(BuildContext context) {
    final curve = widget.curve ?? EdenSprings.curveFor(EdenSprings.smooth);
    final curved = CurvedAnimation(parent: _controller, curve: curve);
    return Stack(alignment: Alignment.topLeft, children: [
      AnimatedBuilder(
        animation: curved,
        builder: (_, __) => Opacity(opacity: curved.value, child: ExcludeSemantics(child: widget.skeleton)),
      ),
      AnimatedBuilder(
        animation: curved,
        builder: (_, __) => Opacity(opacity: 1.0 - curved.value, child: widget.content),
      ),
    ]);
  }
}
```

**Prefer the manual implementation** — gives explicit control over Stack + Opacity semantics, both children in tree always.

<anti_patterns>
- DO NOT use `AnimatedSwitcher` — it removes children on transition end, which breaks Hero / Focus state. Use `Stack` + both children always in tree.
- DO NOT use `IndexedStack` — that shows only one at a time without cross-fade.
- DO NOT default the curve to `Curves.easeInOut` if EdenSprings is available. Default to `EdenSprings.curveFor(EdenSprings.smooth)` for consistency with the rest of the obj-010 polish.
- DO NOT make the skeleton param non-required. Even for "fade to empty" cases, consumers can pass `SizedBox.shrink()` explicitly — required-ness keeps the widget honest about its purpose.
- DO NOT skip the dispose-clean test. Animation controller leaks are the highest-cost test failure (cascading across the suite).
</anti_patterns>

<error_recovery>
- If both children different sizes cause layout jumps mid-transition: wrap each in `Positioned.fill` inside the Stack, OR enforce the larger size via `IntrinsicWidth + IntrinsicHeight`. Document the size-locking behavior.
- If Opacity at 0.0 still consumes pointer events (skeleton intercepts taps on content): use `IgnorePointer(ignoring: opacity == 0.0, child: ...)` on each side.
- If the AnimatedCrossFade approach is needed for some reason and Hero/Focus preservation isn't critical, that's a valid v1 fallback — document the trade-off.
</error_recovery>

   ```dart
   import 'package:flutter/material.dart';
   import '../tokens/durations.dart';
   import '../tokens/springs.dart';

   class EdenSkeletonScope extends StatefulWidget {
     const EdenSkeletonScope({
       super.key,
       required this.isLoading,
       required this.skeleton,
       required this.content,
       this.fadeDuration = EdenDurations.normal,
       this.curve,
     });

     final bool isLoading;
     final Widget skeleton;
     final Widget content;
     final Duration fadeDuration;
     final Curve? curve;

     @override
     State<EdenSkeletonScope> createState() => _EdenSkeletonScopeState();
   }

   class _EdenSkeletonScopeState extends State<EdenSkeletonScope> with SingleTickerProviderStateMixin {
     late final AnimationController _controller;
     late final CurvedAnimation _curved;

     @override
     void initState() {
       super.initState();
       _controller = AnimationController(
         duration: widget.fadeDuration,
         vsync: this,
         value: widget.isLoading ? 1.0 : 0.0,
       );
       _curved = CurvedAnimation(
         parent: _controller,
         curve: widget.curve ?? EdenSprings.curveFor(EdenSprings.smooth),
       );
     }

     @override
     void didUpdateWidget(EdenSkeletonScope oldWidget) {
       super.didUpdateWidget(oldWidget);
       if (oldWidget.isLoading != widget.isLoading) {
         if (widget.isLoading) {
           _controller.forward();
         } else {
           _controller.reverse();
         }
       }
     }

     @override
     void dispose() {
       _curved.dispose();
       _controller.dispose();
       super.dispose();
     }

     @override
     Widget build(BuildContext context) {
       return AnimatedBuilder(
         animation: _curved,
         builder: (_, __) {
           final loadingOpacity = _curved.value;
           final contentOpacity = 1.0 - _curved.value;
           return Stack(alignment: Alignment.topLeft, children: [
             // Content: under skeleton; visible when not loading
             IgnorePointer(
               ignoring: contentOpacity == 0.0,
               child: Opacity(opacity: contentOpacity, child: widget.content),
             ),
             // Skeleton: overlay; visible when loading; always semantically excluded
             IgnorePointer(
               ignoring: loadingOpacity == 0.0,
               child: Opacity(
                 opacity: loadingOpacity,
                 child: ExcludeSemantics(
                   excluding: true,
                   child: Semantics(label: 'Loading content', child: widget.skeleton),
                 ),
               ),
             ),
           ]);
         },
       );
     }
   }
   ```
