<objective>
Ship `EdenStatusDotOverlay` — a small composable widget that overlays a status dot or unread-count badge on any child widget. Per `VERTICAL_UX_RESEARCH_2026-05-16.md` §2.2 row 10 + §2.3.1 row N5: "Avatar overlay (online/offline/away/busy)". 7/7 vertical leverage, XS effort.

The user's prompt clarifies the scope: **composable on any widget** (not avatar-specific). Used heavily in:
- Salon staff strip — staff avatars with online/busy/in-service dots
- Trades dispatch — crew tiles with availability dots
- Legal team list — attorney availability
- Medical care team — provider availability
- Sync state indicators (e.g. companion-mode "offline queue" pill with sync dot)
- Unread count badges (chat, notifications)

Note: `EdenAvatar` already has its own `status: EdenAvatarStatus?` indicator (preserved verbatim — no breaking change). `EdenStatusDotOverlay` is a sibling primitive for non-avatar widgets + a more flexible alternative when consumers need count badges.
</objective>

<anti_patterns>
- DO NOT make EdenStatusDotOverlay take an `EdenAvatar` parameter — it's child-agnostic. The child is `required Widget child`, anything.
- DO NOT replace or deprecate `EdenAvatar.status`. EdenAvatar's built-in status indicator stays. EdenStatusDotOverlay is for the cases where: (a) the child is not an avatar, OR (b) the consumer needs a count badge instead of a plain dot.
- DO NOT intercept taps on the child. Wrap the dot in `IgnorePointer(child: ...)` so the child remains tappable.
- DO NOT hardcode the "99+" overflow string. Match `EdenMobileAiFab._badgeText` pattern: `count > 99 ? '99+' : count.toString()`. Reuse the conventional cap from obj 007.
- DO NOT skip the alignment param. Some consumers need bottom-left, top-right, etc. — use `AlignmentGeometry alignment = Alignment.bottomRight` default; map to Positioned offsets internally.
- DO NOT default sync color to gold (the EdenMobileAiFab donor convention). Sync = blue (info color) per the M3 sync-state convention. Document the choice.
</anti_patterns>

<error_recovery>

- If the count badge "99+" doesn't fit in 16pt: bump size to 18pt when `count > 9` (auto-resize); document the rule.
- If obj-009 `EdenStatusPalette` extension is not yet shipped: use a try/catch around the extension read (extensions can return null, no try/catch actually needed). Fall back to `EdenColors.success/warning/error/info` constants.

<gotchas>
- `EdenColors.success/warning/error/info` shape — verify these exist by reading `lib/src/tokens/colors.dart` before assuming. Some Eden libraries use `EdenColors.green/red/amber/blue`. Match the existing convention exactly.
- The badge size auto-scaling needs careful breakpoints — at count=1 the dot is 16pt circle; at count=10 it's 18pt rounded-rect; at count=100 it shows "99+" in an 18pt rounded-rect. The dot-vs-rect threshold is `count > 9 || hasCount && count > 0`.

1. File `lib/src/widgets/eden_status_dot_overlay.dart`:
   ```dart
   import 'package:flutter/material.dart';
   import '../tokens/colors.dart';

   enum EdenStatusDotKind { online, offline, away, busy, sync, unread }

   class EdenStatusDotOverlay extends StatelessWidget {
     const EdenStatusDotOverlay({
       super.key,
       required this.child,
       this.kind = EdenStatusDotKind.online,
       this.count,
       this.color,
       this.alignment = Alignment.bottomRight,
       this.size,
     });

     final Widget child;
     final EdenStatusDotKind kind;
     final int? count;
     final Color? color;
     final AlignmentGeometry alignment;
     final double? size;

     bool get _showCount => kind == EdenStatusDotKind.unread && count != null && count! > 0;

     String _badgeText() => count! > 99 ? '99+' : count.toString();

     Color _resolveColor(BuildContext context) {
       if (color != null) return color!;
       // Try obj-009 EdenStatusPalette extension (graceful fallback)
       // final palette = Theme.of(context).extension<EdenStatusPalette>();
       // if (palette != null) { return palette.colorFor(kind); }
       switch (kind) {
         case EdenStatusDotKind.online:  return EdenColors.success;
         case EdenStatusDotKind.offline: return EdenColors.neutral[400]!;
         case EdenStatusDotKind.away:    return EdenColors.warning;
         case EdenStatusDotKind.busy:    return EdenColors.error;
         case EdenStatusDotKind.sync:    return EdenColors.info;
         case EdenStatusDotKind.unread:  return Theme.of(context).colorScheme.primary;
       }
     }

     double _resolveSize() {
       if (size != null) return size!;
       if (_showCount) {
         return count! > 9 ? 18.0 : 16.0;  // auto-scale for 2-digit badges
       }
       return 12.0;
     }

     (double? top, double? right, double? bottom, double? left) _resolvePosition() {
       // Use AlignmentGeometry to compute negative-offset positions for Clip.none Stack.
       if (alignment == Alignment.bottomRight) return (null, -2.0, -2.0, null);
       if (alignment == Alignment.bottomLeft) return (null, null, -2.0, -2.0);
       if (alignment == Alignment.topRight) return (-2.0, -2.0, null, null);
       if (alignment == Alignment.topLeft) return (-2.0, null, null, -2.0);
       return (null, -2.0, -2.0, null);  // default bottom-right
     }

     @override
     Widget build(BuildContext context) {
       final dotSize = _resolveSize();
       final dotColor = _resolveColor(context);
       final (top, right, bottom, left) = _resolvePosition();

       final overlay = _showCount
         ? Container(
             constraints: BoxConstraints(minWidth: dotSize, minHeight: dotSize),
             padding: const EdgeInsets.symmetric(horizontal: 4, vertical: 1),
             decoration: BoxDecoration(
               color: dotColor,
               borderRadius: BorderRadius.circular(dotSize / 2),
               border: Border.all(color: Theme.of(context).colorScheme.surface, width: 1.5),
             ),
             child: Center(child: Text(
               _badgeText(),
               style: TextStyle(color: Theme.of(context).colorScheme.onPrimary, fontSize: 10, fontWeight: FontWeight.w600),
             )),
           )
         : Container(
             width: dotSize, height: dotSize,
             decoration: BoxDecoration(
               color: dotColor,
               shape: BoxShape.circle,
               border: Border.all(color: Theme.of(context).colorScheme.surface, width: 1.5),
             ),
           );

       final semanticsLabel = _showCount
         ? '${_badgeText()} unread'
         : kind.name;

       return Stack(clipBehavior: Clip.none, children: [
         child,
         Positioned(
           top: top, right: right, bottom: bottom, left: left,
           child: IgnorePointer(
             child: Semantics(label: semanticsLabel, child: overlay),
           ),
         ),
       ]);
     }
   }
   ```
