@visibleForTesting
String formatSmsDateSeparator(DateTime date, DateTime now) {
  final today = DateTime(now.year, now.month, now.day);
  final messageDay = DateTime(date.year, date.month, date.day);
  if (messageDay == today) return 'Today';
  if (messageDay == today.subtract(const Duration(days: 1))) return 'Yesterday';
  // Use intl-free formatter: 'Mon, May 12'
  const weekdays = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'];
  const months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun',
                  'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
  return '${weekdays[date.weekday - 1]}, ${months[date.month - 1]} ${date.day}';
}

<anti_patterns>
- **Do NOT** introduce a new chat-bubble widget. `EdenMessageBubble` is the canonical primitive — compose, don't reinvent.
- **Do NOT** sort or filter the messages list internally. Consumer is responsible for chronological ordering (oldest first → newest last). Widget assumes the order is correct.
- **Do NOT** persist state for sent messages. The widget is a pure renderer + callback emitter. Consumer manages the messages list.
- **Do NOT** hardcode `Image.network(url)` without an errorBuilder. Network calls fail in test environments; the fallback must render.
- **Do NOT** introduce PHI redaction in this widget. The HIPAA variant (obj 017) wraps this one with overlay logic; THIS widget renders plain content.
- **Do NOT** auto-scroll on EVERY widget rebuild — only when `widget.messages.length > old.messages.length`. Otherwise scrolls jump on unrelated rebuilds (e.g., theme change).
- **Do NOT** generate test message fixtures via LLM. Hand-build 8 realistic salon-context messages.
- **Do NOT** assume `EdenMessageInput.onSend` returns a `String` — it might be `ValueChanged<EdenMessageDraft>`. Verify constructor; if shape differs, adapt the bridging code.
</anti_patterns>
