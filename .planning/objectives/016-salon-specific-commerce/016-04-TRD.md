**Builder mechanics:**

1. **Palette → Canvas drag.** Each palette entry wraps in `Draggable<EdenIntakeFieldType>` (NOT LongPressDraggable — admin-side, click-then-drag is fine). Canvas wraps in `DragTarget<EdenIntakeFieldType>` that appends a new field with default label `'New <type>'` and a fresh UUID-like id.
2. **Canvas reorder.** Use `ReorderableListView` for the canvas list. Each row shows `label` + type icon + required-pill + drag handle + delete button.
3. **Tap row → select.** Tapping a canvas row sets `_selectedFieldId`. RIGHT pane (or modal sheet on narrow) renders the per-field config.
4. **Config pane** — text input for label, toggle for required, multi-line input for options (only when type is singleChoice/multiChoice), dropdown for visibleWhen field selection.
5. **Publish.** Button fires `onPublish` callback. Consumer is responsible for bumping `version` + setting `publishedAt`.

<anti_patterns>
- **Do NOT** modify `lib/src/widgets/eden_intake_form.dart` (obj 001-10). The runner widget is shipped + consumed; its schema shape is a separate class. The builder's `EdenIntakeFieldSchema` is a NEW class.
- **Do NOT** use `LongPressDraggable` for the palette → canvas drag. Admin desktop UX expects immediate drag on click. `Draggable` is the right primitive.
- **Do NOT** use a third-party drag-drop library. `Draggable` + `DragTarget` + `ReorderableListView` are all Flutter built-ins.
- **Do NOT** persist the schema yourself. The builder is a pure stateful widget that emits `onSchemaChanged(newSchema)`. Consumer owns persistence.
- **Do NOT** generate placeholder fixture fields via LLM. Hand-build the 4 starter fields: Full name (shortText) / DOB (date) / Allergies (longText) / Signature (signature).
- **Do NOT** assume `EdenSegmentedControl` exists — verify; fall back to `TabBar` + `DefaultTabController` if not.
- **Do NOT** allow circular visibility rules. A field can only depend on earlier fields in the list (validated at config-pane level — dropdown options exclude the selected field and later fields).
- **Do NOT** support nested conditional logic in v1 (only single `equals`/`notEquals`). Document "Boolean composition (AND/OR) deferred to v2" in the value class doc comment.
</anti_patterns>

<gotchas>
- **Schema mutation immutability.** Always `setState(() => _schema = _schema.copyWith(fields: [...newFields]))`. Never mutate in place — breaks `onSchemaChanged` semantics if the consumer compares object identity.
- **Reorder index quirk.** Flutter's `ReorderableListView.onReorder` passes `newIndex` AFTER the removal — so `if (newIdx > oldIdx) newIdx -= 1`. Same quirk as obj 005-02 `EdenRouteStopList`.
- **Selected-field invalidation on remove.** If `_selectedFieldId` is the field being deleted, clear it (`_selectedFieldId = null`) before applying the new schema. Otherwise the config pane crashes on missing field lookup.
- **VisibleWhen circular check.** When the user changes a field's `visibleWhen.fieldId` to a downstream field, the rule becomes invalid. Validate in the config pane dropdown — only show upstream field IDs.
- **Test-pairing rule.** `lib/src/widgets/eden_intake_form_builder.dart` MUST have paired `test/widgets/eden_intake_form_builder_test.dart`. Enforced.
- **Hand-built fixtures only.** Fixture file MUST start with `// Do NOT regenerate via LLM — hand-built fixtures for EdenIntakeFormBuilder.`
- **salon_screen.dart APPEND not CREATE.** TRD 016-01 creates the file. This TRD appends a Section() entry at the placeholder comment for TRD 016-04. Find the comment `// TRD 016-04 will append: ...` and replace with the actual Section.
- **Tab controller lifecycle.** Use `DefaultTabController` to avoid manual disposal. Initial index = 1 (Canvas tab) so the user lands on the schema view, not the palette.
- **Empty-state hint when no field selected.** Config pane (or Config tab) must show "Tap a field to configure" — otherwise the right pane is blank and looks broken.
</gotchas>

class EdenIntakeFormBuilder extends StatefulWidget {
  const EdenIntakeFormBuilder({
    super.key,
    required this.schema,
    required this.onSchemaChanged,
    this.onPublish,
    this.idGenerator,
  });

  final EdenIntakeFormSchema schema;
  final ValueChanged<EdenIntakeFormSchema> onSchemaChanged;
  final VoidCallback? onPublish;
  final String Function()? idGenerator;

  @override
  State<EdenIntakeFormBuilder> createState() => EdenIntakeFormBuilderState();
}

class EdenIntakeFormBuilderState extends State<EdenIntakeFormBuilder> {
  String? _selectedFieldId;
  int _idCounter = 0;
  String _genId() => widget.idGenerator?.call() ?? 'field-${DateTime.now().millisecondsSinceEpoch}-${_idCounter++}';

  void addField(EdenIntakeFieldType type) {
    final field = EdenIntakeFieldSchema(
      id: _genId(),
      type: type,
      label: 'New ${type.displayLabel.toLowerCase()}',
    );
    final updated = widget.schema.copyWith(fields: [...widget.schema.fields, field]);
    widget.onSchemaChanged(updated);
  }

  void reorderField(int oldIdx, int newIdx) {
    if (newIdx > oldIdx) newIdx -= 1; // Flutter quirk
    final list = [...widget.schema.fields];
    final field = list.removeAt(oldIdx);
    list.insert(newIdx, field);
    widget.onSchemaChanged(widget.schema.copyWith(fields: list));
  }

  void removeField(String id) {
    final list = widget.schema.fields.where((f) => f.id != id).toList();
    if (_selectedFieldId == id) {
      setState(() => _selectedFieldId = null);
    }
    widget.onSchemaChanged(widget.schema.copyWith(fields: list));
  }

  void updateField(String id, EdenIntakeFieldSchema Function(EdenIntakeFieldSchema) mutate) {
    final list = widget.schema.fields.map((f) => f.id == id ? mutate(f) : f).toList();
    widget.onSchemaChanged(widget.schema.copyWith(fields: list));
  }

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(builder: (ctx, c) {
      if (c.maxWidth >= 900) {
        return _ThreePane(state: this);
      }
      return _Tabbed(state: this);
    });
  }
}
