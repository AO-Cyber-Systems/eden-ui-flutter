<objective>
Ship `EdenTimeSlotPicker` — the customer-facing booking widget primitive per `.planning/USE_CASES_SALON_2026-05-17.md` SALON-002 + SALON-008 (#2 in the Top-10 gap list). Distinct from admin-side `EdenScheduler` (obj 004): this is the CONSUMER-facing slot grid where a customer picks a specific time × staff combination during self-booking.

**Grid generation algorithm:**

1. Compute time-row list from `openingHour` to `closingHour` in `slotMinutes` (default 15) increments.
2. For each (timeRow, staff) cell:
   - Find matching slot in `widget.slots` (where `slot.staffId == staff.id` AND `slot.startTime.hour == row.hour && slot.startTime.minute == row.minute`).
   - If no slot → render an EMPTY cell (faded, indicates "no schedule").
   - If slot.available == true → render TAPPABLE cell with primaryContainer color.
   - If slot.available == false → render BLOCKED cell (faded with `Tooltip(message: slot.blockedReason ?? 'Booked')`).
   - If `slot.id == selectedSlotId` → render SELECTED cell (theme.colorScheme.primary border + filled).

**Why not compose EdenScheduler:**

`EdenScheduler` is an admin-side calendar (day/week/month/swimlane views with drag-to-reschedule, conflict layout, multi-event blocks). The customer-facing booking widget needs:
- Tap-to-pick UX (no drag, no conflict resolution).
- Slot-based granularity (15-min cells, NOT continuous time).
- Staff-as-column ALWAYS (even with 1 staff).
- Customer-friendly visuals (clear available/blocked states; no admin chrome).

The two widgets share `EdenSchedulerEvent` conceptually (a slot IS an event), but the value classes are different to keep the surfaces decoupled. Document this in the value-class doc comment.

**Composed primitives:**

- `EdenCard` for the day-navigation header wrapper.
- `EdenChip` for the staff-tab-strip in narrow mode.
- `EdenAvatar` for the staff column header.
- `EdenButton` is NOT used — slot cells are custom-painted `InkWell + Container` cells.

<anti_patterns>
- **Do NOT** import or compose `EdenScheduler` here. Two separate widgets serving two separate audiences (admin vs customer). They will diverge — accept the duplication.
- **Do NOT** auto-generate slot fixtures via LLM. Hand-build a 3-staff × 14-day dataset using `List.generate` loops.
- **Do NOT** persist the selected slot internally. The widget is controlled: `selectedSlotId` + `onSlotSelected` callback. Consumer holds the state.
- **Do NOT** make the day-header navigation buttons un-customizable. Accept a `dayHeaderBuilder` slot for consumers who want different chrome (e.g., calendar drop-down picker).
- **Do NOT** assume all slots have `durationMinutes == 15`. The widget snaps to a 15-min grid for visual rendering BUT the slot data may declare longer durations (e.g., 30, 45, 60). For v1, render a single cell at the slot's `startTime`; multi-cell spanning is deferred to v2.
- **Do NOT** include weekend / holiday awareness. That's a backend concern — consumer passes slots only for days/hours that are bookable.
- **Do NOT** use a `Stack` for the cell visual states. Solid colors per state with `Container.decoration` is cleaner and faster.
</anti_patterns>

<gotchas>
- **Time-row generation rounding.** `openingHour: 9, closingHour: 18, slotMinutes: 15` → 9 hours × 4 = 36 rows. `(closingHour - openingHour) * (60 / slotMinutes)` is the formula. Test edge: opening==closing → 0 rows, NOT a crash.
- **Day-comparison across timezones.** `slot.startTime` may include hour/minute info that creates timezone drift if naively compared. Filter by `DateTime(slot.startTime.year, slot.startTime.month, slot.startTime.day)` for day-equality.
- **Active-staff state.** In narrow mode, the widget needs to track which staff column is active. Use stateful internal `_activeStaffId` initialized to `visibleStaff.first.id`. When `serviceEntry` changes upstream, may need to reset.
- **Test-pairing rule.** `lib/src/widgets/eden_time_slot_picker.dart` MUST have paired test file. Enforced.
- **Hand-built fixtures only.** Header: `// Do NOT regenerate via LLM — hand-built fixtures for EdenTimeSlotPicker.`
- **salon_screen.dart APPEND.** TRD 016-01 creates the file. Find the `// TRD 016-02 will append: ...` placeholder.
- **Selected-cell border priority.** When a cell is both selected AND blocked, selected wins (visually). But selecting a blocked cell is technically a consumer-side bug — tap-disable prevents it.
- **Tooltip on disabled InkWell.** `Tooltip` works regardless of InkWell.onTap state, but mouse-region only triggers on hover. On touch devices, tooltip requires long-press; document this is best-effort UX.
- **Day-nav with onDayChanged null.** If consumer doesn't pass `onDayChanged`, the buttons should be disabled (grey + no-op). Don't crash on null callback.
</gotchas>

@visibleForTesting
String formatDayHeader(DateTime day) {

@visibleForTesting
List<TimeOfDay> timeRowsFor({required int openingHour, required int closingHour, int slotMinutes = 15}) {
  final out = <TimeOfDay>[];
  for (var h = openingHour; h < closingHour; h++) {
    for (var m = 0; m < 60; m += slotMinutes) {
      out.add(TimeOfDay(hour: h, minute: m));
    }
  }
  return out;
}

class EdenTimeSlotPicker extends StatefulWidget {
  const EdenTimeSlotPicker({
    super.key,
    required this.currentDay,
    required this.allStaff,
    required this.slots,
    required this.onSlotSelected,
    this.selectedSlotId,
    this.onDayChanged,
    this.serviceEntry,
    this.openingHour = 9,
    this.closingHour = 18,
    this.slotMinutes = 15,
    this.dayHeaderBuilder,
    this.emptyStaffLabel = 'No staff available for this service',
  });

  final DateTime currentDay;
  final List<EdenTimeSlotStaff> allStaff;
  final List<EdenTimeSlot> slots;
  final ValueChanged<EdenTimeSlot> onSlotSelected;
  final String? selectedSlotId;
  final ValueChanged<DateTime>? onDayChanged;
  final EdenServiceCatalogEntry? serviceEntry;
  final int openingHour;
  final int closingHour;
  final int slotMinutes;
  final Widget Function(BuildContext, DateTime)? dayHeaderBuilder;
  final String emptyStaffLabel;

  @override
  State<EdenTimeSlotPicker> createState() => _EdenTimeSlotPickerState();
}

class _EdenTimeSlotPickerState extends State<EdenTimeSlotPicker> {
  String? _activeStaffId; // narrow-mode active staff

  List<EdenTimeSlotStaff> get visibleStaff {
    if (widget.serviceEntry == null) return widget.allStaff;
    final capableIds = widget.serviceEntry!.capableStaff.map((s) => s.id).toSet();
    return widget.allStaff.where((s) => capableIds.contains(s.id)).toList();
  }

  Map<String, EdenTimeSlot> get _slotByKey {
    final map = <String, EdenTimeSlot>{};
    for (final s in widget.slots) {
      final key = '${s.staffId}|${s.startTime.hour}:${s.startTime.minute}';
      map[key] = s;
    }
    return map;
  }

  @override
  Widget build(BuildContext context) {
    final visible = visibleStaff;
    if (visible.isEmpty) {
      return Center(child: Text(widget.emptyStaffLabel));
    }
    final rows = timeRowsFor(
      openingHour: widget.openingHour,
      closingHour: widget.closingHour,
      slotMinutes: widget.slotMinutes,
    );
    return LayoutBuilder(builder: (ctx, c) {
      final useTabStrip = c.maxWidth < 600 || visible.length > 4;
      _activeStaffId ??= visible.first.id;
      // Reset if active staff no longer in visible set
      if (!visible.any((s) => s.id == _activeStaffId)) {
        _activeStaffId = visible.first.id;
      }
      return Column(
        children: [
          _DayHeader(
            day: widget.currentDay,
            onDayChanged: widget.onDayChanged,
            customBuilder: widget.dayHeaderBuilder,
          ),
          if (useTabStrip)
            _StaffTabStrip(
              staff: visible,
              activeId: _activeStaffId!,
              onTap: (id) => setState(() => _activeStaffId = id),
            ),
          Expanded(
            child: useTabStrip
                ? _SingleStaffSlotList(
                    activeStaff: visible.firstWhere((s) => s.id == _activeStaffId),
                    rows: rows,
                    slotByKey: _slotByKey,
                    selectedSlotId: widget.selectedSlotId,
                    onSlotSelected: widget.onSlotSelected,
                  )
                : _StaffGrid(
                    staff: visible,
                    rows: rows,
                    slotByKey: _slotByKey,
                    selectedSlotId: widget.selectedSlotId,
                    onSlotSelected: widget.onSlotSelected,
                  ),
          ),
        ],
      );
    });
  }
}

        )),
      ),

class _TimeSlotPickerDemo extends StatefulWidget {
  @override
  State<_TimeSlotPickerDemo> createState() => _TimeSlotPickerDemoState();
}

class _TimeSlotPickerDemoState extends State<_TimeSlotPickerDemo> {
  DateTime _day = DateTime(2026, 5, 21);
  String? _selectedSlotId;

  static const _staff = <EdenTimeSlotStaff>[
    EdenTimeSlotStaff(id: 'st-aisha', displayName: 'Aisha', initials: 'AA'),
    EdenTimeSlotStaff(id: 'st-brendan', displayName: 'Brendan', initials: 'BB'),
    EdenTimeSlotStaff(id: 'st-carla', displayName: 'Carla', initials: 'CC'),
  ];

  List<EdenTimeSlot> _slotsFor(DateTime day) {
    final out = <EdenTimeSlot>[];
    for (final s in _staff) {
      for (var h = 9; h < 18; h++) {
        for (var m = 0; m < 60; m += 15) {
          final blocked = (s.id == 'st-brendan' && h == 12) || (s.id == 'st-carla' && h == 15 && m == 30);
          out.add(EdenTimeSlot(
            id: '${s.id}-${day.day}-${h.toString().padLeft(2, '0')}-${m.toString().padLeft(2, '0')}',
            staffId: s.id,
            startTime: DateTime(day.year, day.month, day.day, h, m),
            available: !blocked,
            blockedReason: blocked ? 'Booked' : null,
          ));
        }
      }
    }
    return out;
  }

  @override
  Widget build(BuildContext context) {
    return EdenTimeSlotPicker(
      currentDay: _day,
      allStaff: _staff,
      slots: _slotsFor(_day),
      selectedSlotId: _selectedSlotId,
      onSlotSelected: (slot) {
        setState(() => _selectedSlotId = slot.id);
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text('Booked: ${slot.staffId} at ${slot.startTime.hour}:${slot.startTime.minute.toString().padLeft(2, '0')}')),
        );
      },
      onDayChanged: (newDay) => setState(() {
        _day = newDay;
        _selectedSlotId = null;
      }),
    );
  }
}
