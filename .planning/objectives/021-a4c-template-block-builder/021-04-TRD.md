<objective>
Wave 3. Ship the three right-rail editor panels: `EdenTemplateVariablesPanel`, `EdenTemplateStylesPanel`, `EdenTemplateLayoutPanel`. These are stateless / lightly-stateful sibling widgets that compose into the composite root (TRD-05) as right-rail-tab content. Co-located in one TRD because they share the same shape (panel-sized, callback-driven, registry-or-settings-input-driven).
</objective>

**Composition shape (all 3 panels):**
- All accept a `value: <SettingsType>?` (variables panel doesn't need this; it reads from registry).
- All accept an `onChange: void Function(<SettingsType>)` callback fired when any field changes.
- Variables panel additionally has `onInsertField: void Function(String token)` for variable insertion.
- All are width-constrained to fit in a 240pt right-rail panel (donor uses this width); also tested at 390pt.

**Variables panel — search behavior:**
- TextField at top; on change, sets `_searchQuery`.
- Filter groups: for each group, filter its fields by `field.toLowerCase().contains(query.toLowerCase())`. Drop groups with zero remaining fields.
- Empty state — when search yields zero groups: render "No matching fields" centered text.
- Field rendering — monospace `{{group.field}}` token in a tappable Container with hover highlight.

**Styles panel — brand-color swatches:**
- Row of 6 circular Containers, 28pt × 28pt, with `BoxShape.circle`.
- Selected swatch has white border (2pt) + glow shadow (color `brandColor.withValues(alpha: 0.4)`, blurRadius 4, spreadRadius 1).
- Tap → setState + fires onChangeStyle.

**Styles panel — font-family dropdown:**
- `DropdownButtonFormField<String>` with 4 default options ('Plus Jakarta Sans', 'Inter', 'Outfit', 'System Default'). Consumer-overridable via panel constructor.
- onChanged → setState + fires onChangeStyle.

**Styles panel — font-size inputs:**
- Two `TextField` widgets for header / body font size, each with numeric keyboard + min/max validation (e.g., header: 8-72, body: 8-48).
- On submit / blur: parse double, clamp to range, fires onChangeStyle.
- Donor uses read-only TextField with `controller: TextEditingController(text: '16px')`. Library upgrades to editable; document divergence in dartdoc.

**Layout panel — page-size and orientation SegmentedButtons:**
- Two `SegmentedButton<EdenTemplatePageSize>` and `SegmentedButton<EdenTemplateOrientation>`.
- Selected segment fires onSelectionChanged → setState + fires onChangeLayout.

**Layout panel — margins:**
- 2x2 grid of `_MarginField`s (Top / Right / Bottom / Left).
- Each is a TextField accepting double input (positive); validates >= 0, <= 4 (max 4 inches margin sanity).
- On change, fires onChangeLayout with updated settings.

**Layout panel — page-breaks:**
- Two `CheckboxListTile`-style rows (donor uses custom `_CheckboxRow`). Library uses Material `CheckboxListTile` or custom — choice depends on space; donor's compact custom row is preferred for 240pt rail.
- On change, fires onChangeLayout.
