<objective>
Wave 2A. Ship `EdenTemplateBlockPalette` — the left-rail block palette UI that consumers compose into their template-builder UI. The palette reads from `EdenTemplateBlockRegistry` (TRD-01 surface), renders a categorized 2-column grid of block cards, supports drag-source semantics for drag-to-canvas (Flutter `Draggable<EdenTemplateBlockDescriptor>`), and emits `onAddBlock` for click-to-add fallback on touch / no-drag contexts.

Parallel with TRD-02 in Wave 2 because they own distinct files. Depends on TRD-01 (registry + descriptors).
</objective>

<gotchas>
- **Palette is STATELESS — no internal state.** Hover is a per-card concern handled via a small private `StatefulWidget` for the card. The palette widget itself does not hold state.
- **Registry singleton consumed at build() time.** Reading `EdenTemplateBlockRegistry.instance.all()` inside `build` is FINE — the registry is a singleton; if it changes during the widget's lifetime, the widget needs to be rebuilt by the consumer (e.g., via setState in the parent). DO NOT add a listener pattern in v1 — keep it stateless. If a consumer needs reactive updates, they wrap the palette in a StatefulWidget that calls setState after `register()`.
- **Empty registry handling.** If `EdenTemplateBlockRegistry.instance.all().isEmpty`: render an empty placeholder with a hint ("No block types registered — call EdenTemplateBlockRegistry.instance.resetToDefaults() to load defaults"). DO NOT crash.
- **GridView in a Column inside a ScrollView — overflow risk.** The outer container is a scrolling list of categories (ListView); each category has a section header + an inner GridView. The inner GridView must use `shrinkWrap: true, physics: NeverScrollableScrollPhysics()` to avoid nested-scroll conflicts. Donor uses this pattern (`block_palette_panel.dart:171-188`) — copy it.
- **Aspect ratio of cards.** Donor uses `childAspectRatio: 1.3` (wider than tall). Library matches; ensures the icon + name + description fit at the 240pt donor right-rail width (each card is ~108pt × ~83pt).
- **Iconography from descriptor.** Card renders `descriptor.icon` (IconData from the descriptor). Color: primary when hovered, onSurfaceVariant otherwise.
- **Description ellipsis at 1 line.** `maxLines: 1, overflow: TextOverflow.ellipsis`. At narrow widths, descriptions truncate.
- **iPhone-narrow (390pt) test.** Palette WHEN placed in a 390pt container MUST render without overflow. At 390pt, cards are ~183pt each (with 12pt outer padding + 6pt cross-axis spacing) — should fit fine. Test verifies no `RenderFlex overflowed` errors.
- **Donor `_BlockCard.isDashed` parameter.** Donor passes `isDashed: true` for advanced blocks. Inspection of `block_palette_panel.dart:235-236`: actually both branches use `BorderStyle.solid` (donor's code has a `style: widget.isDashed ? BorderStyle.solid : BorderStyle.solid` bug — both produce solid). Library DROPS `isDashed`; if dashed-border styling is wanted for advanced blocks in the future, that's a separate enhancement.
- **Hover detection on touch devices.** `MouseRegion` doesn't fire on touch — that's fine; touch users get the click-to-add fallback. Hover is mouse-only enhancement.
- **Drag feedback widget.** Use `Material(elevation: 4, color: Colors.transparent, child: SizedBox(width: 108, height: 83, child: _DefaultBlockCard(descriptor: ..., isFeedback: true)))` — fixed size matches card dimensions. The `Material` wrapper is required for the feedback to render correctly (Flutter Draggable feedback is rendered in an Overlay; without Material parent, Text styling may break).
- **Don't dispatch `onAddBlock` on tap AND drag-end.** Tap = click-to-add; drag-end = the DragTarget consumer (canvas) handles. The palette ONLY fires `onAddBlock(descriptor)` on tap.
- **`Draggable.onDragStarted` / `onDragEnd` callbacks (optional).** Library v1 doesn't expose these — they're internal to the Draggable. If consumers need lifecycle hooks (e.g., to track analytics on drag start), that's a follow-up TRD.
</gotchas>

Public API:
```dart
class EdenTemplateBlockPalette extends StatelessWidget {
  const EdenTemplateBlockPalette({
    super.key,
    required this.onAddBlock,
    this.categories,
    this.cardBuilder,
    this.emptyPlaceholder,
  });

  final void Function(EdenTemplateBlockDescriptor descriptor) onAddBlock;
  final List<String>? categories;
  final Widget Function(BuildContext, EdenTemplateBlockDescriptor)? cardBuilder;
  final Widget? emptyPlaceholder;

  @override
  Widget build(BuildContext context) {
    final all = EdenTemplateBlockRegistry.instance.all();
    if (all.isEmpty) {
      return emptyPlaceholder ?? _DefaultEmptyPlaceholder();
    }

    final effectiveCategories = categories
        ?? (all.map((d) => d.category).toSet().toList()..sort());

    return ListView(
      padding: const EdgeInsets.all(12),
      children: [
        for (final category in effectiveCategories) ...[
          _SectionHeader(label: category.toUpperCase()),
          const SizedBox(height: 8),
          _BlockGrid(
            descriptors: all.where((d) => d.category == category).toList(),
            onAddBlock: onAddBlock,
            cardBuilder: cardBuilder,
          ),
          const SizedBox(height: 16),
        ],
      ],
    );
  }
}
```

`_BlockGrid` uses `GridView.builder(shrinkWrap: true, physics: const NeverScrollableScrollPhysics(), gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(crossAxisCount: 2, mainAxisSpacing: 6, crossAxisSpacing: 6, childAspectRatio: 1.3), ...)`.
