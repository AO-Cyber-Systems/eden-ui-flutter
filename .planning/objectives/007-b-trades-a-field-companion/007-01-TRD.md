<objective>
Ship `EdenInspectionFormPage` — a full-page composition for dynamic, multi-section inspection forms with typed field inputs, progress tracking, draft save, and submit gating. The library's flagship "form-with-photos-and-signature" page.

```dart
final updatedForm = await Navigator.of(context).push<EdenInspectionForm?>(
  MaterialPageRoute(builder: (_) => EdenInspectionFormPage(
    form: myForm,
    onSaveDraft: (f) => myRepo.saveDraft(f),
    onSubmit: (f) => myRepo.submit(f),
    onCapturePhoto: (field) async {
      return await Navigator.of(context).push(MaterialPageRoute(
        builder: (_) => EdenPhotoCapturePage(onCapture: ..., fieldId: field.id),
      ));
    },
    onCaptureSignature: (field) async {
      return await Navigator.of(context).push(MaterialPageRoute(
        builder: (_) => EdenSignatureCapturePage(metadata: {'field_id': field.id}),
      ));
    },
  )),
);
```

Internal layout:
1. AppBar with `form.name` title + 'Save Draft' TextButton in actions (when not submitted, not saving).
2. **Progress header strip** (top of body): rendered always; '${completedFields} of ${totalFields} fields' on left + '${percent}% complete' on right; LinearProgressIndicator below.
3. **Submitted state branch** (`form.status == 'submitted'`):
   - Centered Column: check-circle icon (blue, 64pt) + 'Form Submitted' title + 'This form has been submitted and is read-only.' subtitle.
   - No submit button.
4. **Active state branch** (form.status != 'submitted'):
   - ListView of sections (`form.sections`), each rendering:
     - Section title (theme.textTheme.titleSmall, primary color, w700).
     - Primary-color Divider with alpha 0.3.
     - For each field in section: render `_FieldWidget` (switches on field.type → text/number/boolean/singleSelect/multiSelect/photo/signature).
   - Bottom `SafeArea(Padding(_SubmitButton))`:
     - When `form.isReadyToSubmit`: enabled FilledButton 'Submit Form'.
     - When NOT ready: disabled with label 'Complete required fields to submit'.
     - When `_isSubmitting`: spinner + 'Submitting...'.

State machine:
- `_localForm: EdenInspectionForm?` (mutable copy of widget.form, updated on every field change).
- `_isSubmitting: bool`.
- `_isSaving: bool`.

Field type rendering:
- **text** / **longText** — `TextFormField(maxLines: longText ? null : 3)` (donor uses maxLines: 3 for both — preserve).
- **number** — `TextFormField(keyboardType: numberWithOptions(decimal:true), inputFormatters: digitsOnly+decimal)`. `onChanged` parses `double.tryParse(v) ?? v` and emits.
- **boolean** — `Card(elevation:0, surfaceContainerLow) > SwitchListTile(title: label, value, onChanged)`.
- **singleSelect** — `DropdownButtonFormField<String>(items: field.options, value: field.value, hint: 'Select an option')`.
- **multiSelect** — `Wrap(spacing:8, runSpacing:4, FilterChip per option)`. Maintains Set<String> in field.value.
- **photo** — InkWell-wrapped Container 120pt-height; tap fires `onCapturePhoto(field)`; on result, set field.value to `result.filePath` (or to a small `EdenCapturedPhotoRef` value if we want to preserve the photo metadata — see gotchas).
- **signature** — Container 140pt-height; tap fires `onCaptureSignature(field)`; on result, set field.value to a stable identifier (or a summary of the stroke count).

**Per locked decision (constraint 6 + 12):** the donor `InspectionFormPage`:
- Uses Riverpod (`ConsumerStatefulWidget` + `ref.watch(inspectionFormByIdProvider)` + `ref.read(fieldCrewRepositoryProvider)`) → port drops Riverpod; form comes in via constructor, repo via callbacks.
- Imports `trades/features/field_crew/domain/inspection_form_model.dart` → port DEFINES local value types: `EdenInspectionForm`, `EdenInspectionSection`, `EdenInspectionField`, `EdenInspectionFieldType` (enum). Naming mirrors donor for migration simplicity.
- Has `_PhotoFieldPlaceholder` simulating photo capture → port REMOVES; delegates to `onCapturePhoto` callback (TRD 007-04 EdenPhotoCapturePage is the typical consumer-side target, but the page is decoupled from it).
- Has `_SignatureFieldPlaceholder` simulating signature → port REMOVES; delegates to `onCaptureSignature` callback (TRD 007-02 EdenSignatureCapturePage typical target).
- Has 'Save Draft' SnackBar + 'Submit successful' SnackBar — port preserves these UX patterns.

**Composition position:** push as full route; pop with the updated form. Consumer's `onSubmit` returns the persisted form which gets popped; `null` pop on user back-press.

**Out of scope:**
- Conditional field visibility (use existing `EdenIntakeForm` Wave A TRD 001-10 for branching questionnaires; this page does NOT branch).
- Custom field types beyond the 8 listed.
- Field-level validators beyond `required` (consumer pre-validates the schema).
- Auto-save on field change (consumer triggers save explicitly).
- Multi-tab forms (single ListView per page).
</objective>

<gotchas>
- **`EdenInspectionField.value` is dynamic.** Per donor parity. Acceptable but document acceptable value types per field.type (e.g., text → String, boolean → bool, multiSelect → List<String>, photo → String filePath OR an `EdenCapturedPhotoRef`).
- **Field-change setState scope.** When a multi-select field changes, the entire sections list is rebuilt with `copyWith`. This is O(N) for N total fields. Acceptable for <50-field forms; document the v1 perf scope.
- **TextEditingController per text field.** The donor manages `_controller = TextEditingController(text: field.value?.toString() ?? '')` per stateful `_TextFieldState`. Preserve — each text field has its own controller, disposed properly. Don't try to consolidate controllers.
- **Number field formatter.** `FilteringTextInputFormatter.allow(RegExp(r'[0-9.]'))` — preserve donor regex (allows multiple decimals; rely on `double.tryParse` to ultimately validate). Test entering '1.2.3' produces NaN-fallback-to-string `'1.2.3'`.
- **Required asterisk.** `field.isRequired` shows ` *` (red asterisk) appended to label. Wrap label in `Row` per donor.
- **Photo callback null vs absent capture.** When `onCapturePhoto == null`, tapping the photo placeholder triggers `ScaffoldMessenger.showSnackBar('Photo capture not configured')` rather than silent no-op. Same for signature.
- **'Save Draft' button.** AppBar action visible only when `!isSubmitted && !_isSaving`. Tap fires `widget.onSaveDraft?.call(_localForm ?? widget.form)` then updates _localForm with returned value, shows SnackBar 'Draft saved'.
- **Bottom safe-area submit.** `bottomNavigationBar: isSubmitted ? null : SafeArea(child: Padding(EdgeInsets.all(16), child: _SubmitButton))`. Donor pattern.
- **`InspectionForm.copyWith` immutability discipline.** Field changes MUST flow through `copyWith` + `copyWithFields` — no mutation. If any test catches a mutation, refactor.
- **No new pubspec deps.** ZERO camera / signature / Riverpod / dio / http / trades imports. Constraint 4 + 12.
- **iPhone-narrow ≥390pt risk.** All 8 field types must render without overflow. Photo placeholder is 120pt × full-width; signature placeholder is 140pt × full-width — fit. The `Wrap` for multi-select chips auto-wraps. Test with a long-text + long-option field.
- **Form with zero fields.** `form.totalFields == 0` → progress shows '0 of 0 fields · 0% complete' (avoid `0/0` NaN). Handle in `completionPercent` getter with explicit guard returning 0.0.
- **Resolver constraints:** `no_llm_test_data`, `no_property_based_default`, `no_gherkin_layer`.
</gotchas>

**Submitted state**
- `form.status = 'submitted'` → centered 'Form Submitted' + check-circle icon; Submit button NOT rendered; 'Save Draft' NOT visible; fields rendered but disabled.

**Progress tracking**
- 1 section + 2 fields, both required, both empty → '0 of 2 fields · 0% complete'.
- Fill 1 field → setState should produce '1 of 2 · 50%'.
- Fill both → '2 of 2 · 100%' with green LinearProgressIndicator (assert `valueColor` is green).

**Field — text**
- Renders `TextFormField` with field.label visible.
- Enter 'hello' via `tester.enterText(...)` → onChanged setState updates _localForm. Verify by inspecting form state via tester.state OR by re-checking the progress counter (1 field filled → counter updates).
- Required text field with empty value → counter unchanged (does NOT count as completed).

**Field — longText**
- Same as text but `maxLines: null` (multiline) — assert max lines.

**Field — number**
- Enter '42' → field.value == 42 (double).
- Enter 'abc' → input formatter blocks; field.value remains previous.
- Enter '12.34.56' → field.value == '12.34.56' (string fallback per donor).

**Field — boolean**
- Initial value false → SwitchListTile off.
- Tap → setState; value true; progress counter +1 if required.

**Field — singleSelect**
- `options: ['A','B','C']` → DropdownButtonFormField renders all 3 options.
- Tap dropdown → select 'B' → value 'B'.

**Field — multiSelect**
- `options: ['Red','Green','Blue']` → 3 FilterChips.
- Tap 'Red' → selected; tap 'Green' → both selected; tap 'Red' again → only 'Green' remains.

**Field — photo**
- `onCapturePhoto: returns sample` → tap photo placeholder → callback fires once with the field; placeholder updates to 'Photo captured — tap to retake' visual.
- `onCapturePhoto: null` → tap → SnackBar 'Photo capture not configured' visible.

**Field — signature**
- `onCaptureSignature: returns sample` → tap signature placeholder → callback fires; placeholder updates to 'Signature captured' visual.
- `onCaptureSignature: null` → tap → SnackBar 'Signature capture not configured' visible.

**Save Draft**
- `onSaveDraft: capture` → tap 'Save Draft' → callback fires once with current _localForm; SnackBar 'Draft saved' visible.
- `onSaveDraft: null` → 'Save Draft' button NOT visible (hidden).
- Failing onSaveDraft → SnackBar 'Save failed' (red bg) visible.

**Submit gating**
- Form with required field empty + Submit tap → SnackBar 'Please complete all required fields...' visible; `onSubmit` NOT called.
- Form with all required filled + Submit tap → `onSubmit` fires once with _localForm; SnackBar 'Form submitted successfully' (green bg) visible; page pops with the returned form.
- Failing onSubmit → SnackBar 'Submit failed' (red bg) visible; page does NOT pop.

**Pop result**
- After successful submit, page pops with the form returned by `onSubmit`. Verify via `await Navigator.push<EdenInspectionForm?>(...)` returns that form.

**iPhone-narrow ≥390pt**
- `tester.binding.setSurfaceSize(Size(390, 800))` → mount with all 8 field types in one section + long labels → no `RenderFlex` overflow.

## Recovery

If the form-change deep-copy logic is too brittle (test cases break on every minor change), simplify with a single `Map<String, dynamic> answers` keyed by field.id rather than a fully immutable form tree. Document the deviation. The trade-off: easier to mutate, but loses the strongly-typed `EdenInspectionForm` benefit. Recommend: only fall back if widget tests are unstable for ≥30 minutes.

If photo callback semantics cause issues (field.value type ambiguity — String path vs EdenCapturedPhotoRef), define a tagged-union value type `EdenInspectionFieldValue` with subtypes for each field-type's value. Defer this refactor to a follow-up TRD if the simpler `dynamic` approach works for v1.
