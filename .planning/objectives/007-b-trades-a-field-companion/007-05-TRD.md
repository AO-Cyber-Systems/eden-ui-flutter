<objective>
Ship `EdenCheckInPage` — a full-page composition for GPS-aware clock-in / clock-out flows used by field technicians (trades), home-visit nurses (medical), fuel-truck drivers, gov caseworkers visiting sites.

```dart
EdenCheckInPage(
  appointment: EdenCheckInAppointment(
    id: 'apt-123',
    title: 'HVAC Repair — Johnson',
    address: '742 Evergreen Terrace',
    icon: Icons.event_available,  // optional, vertical-customizable
  ),
  gpsStatus: EdenGpsStatus.high,
  gpsAccuracyMeters: 5.2,
  gpsPosition: const EdenLatLng(37.7749, -122.4194),
  events: const [
    EdenCheckInEvent(
      id: 'e1',
      type: EdenCheckInEventType.checkIn,
      timestamp: DateTime(2026, 5, 16, 9, 5),
      isGeofenceVerified: true,
    ),
  ],
  onSubmit: (submission) async => myRepo.submitCheckIn(submission),
);
```

The page renders:
1. AppBar with `title: 'Check In / Out'` (default; overridable via `appBarTitle: String?`).
2. **Appointment info card** — EdenCard with leading CircleAvatar icon + title + address (with location_on icon).
3. **GPS status card** — EdenCard with EdenSectionHeader('Location Status') + EdenDescriptionList containing four rows:
   - GPS Signal: EdenBadge variant (success/warning/danger) + qualityLabel.
   - Accuracy: dot indicator + `${accuracyMeters}m`.
   - Coordinates: monospace `lat, lng` (5 decimal places).
   - Geofence: EdenBadge ('Within geofence' / 'Outside geofence' based on isHighQuality).
4. **Check-in history card** (only when events non-empty) — EdenCard with EdenSectionHeader("Today's Activity") + count subtitle + history rows. Each row: circle icon (login/logout) + 'Checked in' or 'Checked out' label + DateFormat.jm time + Verified EdenBadge if isGeofenceVerified.
5. **Notes input** — TextField with label 'Notes (optional)' + hint + maxLines: 3.
6. **Action button area** — state machine:
   - `_isSubmitting` → EdenSpinner.
   - else if no check_in events → green FilledButton 'Check In'.
   - else if check_in present + no check_out → green check_circle banner + orange FilledButton 'Check Out'.
   - else → blue done_all 'Appointment complete' container.
7. Submit logic: when user taps Check In or Check Out, if `gpsStatus == EdenGpsStatus.unavailable`, show SnackBar error 'GPS is not available. Please enable location services.' and abort. Else call `onSubmit(EdenCheckInSubmission(type, latitude: gpsPosition.lat, longitude: gpsPosition.lng, accuracy: gpsAccuracyMeters ?? 0, isGeofenceVerified: gpsStatus == EdenGpsStatus.high, notes: ...))` then show SnackBar success ('Checked in successfully' or 'Checked out successfully'). On error, show SnackBar 'Failed to check in/out: $e' with backgroundColor red.
