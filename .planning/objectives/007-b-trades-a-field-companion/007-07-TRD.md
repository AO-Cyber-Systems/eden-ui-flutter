<objective>
Ship `EdenMobileQuickAccessGrid` — an icon-tile launcher grid that companion-mode home screens (trades field-tech, medical home-visit nurse, fuel-truck driver, gov caseworker) compose as a "quick actions" panel under the dashboard greeting strip.

Internally:
1. Renders a `GridView.count` with `crossAxisCount` columns (default 3) + `childAspectRatio: 1.1` (donor parity).
2. Each tile is a tappable Container with icon + label, optionally bordered + label-tinted with `item.accent`.
3. Tap fires `onTap?.call(item.id)`.
4. When `reorderable: true`, swaps `GridView.count` → `ReorderableGridView`-like semantics (Flutter's `ReorderableListView` is list-only; for grid we use a hand-rolled long-press-Draggable + DragTarget pattern per existing scheduler patterns OR — simpler for v1 — emit `onReorder` from internal `LongPressDraggable` wrapping each tile + accept `DragTarget` per slot. See gotchas: full reorderable-grid is its own non-trivial Flutter problem; v1 ships the grid + tap; reorder support is the `reorderable: bool` opt-in with a clear "v1 limited drag-swap" semantic — see open question below).

**Per locked decision (this objective constraints rule 6 — no trades binding):** the donor `QuickAccessGrid` hardcodes 6 trades-specific items + a gold/red palette + `context.push('/field/...')` routes. The port:
- Removes hardcoded items (consumer supplies the list).
- Removes hardcoded palette (consumer supplies `accent` per item).
- Removes `go_router` dependency (consumer wires routing via the `onTap(id)` callback).
- Removes "Quick Access" hardcoded title (consumer supplies `title?`).

**Out of scope (deliberate):**
- Routing — `onTap(id)` is the boundary.
- Badge counts on tiles (defer; if needed, add `badgeCount: int?` to `EdenMobileQuickAccessItem` in a follow-up TRD).
- Disabled-tile state (defer).
- "Add new tile" affordance (defer).
- Persistent reorder (consumer owns persistence; library only emits `onReorder`).

<gotchas>
- **`ReorderableGridView` does not ship with Flutter core.** v1 reorder semantics: when `reorderable: true`, wrap each tile in `LongPressDraggable<int>(data: index, ...)` + `DragTarget<int>(onAcceptWithDetails: (d) => onReorder?.call(d.data, index), ...)`. This is "swap two tiles" semantics, NOT "drag to insert at arbitrary position." Document this v1 limitation in dartdoc. Acceptable per donor — donor doesn't ship reorder at all; this is a planned-forward additive.
- **Default `crossAxisCount: 3` + iPhone-narrow 390pt.** 390pt - default Padding(16) on parent = 358pt; minus 2 × crossAxisSpacing(12) = 334pt; ÷ 3 = 111.3pt per tile. With `childAspectRatio: 1.1`, tile height = 111.3 / 1.1 = ~101pt. That's a 28pt icon + 8pt gap + label = well within 101pt. No overflow expected; test asserts no `RenderFlex` overflow warning at 390pt.
- **`Theme.of(context).dividerColor` vs `colorScheme.outlineVariant`.** Donor uses `theme.dividerColor`. Material 3 prefers `colorScheme.outlineVariant`. Use `theme.dividerColor` for donor parity; the consumer's theme override would replace if needed.
- **InkWell inside Container with non-null color.** Material 3 ink ripples require an underlying `Material` ancestor (which `Scaffold` and `Card` provide). When this widget is dropped into a raw `Container` body (no Material ancestor), the ripple may not render. Per donor, wrap the InkWell's outer Container in a `Material(type: MaterialType.transparency)` if no `Card` ancestor is present. **Decision: do NOT wrap in Material** — the widget is designed to render inside `EdenCompanionShell` → `EdenRoleDashboardShell` → `Scaffold` which provides Material. Document this in dartdoc: "Must render under a Material ancestor (Scaffold, Card, etc.)."
- **`shrinkWrap: true` + `physics: NeverScrollableScrollPhysics()` are required defaults.** The grid is composed inside `ListView` (in dashboard sections), so it must NOT compete for scroll. Expose `physics` as optional override; default to `NeverScrollableScrollPhysics()`. Expose `shrinkWrap` as a constant `true` (no opt-out).
- **`accent` color is OPTIONAL.** When null, border = `theme.dividerColor` (width 1.0), label = `theme.colorScheme.onSurface`, icon = `theme.colorScheme.onSurfaceVariant`. When set, border = accent (width 1.5), label = accent, icon = accent. Preserve donor's "icon color matches accent" rule.
- **Existing 1041 tests must still pass.** This widget is additive; no edits to existing files except `lib/eden_ui.dart` (append) and `lib/dev_app/screens/home_screen.dart` (append). Both append-only — no risk to existing tests.
- **Resolver constraint `no_llm_test_data`:** all fixtures hand-built in `test/widgets/_fixtures/eden_mobile_quick_access_grid_fixtures.dart` — explicit static const lists per existing fixture pattern.
