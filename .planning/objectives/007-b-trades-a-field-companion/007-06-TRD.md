<objective>
Ship `EdenLocationMapPage` — a full-bleed map view with a paired list panel. Used by dispatch (trades), shift coordinators (medical home visits, fuel deliveries), supervisors tracking field caseworkers (gov).

```dart
EdenLocationMapPage(
  provider: context.read<EdenMapProvider>(),  // injected; library is provider-agnostic
  pins: [
    EdenLocationPin(
      id: 'tech-1',
      name: 'Mike T.',
      position: const EdenLatLng(37.7749, -122.4194),
      accuracyMeters: 12,
      batteryLevel: 78,
      lastSeenAt: DateTime.now().subtract(const Duration(minutes: 3)),
    ),
    EdenLocationPin(
      id: 'tech-2',
      name: 'Sarah K.',
      position: const EdenLatLng(37.7849, -122.4094),
      accuracyMeters: 8,
      batteryLevel: 92,
      lastSeenAt: DateTime.now().subtract(const Duration(seconds: 45)),
    ),
  ],
  onPinTapped: (id) => router.push('/dispatch/tech/$id'),
  onRefresh: () => myRepo.refreshLocations(),
  appBarTitle: 'Active Technicians',
);
```

The page renders:
1. AppBar with title (default 'Locations') + refresh `IconButton(Icons.refresh)` firing `onRefresh`.
2. **Top 3/5 — map area:** composes `EdenMapPreview(provider, bounds, markers, interactive: true)` where:
   - `bounds = EdenMapBounds.fromMarkers(markers)` (computed from pins).
   - `markers` derived from `pins`: each pin → `EdenMapMarker(id, position, color)`. (Marker visualization is provider-driven.)
   - When `provider is NoOpMapProvider`, EdenMapPreview gracefully renders its placeholder card (Wave A pattern).
3. **Bottom 2/5 — locations list panel:**
   - Header: 'Active Technicians' title (overridable via `listTitle`) + count pill ('${pins.length}').
   - Divider.
   - ListView of pin rows: `ListTile(dense: true, leading: CircleAvatar(initial), title: name, subtitle: Row[GPS dot indicator (color by accuracy) + '±${accuracy.round()}m · ${timeAgo}'], trailing: EdenBatteryIndicator(level) when batteryLevel != null)`.
4. Tap on a list row fires `onPinTapped(pin.id)`.
5. (When `provider` is a real map provider) tap on a map marker fires `onPinTapped` via the provider's `onMarkerTap` callback.

**Per locked decision (constraint 6 — no trades binding):** the donor `LocationMapPage`:
- Uses `flutter_riverpod` `ConsumerWidget` + `ref.watch(locationUpdatesProvider)` → port DROPS riverpod; pins come in via constructor.
- Imports `package:trades/features/field_crew/domain/location_update_model.dart` `LocationUpdate` value → port DEFINES `EdenLocationPin` value type here.
- Uses `package:trades/shared/widgets/battery_indicator.dart` `BatteryIndicator` → port DEFINES `EdenBatteryIndicator` inline as a small private helper widget (OR uses an existing eden_ui battery widget if one exists — verify).
- Uses `package:trades/shared/widgets/gps_status_indicator.dart` `GpsStatusIndicator` → port composes `EdenGpsStatusIndicator` (objective 002) in compact mode OR inlines a small dot+text widget.
- Uses `package:intl/intl.dart` `DateFormat.jm()` → port uses hand-rolled formatter (constraint 12).
- Has a placeholder `_MapPlaceholder` rendering simulated markers in fixed `Positioned` slots → port REMOVES this entirely; uses `EdenMapPreview` + provider abstraction instead.

**Pin clustering (v1 scope):** when `clusterPinsAbove: int?` is set, the page passes a CLUSTERED `markers` list to `EdenMapPreview` where pins within ~50pt screen-distance of each other become a single `EdenMapMarker(id: 'cluster-N', position: avg, color, label: 'N')`. v1 uses a simple O(n²) Euclidean check. Tap on a cluster marker fires `onClusterTapped(List<String> pinIds)` callback (separate from `onPinTapped`). Skipped when `clusterPinsAbove == null` (default).

**Out of scope (deliberate):**
- WebSocket/SSE live updates (consumer's job; refreshes via `onRefresh`).
- Routing / ETA computation.
- Real-time path tracing.
- Map style customization (provider's job).
- Marker icon customization beyond color (defer; consumer's `EdenMapProvider` impl owns marker visuals).
</objective>

<gotchas>
- **3:2 flex split.** Donor uses `Column[Expanded(flex: 3, child: map), Expanded(flex: 2, child: listPanel)]`. Preserve. Test that the map area renders at ~60% of the viewport height.
- **`EdenMapPreview` height vs Flex.** `EdenMapPreview` expects an explicit `height` OR an explicit `width`/`height` from parent constraints. Inside `Expanded`, it gets bounded constraints — pass `height: double.infinity` AND `width: double.infinity` and rely on the Expanded to size it. Verify by reading EdenMapPreview source if Expanded composition works.
- **`EdenMapBounds.fromMarkers(markers)` nullable.** Returns null when markers list is empty. Guard: when `pins.isEmpty`, render `EdenEmptyState` in the map area instead of `EdenMapPreview`, OR pass a default bounds (`EdenMapBounds(north: ..., south: ..., east: ..., west: ...)` — verify the API). **Decision: when pins empty, show `EdenEmptyState` in map area + 'No active locations' in list panel; do NOT mount EdenMapPreview at all.**
- **Cluster heuristic O(n²).** For pins.length > 100, the O(n²) check becomes a perf concern. Document v1 scope as "designed for <100 active pins"; beyond that, consumer should opt out of clustering OR pre-cluster server-side.
- **`onClusterTapped` vs `onPinTapped`.** When clustering is OFF, `onPinTapped` fires for marker tap. When clustering is ON and marker is a cluster, `onClusterTapped` fires; when marker is single, `onPinTapped` fires. Document.
- **iPhone-narrow 390pt list row overflow.** Long names (e.g., 'Christopher Marlborough') + 12pt subtitle + 14pt battery indicator at 390pt. Wrap title `Text` in `Expanded` + `overflow: TextOverflow.ellipsis`. Test with long fixture name.
- **`provider is NoOpMapProvider` check.** Acceptable; EdenMapPreview already handles this internally (placeholder card). Page doesn't need to special-case unless pins.isEmpty.
- **`onRefresh: null` handling.** When null, refresh IconButton is hidden (not just disabled). Donor always shows it; library hides when callback absent.
- **No `flutter_map`/`google_maps_flutter`/`geolocator` imports.** Constraint 4 + 12. ZERO concrete map SDK imports. All map work goes through `EdenMapProvider` interface.
- **Resolver constraints:** `no_llm_test_data`, `no_property_based_default`, `no_gherkin_layer`.
</gotchas>
