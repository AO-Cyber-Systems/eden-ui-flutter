<objective>
Ship `EdenReceiptPreview` — a configurable receipt rendering widget with 4 output modes (web / print / email / sms) for retail POS, trades invoice preview, salon ticket preview, fuel delivery receipt, restaurant check, and any structured-transaction receipt UX. Header → line items → tax/discount/promo breakdown → tender summary → footer.

Generic — knows nothing about retail. Consumer maps `sales`, `invoices`, `tickets`, `orders` rows to `EdenReceiptData`. Composes obj-012's `EdenLineItemEditor.readOnly` when available (or a private shim when obj-012 not yet shipped per OBJECTIVE.md §"Obj-012 dependency policy"). Composes existing `EdenCurrencyDisplay`.

Wave 1 of objective 014 — runs in parallel with 014-02 + 014-04. **Depends on 014-02 ONLY for `retail_screen.dart` file existence** — 014-02 creates it, this TRD APPENDS a Section. Wave-internal serialization handled by `co_modified_files` discipline.

Outside-in test approach: static rendering (web mode renders all 5 sections; line items render; tax/discount/promo breakdown renders; tender summary renders; footer renders) → mode switching (print 80mm / 58mm width; email column layout; sms text-only) → edge cases (zero line items; no discount; no promo; cash change due) → iPhone-narrow safety.
</objective>

**Design (locked):**

Receipt sections, top-to-bottom:
1. **Header** — `storeName` (bold, titleMedium), optional `address`, optional `phone`, optional `logoUrl` (renders via `EdenAuthenticatedImage` at 80x80pt centered).
2. **Line items** — table of (qty × name × unitPrice × subtotal). Composes `EdenLineItemEditor.readOnly` (obj-012) OR private `_ReadOnlyLineItemTable` shim.
3. **Breakdown** — Subtotal, optional Discount (negative, EdenColors.danger or theme equivalent), optional Promo (negative, EdenColors.success, with promo code label), Tax, Total (titleLarge, bold).
4. **Tender summary** — one row per `EdenReceiptTender` (cash / card / check / account / giftCard / other), each with amount. If `cashGiven > total`, final 'Change due' row.
5. **Footer** — optional `returnPolicy` + `taxId` + `thankYouMessage` (caption style, centered).

**Print-mode widths (POS thermal printer common widths):**
- `mm80` → 80mm = ~302pt at 96dpi (industry standard receipt printer).
- `mm58` → 58mm = ~219pt (compact handheld printer).

**Mode rendering rules:**
- **web** — scrollable single-column `ListView`. Full styling (colors, icons). Default mode for catalog/inline preview.
- **print** — constrained `ConstrainedBox(maxWidth: 302 OR 219)`. No interactives. Monochrome (grayscale theme). `pageBreakAfter` marker via empty `Container(key: ValueKey('eden-receipt-page-break-N'))` every ~120 vertical rows or after each major section — consumer's print platform handles actual paging.
- **email** — single-column `Column` (no scroll). HTML-friendly: no fixed widths, no custom paint. Email clients strip CSS so use plain Material widgets.
- **sms** — text-only flat layout, no images, no colors. Renders as `SelectableText` containing the receipt as plain text (multi-line, monospace) so the consumer can `clipboard.copy()` for SMS body. Header → line items → totals → footer in plain text.

**Obj-012 dependency strategy (per OBJECTIVE.md):**
1. Obj-012 widget composed: `EdenLineItemEditor` in `readOnly: true` configuration.

**`null` vs `0` semantics:**
- `discountCents: null` → row hidden.
- `discountCents: 0` → row hidden (no useful info).
- `promo: null` → row hidden.
- `taxCents: 0` → row visible (tax-free transactions still want the line for tax compliance signaling).

<gotchas>
- **Subtotal math is consumer responsibility.** This widget renders `data.subtotalCents` verbatim — it does NOT recompute as `sum(lineItems.subtotalCents)`. Reason: consumer may pre-aggregate, may apply rounding rules, may have multi-currency conversions upstream.
- **Discount/promo sign:** `discountCents` and `promo.amountCents` are stored as positive magnitudes; the widget prefixes a `'-'` when rendering. Test the rendering, not the stored sign.
- **Cash change due:** when `tender.method == cash && tender.cashGivenCents != null && tender.cashGivenCents > tender.amountCents`, render an additional 'Change due' row showing `cashGivenCents - amountCents`. Single-tender single cash-given assumption is acceptable for v1; split-tender cash-given is a v2 edge.
- **`EdenAuthenticatedImage` for logo:** if `logoUrl` is null OR fails to load, render no logo (no fallback icon — receipts look cleaner without).
- **SMS mode `SelectableText`:** must NOT be inside a `Row` or constrained-width container — needs `SelectableText.rich` for multi-line; or use plain `SelectableText` with `TextStyle(fontFamily: 'monospace')`.

**Static rendering — conditional rows**
- `discountCents: null` → no discount row.
- `discountCents: 0` → no discount row.
- `discountCents: 500` (positive int = $5.00 magnitude) → discount row visible with `-` prefix.
- `promo: null` → no promo row.
- `promo: EdenReceiptPromo(code: 'SUMMER10', amountCents: 1000)` → promo row visible with code label and `-` prefix.
- `footer: null` → no footer.
- `footer: EdenReceiptFooter(returnPolicy: '...', taxId: '...')` → footer renders both.

**Static rendering — tender variants**
- Single cash tender (no cashGiven) → one row, no change-due.
- Single cash tender with cashGivenCents > totalCents → row + 'Change due' row showing difference.
- Single card tender with last4 → renders 'Card **** 4242'.
- Split tender (cash + card) → 2 rows.

**Mode switching**
- `mode: EdenReceiptPreviewMode.print, printWidth: mm80` → constrained ConstrainedBox.maxWidth == 302pt (verify via `tester.getSize(find.byKey(ValueKey('eden-receipt-body')))`).
- `mode: EdenReceiptPreviewMode.print, printWidth: mm58` → constrained 219pt.
- `mode: EdenReceiptPreviewMode.email` → renders as Column (no ConstrainedBox wrapping at fixed width); flexible width.
- `mode: EdenReceiptPreviewMode.sms` → renders `SelectableText` containing plain-text receipt.

**SMS plain-text content**
- SMS mode SelectableText contains `'Espresso Single'`.
- SMS mode contains `'Total:'` substring.
- SMS mode contains `'Subtotal:'` substring.
- SMS mode does NOT contain colored markup (no Container with non-default decoration).

**Edge cases**
- Empty line items (`lineItems: []`) → no rows rendered, still shows header + breakdown + tender + footer.
- Zero total (`totalCents: 0`) — renders 'Total: $0.00'.
- Long product name 'Vanilla Hazelnut Latte Macchiato Extra Foam' → truncates with ellipsis in web mode at narrow width.

**iPhone-narrow safe (390pt)**
- `tester.binding.setSurfaceSize(Size(390, 800))` + web mode receipt → no `RenderFlex overflowed`.

class _TenderSection extends StatelessWidget {
  const _TenderSection({required this.tenders, required this.currency});
  final List<EdenReceiptTender> tenders;
  final String currency;

  String _methodLabel(EdenReceiptTender t) {
    switch (t.method) {
      case EdenReceiptTenderMethod.cash:    return 'Cash';
      case EdenReceiptTenderMethod.card:    return t.last4 != null ? 'Card **** ${t.last4}' : 'Card';
      case EdenReceiptTenderMethod.check:   return 'Check';
      case EdenReceiptTenderMethod.account: return 'Account';
      case EdenReceiptTenderMethod.giftCard:return 'Gift card';
      case EdenReceiptTenderMethod.other:   return 'Other';
    }
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        for (final t in tenders) ...[
          _BreakdownRow(label: _methodLabel(t), cents: t.amountCents, currency: currency),
          if (t.method == EdenReceiptTenderMethod.cash
              && t.cashGivenCents != null
              && t.cashGivenCents! > t.amountCents)
            _BreakdownRow(label: 'Change due', cents: t.cashGivenCents! - t.amountCents, currency: currency),
        ],
      ],
    );
  }
}

class _SmsBody extends StatelessWidget {
  const _SmsBody({required this.data});
  final EdenReceiptData data;

  String _fmt(int cents, String currency) {
    final sign = cents < 0 ? '-' : '';
    final abs = cents.abs();
    final dollars = abs ~/ 100;
    final centsRem = abs % 100;
    final symbol = currency == 'USD' ? '\$' : '$currency ';
    return '$sign$symbol$dollars.${centsRem.toString().padLeft(2, '0')}';
  }

  String _render() {
    final buf = StringBuffer();
    buf.writeln(data.storeHeader.storeName);
    if (data.storeHeader.address != null) buf.writeln(data.storeHeader.address);
    if (data.storeHeader.phone != null) buf.writeln(data.storeHeader.phone);
    buf.writeln('-' * 32);
    for (final li in data.lineItems) {
      buf.writeln('${li.qty}x ${li.name}');
      buf.writeln('   ${_fmt(li.subtotalCents, data.currency)}');
    }
    buf.writeln('-' * 32);
    buf.writeln('Subtotal: ${_fmt(data.subtotalCents, data.currency)}');
    if (data.discountCents != null && data.discountCents! > 0) {
      buf.writeln('Discount: ${_fmt(-data.discountCents!, data.currency)}');
    }
    if (data.promo != null) {
      buf.writeln('Promo (${data.promo!.code}): ${_fmt(-data.promo!.amountCents, data.currency)}');
    }
    buf.writeln('Tax: ${_fmt(data.taxCents, data.currency)}');
    buf.writeln('Total: ${_fmt(data.totalCents, data.currency)}');
    return buf.toString();
  }

  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.all(EdenSpacing.space3),
      child: SelectableText(
        _render(),
        style: const TextStyle(fontFamily: 'monospace'),
      ),
    );
  }
}
