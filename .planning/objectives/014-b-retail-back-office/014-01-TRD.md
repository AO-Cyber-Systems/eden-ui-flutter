<objective>
Ship `EdenPOSRegisterScaffold` — **the headline missing surface** for retail vertical: full POS register (web + iPad-native) with 3-zone layout (quick-add grid · cart · tender), customer-attach affordance, receipt slide-out, and PCI-aware card entry via obj-011 `EdenSecretField.classified`. Per locked decision B-R1 (coverage assessment §6 item 4): web + iPad/POS terminal native from v1. Responsive collapse to tabbed single-zone layout at <1024pt logical width.

Generic — knows nothing about retail. Consumer maps `sales`, `pos_sessions`, `customers`, `tenders` to `EdenPosSession`. Composes:
- 014-02 `EdenQuickAddProductGrid` for left zone (already shipped in Wave 1).
- 014-03 `EdenReceiptPreview` for the receipt slide-out drawer.
- obj-012 `EdenLineItemEditor` for cart center zone (or `_CartShim` fallback).
- obj-012 `EdenSplitTender` for right tender zone (or `_TenderShim` fallback).
- obj-001-06 `EdenMembershipTierBadge` for customer attached state.
- obj-011-08 `EdenSecretField.classified` for PAN entry inside tender zone (no hand-rolled card UI).
- existing `EdenBarcodeScanner` icon button trigger.
- existing `EdenSearchInput` for product search.

Wave 3 of objective 014 — final capstone. Depends on 014-02 (`EdenQuickAddProductGrid`) and 014-03 (`EdenReceiptPreview`). Plans against obj-012 TRD spec for line-item-editor + split-tender; uses shims when obj-012 not yet shipped (executor detects at TRD start).

Outside-in test approach: top-level zone layout (3-zone vs tabbed at width breakpoint) → wire each zone (left renders QuickAddProductGrid + search + scan icon; center renders cart shim or EdenLineItemEditor; right renders tender shim or EdenSplitTender) → customer attach (button → callback → mocked attach → badge rendered) → receipt slide-out (button → drawer opens with EdenReceiptPreview) → PCI compliance (PAN entry uses EdenSecretField.classified; no hand-rolled UI) → session event emission (productAdded fires on tile tap; tenderUpdated fires on tender change) → narrow-mode tabbed layout switching → touch-target compliance → iPhone-narrow safety.
</objective>

**Responsive logic:**
- `forceCompact: bool?` — explicit override; null = auto.
- `forceExpanded: bool?` — explicit override; null = auto.
- Auto: `constraints.maxWidth >= 1024 && EdenAdaptiveTierScope.maybeOf(context) != EdenAdaptiveTier.compact` → expanded (3-zone). Otherwise tabbed.

**Touch targets ≥48pt on tablet:**
Apple HIG: 44pt minimum; POS recommends 48pt+ for thumb operation. Enforce via `SizedBox(width: ≥48, height: ≥48)` around all buttons + tiles. `EdenQuickAddProductGrid` already auto-derives to 4-col at narrow widths and tiles >48pt (Task 1 verified).

**Customer attach flow:**
- Top of CENTER zone: when `session.customer == null`, render `EdenButton('Attach customer', onPressed: onAttachCustomerRequest)`.
- `onAttachCustomerRequest` is a callback; consumer opens their own customer-search modal and eventually calls the consumer-side state-update wiring.
- When `session.customer != null`, render `Row([EdenMembershipTierBadge(tier: customer.tier), Text(customer.name), IconButton(close)])`. Tapping close detaches.

**Receipt slide-out:**
- Right-edge `Drawer` controlled by `Scaffold.endDrawer` OR a custom slide-out (since we may already be inside a Scaffold). Decision: use a `Stack` + `Positioned` slide-out with `AnimatedPositioned`.
- A trigger button at the bottom of the right TENDER zone: `EdenButton('Show receipt')`. Fires `onShowReceipt: () { setState(() => _receiptOpen = true); }`.
- Drawer renders `EdenReceiptPreview` (014-03) with `EdenReceiptData` derived from current session.

**Obj-012 dependency strategy (per OBJECTIVE.md):**
1. Obj-012 widgets composed: `EdenLineItemEditor` (cart) + `EdenSplitTender` (tender).
2. Expected APIs per VERTICAL_WIREFRAMES_VALIDATION_2026-05-17.md §5 Obj-012 proposal TRD-01 + TRD-04.
3. **Behavioural shims:**
   - `_CartShim` — private `StatelessWidget` rendering `ListView.builder` of `Row(SKU, name, qty stepper, unit price, subtotal, remove icon)`; onQtyChanged + onRemove callbacks.
   - `_TenderShim` — private `StatefulWidget` rendering tender method picker + amount input + (for card) PAN entry via `EdenSecretField.classified` + change calc; emits `EdenPosTenderState`.
4. **Detection rule:** executor reads `lib/src/widgets/eden_line_item_editor.dart` + `lib/src/widgets/eden_split_tender.dart` at TRD start. Present → import + compose. Absent → use shim + add `TODO(obj-014→obj-012 swap):` markers.

**PCI compliance (locked):**
- Card-number entry MUST use `EdenSecretField` in `EdenSecretClipboardMode.classified` mode (shipped via obj-011-08).
- Widget MUST NOT contain any hand-rolled text field for PAN; verified by grep at the end (no `TextField` or raw `EdenInput` for card data).
- `panClassified` field in `EdenPosTenderState` is captured but should NOT be displayed back to the user — it's an opaque pass-through to the payment processor.

**Theme:** uses `Theme.of(context)` only — automatically respects `EdenThemeProfile.retailVibrant` when consumer wraps in `EdenAdaptiveTheme(profile: retailVibrant, ...)`.

**No backend bind:** no Stripe / Square / Toast / Shopify imports. `onSessionEvent` callback emits events; consumer's app dispatches to backend. `onShowReceipt` → consumer manages receipt-print plugin.

```dart
import 'package:flutter/material.dart';

import '../tokens/spacing.dart';
import 'eden_adaptive_layout.dart';
import 'eden_barcode_scanner.dart';
import 'eden_button.dart';

import 'eden_search_input.dart';
import 'eden_secret_field.dart';

// Value classes (see <context>) — define all at the top.

class EdenPOSRegisterScaffold extends StatefulWidget {
  const EdenPOSRegisterScaffold({
    super.key,
    required this.session,
    required this.products,
    this.categories,
    this.onSessionEvent,
    this.onAttachCustomerRequest,
    this.onBarcodeScanRequest,
    this.forceCompact,
    this.forceExpanded,
    this.animationDuration = const Duration(milliseconds: 200),
  });

  final EdenPosSession session;
  final List<EdenQuickAddProduct> products;
  final List<EdenQuickAddCategory>? categories;
  final void Function(EdenPosSessionEvent event)? onSessionEvent;
  final VoidCallback? onAttachCustomerRequest;
  final Future<String?> Function()? onBarcodeScanRequest;
  final bool? forceCompact;
  final bool? forceExpanded;
  final Duration animationDuration;

  @override
  State<EdenPOSRegisterScaffold> createState() => _EdenPOSRegisterScaffoldState();
}

class _EdenPOSRegisterScaffoldState extends State<EdenPOSRegisterScaffold> {
  bool _receiptOpen = false;
  String? _selectedCategoryId;
  String _searchQuery = '';

  bool _resolveExpanded(BuildContext context, double maxWidth) {
    if (widget.forceCompact == true) return false;
    if (widget.forceExpanded == true) return true;
    final tier = EdenAdaptiveTierScope.maybeOf(context);
    if (tier == EdenAdaptiveTier.compact) return false;
    return maxWidth >= 1024;
  }

  void _emit(EdenPosSessionEvent ev) {
    final cb = widget.onSessionEvent;
    if (cb != null) cb(ev);
  }

  EdenReceiptData _deriveReceiptData() {
    final subtotal = widget.session.cartItems.fold<int>(0, (s, i) => s + i.subtotalCents);
    final tax = 0; // consumer-derived in practice; this is a preview-only widget
    final tenders = <EdenReceiptTender>[];
    if (widget.session.tenderState != null) {
      final t = widget.session.tenderState!;
      tenders.add(EdenReceiptTender(
        method: _toReceiptTender(t.method),
        amountCents: t.amountCents,
        cashGivenCents: t.cashGivenCents,
        last4: t.last4,
      ));
    }
    return EdenReceiptData(
      storeHeader: const EdenReceiptStoreHeader(storeName: 'POS preview'),
      lineItems: [
        for (final c in widget.session.cartItems)
          EdenReceiptLineItem(name: c.name, qty: c.qty, unitPriceCents: c.unitPriceCents, sku: c.sku),
      ],
      subtotalCents: subtotal,
      taxCents: tax,
      totalCents: subtotal + tax,
      tenderSummary: tenders,
      currency: widget.session.currency,
    );
  }

  EdenReceiptTenderMethod _toReceiptTender(EdenPosTenderMethod m) {
    switch (m) {
      case EdenPosTenderMethod.cash:     return EdenReceiptTenderMethod.cash;
```
