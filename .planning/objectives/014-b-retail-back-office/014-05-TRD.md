<objective>
Ship `EdenReceivingFlow` — multi-step PO receiving flow primitive for retail back-office (incoming shipment intake, variance flagging, cost-update workflow). 4 sequential steps: select PO → variance reconciliation → cost update → disposition (partial / full / damaged). Cross-vertical: trades materials receiving, salon product replenishment, fuel parts receiving.

Generic — knows nothing about retail. Consumer maps `purchase_orders` + `po_line_items` + `received_shipments` to `EdenReceivingDoc` + emits a generic `EdenReceivingDraft` for the consumer to persist. Composes obj-012 `EdenLineItemEditor` where available (or private shims per Obj-012 dependency policy in OBJECTIVE.md). Photo capture is a callback (`onPhotoCapture`); consumer wires camera plugin.

Wave 2 of objective 014 — runs in parallel with 014-06. Depends on 014-03 ONLY because both share the obj-012 dependency policy + the `_ReadOnlyLineItemTable` shim pattern (which 014-03 establishes). If executor finds the shim already defined in `eden_receipt_preview.dart` as a private class, this TRD imports + reuses it. If not (e.g., shim was inlined or removed), this TRD defines its own private shim.

Outside-in test approach: state machine (step 1 → step 2 → step 3 → step 4 → onSubmit) → step 1 SelectPo (search input, scan input, lookup callback) → step 2 Variance (expected vs received display, variance reason picker only when qty mismatch) → step 3 CostUpdate (cost input only for varianced rows) → step 4 Disposition (3 radio options, photo callback when damaged) → narrow responsive (split-pane → tabbed) → submission emits correct draft.
</objective>

<context>
**Design (locked):**

Multi-step wizard pattern. Single `EdenReceivingFlow` widget owns the 4-step state machine. Consumer sees a top-level widget + receives final `EdenReceivingDraft` on `onSubmit`.

**State machine:**
- Initial state: `step = EdenReceivingStep.selectPo`, `_doc: EdenReceivingDoc? = null`.
- User types in search OR scans barcode → `onPoLookup(query)` fires. Consumer returns a `Future<EdenReceivingDoc?>`. On success, widget sets `_doc = result` and transitions to `step = EdenReceivingStep.variance`.
- On variance step: user adjusts received quantities + picks variance reasons for mismatches. Internal map `_received: Map<String, EdenReceivingReceivedItem>`.
- 'Next' → cost update step (only shown if at least one variance reason set; else skip to disposition).
- On cost update step: user enters new unit costs (optional). Updates internal map.
- 'Next' → disposition step.
- On disposition step: user picks one of 3 options. If `damaged`, photo capture button required.
- 'Submit' → `onSubmit(EdenReceivingDraft)`.

**Step 1 — SelectPo:**
- `EdenSearchInput` for typed PO number lookup.
- Icon button for barcode scan (composes `EdenBarcodeScanner` if exported as a discrete widget, OR delegates via callback `onBarcodeScan: () async => String?`).
- Lookup is a callback: `Future<EdenReceivingDoc?> onPoLookup(String query)`. Consumer hits their own backend.

**Step 2 — Variance:**
- Split-pane (≥700pt): LEFT = read-only expected items (composes shim/EdenLineItemEditor.readOnly), RIGHT = editable received items (qty input + variance reason picker only when received != expected).
- Tabbed (<700pt): tab strip "Expected" | "Received".

**Step 3 — CostUpdate:**
- Lists only the lines with `varianceReason != null` (typically `damaged` or `wrongItem` → may have different unit cost).
- For each, an optional `EdenInput` for new unit cost. Empty input = unchanged cost.

**Step 4 — Disposition:**
- `RadioListTile<EdenReceivingDisposition>` × 3.
- When `damaged` selected: shows an "Attach photo" button wired to `onPhotoCapture` callback. Stores returned `photoRef` in draft.
- 'Submit' button enabled only when disposition is selected (and photo attached if damaged).

**Shim reuse from 014-03:**
The `_ReadOnlyLineItemTable` shim from 014-03 is a private class — not importable across files. This TRD defines a local private shim of the same name in `eden_receiving_flow.dart`. If obj-012 lands later, swap both TRDs' shims to `EdenLineItemEditor` in a single follow-up commit.

**Photo capture callback:**
`onPhotoCapture: Future<String?> Function()?` — consumer wires their camera plugin and returns the captured image's signed-URL or local path. `null` return = user cancelled. Widget renders no photo UI; just calls the callback.

class _State {
  EdenReceivingStep _step = EdenReceivingStep.selectPo;
  EdenReceivingDoc? _doc;
  final Map<String, EdenReceivingReceivedItem> _received = {};
  EdenReceivingDisposition? _disposition;
  String? _damagedPhotoRef;

  void _nextStep() {
    setState(() {
      switch (_step) {
        case EdenReceivingStep.selectPo:
          _step = EdenReceivingStep.variance;
          break;
        case EdenReceivingStep.variance:
          final hasVariance = _received.values.any((r) => r.varianceReason != null);
          _step = hasVariance ? EdenReceivingStep.costUpdate : EdenReceivingStep.disposition;
          break;
        case EdenReceivingStep.costUpdate:
          _step = EdenReceivingStep.disposition;
          break;
        case EdenReceivingStep.disposition:
          break; // terminal; Submit handler manages
      }
    });
  }
}

Widget _buildCostUpdate() {
  final variancedLines = _doc!.expectedItems.where((e) {
    return _received[e.lineId]?.varianceReason != null;
  }).toList();
  return Column(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Text('Step 3 of 4 — Cost adjustments', style: Theme.of(context).textTheme.titleMedium),
      const SizedBox(height: 12),
      for (final e in variancedLines)
        Padding(
          padding: const EdgeInsets.symmetric(vertical: 4),
          child: Row(
            children: [
              Expanded(child: Text('${e.sku} — ${e.name}')),
              const SizedBox(width: 8),
              Text('Was: ${(e.expectedUnitCostCents / 100).toStringAsFixed(2)}'),
              const SizedBox(width: 12),
              SizedBox(
                width: 100,
                child: EdenInput(
                  decoration: const InputDecoration(hintText: 'New cost'),
                  keyboardType: const TextInputType.numberWithOptions(decimal: true),
                  onChanged: (v) {
                    final newCost = double.tryParse(v);
                    if (newCost != null) {
                      setState(() {
                        final existing = _received[e.lineId]!;
                        _received[e.lineId] = EdenReceivingReceivedItem(
                          lineId: existing.lineId,
                          receivedQty: existing.receivedQty,
                          varianceReason: existing.varianceReason,
                          newUnitCostCents: (newCost * 100).round(),
                          photoRef: existing.photoRef,
                        );
                      });
                    }
                  },
                ),
              ),
            ],
          ),
        ),
      const Spacer(),
      _stepNav(),
    ],
  );
}

Widget _buildDisposition() {
  return Column(

          child: Row(
            children: [
              ElevatedButton.icon(
                icon: const Icon(Icons.photo_camera_outlined),
                label: Text(_damagedPhotoRef == null ? 'Attach photo' : 'Photo attached'),
                onPressed: widget.onPhotoCapture == null ? null : () async {
                  final ref = await widget.onPhotoCapture!();
                  setState(() => _damagedPhotoRef = ref);
                },
              ),
            ],
          ),
        ),
      const Spacer(),
      Row(
        children: [
          OutlinedButton(onPressed: _back, child: const Text('Back')),
          const SizedBox(width: 12),
          ElevatedButton(
            onPressed: _canSubmit() ? _submit : null,
            child: const Text('Submit'),
          ),
        ],
      ),
    ],
  );
}

String _dispositionLabel(EdenReceivingDisposition d) {
  switch (d) {
    case EdenReceivingDisposition.receivePartial: return 'Receive partial';
    case EdenReceivingDisposition.receiveFull:    return 'Receive full';
    case EdenReceivingDisposition.damaged:        return 'Damaged';
  }
}

bool _canSubmit() {
  if (_disposition == null) return false;
  if (_disposition == EdenReceivingDisposition.damaged && _damagedPhotoRef == null) return false;
  return true;
}

void _submit() {
  if (!_canSubmit()) return;
  widget.onSubmit(EdenReceivingDraft(
    poNumber: _doc!.poNumber,
    disposition: _disposition!,
    receivedItems: _received.values.toList(),
    damagedPhotoRef: _damagedPhotoRef,
  ));
}
