<objective>
Ship `EdenSalesAnalyticsScaffold` — composite analytics shell for retail sales dashboards, owner laptop view. Header KPI strip + trend chart + top-products ranked list + top-categories chart + date-range filter. Cross-vertical: trades / fuel / salon / medical analytics scaffolds. Owner-mode pattern is identical across verticals.

Generic — knows nothing about retail. Consumer maps domain metrics (`sales` aggregates, `appointments` aggregates, `deliveries` aggregates, etc.) to `EdenSalesAnalyticsData`. Composes obj-012's `EdenAggregateKpiStrip` and `EdenDonutChart` when available (or shim fallbacks). Composes already-shipped `EdenBarChart` + `EdenSparkline` (in `lib/src/widgets/eden_chart.dart`) and `EdenQuickDateRange`.

Wave 2 of objective 014 — runs in parallel with 014-05. **No internal dependencies on other 014 TRDs.** Has obj-012 dependency on EdenAggregateKpiStrip + EdenDonutChart — uses behavioural shim per OBJECTIVE.md §"Obj-012 dependency policy".

Outside-in test approach: static rendering of all 5 sections (date-range header + KPI strip + trend chart + top products + top categories) → date-range change interaction (callback fires) → chart-type switching (bar / line / sparkline) → responsive (2-col → 1-col at narrow widths) → edge cases (empty kpis, empty trend, empty top-products) → iPhone-narrow safety.
</objective>

<context>
**Design (locked):**

Composite analytics shell with 5 sections, top-to-bottom:
1. **Header — date range picker** (composes `EdenQuickDateRange` — already shipped).
2. **KPI strip** — 3-7 KPIs in a horizontal scroll Row (or Wrap on narrow).
3. **Trend chart** — bar OR line OR sparkline of a primary metric over time.
4. **Top products** — ranked list (rank · name · units · revenue · trend arrow).
5. **Top categories** — donut chart (or horizontal bar fallback) breakdown.

**Trend chart:**
- `bar` → composes `EdenBarChart` (already shipped in `eden_chart.dart`). Single series, labels from `trendSeries[i].label`.
- `line` → composes `EdenLineChart` (already shipped). Single series.
- `sparkline` → composes `EdenSparkline` (already shipped). Just values, no labels.

Default: `bar`. Consumer can override via `trendChartType` parameter.

**Top products:**
Plain `Column` of `_TopProductRow` widgets. Each row:
- Rank gutter (24pt, monospace, theme.colorScheme.primary).
- Product name (Expanded, ellipsis).
- Units sold ('42 sold' label).
- Revenue (EdenCurrencyDisplay).
- Trend arrow (Icons.arrow_upward / arrow_downward / horizontal_rule with semantic color).

Note: this NOT a generic `EdenRankedList` widget — that's a future v2 promotion. For 014, the inline composition is sufficient.

**Top categories — obj-012 dependency:**
- If `EdenDonutChart` exists: import + pass `data.topCategories` mapped to chart's expected format.
- Else: private `_CategoryBarChartShim` — horizontal bar list, one row per category, with bar fill proportional to `slice.value / max(allValues)`. Uses simple `LinearProgressIndicator` per row.

**Responsive layout:**
- `≥1024pt` → 2-column `Row`: left column (KPIs + trend chart), right column (top products + top categories), 60/40 split.
- `<1024pt` → single-column stacked.

**No retail-specific binding:**
A trades app's analytics dashboard uses identical scaffold with different KPIs (jobs completed / revenue / avg ticket / first-time-customer rate). Fuel delivery: deliveries / gallons / route efficiency. Salon: bookings / chair utilization / repeat-visit rate. All generic.

**Display vs data:**
Widget renders pre-formatted `valueText` for KPIs — consumer formats `'$12,438'` or `'142 transactions'` themselves. Avoids locale + currency formatting concerns in the widget.

class _TopProductRow extends StatelessWidget {
  const _TopProductRow({required this.row, required this.currency});
  final EdenAnalyticsTopProductRow row;
  final String currency;

  IconData _trendIcon() {
    switch (row.trend) {
      case 'up':   return Icons.arrow_upward;
      case 'down': return Icons.arrow_downward;
      default:     return Icons.horizontal_rule;
    }
  }
  Color? _trendColor(BuildContext context) {
    switch (row.trend) {
      case 'up':   return Colors.green.shade700;
      case 'down': return Colors.red.shade700;
      default:     return Theme.of(context).colorScheme.onSurfaceVariant;
    }
  }

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    return Padding(
      padding: const EdgeInsets.symmetric(vertical: 4),
      child: Row(
        children: [
          SizedBox(width: 24, child: Text(row.rank.toString(), style: theme.textTheme.labelMedium?.copyWith(color: theme.colorScheme.primary, fontWeight: FontWeight.bold))),
          Expanded(child: Text(row.name, maxLines: 1, overflow: TextOverflow.ellipsis)),
          SizedBox(width: 80, child: Text('${row.unitsSold} sold', textAlign: TextAlign.right, style: theme.textTheme.labelSmall)),
          const SizedBox(width: 8),
          EdenCurrencyDisplay(centsMinor: row.revenueCents, currency: currency),
          const SizedBox(width: 8),
          Icon(_trendIcon(), size: 16, color: _trendColor(context)),
        ],
      ),
    );
  }
}
