<objective>
Ship `EdenQuickAddProductGrid` — a touch-friendly product tile grid for retail POS quick-add, trades quick-quote parts picker, fuel parts grid, salon retail front-counter. Each tile shows photo + name + price + optional stock level. Tap-to-add fires onTap; long-press-drag wraps the tile in `LongPressDraggable<EdenQuickAddProduct>` for drag-to-cart UX.

Generic — the widget knows nothing about retail. Consumer maps domain entities (`products`, `parts`, `services`, etc.) to `EdenQuickAddProduct` value class. Composes existing primitives: `EdenAuthenticatedImage` (obj 001-07), `EdenStockLevelIndicator` (obj 003-04), `EdenCurrencyDisplay` (obj 001-04), `EdenCard`, `EdenEmptyState`.

Wave 1 of objective 014 — runs in parallel with 014-03 (`EdenReceiptPreview`) + 014-04 (`EdenInventoryRowEditor`). **This TRD bootstraps `lib/dev_app/screens/retail_screen.dart`** — it's the lowest-numbered TRD in Wave 1 so it creates the file; 014-03 + 014-04 + 014-05 + 014-06 + 014-01 each append a Section().

Outside-in test approach: static rendering (renders tiles, renders empty state, renders photo / name / price / stock, renders without optional fields) → interaction (tap fires onTap; long-press starts drag) → category filter behavior → responsive (crossAxisCount auto-derives by width) → iPhone-narrow safety.
</objective>

**Tile layout (lockedl, top-to-bottom inside an EdenCard):**
1. Photo (square aspect, fills tile width; EdenAuthenticatedImage with `signedUrl: photoUrl`; placeholder icon when null).
2. Stock indicator (small corner overlay top-right, only if `onHand != null` — uses `EdenStockLevelIndicator` thin variant).
3. Name (`maxLines: 2`, ellipsis, theme.textTheme.labelMedium).
4. Price (EdenCurrencyDisplay; bold; theme.textTheme.titleSmall).

**Generic — no retail domain binding:**
A trades app passes `EdenQuickAddProduct(id: 'part-123', name: 'PVC elbow', priceCents: 350, ...)` for parts catalog. A salon app passes service tiles. A retail POS passes inventory items. Library widget renders the same tiles.

**Responsive grid (crossAxisCount auto-derives):**
- < 600pt logical width: 4 cols (mobile / iPhone-narrow)
- 600 — 1024pt: 6 cols (iPad portrait / small tablet)
- ≥ 1024pt: 8 cols (iPad landscape / desktop)

Explicit `crossAxisCount: int?` override always wins. Internally uses `LayoutBuilder` to read constraints (NOT `MediaQuery.size.width` — works correctly inside nested layouts like the POS register's left zone).

**Touch target enforcement:**
At 4-col layout, 390pt width minus padding (~16pt) ÷ 4 = ~93pt per tile. With internal vertical stack (photo + 8pt + name + 4pt + price), total tile height ~140pt. Well above 48pt minimum.

**Long-press drag (drag-to-cart):**
Wrap each tile in `LongPressDraggable<EdenQuickAddProduct>(data: product, feedback: ..., child: tile, childWhenDragging: opacity-0.4 placeholder)`. Consumer wires a `DragTarget<EdenQuickAddProduct>` on the cart side. This widget does NOT contain a DragTarget — that's the consumer's POS register composition.

**Existing primitives composed:**
- `EdenAuthenticatedImage` (obj 001-07): `lib/src/widgets/eden_authenticated_image.dart` — handles signed-URL + auth header rotation + placeholder.
- `EdenStockLevelIndicator` (obj 003-04): `lib/src/widgets/eden_stock_level_indicator.dart` — linear bar with green/amber/red. Use `value: onHand / max(reorderPoint * 2, onHand + 1)` so reorder-point sits at amber threshold (50%).
- `EdenCurrencyDisplay` (obj 001-04): `lib/src/widgets/eden_currency_display.dart` — locale-aware.
- `EdenCard`: tile wrapper.
- `EdenEmptyState`: empty list fallback.

<anti_patterns>
- **Do NOT** use `MediaQuery.size.width` for crossAxisCount derivation — breaks when widget is in a constrained subtree (e.g., POS register's left zone gets 60% width, not full screen). Use `LayoutBuilder` constraints.

<gotchas>
- **Stock-level value normalization:** `onHand / (reorderPoint * 2)` is the formula. If `reorderPoint == null` OR `reorderPoint == 0`, fall back to `onHand > 0 ? 1.0 : 0.0` (binary in-stock / out-of-stock). Test the null path.
- **`null` photoUrl:** `EdenAuthenticatedImage` may not handle null gracefully. Wrap in `product.photoUrl != null ? EdenAuthenticatedImage(...) : _PlaceholderTileIcon()`.
- **Long-press drag conflicts with scroll on iOS:** `LongPressDraggable.delay: Duration(milliseconds: 200)` is the canonical delay. Shorter delays trigger drag on scroll-attempt; longer feels unresponsive.
- **GridView inside Column overflow:** Always wrap `GridView.builder` in `Expanded` when it's a child of `Column` — otherwise renders zero-height. In the dev catalog, wrap in `SizedBox(height: 400, ...)` for the demo.
- **Category chip strip narrow-screen wrap:** Use `Wrap(spacing: 8, runSpacing: 4, children: chips)` not `Row` — categories overflow at 390pt otherwise.
- **`LayoutBuilder` rebuilds on every constraint change:** harmless here (grid is cheap to rebuild) but document for future readers.
- **Test-pairing rule:** source file `lib/src/widgets/eden_quick_add_product_grid.dart` MUST have paired `test/widgets/eden_quick_add_product_grid_test.dart`. Enforced.

import 'package:flutter/material.dart';

import '../tokens/spacing.dart';
import 'eden_authenticated_image.dart';
import 'eden_card.dart';
import 'eden_currency_display.dart';
import 'eden_empty_state.dart';
import 'eden_stock_level_indicator.dart';

@immutable
class EdenQuickAddProduct {
  const EdenQuickAddProduct({
    required this.id,
    required this.name,
    required this.priceCents,
    this.currency = 'USD',
    this.photoUrl,
    this.onHand,
    this.reorderPoint,
    this.categoryId,
    this.sku,
  });
  final String id;
  final String name;
  final int priceCents;
  final String currency;
  final String? photoUrl;
  final int? onHand;
  final int? reorderPoint;
  final String? categoryId;
  final String? sku;
}

@immutable
class EdenQuickAddCategory {
  const EdenQuickAddCategory({required this.id, required this.label, this.icon});
  final String id;
  final String label;
  final IconData? icon;
}

class EdenQuickAddProductGrid extends StatelessWidget {
  const EdenQuickAddProductGrid({
    super.key,
    required this.products,
    this.onTap,
    this.crossAxisCount,
    this.categories,
    this.selectedCategoryId,
    this.onCategorySelected,
    this.emptyLabel = 'No products',
  });

  final List<EdenQuickAddProduct> products;
  final ValueChanged<EdenQuickAddProduct>? onTap;
  /// Explicit override; when null, auto-derives from LayoutBuilder constraints.
  final int? crossAxisCount;
  final List<EdenQuickAddCategory>? categories;
  final String? selectedCategoryId;
  final ValueChanged<String?>? onCategorySelected;
  final String emptyLabel;

  int _autoCols(double width) {
    if (width < 600) return 4;
    if (width < 1024) return 6;
    return 8;
  }

  @override
  Widget build(BuildContext context) {
    if (products.isEmpty) {
      return EdenEmptyState(title: emptyLabel);
    }
    final body = LayoutBuilder(
      builder: (context, constraints) {
        final cols = crossAxisCount ?? _autoCols(constraints.maxWidth);
        return GridView.builder(
          gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
            crossAxisCount: cols,
            childAspectRatio: 0.75,
            crossAxisSpacing: EdenSpacing.space2,
            mainAxisSpacing: EdenSpacing.space2,
          ),
          itemCount: products.length,
          itemBuilder: (ctx, i) {
            final p = products[i];
            final tile = _ProductTile(product: p, onTap: onTap);
            return LongPressDraggable<EdenQuickAddProduct>(
              data: p,
              delay: const Duration(milliseconds: 200),
              feedback: Material(
                elevation: 8,
                color: Colors.transparent,
                child: SizedBox(
                  width: constraints.maxWidth / cols,
                  child: _ProductTile(product: p, onTap: null),
                ),
              ),
              childWhenDragging: Opacity(opacity: 0.4, child: tile),
              child: tile,
            );
          },
        );
      },
    );
    if (categories == null || categories!.isEmpty) {
      return body;
    }
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Padding(
          padding: const EdgeInsets.symmetric(horizontal: EdenSpacing.space2, vertical: EdenSpacing.space2),
          child: Wrap(
            spacing: EdenSpacing.space2,
            runSpacing: EdenSpacing.space1,
            children: [
              for (final c in categories!)
                ChoiceChip(
                  label: Text(c.label),
                  selected: selectedCategoryId == c.id,
                  onSelected: onCategorySelected == null
                      ? null
                      : (sel) => onCategorySelected!(sel ? c.id : null),
                ),
            ],
          ),
        ),
        Expanded(child: body),
      ],
    );
  }
}

class _ProductTile extends StatelessWidget {
  const _ProductTile({required this.product, required this.onTap});
  final EdenQuickAddProduct product;
  final ValueChanged<EdenQuickAddProduct>? onTap;

  double? _stockRatio() {
    final h = product.onHand;
    if (h == null) return null;
    final rp = product.reorderPoint;
    if (rp == null || rp <= 0) return h > 0 ? 1.0 : 0.0;
    return (h / (rp * 2)).clamp(0.0, 1.0);
  }

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final ratio = _stockRatio();
    return EdenCard(
      child: InkWell(
        onTap: onTap == null ? null : () => onTap!(product),
        child: Padding(
          padding: const EdgeInsets.all(EdenSpacing.space1),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              AspectRatio(
                aspectRatio: 1,
                child: Stack(
                  children: [
                    Positioned.fill(
                      child: product.photoUrl != null
                          ? EdenAuthenticatedImage(signedUrl: product.photoUrl!, fit: BoxFit.cover)
                          : const _PlaceholderTileIcon(),
                    ),
                    if (ratio != null)
                      Positioned(
                        top: 4, right: 4, left: 4,
                        child: SizedBox(
                          height: 6,
                          child: EdenStockLevelIndicator(value: ratio),
                        ),
                      ),
                  ],
                ),
              ),
              const SizedBox(height: EdenSpacing.space1),
              Text(
                product.name,
                maxLines: 2,
                overflow: TextOverflow.ellipsis,
                style: theme.textTheme.labelMedium,
              ),
              const SizedBox(height: 2),
              EdenCurrencyDisplay(centsMinor: product.priceCents, currency: product.currency),
            ],
          ),
        ),
      ),
    );
  }
}

class _PlaceholderTileIcon extends StatelessWidget {
  const _PlaceholderTileIcon();
  @override
  Widget build(BuildContext context) {
    final cs = Theme.of(context).colorScheme;
    return Container(
      color: cs.surfaceContainerHighest,
      child: Center(
        child: Icon(Icons.image_outlined, size: 32, color: cs.onSurfaceVariant),
      ),
    );
  }
}
