<objective>
Ship `EdenInventoryRowEditor` — inline-edit row primitive for inventory lists. Each row presents SKU / name / cost / price / on-hand / reorder-point / location with editable toggles + bulk-select checkbox. Cross-vertical: retail back-office inventory, salon back-bar, trades truck stock, fuel parts inventory, medical supply ledger.

Generic — knows nothing about retail. Consumer maps `inventory_items`, `products`, `parts`, `supplies` rows to `EdenInventoryRowData`. Composes existing `EdenStockLevelIndicator` (obj 003-04) + `EdenCurrencyDisplay` (obj 001-04) + `EdenInput` for editable cells.

Wave 1 of objective 014 — runs in parallel with 014-02 + 014-03. **Depends on 014-02 ONLY for `retail_screen.dart` file existence** — appends a Section() at the 014-04 anchor.

Outside-in test approach: static rendering (read-only mode renders all columns; editable mode renders inputs; bulk-select checkbox renders) → interaction (input changes captured; onCommit fires with EdenInventoryRowDraft; onCancel reverts; bulk-select fires onSelectionChanged) → compact-mode auto-derivation (narrow constraint → 2-row layout) → edge cases (null cost / null price / null onHand) → iPhone-narrow safety.
</objective>

**Design (locked):**

A single row, not a table. Consumer composes many rows inside their own `ListView` / `Column` / `EdenDataTable` body. Pattern: a `RowEditor` widget is a leaf primitive; a `Table` widget composes many `RowEditor`s.

**Column layout (≥700pt logical width, expanded mode):**
| Col | Width | Content |
|---|---|---|
| Checkbox | 40pt | Bulk-select wired to selected: + onSelectionChanged |
| SKU | 100pt | Monospace text, read-only always (SKU is immutable in v1) |
| Name | Expanded | Text, read-only in v1 (rename is a separate workflow) |
| Cost | 80pt | EdenCurrencyDisplay (read-only) OR EdenInput (editable) |
| Price | 80pt | Same pattern as cost |
| OnHand | 60pt | Numeric text OR EdenInput |
| Reorder | 60pt | Numeric text OR EdenInput |
| Location | 100pt | Text OR EdenInput |
| Stock indicator | 40pt | EdenStockLevelIndicator (thin) when onHand + reorderPoint both non-null |
| Actions | 80pt | When editable: 'Save' button + 'Cancel' button. When read-only: edit-pencil icon button (consumer wires `onRequestEdit`). |

**Compact mode (<700pt OR explicit `compact: true` OR EdenAdaptiveTierScope.maybeOf == compact):**
Row 1: Checkbox · SKU · Name (flex) · Stock indicator · Actions
Row 2: Cost · Price · OnHand · Reorder · Location

Used at 390pt iPhone-narrow + iPad-portrait edge cases.

**Edit state machine:**
- Initial: read-only display.
- `editable: true` (consumer prop) OR consumer calls a future `onRequestEdit` callback → widget enters edit mode with inputs pre-populated.
- User edits inputs; widget tracks a local `_draft: EdenInventoryRowDraft`.
- 'Save' → `onCommit(_draft)`.
- 'Cancel' → reset `_draft`, exit edit mode (NO onCommit fires).

**Editable param vs internal state:**
For v1 simplicity: `editable: bool` is a parent-controlled prop. Parent toggles `editable: true` to start editing; widget commits via `onCommit` callback; parent toggles back to `editable: false` AND updates the row data with the new values. This is the "controlled component" pattern. Internal state is only the in-flight draft.

**Stock-level value normalization:**
- `onHand == null` → no indicator.
- `onHand != null && reorderPoint == null` → indicator shows binary (full if onHand > 0, empty otherwise).
- `onHand != null && reorderPoint != null` → indicator shows `onHand / (reorderPoint * 2)` clamped to [0, 1]. Reorder point sits at 50% (amber zone).

**Bulk-select:**
Checkbox wired purely as a prop + callback. Widget does NOT maintain a selection state. Consumer's table maintains a `Set<String> _selectedIds` and passes `selected: _selectedIds.contains(row.rowId)` + `onSelectionChanged: (id, sel) => setState(() => sel ? _selectedIds.add(id) : _selectedIds.remove(id))`.

**No new pubspec deps:** EdenInput already exists. Number-only inputs use `keyboardType: TextInputType.number` + `inputFormatters: [FilteringTextInputFormatter.digitsOnly]` from `flutter/services.dart`.

<anti_patterns>
- **Do NOT** maintain selected state inside the widget. Selection is a parent-owned prop (`selected: bool` + `onSelectionChanged`).
- **Do NOT** allow editing SKU or name in v1. SKU rename is a destructive operation; name rename is a separate workflow. Lock both as read-only.
- **Do NOT** validate cost/price/onHand/reorderPoint server-side rules in this widget. Widget is presentation-only. Validation lives in the consumer's onCommit handler.
- **Do NOT** use a `Form` widget — overkill for a single row. Direct `EdenInput` instances with `onChanged` callbacks suffice.
- **Do NOT** generate fixture inventory rows via LLM. Hand-built `EdenInventoryRowFixtures.coffeeBeans()`, `.tshirts()`, `.plumbingParts()`, etc.

<gotchas>
- **`int?` parsing from input text:** Use `int.tryParse(text)` — returns null if parse fails. Treat null as "unchanged" in draft.
- **Cents conversion:** cost / price are stored as `int? costCents` (e.g., 350 = $3.50). Editable input shows decimal string ($3.50) and converts back to cents on commit. Use a helper `_centsToDollarStr(int? cents) → '$3.50'` and `_dollarStrToCents(String s) → int?` (parses '3.50', '3.5', '0.5', etc.).
- **Number-only input keyboard:** `TextInputType.numberWithOptions(decimal: true)` for cost/price; `TextInputType.number` for onHand/reorderPoint integers.
- **`InputFormatter` for digit-only:** import `package:flutter/services.dart` for `FilteringTextInputFormatter`.
- **Bulk-select checkbox null callback:** when `onSelectionChanged: null`, render checkbox as disabled (gray) — Flutter's Checkbox handles this.
- **`EdenAdaptiveTierScope.maybeOf`:** safe even if `EdenAdaptiveLayout` ancestor absent — returns null.

class EdenInventoryRowEditor extends StatefulWidget {
  const EdenInventoryRowEditor({
    super.key,
    required this.data,
    this.editable = false,
    this.selected = false,
    this.onSelectionChanged,
    this.onCommit,
    this.onCancel,
    this.onRequestEdit,
    this.compact,
  });

  final EdenInventoryRowData data;
  final bool editable;
  final bool selected;
  final void Function(String rowId, bool selected)? onSelectionChanged;
  final void Function(EdenInventoryRowDraft draft)? onCommit;
  final VoidCallback? onCancel;
  final VoidCallback? onRequestEdit;
  /// Explicit override; when null, auto-derives from constraints + EdenAdaptiveTierScope.
  final bool? compact;

  @override
  State<EdenInventoryRowEditor> createState() => _EdenInventoryRowEditorState();
}

class _EdenInventoryRowEditorState extends State<EdenInventoryRowEditor> {
  late TextEditingController _costCtl;
  late TextEditingController _priceCtl;
  late TextEditingController _onHandCtl;
  late TextEditingController _reorderCtl;
  late TextEditingController _locationCtl;

  String _centsToStr(int? cents) =>
      cents == null ? '' : (cents / 100).toStringAsFixed(2);
  int? _strToCents(String s) {
    if (s.trim().isEmpty) return null;
    final v = double.tryParse(s);
    if (v == null) return null;
    return (v * 100).round();
  }

  @override
  void initState() {
    super.initState();
    _costCtl = TextEditingController(text: _centsToStr(widget.data.costCents));
    _priceCtl = TextEditingController(text: _centsToStr(widget.data.priceCents));
    _onHandCtl = TextEditingController(text: widget.data.onHand?.toString() ?? '');
    _reorderCtl = TextEditingController(text: widget.data.reorderPoint?.toString() ?? '');
    _locationCtl = TextEditingController(text: widget.data.location ?? '');
  }

  @override
  void dispose() {
    _costCtl.dispose();
    _priceCtl.dispose();
    _onHandCtl.dispose();
    _reorderCtl.dispose();
    _locationCtl.dispose();
    super.dispose();
  }

  EdenInventoryRowDraft _buildDraft() {
    final origCost = widget.data.costCents;
    final newCost = _strToCents(_costCtl.text);
    final origPrice = widget.data.priceCents;
    final newPrice = _strToCents(_priceCtl.text);
    final origOnHand = widget.data.onHand;
    final newOnHand = int.tryParse(_onHandCtl.text);
    final origReorder = widget.data.reorderPoint;
    final newReorder = int.tryParse(_reorderCtl.text);
    final origLocation = widget.data.location ?? '';
    final newLocation = _locationCtl.text;
    return EdenInventoryRowDraft(
      rowId: widget.data.rowId,
      costCents: newCost != origCost ? newCost : null,
      priceCents: newPrice != origPrice ? newPrice : null,
      onHand: newOnHand != origOnHand ? newOnHand : null,
      reorderPoint: newReorder != origReorder ? newReorder : null,
      location: newLocation != origLocation ? newLocation : null,
    );
  }

  double? _stockRatio() {
    final h = widget.data.onHand;
    if (h == null) return null;
    final rp = widget.data.reorderPoint;
    if (rp == null || rp <= 0) return h > 0 ? 1.0 : 0.0;
    return (h / (rp * 2)).clamp(0.0, 1.0);
  }

  bool _resolveCompact(BuildContext context, double maxWidth) {
    if (widget.compact != null) return widget.compact!;
    final tier = EdenAdaptiveTierScope.maybeOf(context);
    if (tier == EdenAdaptiveTier.compact) return true;
    return maxWidth < 700;
  }

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(
      builder: (context, constraints) {
        final isCompact = _resolveCompact(context, constraints.maxWidth);
        return isCompact ? _buildCompact(context) : _buildExpanded(context);
      },
    );
  }

  Widget _buildExpanded(BuildContext context) {
    final theme = Theme.of(context);
    final ratio = _stockRatio();
    return Padding(
      key: const ValueKey('eden-inventory-row-expanded'),
      padding: const EdgeInsets.symmetric(vertical: EdenSpacing.space1, horizontal: EdenSpacing.space2),
      child: Row(
        crossAxisAlignment: CrossAxisAlignment.center,
        children: [
          SizedBox(
            width: 40,
            child: Checkbox(
              value: widget.selected,
              onChanged: widget.onSelectionChanged == null
                  ? null
                  : (v) => widget.onSelectionChanged!(widget.data.rowId, v ?? false),
            ),
          ),
          SizedBox(width: 100, child: Text(widget.data.sku, style: const TextStyle(fontFamily: 'monospace'))),
          Expanded(child: Text(widget.data.name, maxLines: 1, overflow: TextOverflow.ellipsis)),
          SizedBox(width: 80, child: _costCell(theme)),
          SizedBox(width: 80, child: _priceCell(theme)),
          SizedBox(width: 60, child: _onHandCell(theme)),
          SizedBox(width: 60, child: _reorderCell(theme)),
          SizedBox(width: 100, child: _locationCell(theme)),
          if (ratio != null)
            SizedBox(width: 40, height: 6, child: EdenStockLevelIndicator(value: ratio)),
          _actionsCell(),
        ],
      ),
    );
  }

  Widget _buildCompact(BuildContext context) {
    final theme = Theme.of(context);
    final ratio = _stockRatio();
    return Padding(
      key: const ValueKey('eden-inventory-row-compact'),
      padding: const EdgeInsets.symmetric(vertical: EdenSpacing.space1, horizontal: EdenSpacing.space2),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Row(
            children: [
              SizedBox(
                width: 40,
                child: Checkbox(
                  value: widget.selected,
                  onChanged: widget.onSelectionChanged == null
                      ? null
                      : (v) => widget.onSelectionChanged!(widget.data.rowId, v ?? false),
                ),
              ),
              SizedBox(width: 80, child: Text(widget.data.sku, style: const TextStyle(fontFamily: 'monospace'), maxLines: 1, overflow: TextOverflow.ellipsis)),
              Expanded(child: Text(widget.data.name, maxLines: 1, overflow: TextOverflow.ellipsis)),
              if (ratio != null) SizedBox(width: 40, height: 6, child: EdenStockLevelIndicator(value: ratio)),
              _actionsCell(),
            ],
          ),
          const SizedBox(height: 4),
          Row(
            children: [
              Expanded(child: _costCell(theme)),
              const SizedBox(width: 8),
              Expanded(child: _priceCell(theme)),
              const SizedBox(width: 8),
              Expanded(child: _onHandCell(theme)),
              const SizedBox(width: 8),
              Expanded(child: _reorderCell(theme)),
              const SizedBox(width: 8),
              Expanded(child: _locationCell(theme)),
            ],
          ),
        ],
      ),
    );
  }

  Widget _costCell(ThemeData theme) {
    if (widget.editable) {
      return EdenInput(
        controller: _costCtl,
        keyboardType: const TextInputType.numberWithOptions(decimal: true),
        onChanged: (_) => setState(() {}),
      );
    }
    return widget.data.costCents == null
        ? const Text('—')
        : EdenCurrencyDisplay(centsMinor: widget.data.costCents!, currency: widget.data.currency);
  }
  Widget _priceCell(ThemeData theme) {
    if (widget.editable) {
      return EdenInput(
        controller: _priceCtl,
        keyboardType: const TextInputType.numberWithOptions(decimal: true),
        onChanged: (_) => setState(() {}),
      );
    }
    return widget.data.priceCents == null
        ? const Text('—')
        : EdenCurrencyDisplay(centsMinor: widget.data.priceCents!, currency: widget.data.currency);
  }
  Widget _onHandCell(ThemeData theme) {
    if (widget.editable) {
      return EdenInput(
        controller: _onHandCtl,
        keyboardType: TextInputType.number,
        inputFormatters: [FilteringTextInputFormatter.digitsOnly],
        onChanged: (_) => setState(() {}),
      );
    }
    return Text(widget.data.onHand?.toString() ?? '—');
  }
  Widget _reorderCell(ThemeData theme) {
    if (widget.editable) {
      return EdenInput(
        controller: _reorderCtl,
        keyboardType: TextInputType.number,
        inputFormatters: [FilteringTextInputFormatter.digitsOnly],

    }

        onChanged: (_) => setState(() {}),
      );
    }

  }

  Widget _actionsCell() {
    if (widget.editable) {
      return Row(
        mainAxisSize: MainAxisSize.min,
        children: [

            tooltip: 'Save',
            onPressed: widget.onCommit == null ? null : () => widget.onCommit!(_buildDraft()),
          ),
          IconButton(
            icon: const Icon(Icons.close),
            tooltip: 'Cancel',
            onPressed: widget.onCancel,
          ),
        ],
      );
    }
    return IconButton(
      icon: const Icon(Icons.edit_outlined),
      tooltip: 'Edit',
      onPressed: widget.onRequestEdit,

}

    return Column(

          ),
          child: Column(
            children: [
              for (final row in _rows) ...[
                EdenInventoryRowEditor(
                  data: row,
                  editable: _editingId == row.rowId,
                  selected: _selected.contains(row.rowId),
                  onSelectionChanged: (id, sel) => setState(() {
                    sel ? _selected.add(id) : _selected.remove(id);
                  }),
                  onRequestEdit: () => setState(() => _editingId = row.rowId),
                  onCommit: (d) {
                    setState(() => _editingId = null);
                    ScaffoldMessenger.of(context).showSnackBar(SnackBar(
                      content: Text('Committed: ${d.rowId} cost=${d.costCents} price=${d.priceCents} onHand=${d.onHand} reorder=${d.reorderPoint} loc=${d.location}'),
                    ));
                  },
                  onCancel: () => setState(() => _editingId = null),
                ),
                if (row != _rows.last) const Divider(height: 1),
              ],
            ],
          ),
        ),
      ],
    );
  }
}
