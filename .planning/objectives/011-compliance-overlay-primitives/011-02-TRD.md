<objective>
Ship `EdenCacPivButton` — the smartcard authentication affordance for federal apps requiring CAC (Common Access Card / DOD) or PIV (Personal Identity Verification / federal civilian) hardware credentials. Renders a state-machine-driven UI cycling through `idle → reading → promptPin → authenticating → (success/error)` with callbacks at each transition so the consumer can wire platform-channel calls to native smartcard reader APIs.

**Library scope: interface-only.** The library widget renders the UI + state machine. It does NOT include platform-channel code (iOS/Android smartcard reader Swift/Kotlin), per `PROJECT.md` "transport-agnostic + no new pubspec deps" constraints. Consumer apps wire `EdenCacPivController.transitionTo(...)` from their native code via callbacks.

Wave 2, parallel with 011-10 (MFA hardware token). Depends on 011-01 ONLY for `compliance_screen.dart` file existence (this TRD APPENDS a Section).

Outside-in: widget renders 5 distinct states; controller transitions trigger re-renders; callbacks fire at right transitions; a11y + iPhone-narrow checks.
</objective>

<anti_patterns>
- **Do NOT add `flutter_smart_card_reader` or any smartcard pubspec dep.** Library is interface-only.
- **Do NOT use platform channels in the widget itself.** No `MethodChannel('cac_piv')` invocations. Consumer wires.
- **Do NOT store the PIN in the widget state forever.** Clear it after `onPinSubmitted` fires. Don't log it. Don't include it in error messages.

<gotchas>
- **Controller lifecycle.** `EdenCacPivController` extends `ChangeNotifier`. Widget calls `controller.addListener(_onChange)` in initState, `removeListener` in dispose. Otherwise listeners leak. Test by pumping widget twice with same controller and asserting no `setState after dispose` error.
- **PIN clearing.** After `onPinSubmitted` fires, internal `_pinController.clear()` MUST run. If state transitions back to `promptPin` (e.g., user typed wrong PIN), the field starts empty. Test this.
- **Error state with retry.** `onRetry` callback should transition state back to `idle` (consumer-controlled). Default impl: widget's "Try again" button calls `widget.onRetry?.call()` AND `controller.reset()`. Document precedence.
- **Async PIN verification.** The widget does NOT verify the PIN — it only calls `onPinSubmitted(pin)`. The consumer's verification is async; consumer is responsible for transitioning state to `authenticating` then either success or `error`.
- **EdenSecretField inside promptPin state.** Wrap in a Column with the label above and Submit button below. SecretField doesn't expose a "submit" affordance — add a separate `ElevatedButton('Submit PIN')` next to it.

```dart
enum EdenCacPivState {
  idle,            // 'Insert your CAC/PIV card' + card icon
  reading,         // spinner + 'Reading card…'
  promptPin,       // PIN field + 'Enter PIN' + Submit button
  authenticating,  // spinner + 'Verifying credentials…'
  error,           // error icon + message + 'Try again' button
}

class EdenCacPivController extends ChangeNotifier {
  EdenCacPivState _state = EdenCacPivState.idle;
  String? _errorMessage;

  EdenCacPivState get state => _state;
  String? get errorMessage => _errorMessage;

  void transitionTo(EdenCacPivState s, {String? errorMessage}) {
    _state = s;
    _errorMessage = errorMessage;
    notifyListeners();
  }

  void reset() {
    _state = EdenCacPivState.idle;
    _errorMessage = null;
    notifyListeners();
  }
}

class EdenCacPivButton extends StatefulWidget {
  const EdenCacPivButton({
    super.key,
    required this.controller,
    this.onInsertRequested,
    this.onPinSubmitted,
    this.onAuthenticated,
    this.onRetry,
  });

  final EdenCacPivController controller;
  final VoidCallback? onInsertRequested;
  final ValueChanged<String>? onPinSubmitted;
  final VoidCallback? onAuthenticated;
  final VoidCallback? onRetry;
  ...
}
```

State→render mapping:
- `idle` → ElevatedButton with `Icons.credit_card` + Text 'Insert your CAC/PIV card'; tap fires `onInsertRequested`.
- `reading` → Row with `CircularProgressIndicator` + Text 'Reading card…'.
- `promptPin` → Column with Text 'Enter PIN' + EdenSecretField + ElevatedButton 'Submit PIN' that fires `onPinSubmitted` with current value and clears the field.
- `authenticating` → Row with `CircularProgressIndicator` + Text 'Verifying credentials…'.
- `error` → Column with `Icons.error_outline` + Text(errorMessage) + ElevatedButton 'Try again' that fires `onRetry` and calls `controller.reset()`.

Consumer-side flow (documented in dartdoc):
1. UI mounts in `idle` state. User taps button → `onInsertRequested` fires.
2. Consumer calls platform channel to start smartcard read → calls `controller.transitionTo(reading)`.
3. Platform reports success → consumer calls `controller.transitionTo(promptPin)`.
4. User enters PIN, taps Submit → `onPinSubmitted(pin)` fires + field clears.
5. Consumer calls platform channel to verify PIN → calls `controller.transitionTo(authenticating)`.
6. On success: consumer calls `onAuthenticated` (via controller — actually consumer just doesn't transition back; success ends the flow). The widget watches for `state == promptPin && next call == ...` — practically, when consumer transitions to a state NOT in this enum, widget renders nothing? Cleaner: emit `onAuthenticated` from widget when state transitions FROM `authenticating` TO any non-error state (or just: consumer calls `onAuthenticated` directly via their own callback).
   Final design: `onAuthenticated` is a callback the WIDGET fires when `transitionTo` is called with state OUTSIDE the enum — actually, simpler: consumer just calls their own success handler; widget doesn't fire `onAuthenticated`. **Drop `onAuthenticated` from widget API.** Consumer handles success themselves.

/// Smartcard authentication affordance (CAC for DOD / PIV for federal
/// civilian). Renders a 5-state UI cycling through idle → reading →
/// promptPin → authenticating → error.
///
/// **Library scope: interface-only.** This widget renders state + collects
/// PIN input. The consumer app wires native platform-channel calls to the
/// smartcard reader (iOS/Android/macOS) and drives state transitions via
/// [EdenCacPivController].
///
/// Consumer flow:
/// 1. User taps button in `idle` → [onInsertRequested] fires.
/// 2. Consumer calls native smartcard reader → on read, calls
///    `controller.transitionTo(promptPin)`.
/// 3. User enters PIN → [onPinSubmitted] fires with PIN string.
/// 4. Consumer verifies PIN → calls `controller.transitionTo(...)` to
///    indicate success (consumer-defined) or `(error, errorMessage: ...)`.
class EdenCacPivButton extends StatefulWidget {
  const EdenCacPivButton({
    super.key,
    required this.controller,
    this.onInsertRequested,
    this.onPinSubmitted,
    this.onRetry,
  });

  final EdenCacPivController controller;
  final VoidCallback? onInsertRequested;
  final ValueChanged<String>? onPinSubmitted;
  final VoidCallback? onRetry;

  @override
  State<EdenCacPivButton> createState() => _EdenCacPivButtonState();
}

class _EdenCacPivButtonState extends State<EdenCacPivButton> {
  String _pin = '';

  @override
  void initState() {
    super.initState();
    widget.controller.addListener(_onChange);
  }

  @override
  void didUpdateWidget(covariant EdenCacPivButton old) {
    super.didUpdateWidget(old);
    if (old.controller != widget.controller) {
      old.controller.removeListener(_onChange);
      widget.controller.addListener(_onChange);
    }
  }

  @override
  void dispose() {
    widget.controller.removeListener(_onChange);
    super.dispose();
  }

  void _onChange() {
    if (mounted) setState(() {});
  }

  void _submitPin() {
    final pin = _pin;
    setState(() => _pin = '');
    widget.onPinSubmitted?.call(pin);
  }

  void _retry() {
    widget.onRetry?.call();
    widget.controller.reset();
  }

  @override
  Widget build(BuildContext context) {
    final state = widget.controller.state;
    final semanticLabel = 'CAC/PIV smartcard authentication, ${state.name}';
    return Semantics(
      label: semanticLabel,
      container: true,
      child: switch (state) {
        EdenCacPivState.idle => ElevatedButton.icon(
            onPressed: widget.onInsertRequested,
            icon: const Icon(Icons.credit_card),
            label: const Text('Insert your CAC/PIV card'),
          ),
        EdenCacPivState.reading => const Row(
            mainAxisSize: MainAxisSize.min,
            children: [
              SizedBox(width: 16, height: 16, child: CircularProgressIndicator(strokeWidth: 2)),
              SizedBox(width: 8),
              Text('Reading card…'),
            ],
          ),
        EdenCacPivState.promptPin => Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            mainAxisSize: MainAxisSize.min,
            children: [
              const Text('Enter PIN'),
              const SizedBox(height: 8),
              EdenSecretField(
                value: _pin,
                label: 'CAC/PIV PIN entry',
                onChanged: (v) => setState(() => _pin = v),
              ),
              const SizedBox(height: 12),
              ElevatedButton(
                onPressed: _submitPin,
                child: const Text('Submit PIN'),
              ),
            ],
          ),
        EdenCacPivState.authenticating => const Row(
            mainAxisSize: MainAxisSize.min,
            children: [
              SizedBox(width: 16, height: 16, child: CircularProgressIndicator(strokeWidth: 2)),
              SizedBox(width: 8),
              Text('Verifying credentials…'),
            ],
          ),
        EdenCacPivState.error => Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            mainAxisSize: MainAxisSize.min,
            children: [
              Row(
                children: [
                  const Icon(Icons.error_outline, color: Colors.red),
                  const SizedBox(width: 8),
                  Flexible(
                    child: Text(widget.controller.errorMessage ?? 'Authentication failed'),
                  ),
                ],
              ),
              const SizedBox(height: 12),
              ElevatedButton(
                onPressed: _retry,
                child: const Text('Try again'),
              ),
            ],
          ),
      },
    );
  }
}

class _CacPivDemo extends StatefulWidget {
  const _CacPivDemo();
  @override
  State<_CacPivDemo> createState() => _CacPivDemoState();
}

class _CacPivDemoState extends State<_CacPivDemo> {
  final _controller = EdenCacPivController();

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  void _simulateFlow() async {
    _controller.transitionTo(EdenCacPivState.reading);
    await Future.delayed(const Duration(seconds: 1));
    if (!mounted) return;
    _controller.transitionTo(EdenCacPivState.promptPin);
  }

  void _simulatePinVerify(String pin) async {
    _controller.transitionTo(EdenCacPivState.authenticating);
    await Future.delayed(const Duration(seconds: 1));
    if (!mounted) return;
    if (pin == '123456') {
      _controller.reset(); // success → back to idle for demo loop
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Authenticated! (demo)')),
      );
    } else {
      _controller.transitionTo(
        EdenCacPivState.error,
        errorMessage: 'PIN verification failed. Demo accepts "123456".',
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        const Text('Interactive demo (PIN = "123456")', style: TextStyle(fontWeight: FontWeight.w600)),
        const SizedBox(height: 12),
        EdenCacPivButton(
          controller: _controller,
          onInsertRequested: _simulateFlow,
          onPinSubmitted: _simulatePinVerify,
        ),
      ],
    );
  }
}
