<objective>
Ship `EdenClassificationBanner` — the foundation federal-compliance UI primitive. Renders classification marking at the top (and optionally bottom) of a regulated app screen, per ICD 710 (Intelligence Community Directive 710) marking standard. Two display modes: bar (full-width top/bottom strip — the dominant federal pattern) and watermark (diagonal overlay for screen-capture-sensitive content). Backwards-compatible civilian re-use as `EdenSensitivityBanner` via typedef — same widget, federal palette swapped for custom colors/labels per locked decision C.

This is the FIRST Wave 1 TRD. It bootstraps the new `lib/dev_app/screens/compliance_screen.dart` dev catalog screen + the home_screen tile registration. Subsequent Wave 1-5 TRDs APPEND `Section(...)` entries to compliance_screen.dart but do not re-create the file or re-register on home_screen.

Outside-in test approach (per user TDD Playbook habit 5): start with widget-rendering system tests (banner visible at top of a screen scaffold; semantics-tree label inspect), then mode-switch tests (bar vs watermark), then level-palette tests (4 federal levels render their distinctive colors), then civilian-override tests (custom labelText + colors), then a11y + responsive tests.
</objective>

<gotchas>
- **ICD 710 actual hex values.** The federal classification color spec uses `#007A33` (CIA Heritage Green) for UNCLASSIFIED, `#502B85` (Purple) for CUI, `#C8102E` (Red) for SECRET, `#FF7F00` (Orange/Yellow) for TOP SECRET. These are research-confirmed (GSA CUI Guide + DOD Instruction 5200.48 cited in research doc). Do not pull from EdenColors — these are level-specific federal mandated values.
- **All-caps required.** Per ICD 710, classification labels MUST render all-uppercase. The widget uppercases the label text internally — even if consumer passes `'secret'`, render as `'SECRET'`. Test this.
- **Contrast gate.** SECRET red bg + white fg → 4.95:1 (passes). TOP SECRET orange bg + BLACK fg → 7.51:1 (passes — that's why TS uses black text on orange, not white). Verify by computing relative luminance in the test (or by visual inspection with screenshot — but stick with widget rendering test asserting fg color matches palette).
- **Watermark rotation in Flutter.** `Transform.rotate(angle: -math.pi / 4)` for -45°. Wrap in `IgnorePointer` so it doesn't eat taps on the underlying child.
- **Bar height per ICD 710.** Min 28pt height, 14pt font weight 700 (bold) — verify text-renderable at this size by computing `TextPainter` width vs banner width. Don't truncate the label; if width insufficient (e.g. on iPhone-narrow), shrink label vertical padding before ever truncating.
- **EdenClassificationBannerScaffold helper.** Wraps a `child` (any Widget) with a top bar + optional bottom bar. Mimics the Stack pattern used in trades-flutter's screen scaffolds. Useful when consumer wants `Scaffold(body: EdenClassificationBannerScaffold(level: ..., child: ...))`.

- **home_screen.dart registration is THIS TRD only.** Subtitle covers all compliance widgets so later TRDs don't need to edit it.
- **The `EdenSensitivityBanner` typedef goes in the SAME file** as `EdenClassificationBanner` — single export, single source of truth, just a different name surfaced for civilian-vertical consumers.
- **Test-pairing rule.** Source `lib/src/widgets/eden_classification_banner.dart` MUST have paired `test/widgets/eden_classification_banner_test.dart`. Enforced.

**Bar mode — civilian custom level**

**Watermark mode**
- `EdenClassificationBanner(level: secret, display: watermark, child: const Text('payload'))` renders a Stack with the child below and a `Transform.rotate`-wrapped Text at angle ~-π/4 (45°) and opacity ~0.16.
- Watermark mode does NOT block taps on the child (find an `IgnorePointer` ancestor of the watermark text).

**EdenClassificationBannerScaffold helper**
- `EdenClassificationBannerScaffold(level: secret, child: const Placeholder())` renders top banner + Placeholder + no bottom banner.
- `EdenClassificationBannerScaffold(level: secret, showBottomBanner: true, child: const Placeholder())` renders top banner + Placeholder + bottom banner (both with same level palette).

**Section 508 / a11y**
- Banner has `Semantics` ancestor with `label: 'UNCLASSIFIED classification banner'` (formatted as `{label} classification banner`).
- Semantics node is read-only (`readOnly: true` or no `enabled: true`); has `container: true` so screen readers announce as one unit.
- Color contrast for each level passes 4.5:1 minimum (assert via relative-luminance ratio computation in test):
  - UNCLASSIFIED green/white: ratio ≥ 4.5
  - CUI purple/white: ratio ≥ 4.5
  - SECRET red/white: ratio ≥ 4.5
  - TOP SECRET orange/black: ratio ≥ 4.5

**iPhone-narrow (390pt) safe**
- `SizedBox(width: 390, child: EdenClassificationBanner(level: topSecret))` renders with no `RenderFlex overflowed` warnings.
- Long custom label (`labelText: 'EXTREMELY LONG CLASSIFICATION LABEL THAT EXCEEDS NARROW VIEWPORT'`) at 390pt either shrinks via `FittedBox(BoxFit.scaleDown)` OR ellipsizes — assert no overflow exception via `expect(tester.takeException(), isNull)`.

```dart
import 'dart:math' as math;
import 'package:flutter/material.dart';

import '../tokens/spacing.dart';

/// Federal classification level per ICD 710 + custom civilian use.
enum EdenClassificationLevel {
  unclassified,
  controlledUnclassified,
  secret,
  topSecret,
  custom, // requires labelText + backgroundColor + foregroundColor
}

/// Banner display mode.
enum EdenClassificationDisplay {
  /// Full-width strip; dominant federal pattern.
  bar,
  /// Semi-transparent diagonal overlay for screen-capture-sensitive content.
  watermark,
}

/// Local palette stub for federal levels.
/// TODO(obj-009): move to `Theme.of(context).extension<EdenStatusPalette>()`
/// once `EdenThemeProfile.govFederal` ships.
const _classificationPalette = <EdenClassificationLevel, ({Color bg, Color fg})>{
  EdenClassificationLevel.unclassified:
      (bg: Color(0xFF007A33), fg: Color(0xFFFFFFFF)),
  EdenClassificationLevel.controlledUnclassified:
      (bg: Color(0xFF502B85), fg: Color(0xFFFFFFFF)),
  EdenClassificationLevel.secret:
      (bg: Color(0xFFC8102E), fg: Color(0xFFFFFFFF)),
  EdenClassificationLevel.topSecret:
      (bg: Color(0xFFFF7F00), fg: Color(0xFF000000)),
};

const _defaultLabels = <EdenClassificationLevel, String>{
  EdenClassificationLevel.unclassified: 'UNCLASSIFIED',
  EdenClassificationLevel.controlledUnclassified: 'CUI',
  EdenClassificationLevel.secret: 'SECRET',
  EdenClassificationLevel.topSecret: 'TOP SECRET',
};

/// A federal classification banner per ICD 710 (Intelligence Community
/// Directive 710). Renders the classification level at top (and optionally
/// bottom) of a regulated app screen.
///
/// Federal levels (UNCLASSIFIED / CUI / SECRET / TOP SECRET) come with
/// ICD 710 mandated colors. The [EdenClassificationLevel.custom] level
/// supports civilian re-use as a generic sensitivity banner: pass [labelText]
/// + [backgroundColor] + [foregroundColor] to render commercial sensitivity
/// labels (e.g., 'CONFIDENTIAL', 'INTERNAL USE ONLY', 'ATTORNEY-CLIENT
/// PRIVILEGED').
///
/// Civilian re-use: see [EdenSensitivityBanner] typedef — same widget, named
/// for commercial vertical readability.
class EdenClassificationBanner extends StatelessWidget {
  const EdenClassificationBanner({
    super.key,
    required this.level,
    this.display = EdenClassificationDisplay.bar,
    this.labelText,
    this.backgroundColor,
    this.foregroundColor,
    this.height = 28,
    this.child,
  });

  final EdenClassificationLevel level;
  final EdenClassificationDisplay display;
  final String? labelText;
  final Color? backgroundColor;
  final Color? foregroundColor;
  final double height;
  /// Required when [display] is [EdenClassificationDisplay.watermark].
  final Widget? child;

  String _resolveLabel() {
    final raw = labelText ?? _defaultLabels[level] ?? '';
    return raw.toUpperCase();
  }

  Color _resolveBg() {
    if (backgroundColor != null) return backgroundColor!;
    final palette = _classificationPalette[level];
    return palette?.bg ?? Colors.grey;
  }

  Color _resolveFg() {
    if (foregroundColor != null) return foregroundColor!;
    final palette = _classificationPalette[level];
    return palette?.fg ?? Colors.white;
  }

  @override
  Widget build(BuildContext context) {
    final label = _resolveLabel();
    final bg = _resolveBg();
    final fg = _resolveFg();

    if (display == EdenClassificationDisplay.bar) {
      return Semantics(
        label: '$label classification banner',
        container: true,
        readOnly: true,
        child: Container(
          width: double.infinity,
          constraints: BoxConstraints(minHeight: height),
          color: bg,
          padding: const EdgeInsets.symmetric(
            horizontal: EdenSpacing.space2,
            vertical: 4,
          ),
          alignment: Alignment.center,
          child: FittedBox(
            fit: BoxFit.scaleDown,
            child: Text(
              label,
              style: TextStyle(
                color: fg,
                fontWeight: FontWeight.w700,
                fontSize: 14,
                letterSpacing: 0.5,
              ),
              maxLines: 1,
            ),
          ),
        ),
      );
    }

    // Watermark mode — Stack child + diagonal overlay, ignore pointer.
    assert(child != null,
        'EdenClassificationBanner watermark mode requires a non-null child');
    return Stack(
      children: [
        child!,
        Positioned.fill(
          child: IgnorePointer(
            child: Center(
              child: Transform.rotate(
                angle: -math.pi / 4,
                child: Opacity(
                  opacity: 0.16,
                  child: Text(
                    label,
                    style: TextStyle(
                      color: fg,
                      fontWeight: FontWeight.w700,
                      fontSize: 64,
                      letterSpacing: 4,
                    ),
                  ),
                ),
              ),
            ),
          ),
        ),
      ],
    );
  }
}

/// Civilian-vertical alias for [EdenClassificationBanner]. Same widget, named
/// for commercial-context readability.
typedef EdenSensitivityBanner = EdenClassificationBanner;
```
