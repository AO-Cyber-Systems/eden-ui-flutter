<objective>
Ship `EdenAuditLogViewer` — user-facing immutable activity stream for federal audit-trail UX (HIPAA, FedRAMP, DOD). Renders actor / action / target / timestamp with optional hash-chain verification badge and failed-action indicator. Generic enough for civilian re-use: any SOC 2 audit trail, activity log, or compliance event stream.

Critical Wave 5 dependency: `EdenCaseFileShell` (011-06) embeds this viewer as the "audit" tab of regulated dossiers.

Wave 4, parallel with 011-03 / 011-07. depends_on ["011-03"] for compliance_screen.dart APPEND ordering.

Outside-in: value class → entry rendering → filter affordances → hash-chain badge → expand-on-tap → a11y → catalog.
</objective>

<embedded_context>

<codebase_examples>
**Existing EdenActivityFeed** — `lib/src/widgets/eden_activity_feed.dart` — similar actor/action/time pattern but more product-team oriented (comments, mentions). Audit log is similar but stricter (no mutation, hash chain, federal-shaped).

The two are SIBLINGS — don't replace EdenActivityFeed. Audit log has different semantics:
- Immutable (no edit affordance)
- Hash-chain badge
- Failed action indicator
- Stricter Semantics for screen readers (announces full audit phrasing)

**Existing EdenActivity** — used as inspiration for `EdenAuditLogEntry` shape but with audit-specific additions.

**Test pattern** — same wrap() helper.
</codebase_examples>

<anti_patterns>
- **Do NOT compose EdenActivityFeed directly.** EdenActivityFeed has comment/mention features that don't belong in audit log. Build EdenAuditLogViewer fresh with cross-pollinated patterns.
- **Do NOT mutate the entries.** Widget is read-only display; consumer drives data.
- **Do NOT compute the hash chain.** Consumer pre-computes (or pulls from server); widget renders status.
- **Do NOT auto-paginate.** Consumer controls entry list; if needed, consumer wraps in EdenListPageScaffold from obj 001.
</anti_patterns>

<gotchas>
- **DateTime formatting.** Pass `timestampFormatter` callback (default: ISO 8601 short). Consumer can pass custom (e.g. relative time "2 min ago" via Jiffy or hand-rolled).
- **Hash chain rendering.** If `prevHash != null && currHash != null` → show small lock-link icon. If `brokenIndices.contains(idx)` → show red broken-link icon + Semantics warning.
- **Failed action.** Distinct from category — orthogonal flag. `failed: true` renders red icon + 'FAILED' chip.
- **Filter state.** Internal `_actorFilter` (String?), `_failedOnly` (bool), `_actionCategoryFilter` (Set<String>? null = all). Filtering happens on the visible list, NOT on the controller (display-only filter).
- **Empty state** — when filtered visible list is empty.
- **Hand-built fixtures** — header required.
- **Test-pairing rule** — paired test required.
- **APPEND only for compliance_screen.dart**.
</gotchas>

<error_recovery>
- **If DateTime.toIso8601String() too long for narrow:** use `MM/dd HH:mm` short format inline; document customizability via `timestampFormatter`.
- **If filter logic explodes the visible list count:** verify `where` chain order — search first, then chips, then failed.

```dart
import 'package:flutter/material.dart';

import '../tokens/colors.dart';
import '../tokens/spacing.dart';

@immutable
class EdenAuditLogEntry {
  const EdenAuditLogEntry({
    required this.id,
    required this.timestamp,
    required this.actor,
    required this.action,
    required this.target,
    this.category,
    this.details = const {},
    this.prevHash,
    this.currHash,
    this.failed = false,
  });

  final String id;
  final DateTime timestamp;
  final String actor;
  final String action;
  final String target;
  final String? category;
  final Map<String, String> details;
  final String? prevHash;
  final String? currHash;
  final bool failed;
}

/// Immutable user-facing audit-log viewer for HIPAA / FedRAMP / DOD audit
/// trails. Civilian re-use: any SOC 2 or activity log.
///
/// Renders entries with optional hash-chain integrity badge and failed-
/// action indicator. Filtering by actor / action category / failed-only is
/// supported when [showFilters] is true.
class EdenAuditLogViewer extends StatefulWidget {
  const EdenAuditLogViewer({
    super.key,
    required this.entries,
    this.brokenChainIndices = const <int>{},
    this.timestampFormatter,
    this.showFilters = true,
  });

  final List<EdenAuditLogEntry> entries;
  final Set<int> brokenChainIndices;
  final String Function(DateTime)? timestampFormatter;
  final bool showFilters;

  @override
  State<EdenAuditLogViewer> createState() => _EdenAuditLogViewerState();
}

class _EdenAuditLogViewerState extends State<EdenAuditLogViewer> {
  String _actorQuery = '';
  bool _failedOnly = false;
  final Set<String> _hiddenCategories = {};
  String? _expandedId;

  String _formatTimestamp(DateTime ts) {
    if (widget.timestampFormatter != null) return widget.timestampFormatter!(ts);
    final mm = ts.month.toString().padLeft(2, '0');
    final dd = ts.day.toString().padLeft(2, '0');
    final hh = ts.hour.toString().padLeft(2, '0');
    final mi = ts.minute.toString().padLeft(2, '0');
    final ss = ts.second.toString().padLeft(2, '0');
    return '${ts.year}-$mm-$dd $hh:$mi:$ss';
  }

  bool _isVisible(EdenAuditLogEntry e) {
    if (_failedOnly && !e.failed) return false;
    if (_actorQuery.isNotEmpty && !e.actor.toLowerCase().contains(_actorQuery.toLowerCase())) return false;
    if (e.category != null && _hiddenCategories.contains(e.category)) return false;
    return true;
  }

  List<({int idx, EdenAuditLogEntry entry})> get _visibleWithIndex {
    final out = <({int idx, EdenAuditLogEntry entry})>[];
    for (var i = 0; i < widget.entries.length; i++) {
      if (_isVisible(widget.entries[i])) out.add((idx: i, entry: widget.entries[i]));
    }
    return out;
  }

  Iterable<String> get _categories =>
      widget.entries.map((e) => e.category).whereType<String>().toSet();

  Widget _chainIcon(int idx, EdenAuditLogEntry e) {
    if (widget.brokenChainIndices.contains(idx)) {
      return Semantics(
        label: 'Hash chain broken',
        child: const Icon(Icons.link_off, color: Colors.red, size: 16),
      );
    }
    if (e.prevHash != null && e.currHash != null) {
      return Semantics(
        label: 'Hash chain verified',
        child: const Icon(Icons.link, color: Colors.green, size: 16),
      );
    }
    return const SizedBox(width: 16);
  }

  @override
  Widget build(BuildContext context) {
    final visible = _visibleWithIndex;
    return Column(
      crossAxisAlignment: CrossAxisAlignment.stretch,
      children: [
        if (widget.showFilters) _buildFilters(),
        if (visible.isEmpty)
          const Padding(
            padding: EdgeInsets.all(16),
            child: Center(child: Text('No audit log entries match the current filters')),
          )
        else
          ListView.builder(
            shrinkWrap: true,
            physics: const NeverScrollableScrollPhysics(),
            itemCount: visible.length,
            itemBuilder: (context, i) {
              final (idx: realIdx, entry: e) = visible[i];
              final expanded = _expandedId == e.id;
              final timestamp = _formatTimestamp(e.timestamp);
              return Semantics(
                label: 'Audit: ${e.actor} ${e.action} ${e.target} at $timestamp${e.failed ? ", failed" : ""}',
                child: Column(
                  children: [
                    ListTile(
                      leading: Row(mainAxisSize: MainAxisSize.min, children: [
                        if (e.failed)
                          const Icon(Icons.error_outline, color: Colors.red, size: 18)
                        else
                          const Icon(Icons.check_circle_outline, color: Colors.green, size: 18),
                        const SizedBox(width: 4),
                        _chainIcon(realIdx, e),
                      ]),
                      title: Row(
                        children: [
                          Flexible(
                            child: Text(
                              '${e.actor} ${e.action} ${e.target}',
                              style: const TextStyle(fontSize: 13),
                              overflow: TextOverflow.ellipsis,
                            ),
                          ),
                          if (e.failed) ...[
                            const SizedBox(width: 8),
                            Container(
                              padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
                              decoration: BoxDecoration(color: Colors.red.shade100, borderRadius: BorderRadius.circular(4)),
                              child: const Text('FAILED', style: TextStyle(color: Colors.red, fontSize: 10, fontWeight: FontWeight.w700)),
                            ),
                          ],
                        ],
                      ),
                      subtitle: Text(timestamp, style: const TextStyle(fontSize: 11)),
                      onTap: e.details.isEmpty
                          ? null
                          : () => setState(() => _expandedId = expanded ? null : e.id),
                    ),
                    if (expanded && e.details.isNotEmpty)
                      Padding(
                        padding: const EdgeInsets.fromLTRB(72, 0, 16, 8),
                        child: Column(
                          crossAxisAlignment: CrossAxisAlignment.start,
                          children: [
                            for (final entry in e.details.entries)
                              Padding(
                                padding: const EdgeInsets.symmetric(vertical: 2),
                                child: Row(children: [
                                  Text('${entry.key}: ', style: const TextStyle(fontWeight: FontWeight.w600, fontSize: 11)),
                                  Flexible(child: Text(entry.value, style: const TextStyle(fontSize: 11), overflow: TextOverflow.ellipsis)),
                                ]),
                              ),
                          ],
                        ),
                      ),
                  ],
                ),
              );
            },
          ),
      ],
    );
  }

  Widget _buildFilters() {
    final categories = _categories.toList();
    return Padding(
      padding: const EdgeInsets.all(8),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Row(
            children: [
              Expanded(
                child: TextField(
                  decoration: const InputDecoration(
                    isDense: true,
                    hintText: 'Filter by actor',
                    prefixIcon: Icon(Icons.search, size: 16),
                  ),
                  onChanged: (v) => setState(() => _actorQuery = v),
                ),
              ),
              const SizedBox(width: 8),
              FilterChip(
                label: const Text('Failed only', style: TextStyle(fontSize: 11)),
                selected: _failedOnly,
                onSelected: (v) => setState(() => _failedOnly = v),
              ),
            ],
          ),
          if (categories.length > 1) ...[
            const SizedBox(height: 4),
            Wrap(
              spacing: 4,
              runSpacing: 4,
              children: [
                for (final cat in categories)
                  FilterChip(
                    label: Text(cat, style: const TextStyle(fontSize: 11)),
                    selected: !_hiddenCategories.contains(cat),
                    onSelected: (sel) {
                      setState(() {
                        if (sel) {
                          _hiddenCategories.remove(cat);
                        } else {
                          _hiddenCategories.add(cat);
                        }
                      });
                    },
                  ),
              ],
            ),
          ],
        ],
      ),
    );
  }
}
```
