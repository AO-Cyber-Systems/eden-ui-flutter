<objective>
Port `trades-react/client/src/components/FieldViewGate.tsx` to Flutter as `EdenFieldViewGate` — an inline gate widget that conditionally renders its child based on the current `EdenAppMode`.

Per user prompt: "Two variants: `EdenFieldViewGate.companionOnly(child:)` and `EdenFieldViewGate.adminOnly(child:)`. Useful for inline UI conditional rendering."

This is the **inline** companion to TRD-03's escape-hatch toggle. Whereas the toggle lets users flip modes, the gate lets developers conditionally surface widgets per mode. Examples:
- A FAB shown only in companion mode: `EdenFieldViewGate.companionOnly(child: EdenButton.fab(...))`.
- A bulk-edit toolbar shown only in admin mode: `EdenFieldViewGate.adminOnly(child: EdenBulkEditToolbar(...))`.
- A page-level forbidden surface: `EdenFieldViewGate.companionOnly(child: TheActualPage(), fallback: const _NotAvailableInFieldViewCard())`.

**Relationship to the donor.** Trades-react's `FieldViewGate.tsx` is a full-page surface (the "Not available in field view" card with an "Exit field view" button). The Eden version is more general — it ships the inline widget, and consumers can pass a custom `fallback` to recreate the donor's full-page experience when they need it. The library does NOT pre-bake the "Exit field view" button + navigation, because navigation is consumer-owned (`go_router` lives in `eden-platform-flutter`).

**Relationship to `EdenAdaptiveLayout` (TRD-02).** Different concerns:
- `EdenAdaptiveLayout` picks subtree based on VIEWPORT SIZE.
- `EdenFieldViewGate` picks subtree based on APP MODE.

They compose cleanly: `EdenFieldViewGate.companionOnly(child: EdenAdaptiveLayout(compactBuilder: ..., expandedBuilder: ...))` shows the adaptive layout only when in companion mode.
</objective>

**Design choice — `fallback` vs `builder`.**
- `fallback: Widget` — simplest case, just an alternative widget to render. Defaults to `SizedBox.shrink()`.
- `builder: Widget Function(BuildContext, EdenAppMode currentMode)` — more powerful; the fallback can vary based on what mode IS active. E.g., `.companionOnly(child: AdminPage(), builder: (ctx, mode) => mode == EdenAppMode.askUser ? PleasePickAMode() : NotAvailableInCompanion())`.
- Either may be passed; if both passed → constructor asserts (the user must pick one).
</context>

<gotchas>
- **Required ancestor scope.** Unlike `EdenUxModeToggle` (TRD-03), this widget does NOT accept an explicit controller arg — gate-by-mode is inherently scope-bound. Assert clearly if no `EdenAppModeScope` ancestor is found.
- **Rebuild on mode change.** Because `EdenAppModeScope.modeOf(context)` calls `dependOnInheritedWidgetOfExactType` (per TRD-01), this widget rebuilds automatically when the controller calls `notifyListeners()`. Verify with a controller mutation test.
- **`fallback` and `builder` are mutually exclusive.** Constructor assertion: `assert(fallback == null || builder == null, 'Pass fallback OR builder, not both.')`.
- **No animation by default.** Unlike `EdenNetworkStatusBar` (which has `AnimatedSwitcher` + slide transitions), `EdenFieldViewGate` is a hard cut. Mode changes are infrequent enough that animation isn't required; adding it would couple this widget to motion preferences. Document.
- **`askUser` mode handling.** Neither `.companionOnly` NOR `.adminOnly` matches `askUser` — both render fallback in that case. Tests must explicitly cover this.
</gotchas>

- Same, in companion mode → renders `'A'` (builder is for the unmatched case).

- Constructing with BOTH `fallback` and `builder` → throws assertion error with a clear message.

**Rebuild on mode change**

**Missing scope assertion**
- Mount `EdenFieldViewGate.companionOnly(child: Text('A'))` with NO `EdenAppModeScope` ancestor → throws an assertion error with helpful message (e.g., "EdenFieldViewGate requires an EdenAppModeScope ancestor. Wrap your subtree in EdenAppModeScope(controller: ...)").

**Responsive**
- iPhone-narrow (390pt): a `.companionOnly(child: Row(children: [...]))` renders without overflow when the child is itself iPhone-narrow safe.

```dart
import 'package:flutter/widgets.dart';
import 'eden_app_mode.dart';

/// Inline gate that conditionally renders [child] based on the current
/// [EdenAppMode] from the surrounding [EdenAppModeScope].
///
/// Donor: trades-react `client/src/components/FieldViewGate.tsx`. The
/// donor is a full-page forbidden card; this Flutter version is more
/// general — use [fallback] to recreate the donor's full-page shape.
///
/// Two variants:
///   - [EdenFieldViewGate.companionOnly] — show child only in
///     `EdenAppMode.fieldCompanion`.
///   - [EdenFieldViewGate.adminOnly] — show child only in
///     `EdenAppMode.admin`.
///
/// When the current mode does not match, renders [fallback] (defaults
/// to `SizedBox.shrink()`) or invokes [builder] (mutually exclusive
/// with [fallback]) with the actual current mode.
class EdenFieldViewGate extends StatelessWidget {
  const EdenFieldViewGate._({
    super.key,
    required this.child,
    required this.targetMode,
    this.fallback,
    this.builder,
  }) : assert(fallback == null || builder == null,
            'EdenFieldViewGate: pass fallback OR builder, not both.');

  factory EdenFieldViewGate.companionOnly({
    Key? key,
    required Widget child,
    Widget? fallback,
    Widget Function(BuildContext, EdenAppMode)? builder,
  }) =>
      EdenFieldViewGate._(
        key: key,
        child: child,
        targetMode: EdenAppMode.fieldCompanion,
        fallback: fallback,
        builder: builder,
      );

  factory EdenFieldViewGate.adminOnly({
    Key? key,
    required Widget child,
    Widget? fallback,
    Widget Function(BuildContext, EdenAppMode)? builder,
  }) =>
      EdenFieldViewGate._(
        key: key,
        child: child,
        targetMode: EdenAppMode.admin,
        fallback: fallback,
        builder: builder,
      );

  final Widget child;
  final EdenAppMode targetMode;
  final Widget? fallback;
  final Widget Function(BuildContext, EdenAppMode)? builder;

  @override
  Widget build(BuildContext context) {
    final controller = EdenAppModeScope.maybeOf(context);
    assert(
      controller != null,
      'EdenFieldViewGate requires an EdenAppModeScope ancestor. '
      'Wrap your subtree in EdenAppModeScope(controller: ...).',
    );
    final current = controller!.currentMode;
    if (current == targetMode) return child;
    if (builder != null) return builder!(context, current);
    return fallback ?? const SizedBox.shrink();
  }
}
```
