<objective>
Port `trades-react/client/src/components/layout/UXModeToggle.tsx` to Flutter as `EdenUxModeToggle` — the always-on toggle escape hatch from `COMPANION_UX_PATTERNS_2026-05-15.md` §0 locked decision A:

> Hybrid: screen-size auto-detect + JWT-claim override + always-on user toggle escape hatch.

The toggle is the "always-on user toggle" component — the third leg of the hybrid discrimination tripod. Users can flip between `admin` / `fieldCompanion` / `askUser` (`auto` in the donor's vocabulary) at any time on any device that shows it.

**Two variants for two host contexts:**
- `EdenUxModeToggle.compact` — icon-only, 44pt × 44pt × 3 = ~132pt horizontal footprint. Designed to sit in the companion bottom-nav slot (`EdenCompanionShell`, TRD-05) where horizontal space is precious.
- `EdenUxModeToggle.labeled` — icon + short text label per mode, ~240pt horizontal footprint. Designed to sit in the admin top-bar slot (used by `eden-platform-flutter` admin shells, not by anything in THIS library — but library ships the widget).

Donor mapping:
| trades-react UXModeToggle.tsx state | Eden equivalent |
|---|---|
| `'mobile'` (smartphone icon) | `EdenAppMode.fieldCompanion` |
| `'desktop'` (monitor icon) | `EdenAppMode.admin` |
| `'auto'` (sparkles icon) | `EdenAppMode.askUser` |

Donor's `canToggleUX` gate (only show on tablet + large mobile) is OUT OF SCOPE for this TRD — the gating decision is the consumer's via conditional rendering (`if (shouldShowToggle) EdenUxModeToggle.compact(...)`). The library ships the widget unconditionally; the consumer decides when to mount it. This matches the same pattern Wave A used for `EdenNetworkStatusBar` (state passed in, no internal "should I show" logic).
</objective>

**Design choice — controller-arg override.** For dev catalog use, widget tests, and downstream test contexts, the toggle accepts an explicit `controller: EdenAppModeController?` constructor arg. When provided, the toggle uses that controller directly and SKIPS the `EdenAppModeScope.of(context)` lookup. When null (default), it reads from the scope. This mirrors the dual-mode pattern used by Flutter's own `Theme.of(context)` vs `Theme(data: ..., child: ...)` — explicit wins over implicit.

<gotchas>
- **`EdenAppModeScope.of(context)` will assert/throw if no scope is in the tree.** Use `EdenAppModeScope.maybeOf(context)` when `controller` arg is null AND degrade with an assertion message if maybeOf also returns null. Document the "either pass a controller, or wrap in an EdenAppModeScope" contract in dartdoc.
- **Active-state Semantics.** `Semantics(selected: true)` on the active option is essential for screen-readers — verify with `find.bySemanticsLabel(...)` in the a11y test.
- **Icon selection.** Donor uses lucide-react `Smartphone`, `Monitor`, `Sparkles`. Flutter equivalents from Material icons: `Icons.smartphone`, `Icons.desktop_windows`, `Icons.auto_awesome`. Use these (do NOT add `lucide_icons` dep).
- **Compact variant 44pt tap targets.** WCAG 2.5.5 minimum tap target 44×44pt — verify in iPhone-narrow test that each option has at least 44pt hit area (use `tester.getSize(find.byType(InkWell))` or equivalent).
- **`EdenColors` token usage.** Use `Theme.of(context).colorScheme.primary` for active state and `.surface` for inactive (M3 design tokens), NOT hardcoded `Color(0xff...)`. Matches the rest of the library.
- **No `onChange` callback prop.** The widget's mutation channel IS `EdenAppModeController.setMode()`. Adding a duplicate `onChange` prop creates two sources of truth and is an anti-pattern. The controller's `onChange` constructor arg (TRD-01) is the persistence hook.
</gotchas>

**Scope-vs-controller resolution**
- `EdenUxModeToggle.compact()` with no `controller` arg, wrapped in `EdenAppModeScope` → reads + mutates the scope's controller.
- `EdenUxModeToggle.compact(controller: explicitController)` wrapped in `EdenAppModeScope(controller: scopeController)` → tapping mutates `explicitController` (NOT the scope's). Explicit beats scope.
- `EdenUxModeToggle.compact()` with no `controller` arg AND no scope → throws assertion error with helpful message ("Either pass a controller arg or wrap in an EdenAppModeScope").

**Accessibility**
- The active option has `Semantics(selected: true)` — verify with `tester.getSemantics(find.byTooltip('Field companion')).hasFlag(SemanticsFlag.isSelected) == true` (or similar; use the actual Flutter test API for Semantics).

- Tapping is keyboard-reachable (test by focusing + pressing Enter? — at minimum verify the underlying `InkWell` / `IconButton` doesn't suppress focus traversal).

**Responsive**
- iPhone-narrow (390pt): `EdenUxModeToggle.compact` fits in a 44pt-tall row at 390pt width without overflow (3 × 44pt tap targets + spacing < 390pt).
- `EdenUxModeToggle.labeled` at 390pt may wrap or scroll horizontally; the spec is "does not overflow" — wrapping or fitting are both acceptable. Test: no `RenderFlex overflowed` warning.

```dart
import 'package:flutter/material.dart';
import 'eden_app_mode.dart';

/// Always-on mode-toggle escape hatch per
/// COMPANION_UX_PATTERNS_2026-05-15.md §0 lock A.
///
/// Donor: trades-react `client/src/components/layout/UXModeToggle.tsx`.
/// 3-state: admin / fieldCompanion / askUser (donor names them
/// desktop / mobile / auto — same semantics).
///
/// Ships two variants:
///   - [EdenUxModeToggle.compact] — icon-only, fits in companion
///     bottom-nav slot.
///   - [EdenUxModeToggle.labeled] — icon + short text label, fits in
///     admin top-bar slot.
///
/// Wiring contract: tapping calls `controller.setMode(target)`. Either
/// pass a [controller] explicitly OR wrap in an [EdenAppModeScope] so
/// the toggle can read one. Asserts at runtime if neither is supplied.
class EdenUxModeToggle extends StatelessWidget {
  const EdenUxModeToggle._({
    super.key,
    this.controller,
    required this.variant,
  });

  factory EdenUxModeToggle.compact({Key? key, EdenAppModeController? controller}) =>
      EdenUxModeToggle._(
        key: key,
        controller: controller,
        variant: _Variant.compact,
      );

  factory EdenUxModeToggle.labeled({Key? key, EdenAppModeController? controller}) =>
      EdenUxModeToggle._(
        key: key,
        controller: controller,
        variant: _Variant.labeled,
      );

  final EdenAppModeController? controller;
  final _Variant variant;

  @override
  Widget build(BuildContext context) {
    final resolved = controller ?? EdenAppModeScope.maybeOf(context);
    assert(
      resolved != null,
      'EdenUxModeToggle requires either a controller arg or an EdenAppModeScope ancestor.',
    );
    // Listen to controller changes via AnimatedBuilder for rebuild on mutation
    return AnimatedBuilder(
      animation: resolved!,
      builder: (context, _) => _buildOptions(context, resolved),
    );
  }

  Widget _buildOptions(BuildContext context, EdenAppModeController c) {
    final options = [EdenAppMode.fieldCompanion, EdenAppMode.admin, EdenAppMode.askUser];
    return Row(
      mainAxisSize: MainAxisSize.min,
      children: [
        for (final mode in options)
          _buildOption(context, c, mode),
      ],
    );
  }

  Widget _buildOption(BuildContext context, EdenAppModeController c, EdenAppMode mode) {
    final theme = Theme.of(context);
    final isActive = c.currentMode == mode;
    final bg = isActive ? theme.colorScheme.primaryContainer : Colors.transparent;
    final fg = isActive ? theme.colorScheme.onPrimaryContainer : theme.colorScheme.onSurfaceVariant;
    return Tooltip(
      message: _tooltipFor(mode),
      child: Semantics(
        selected: isActive,
        button: true,
        label: _labelFor(mode),
        child: InkWell(
          onTap: () => c.setMode(mode),
          child: Container(
            constraints: const BoxConstraints(minWidth: 44, minHeight: 44),
            decoration: BoxDecoration(color: bg, borderRadius: BorderRadius.circular(8)),
            padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 8),
            child: variant == _Variant.compact
                ? Icon(_iconFor(mode), color: fg)
                : Row(
                    mainAxisSize: MainAxisSize.min,
                    children: [
                      Icon(_iconFor(mode), color: fg),
                      const SizedBox(width: 6),
                      Text(_labelFor(mode), style: TextStyle(color: fg)),
                    ],
                  ),
          ),
        ),
      ),
    );
  }

  IconData _iconFor(EdenAppMode mode) => switch (mode) {
        EdenAppMode.fieldCompanion => Icons.smartphone,
        EdenAppMode.admin => Icons.desktop_windows,
        EdenAppMode.askUser => Icons.auto_awesome,
      };

  String _labelFor(EdenAppMode mode) => switch (mode) {
        EdenAppMode.fieldCompanion => 'Field',
        EdenAppMode.admin => 'Admin',
        EdenAppMode.askUser => 'Auto',
      };

  String _tooltipFor(EdenAppMode mode) => switch (mode) {
        EdenAppMode.fieldCompanion => 'Field companion',
        EdenAppMode.admin => 'Admin (desktop view)',
        EdenAppMode.askUser => 'Auto (resize-driven)',
      };
}

enum _Variant { compact, labeled }
```
