<objective>
Codify and ship `EdenGpsStatusIndicator` — a cross-vertical GPS quality + permission status pill, promoted from trades-only to library-level per `COMPANION_UX_PATTERNS_2026-05-15.md` §P-17 evidence:

> Trades-flavored but useful for fuel-truck (route adherence), medical home-visit (verify visit occurred at patient address), gov field inspection (chain-of-custody verification of inspection location). PROMOTE TO WAVE B cross-vertical primitive (multiple verticals need it).

Use-case matrix (`COMPANION_USE_CASE_MATRIX_2026-05-15.md`) reinforces:
- UC-02: "Field tech checks in at job site with GPS verification" — verticals T, F, M, G.
- UC-28: "Driver navigates from stop to stop on the route" — F, T, M, G.
- UC-30: "Driver captures delivery confirmation signature" — uses MP, references P-17.
- UC-39: "Nurse verifies patient identity at door (face + DOB confirm)" — M, G; location proof relevant to chain-of-custody.

Donor pattern from trades-flutter `field_crew/.../check_in_page.dart`: `EdenBadge` (success/warning/danger variants) + ad-hoc colored dot + `EdenDescriptionList` for coordinate display. This TRD codifies the assembly into a single primitive.

**Why mode-aware (small twist).** Per `EdenAppModeScope.maybeOf(context)`:
- In `fieldCompanion` mode, the indicator renders the full UI (pill + accuracy + lat/lng coords) — field user needs to verify accuracy before checking in.
- In `admin` mode, the indicator collapses to a compact inline badge (pill + accuracy only, no coords) — admins viewing a tech's location card in a list don't need the full coords inline (they can drill into the detail).
- If no scope is in the tree, defaults to full mode (no mode-aware compression). Useful in dev catalog and isolated test contexts.

**Why transport-agnostic.** The library does NOT call `geolocator`, `location`, `permission_handler`, or any platform-channel API. The consumer subscribes to the platform's location stream + permission state and passes the resolved `EdenGpsStatus` + `EdenGpsCoordinate` + `double accuracyMeters` IN. This matches the pattern Wave A used for `EdenNetworkStatusBar` (state in, no internal polling).
</objective>

- `compact: true` in `fieldCompanion` mode → renders compact (NOT full). Override beats mode.
- `compact: false` in `admin` mode → renders full (NOT compact). Override beats mode.

```dart
import 'package:flutter/material.dart';
import 'eden_app_mode.dart';
import 'map_providers/eden_map_types.dart' show EdenLatLng;

/// GPS signal quality + permission state, codified per
/// COMPANION_UX_PATTERNS_2026-05-15.md §P-17.
enum EdenGpsStatus { high, moderate, poor, unavailable }

/// Cross-vertical GPS status pill + accuracy + lat/lng readout.
///
/// Promoted from trades-only to library-level per P-17 evidence:
/// fuel (route adherence), medical (home-visit chain-of-custody),
/// gov (field inspection) all need it.
///
/// **Transport-agnostic.** Consumer subscribes to `geolocator` /
/// `location` / equivalent platform stream and pushes resolved
/// [EdenGpsStatus] + [EdenLatLng] + [accuracyMeters] in. Library
/// renders only.
///
/// **Mode-aware compression.** Reads
/// `EdenAppModeScope.maybeOf(context)`:
///   - `fieldCompanion` or absent scope → full UI (pill + accuracy + coords).
///   - `admin` → compact UI (pill + accuracy only).
/// Override via [compact] constructor arg.
class EdenGpsStatusIndicator extends StatelessWidget {
  const EdenGpsStatusIndicator({
    super.key,
    required this.status,
    this.accuracyMeters,
    this.position,
    this.compact,
  });

  final EdenGpsStatus status;
  final double? accuracyMeters;
  final EdenLatLng? position;

  /// null = read from EdenAppModeScope (admin → compact, else full).
  /// true = force compact. false = force full.
  final bool? compact;

  @override
  Widget build(BuildContext context) {
    final useCompact = compact ?? _shouldUseCompact(context);
    return Semantics(
      label: _semanticsLabel(),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: [
          _pill(context),
          if (status != EdenGpsStatus.unavailable && accuracyMeters != null) ...[
            const SizedBox(width: 8),
            Text('${accuracyMeters!.round()} m'),
          ],
          if (!useCompact && position != null && status != EdenGpsStatus.unavailable) ...[
            const SizedBox(width: 8),
            Flexible(
              child: Text(
                _formatCoords(position!),
                style: const TextStyle(fontFamily: 'monospace'),
                overflow: TextOverflow.ellipsis,
              ),
            ),
          ],
        ],
      ),
    );
  }

  bool _shouldUseCompact(BuildContext context) {
    final scope = EdenAppModeScope.maybeOf(context);
    if (scope == null) return false; // graceful default = full
    return scope.currentMode == EdenAppMode.admin;
  }

  Widget _pill(BuildContext context) {
    final (bgColor, label) = switch (status) {
      EdenGpsStatus.high => (Colors.green.shade100, 'High'),
      EdenGpsStatus.moderate => (Colors.amber.shade100, 'Moderate'),
      EdenGpsStatus.poor => (Colors.red.shade100, 'Poor'),
      EdenGpsStatus.unavailable => (Colors.grey.shade200, 'GPS unavailable'),
    };
    return Container(
      padding: const EdgeInsets.symmetric(horizontal: 10, vertical: 4),
      decoration: BoxDecoration(
        color: bgColor,
        borderRadius: BorderRadius.circular(12),
      ),
      child: Text(label),
    );
  }

  String _formatCoords(EdenLatLng p) =>
      '${p.lat.toStringAsFixed(6)}, ${p.lng.toStringAsFixed(6)}';

  String _semanticsLabel() {
    if (status == EdenGpsStatus.unavailable) return 'GPS unavailable';
    final qty = status.name; // 'high' / 'moderate' / 'poor'
    final acc = accuracyMeters?.round() ?? 0;
    return 'GPS signal: $qty, accuracy $acc meters';
  }
}
```
