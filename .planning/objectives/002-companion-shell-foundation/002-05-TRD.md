<objective>
Ship `EdenCompanionShell` — the mode-aware composition that puts the four foundational pieces together into a single shell consumers can drop on a page:

```dart
EdenCompanionShell(
  // From the consumer's auth / vertical context:
  greeting: 'Good morning, Sarah',
  roleLabel: 'Field Tech',
  rolePalette: EdenRolePalette.trades,
  sections: tradesVerticalSkin.companionDashboardSections,
  navItems: tradesVerticalSkin.companionNavItems,  // ≤5 items
  selectedNavId: 'home',
  onNavChanged: (id) => router.navigate(id),
  networkStatus: EdenNetworkStatus.online,         // from consumer's connectivity stream
)
```

The shell internally:
1. Reads `EdenAppModeScope.modeOf(context)` to know the current mode.
2. Renders `EdenNetworkStatusBar` at the top (no chrome when status is online).
3. Renders `EdenRoleDashboardShell` (Wave A) as the body — populated with the consumer's `sections` list.
4. Renders a bottom-nav with the consumer's `navItems` (≤5).
5. Renders `EdenUxModeToggle.compact` at the bottom-right of the chrome (or wherever the spec says — see "open question" below) as the always-on escape hatch.
6. Wraps everything in `EdenAdaptiveLayout` with `forceCompact: (currentMode == fieldCompanion)` to honor lock E.

**The CRITICAL test of this TRD** (and the reason the user prompt called it out): at viewport width 1200pt (which Material 3 + `EdenAdaptiveLayout` would normally classify as Expanded), when `currentMode == fieldCompanion`, the shell MUST still render the Compact layout (bottom-nav at bottom, single-column body, compact UX toggle). The `forceCompact` flag from TRD-02 is the mechanism; the test in this TRD is the enforcement gate.

**Per lock B (shell + nav consistent; pages vary):** This TRD ships ONLY the shell + nav STRUCTURE. The `sections` and `navItems` are vertical-supplied data — the library DOES NOT know what "Today's chair appointments" vs "Today's jobs" means. Verticals plug in their own `EdenDashboardSection` lists and `EdenCompanionNavItem` lists. The shell + nav SHAPE is identical; only the data varies.

**Out of scope (deliberate):**
- Routing — the shell calls back via `onNavChanged(itemId)`; consumer's `go_router` handles the actual navigation.
- Auth state — passed in via `greeting` + `roleLabel`; library doesn't read JWTs.
- Sections content — consumer-supplied as `List<EdenDashboardSection>`.
- Bottom-nav submenu sheets (the 1271-LOC `MobileBottomNav.tsx` paginated 6-tab strip from trades-react with submenu bottom sheets). v1 ships a simple ≤5-tab BottomNavigationBar; the more complex paginated-strip primitive is deferred to a follow-on TRD if salon/medical verticals demand it.
</objective>

```dart
import 'package:flutter/material.dart';
import 'eden_adaptive_layout.dart';
import 'eden_app_mode.dart';
import 'eden_network_status_bar.dart';
import 'eden_role_dashboard_shell.dart';
import 'eden_ux_mode_toggle.dart';

class EdenCompanionShell extends StatelessWidget {
  EdenCompanionShell({
    super.key,
    required this.greeting,
    required this.roleLabel,
    this.rolePalette,
    this.avatar,
    required this.sections,
    required this.navItems,
    required this.selectedNavId,
    required this.onNavChanged,
    this.networkStatus = EdenNetworkStatus.online,
  }) : assert(navItems.length <= 5,
            'EdenCompanionShell supports ≤5 navItems; pagination is deferred. '
            'navItems.length was ${navItems.length}.');

  final String greeting;
  final String roleLabel;
  final EdenRolePalette? rolePalette;
  final Widget? avatar;
  final List<EdenDashboardSection> sections;
  final List<EdenCompanionNavItem> navItems;
  final String selectedNavId;
  final ValueChanged<String> onNavChanged;
  final EdenNetworkStatus networkStatus;

  @override
  Widget build(BuildContext context) {
    final mode = EdenAppModeScope.modeOf(context); // asserts ancestor presence per TRD-01
    final forceCompact = mode == EdenAppMode.fieldCompanion;

    return EdenAdaptiveLayout(
      forceCompact: forceCompact,
      compactBuilder: (ctx) => _buildCompactShell(ctx),
      expandedBuilder: (ctx) => _buildExpandedShell(ctx),
    );
  }

  Widget _buildCompactShell(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text(roleLabel),
        actions: [
          EdenUxModeToggle.compact(),
          const SizedBox(width: 8),
        ],
      ),
      body: Column(
        children: [
          EdenNetworkStatusBar(status: networkStatus),
          Expanded(
            child: EdenRoleDashboardShell(
              greeting: greeting,
              roleLabel: roleLabel,
              rolePalette: rolePalette ?? EdenRolePalette.neutral,
              avatar: avatar,
              sections: sections,
            ),
          ),
        ],
      ),
      bottomNavigationBar: SafeArea(
        bottom: true,
        child: BottomNavigationBar(
          type: BottomNavigationBarType.fixed,
          currentIndex: _currentNavIndex(),
          onTap: (index) => onNavChanged(navItems[index].id),
          items: [
            for (final item in navItems)
              BottomNavigationBarItem(
                icon: Icon(item.icon),
                activeIcon: item.activeIcon != null ? Icon(item.activeIcon) : null,
                label: item.label,
              ),
          ],
        ),
      ),
    );
  }

  Widget _buildExpandedShell(BuildContext context) {
    // Admin mode: minimal expanded shell. The expectation is that admin
    // chrome lives in `eden-platform-flutter`'s admin shell, NOT here.
    // For the few cases where EdenCompanionShell is rendered in admin
    // mode (e.g., the dev catalog or a transitional state during
    // mode-flip), render a sensible placeholder that signals "use the
    // admin shell instead."
    return Scaffold(
      key: const ValueKey('expanded-companion-shell'),
      appBar: AppBar(
        title: Text(roleLabel),
        actions: [
          EdenUxModeToggle.labeled(),
          const SizedBox(width: 8),
        ],
      ),
      body: Column(
        children: [
          EdenNetworkStatusBar(status: networkStatus),
          Expanded(
            child: EdenRoleDashboardShell(
              greeting: greeting,
              roleLabel: roleLabel,
              rolePalette: rolePalette ?? EdenRolePalette.neutral,
              avatar: avatar,
              sections: sections,
            ),
          ),
        ],
      ),
    );
  }

  int _currentNavIndex() {
    final i = navItems.indexWhere((n) => n.id == selectedNavId);
    return i < 0 ? 0 : i;
  }
}
```
