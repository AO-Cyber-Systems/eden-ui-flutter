<objective>
Ship `EdenAdaptiveLayout` — the canonical Material 3 three-tier responsive scaffold honoring `COMPANION_UX_PATTERNS_2026-05-15.md` §0 locked decision E:

> Three Material 3 tiers locked: Compact <600pt, Medium 600–840pt, Expanded ≥840pt. Use `LayoutBuilder.constraints.maxWidth` (logical pt, NOT raw pixels). Companion mode pins to Compact at ALL widths.

**Why this is foundational.** Every page in the companion shell (TRD-05) renders inside an `EdenAdaptiveLayout`. The same widget can also be used by admin-mode pages that want the M3 three-tier shape. The `forceCompact` flag is the mechanism by which `EdenCompanionShell` (TRD-05) implements "companion pins to Compact at ALL widths" — when `EdenAppModeScope.modeOf(context) == fieldCompanion`, the shell wraps its body in `EdenAdaptiveLayout(forceCompact: true, ...)` regardless of the device width.

**Relationship to existing layout widgets.** `EdenMobileLayout` and `EdenDesktopLayout` already exist at `lib/src/widgets/eden_layout/`. Those are CHROME (app bars, drawers, bottom-nav with specific shapes). `EdenAdaptiveLayout` is a HIGHER-LEVEL responsive scaffold — it picks between layouts based on tier. A typical composition: `EdenAdaptiveLayout(compactBuilder: (ctx) => EdenMobileLayout(...), expandedBuilder: (ctx) => EdenDesktopLayout(...))`. Existing widgets ARE NOT modified or replaced.

**Relationship to existing `EdenResponsive` / `EdenResponsiveBuilder` utilities.** `lib/src/utils/responsive.dart` already has `EdenResponsive.layoutMode(context)` returning `EdenLayoutMode { mobile, tablet, desktop, wide }` using DIFFERENT breakpoints (768/1024/1280). This TRD does NOT change `EdenResponsive`. `EdenAdaptiveLayout` introduces an independent `EdenAdaptiveTier { compact, medium, expanded }` enum tied to Material 3 600/840 breakpoints from lock E. The two coexist; new companion code uses `EdenAdaptiveLayout`, legacy admin code can stay on `EdenResponsive`.
</objective>

<gotchas>
- **`LayoutBuilder.constraints.maxWidth` can be `double.infinity` in unbounded contexts** (e.g., inside a horizontally scrolling parent). Guard: if `maxWidth.isInfinite`, fall back to `MediaQuery.of(context).size.width`. Document the fallback in dartdoc + add a test for it.
- **`WidgetBuilder` vs `Widget`.** Use `WidgetBuilder` (a function `Widget Function(BuildContext)`) so the picked tier rebuilds its subtree with a fresh `BuildContext` (important for `MediaQuery` / `Theme` lookups inside the builder).
- **Null `mediumBuilder` / `expandedBuilder` fallback order.** Document fallback chain in dartdoc: Expanded → expandedBuilder → mediumBuilder → compactBuilder. Medium → mediumBuilder → compactBuilder. Compact → compactBuilder (required, not nullable).
- **Reuse TRD-01 constants.** `import 'eden_app_mode.dart'` for `kEdenAppModeCompactMax` and `kEdenAppModeExpandedMin`. Single source of truth for breakpoint values.
- **Wrapping in `MediaQuery`.** `LayoutBuilder` gives constraints, not MediaQuery. If the picked-tier subtree needs to know "I'm in compact mode," expose the chosen tier through an `InheritedWidget` OR pass it as the second arg to `WidgetBuilder` (consider Dart can't extend `WidgetBuilder` signature) — simplest: ship `EdenAdaptiveTierScope` that the picked subtree can read via `EdenAdaptiveTier.of(context)`.
</gotchas>

**`forceCompact: true` invariant**
- `EdenAdaptiveLayout(forceCompact: true, compactBuilder: ..., expandedBuilder: ...)` at 1200pt width → calls `compactBuilder`, NEVER `expandedBuilder`. THIS IS THE COMPANION-MODE INVARIANT (lock E rule 3). Marked CRITICAL in test name.

**Fallback chain (null builders)**
- `mediumBuilder: null, expandedBuilder: null` at 700pt width → renders `compactBuilder`.
- `mediumBuilder: null, expandedBuilder: null` at 1200pt width → renders `compactBuilder`.
- `mediumBuilder: <X>, expandedBuilder: null` at 1200pt width → renders `mediumBuilder` (Expanded falls back to Medium when expandedBuilder is null).
- `mediumBuilder: null, expandedBuilder: <Y>` at 700pt width → renders `compactBuilder` (Medium falls back to Compact, not Expanded — fallback walks DOWN tiers).

**Unbounded-width fallback**
- `EdenAdaptiveLayout` inside an unbounded-width parent (e.g., `SingleChildScrollView` with `scrollDirection: Axis.horizontal`) where `constraints.maxWidth.isInfinite` → falls back to `MediaQuery.of(context).size.width` and picks the correct tier. Verified by wrapping in a SizedBox + scroll view + `tester.binding.setSurfaceSize(Size(1200, 800))`.

**`EdenAdaptiveTierScope` (sub-API for picked-tier subtree)**
- The picked subtree can read `EdenAdaptiveTier.of(context)` and get the resolved tier.
- At 390pt width with `forceCompact: false`, `EdenAdaptiveTier.of(context)` → `EdenAdaptiveTier.compact`.
- At 1200pt width with `forceCompact: true`, `EdenAdaptiveTier.of(context)` → `EdenAdaptiveTier.compact` (matches the forced rendering).
- `EdenAdaptiveTier.maybeOf(context)` outside the scope → `null`.

**iPhone-narrow safety**
- At 390pt with a minimal compactBuilder (just `Text('hello')`), no overflow warnings.

```dart
import 'package:flutter/widgets.dart';

import 'eden_app_mode.dart' show kEdenAppModeCompactMax, kEdenAppModeExpandedMin;

/// Material 3 responsive tier classification per
/// COMPANION_UX_PATTERNS_2026-05-15.md §0 lock E:
///   - Compact: <600pt
///   - Medium: 600–840pt
///   - Expanded: ≥840pt
enum EdenAdaptiveTier { compact, medium, expanded }

/// InheritedWidget exposing the resolved [EdenAdaptiveTier] to the
/// chosen builder's subtree. Consumers can call
/// [EdenAdaptiveTier.of(context)] (extension method below) to know
/// which tier was picked.
class EdenAdaptiveTierScope extends InheritedWidget {
  const EdenAdaptiveTierScope({
    super.key,
    required this.tier,
    required super.child,
  });

  final EdenAdaptiveTier tier;

  static EdenAdaptiveTier of(BuildContext context) {
    final scope = context.dependOnInheritedWidgetOfExactType<EdenAdaptiveTierScope>();
    assert(scope != null, 'EdenAdaptiveTier.of() called with no EdenAdaptiveLayout in the tree.');
    return scope!.tier;
  }

  static EdenAdaptiveTier? maybeOf(BuildContext context) {
    return context.dependOnInheritedWidgetOfExactType<EdenAdaptiveTierScope>()?.tier;
  }

  @override
  bool updateShouldNotify(EdenAdaptiveTierScope oldWidget) =>
      tier != oldWidget.tier;
}

/// Material 3 three-tier adaptive scaffold.
///
/// Picks one of [compactBuilder] / [mediumBuilder] / [expandedBuilder]
/// based on the parent's `LayoutBuilder.constraints.maxWidth` (logical
/// pt, NOT raw pixel — per lock E rule 1).
///
/// Pass [forceCompact] = true to bypass tier selection and always
/// render [compactBuilder]. This is the hook `EdenCompanionShell` uses
/// to honor lock E rule 3: "Companion mode pins to Compact at ALL
/// widths."
///
/// Fallback chain when a higher-tier builder is null:
///   Expanded → expandedBuilder → mediumBuilder → compactBuilder
///   Medium → mediumBuilder → compactBuilder
///   Compact → compactBuilder (required)
class EdenAdaptiveLayout extends StatelessWidget {
  const EdenAdaptiveLayout({
    super.key,
    required this.compactBuilder,
    this.mediumBuilder,
    this.expandedBuilder,
    this.forceCompact = false,
  });

  final WidgetBuilder compactBuilder;
  final WidgetBuilder? mediumBuilder;
  final WidgetBuilder? expandedBuilder;
  final bool forceCompact;

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(
      builder: (context, constraints) {
        final width = constraints.maxWidth.isFinite
            ? constraints.maxWidth
            : MediaQuery.of(context).size.width;
        final tier = forceCompact
            ? EdenAdaptiveTier.compact
            : _tierFor(width);
        final builder = _builderFor(tier);
        return EdenAdaptiveTierScope(
          tier: tier,
          child: Builder(builder: builder),
        );
      },
    );
  }

  EdenAdaptiveTier _tierFor(double width) {
    if (width < kEdenAppModeCompactMax) return EdenAdaptiveTier.compact;
    if (width < kEdenAppModeExpandedMin) return EdenAdaptiveTier.medium;
    return EdenAdaptiveTier.expanded;
  }

  WidgetBuilder _builderFor(EdenAdaptiveTier tier) {
    switch (tier) {
      case EdenAdaptiveTier.expanded:
        return expandedBuilder ?? mediumBuilder ?? compactBuilder;
      case EdenAdaptiveTier.medium:
        return mediumBuilder ?? compactBuilder;
      case EdenAdaptiveTier.compact:
        return compactBuilder;
    }
  }
}
```
