<gotchas>
- **enabled=false short-circuits to `SizedBox.shrink()` BEFORE checking other params** — even if insights are passed, the widget renders nothing. Preserve.
- **`isExpanded` priority:** if `widget.isExpanded != null`, use it; ELSE use `_internalExpanded`. Both states-coexist pattern.
- **`didUpdateWidget` sync** — when external `isExpanded` changes, internal mirror updates so subsequent renders are consistent. Preserve exact donor logic.
- **`onToggle` priority:** if external callback provided, fire it on toggle; ELSE internally setState. Donor's `_toggle()` method codifies this.
- **Default persona `EdenAiPersona.operations`** — donor's `widget.persona ?? AiPersona.operations`. Preserve.
- **Default expanded `true`** — donor's `_internalExpanded = widget.isExpanded ?? true;` in initState. Preserve.
</gotchas>

## Test list (write FIRST)

**Disabled path**
- `EdenAiInsightSlot(enabled: false, insights: someInsights, persona: ...)` → renders `SizedBox.shrink()` (no EdenAiPanel in subtree). Use `find.byType(EdenAiPanel)` findsNothing.
- Even with `isExpanded: true` + `onToggle` callback, disabled=false renders nothing.

**Enabled — composes EdenAiPanel**
- `EdenAiInsightSlot(enabled: true, insights: [summaryInsight], persona: EdenAiPersona.finance)` → finds an EdenAiPanel child with the correct insights + persona props.

**Default persona fallback**
- `EdenAiInsightSlot(enabled: true, insights: [...])` (no persona) → EdenAiPanel persona prop equals EdenAiPersona.operations.

**Internal state — default expanded=true**
- `EdenAiInsightSlot(enabled: true, insights: [...])` (no isExpanded) → EdenAiPanel isExpanded prop is true initially.

**Internal toggle**
- Mount with no `isExpanded` and no `onToggle`. Tap the EdenAiPanel's chevron → EdenAiPanel's isExpanded prop flips to false on next pump. Tap again → flips back to true.

**External state — isExpanded controlled**
- `EdenAiInsightSlot(enabled: true, isExpanded: false, ...)` → EdenAiPanel isExpanded prop is false.
- Rebuild widget tree with `isExpanded: true` → EdenAiPanel isExpanded prop becomes true.

**External callback**
- `EdenAiInsightSlot(enabled: true, isExpanded: true, onToggle: () => count++, ...)` → tapping the panel chevron fires onToggle; library does NOT mutate internal state (no internal setState).

**Edge / responsive**
- enabled=true at 280pt sidebar → EdenAiPanel renders without overflow.
