<gotchas>
- **`count` is `String?`** (donor) — not int. Allows '$24,500' or '7' uniformly. Preserve.
- **Label rendering:** when `count != null`, label is `'$count $label'` (e.g. '7 photos'); when `count == null`, label is just `label`. Test both paths.
- **Button vs trailing-text mutual exclusion:** donor renders button ONLY if `onAddPressed != null`; otherwise renders trailing text ONLY if `trailingText != null`. Both null → empty trailing. Test all 3 paths.
- **`Expanded(child: _MediaCell(...))`** — each cell is Expanded, so 3 cells in a Row at 390pt width get ~130pt each (minus gaps). Test no-overflow at narrow widths.
- **`overflow: TextOverflow.ellipsis, maxLines: 1`** on the label Text — narrow-safe but means long labels ('45 photos and screenshots') will truncate. Document; test ellipsis behavior at narrow widths.
- **`_AddButton` InkWell border radius 4px** — donor uses 4 not 8. Preserve.
</gotchas>

## Test list (write FIRST)

**Empty path**
- `EdenMediaRow(items: const [])` → renders only `SizedBox.shrink()`; no Container, no border, no text.

**Happy path (3 cells)**
- `EdenMediaRow(items: [photos, docs, budget])` where photos has onAddPressed, docs has onAddPressed, budget has trailingText → 3 cells rendered with their respective trailing content.

**Count + label combination**
- `EdenMediaRowItem(icon: Icons.camera_alt, label: 'photos', count: '7')` → label Text reads '7 photos'.
- `EdenMediaRowItem(icon: Icons.camera_alt, label: 'photos')` (no count) → label Text reads 'photos'.
- `EdenMediaRowItem(icon: Icons.attach_money, label: 'budget', count: r'$24,500')` → label Text reads r'$24,500 budget'.

**Trailing button**
- `onAddPressed: () => tapped = true` → renders '+ Add' Text; tapping it sets `tapped = true`.
- `onAddPressed: null, trailingText: '1 CO'` → renders '1 CO' Text, NO '+ Add' button.
- `onAddPressed: null, trailingText: null` → renders neither '+ Add' nor any trailing text.

**Button-vs-text priority**
- `onAddPressed: () => {}, trailingText: '1 CO'` → '+ Add' button renders, '1 CO' DOES NOT render (button takes priority).

**Edge / responsive**
- 3 cells at `SizedBox(width: 390)` → no overflow warnings.
- 1 cell with long label (40 chars) ellipsizes; no overflow.
