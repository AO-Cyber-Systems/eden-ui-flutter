## Test list (write FIRST)

**Happy path**
- Renders empty state with 'No pending changes' + checkmark when queue is empty.
- Renders 1 row per queue item with: action type icon, summary text, relative timestamp ('5 min ago'), status pill (pending/syncing/conflict/error).
- Tapping Retry on a failed item invokes `onRetry(item)`.
- Tapping Discard invokes `onDiscard(item)` after a confirm dialog.
- Conflict item shows a 'Resolve' button; tapping invokes `onResolveConflict(item)`.

**Edge**
- Queue with 50 items renders efficiently in a ListView.builder (no jank — verified by frame timing assertion or sampled measure).
- Status badge colors match: pending=neutral, syncing=blue, conflict=amber, error=red.
- Payload-preview text is truncated to 80 chars with ellipsis.

**Failure / safety**
- iPhone-narrow safe.
- Long action types ('Update customer contact address line 1...') wrap or truncate.
