## Test list (write FIRST)

**Happy path**
- Renders an `Image.network` with the given URL.
- Headers map is passed through to the underlying `NetworkImage(headers: ...)`.
- Loading placeholder (default = `EdenSpinner`) is visible before image loads.
- `headersBuilder` (Future<Map<String, String>>) is awaited; image only resolves once headers resolve.

**Edge**
- `headers: {}` (empty map) works — image still loads, no auth header.
- `headersBuilder` returns null → no headers passed (treat as anonymous fetch).
- Custom `placeholder` widget overrides default spinner.
- Custom `errorWidget` overrides default error icon.

**Failure / safety**
- Bad URL (404) renders the error placeholder, not the loading spinner forever.
- `headersBuilder` throws → error placeholder renders.
- iPhone-narrow safe (image scales to BoxConstraints).

```dart
class EdenAuthenticatedImage extends StatefulWidget {
  const EdenAuthenticatedImage({
    super.key,
    required this.url,
    this.headers,                  // Map<String, String>?
    this.headersBuilder,           // Future<Map<String, String>?> Function()? — async resolver
    this.placeholder,              // Widget?
    this.errorWidget,              // Widget?
    this.width,
    this.height,
    this.fit = BoxFit.cover,
  });
  final String url;
  final Map<String, String>? headers;
  final Future<Map<String, String>?> Function()? headersBuilder;
  final Widget? placeholder;
  final Widget? errorWidget;
  final double? width;
  final double? height;
  final BoxFit fit;
}

class _EdenAuthenticatedImageState extends State<EdenAuthenticatedImage> {
  Map<String, String>? _resolvedHeaders;
  Object? _headerError;

  @override
  void initState() {
    super.initState();
    if (widget.headersBuilder != null) {
      widget.headersBuilder!().then((h) => setState(() => _resolvedHeaders = h)).catchError((e) => setState(() => _headerError = e));
    } else {
      _resolvedHeaders = widget.headers ?? const {};
    }
  }

  @override
  Widget build(BuildContext context) {
    if (_headerError != null) return widget.errorWidget ?? const Icon(Icons.broken_image);
    if (_resolvedHeaders == null) return widget.placeholder ?? const EdenSpinner();
    return Image.network(
      widget.url,
      headers: _resolvedHeaders,
      width: widget.width,
      height: widget.height,
      fit: widget.fit,
      loadingBuilder: (_, child, progress) => progress == null ? child : (widget.placeholder ?? const EdenSpinner()),
      errorBuilder: (_, __, ___) => widget.errorWidget ?? const Icon(Icons.broken_image),
    );
  }
}
```
