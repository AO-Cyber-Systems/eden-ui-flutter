<objective>
Add `EdenIntakeForm` — generic branching questionnaire built on `eden_form_wizard`. Used by medical intake, legal client intake, government case intake, salon onboarding, retail loyalty signup.

**Question schema is declarative** (not a Form Builder). Caller passes a `List<EdenIntakeQuestion>`; widget renders them with conditional visibility, validation, and a final review step.
</objective>

## Test list (write FIRST)

**Happy path**
- Renders first question (text type) with placeholder + label.
- Typing into text question updates answers map.
- Advancing to next question stores current answer; cannot advance if `required: true` and answer is empty.
- After all questions answered, review step shows all Q&A pairs.
- Submit invokes `onComplete` with `Map<String, dynamic>` (questionId → answer).

**Question types**
- `text` → TextField.
- `longText` → multi-line TextField.
- `singleChoice` → RadioListTile per option.
- `multipleChoice` → CheckboxListTile per option; answer is `List<String>`.
- `number` → numeric keyboard TextField; answer is `num`.
- `date` → uses existing `eden_date_picker`.
- `yesNo` → 2-button segmented choice; answer is `bool`.

**Conditional branching**
- Question B has `visibleWhen: (answers) => answers['Q-A'] == 'yes'`. Q-B is NOT rendered if Q-A is 'no'; Q-A answer 'yes' makes Q-B visible on next step.

**Save and resume**
- `onPartialSave` callback fires on each step advance with current answers map.
- `initialAnswers: {...}` pre-fills the form (resume scenario).

**Failure / safety**
- iPhone-narrow safe.
- Validation summary at end lists questions with missing required answers; submit disabled until resolved.

```dart
class EdenIntakeForm extends StatefulWidget {
  const EdenIntakeForm({
    super.key,
    required this.questions,
    this.initialAnswers = const {},
    this.onPartialSave,                                            // ValueChanged<Map<String, dynamic>>?
    required this.onComplete,                                       // ValueChanged<Map<String, dynamic>>
    this.onCancel,
  });
  final List<EdenIntakeQuestion> questions;
  final Map<String, dynamic> initialAnswers;
  final ValueChanged<Map<String, dynamic>>? onPartialSave;
  final ValueChanged<Map<String, dynamic>> onComplete;
  final VoidCallback? onCancel;
}
```

Internal state: `_answers` map, `_currentIndex` int (index into visible questions). Visible-questions list recomputed on each `setState` from `widget.questions.where((q) => q.visibleWhen?.call(_answers) ?? true).toList()`.

Composes `eden_form_wizard` — but probably more natural to render a single-question-per-screen pattern with explicit Back/Next buttons because the wizard's step list is dynamic (visibleWhen).

Export to `lib/eden_ui.dart`. Dev catalog entry in `compound_screen.dart` showing 3 fixture demos.
