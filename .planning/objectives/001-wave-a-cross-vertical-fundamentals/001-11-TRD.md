<objective>
Add `EdenRoleDashboardShell` — role-specific home shell used as the landing screen for each user role across all verticals. Pattern donor: trades-react `client/src/components/forefront/*` (6 role panels: Head, Lead, Dispatcher, Tech, Admin, +Forefront-Appointment). Per `TRADES_REMAP_DEEP_AUDIT_2026-05-15.md` §5 — promoted from B-trades to Wave A because every vertical needs role-specific landing screens.

**Composition pattern:**
- Header strip: greeting (Good morning, {name}) + role label badge + avatar + optional notification icon row.
- Main area: configurable section grid. Caller supplies `List<EdenDashboardSection>`; widget arranges them in a responsive grid (2 cols at desktop, 1 col at mobile).
- Right rail (optional): collapsible slot for AI insights / quick-stat strip / activity feed.
</objective>

## Test list (write FIRST)

**Happy path**
- Renders header strip with greeting + roleLabel + avatar.
- Renders 4 sections in a 2-column grid at desktop width (1280pt).
- Renders right rail when `rightRail: Widget(...)` passed.
- Section onTap callback invoked when section is tapped (sections are full-card tappable).

**Role variants (string-driven, not enum)**
- `roleLabel: 'Dispatcher', rolePalette: trades` → orange tier palette on the role badge.
- `roleLabel: 'Doctor', rolePalette: medical` → blue tier palette.
- `roleLabel: 'Owner', rolePalette: salon` → brand-gold palette.
- `rolePalette: null` → default neutral palette.

**Sections**
- Empty sections list → renders header only (no grid).
- Section with `priority: high` renders at top with a 'New' or 'Action needed' indicator strip.
- Section body is freeform widget (can host a ListView, Chart, etc.).

**Edge / responsive**
- iPhone-narrow (390pt): sections stack vertically (1 col), right rail collapses to a bottom sheet trigger.
- Tablet (768pt): 2 cols if rightRail null, 1 col + rail if rightRail present.
