## Test list (write FIRST)

**EdenAddressInput**
- Renders 5 TextField fields: line1, line2 (optional), city, region/state, postal code.
- Renders an autocomplete dropdown at the top tied to line1 field.
- Typing in line1 (≥3 chars) calls `provider.autocompletePlaces(query)` and shows suggestions.
- Selecting a suggestion calls `provider.resolvePlace(placeId)` and populates all 5 fields from the returned EdenAddress.
- `onChanged` callback fires with current EdenAddress on every field edit.
- `initialAddress: EdenAddress(...)` pre-fills fields.
- `provider: NoOpMapProvider()` — autocomplete dropdown is hidden (no provider → no suggestions); fields still render and accept manual entry.

**EdenMapPreview**
- Calls `provider.showMap(bounds, markers)` and embeds the returned Widget.
- Renders SizedBox with given width/height; provider's widget fills it.
- `pinPicker: true` enables tap-to-set-pin; `onPinSet(EdenLatLng)` fires on tap.
- `provider: NoOpMapProvider()` — renders SizedBox.shrink wrapped in a placeholder card with 'Map unavailable' text.

**RecordingMapProvider (test double)**
- Records all method calls in an in-memory log accessible via `provider.recordedCalls`.
- Returns canned `EdenAddress` for `geocodeAddress` (configurable via constructor).
- Returns canned `List<EdenPlaceSuggestion>` for `autocompletePlaces` (configurable).
- `showMap` returns a deterministic test widget (e.g., `Container(key: ValueKey('recorded-map-${bounds.hashCode}'))`).

```dart
class RecordingMapProvider implements EdenMapProvider {
  RecordingMapProvider({
    this.cannedAddress,
    this.cannedSuggestions = const [],
  });

  final EdenAddress? cannedAddress;
  final List<EdenPlaceSuggestion> cannedSuggestions;
  final List<RecordedMapCall> _calls = [];

  List<RecordedMapCall> get recordedCalls => List.unmodifiable(_calls);

  void clear() => _calls.clear();

  @override
  Widget showMap({required EdenMapBounds bounds, ...}) {
    _calls.add(RecordedMapCall.showMap(bounds: bounds, markers: markers, interactive: interactive));
    return Container(key: ValueKey('recorded-map-${bounds.hashCode}'));
  }

  @override
  Future<EdenAddress?> geocodeAddress(String query) async {
    _calls.add(RecordedMapCall.geocodeAddress(query));
    return cannedAddress;
  }

  // ... other methods following the same record-then-return pattern
}

class RecordedMapCall {
  const RecordedMapCall._(this.method, this.arguments);
  factory RecordedMapCall.showMap({...}) => RecordedMapCall._('showMap', {...});
  factory RecordedMapCall.geocodeAddress(String query) => RecordedMapCall._('geocodeAddress', {'query': query});
  // ...
  final String method;
  final Map<String, dynamic> arguments;
}
```

```dart
class EdenMapPreview extends StatelessWidget {
  const EdenMapPreview({
    super.key,
    required this.provider,
    required this.bounds,
    this.markers = const [],
    this.width,
    this.height = 200,
    this.pinPicker = false,
    this.onPinSet,
    this.interactive = true,
    this.unavailableMessage = 'Map unavailable',
  });
  final EdenMapProvider provider;
  final EdenMapBounds bounds;
  final List<EdenMapMarker> markers;
  final double? width;
  final double height;
  final bool pinPicker;
  final ValueChanged<EdenLatLng>? onPinSet;
  final bool interactive;
  final String unavailableMessage;

  @override
  Widget build(BuildContext context) {
    if (provider is NoOpMapProvider) {
      return SizedBox(
        width: width,
        height: height,
        child: Card(
          child: Center(child: Text(unavailableMessage)),
        ),
      );
    }
    return SizedBox(
      width: width,
      height: height,
      child: provider.showMap(
        bounds: bounds,
        markers: markers,
        interactive: interactive,
        onTap: pinPicker ? onPinSet : null,
      ),
    );
  }
}
```
