<objective>
Add `EdenMembershipTierBadge` — a Chip-like badge denoting membership tier. Open-ended (any string label with custom palette) so it serves multiple verticals: salon membership (Bronze/Silver/Gold/Platinum), retail loyalty (Bronze/Silver/Gold/VIP), legal retainer (Active/On Hold/Lapsed), gov clearance (Public Trust / Secret / TS / TS-SCI — Wave C will repaint with classification palette).

Distinct from `EdenBadge` (already in lib) because:
- Tier-specific palette baked in (Bronze=brown, Silver=neutral, Gold=amber, Platinum=blue-grey, VIP=brand-primary).
- Optional crown/star/shield icon adornment per tier.
- Supports a custom tier (any label + palette override) for verticals that don't fit the preset set.
</objective>

## Test list (write FIRST)

**Happy path (preset tiers)**
- `EdenMembershipTierBadge(tier: EdenMembershipTier.bronze)` renders 'Bronze' label with brown palette.
- `tier: silver` renders 'Silver' with neutral grey palette.
- `tier: gold` renders 'Gold' with amber palette + star icon (default for gold).
- `tier: platinum` renders 'Platinum' with blue-grey palette + shield icon.
- `tier: vip` renders 'VIP' with brand-primary palette + crown icon.

**Custom tier**
- `EdenMembershipTierBadge.custom(label: 'Elite', backgroundColor: Colors.pink, foregroundColor: Colors.white)` renders 'Elite' with pink background.
- Custom with icon: `EdenMembershipTierBadge.custom(label: 'TS-SCI', icon: Icons.security, ...)` renders icon + label.

**Edge**
- `showIcon: false` on a preset tier hides the icon.
- Custom label longer than 20 chars truncates with ellipsis (single-line constraint).

**Failure / safety**
- Renders at iPhone-narrow (390pt) inside a Row of badges without overflow.

enum EdenMembershipTier { bronze, silver, gold, platinum, vip }

class EdenMembershipTierBadge extends StatelessWidget {
  /// Preset tier with built-in palette + icon.
  const EdenMembershipTierBadge({
    super.key,
    required EdenMembershipTier this.tier,
    this.showIcon = true,
  })  : _customLabel = null,
        _customBg = null,
        _customFg = null,
        _customIcon = null;

  /// Custom tier with caller-supplied palette.
  const EdenMembershipTierBadge.custom({
    super.key,
    required String label,
    required Color backgroundColor,
    required Color foregroundColor,
    IconData? icon,
  })  : tier = null,
        _customLabel = label,
        _customBg = backgroundColor,
        _customFg = foregroundColor,
        _customIcon = icon,
        showIcon = icon != null;

  final EdenMembershipTier? tier;
  final bool showIcon;
  final String? _customLabel;
  final Color? _customBg;
  final Color? _customFg;
  final IconData? _customIcon;

}
