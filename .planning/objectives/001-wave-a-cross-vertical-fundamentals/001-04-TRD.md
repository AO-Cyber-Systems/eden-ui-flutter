<objective>
Port trades-flutter `lib/shared/widgets/currency_display.dart` to eden-ui-flutter as `EdenCurrencyDisplay`. Locale-aware money rendering used by invoicing, POS, payroll, expenses, portal payments, fuel pricing, legal billing.

**Key enhancement over donor:** the trades donor hard-codes USD `$` symbol. Library version takes an optional `currencyCode` (ISO 4217: USD/EUR/GBP/CAD/AUD) and an optional `locale` (Locale or string like 'en_US') to drive the symbol + decimal-separator + thousand-separator choices. Defaults to USD + en_US for parity with the donor.
</objective>

## Test list (write FIRST)

**Happy path**
- `EdenCurrencyDisplay(cents: 12500)` renders '$125.00'.
- `EdenCurrencyDisplay(cents: -5000)` renders '-$50.00'.
- `EdenCurrencyDisplay(cents: 0)` renders '$0.00'.
- `EdenCurrencyDisplay(cents: 5000, showSign: true)` renders '+$50.00'.
- `EdenCurrencyDisplay(cents: 5000, showCents: false)` renders '$50'.
- `EdenCurrencyDisplay(cents: 1234500)` renders '$12,345.00' (thousands separator).
- `EdenCurrencyDisplay(cents: 12500, currencyCode: 'EUR')` renders '€125.00'.
- `EdenCurrencyDisplay(cents: 12500, currencyCode: 'GBP')` renders '£125.00'.

**Colorize**
- `colorize: true, cents: 5000` uses theme.colorScheme.primary (or positiveColor override).
- `colorize: true, cents: -5000` uses theme.colorScheme.error (or negativeColor override).
- `colorize: true, cents: 0` uses default text color (no override).

**Edge**
- Very large cents (1_000_000_00 = $1,000,000.00) renders correctly.
- Very small fractional cents not possible (cents is int); explicit overflow-of-int test deferred.

**Failure / safety**
- Renders inside narrow `SizedBox(width: 60)` without overflow (single Text auto-ellipsizes — test `softWrap: false, overflow: TextOverflow.ellipsis`).
