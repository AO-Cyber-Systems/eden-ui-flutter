## Test list (write FIRST)

**Happy path**
- Renders 4 action icons in a horizontal row.
- Tapping an action invokes its `onPressed` callback.
- Long-pressing an action shows its tooltip.
- Badge count > 0 renders a red dot with count on that action's icon.

**Overflow**
- With 8 actions at desktop width (1280pt): all 8 visible.
- With 8 actions at iPhone-narrow (390pt): 4 visible inline + 'More' PopupMenuButton showing the other 4.
- `maxInlineActions: 3` forces collapse-to-overflow after 3 actions regardless of width.

**Edge**
- Empty actions list → renders SizedBox.shrink (no chrome).
- Single action → renders inline; no overflow menu.
- Disabled action (onPressed null) shows greyed-out icon and ignores taps.

```dart
class EdenQuickActionBar extends StatelessWidget {
  const EdenQuickActionBar({
    super.key,
    required this.actions,
    this.maxInlineActions,                // null = compute from width
    this.height = 56.0,
    this.elevation = 4.0,
    this.padding = const EdgeInsets.symmetric(horizontal: 12),
  });
  final List<EdenQuickAction> actions;
  final int? maxInlineActions;
  final double height;
  final double elevation;
  final EdgeInsets padding;

  @override
  Widget build(BuildContext context) {
    if (actions.isEmpty) return const SizedBox.shrink();
    return LayoutBuilder(
      builder: (context, constraints) {
        final maxInline = maxInlineActions ?? (constraints.maxWidth / 56).floor() - 1;
        final inline = actions.take(maxInline).toList();
        final overflow = actions.skip(maxInline).toList();
        return Material(
          elevation: elevation,
          child: Container(
            height: height,
            padding: padding,
            child: Row(
              children: [
                ...inline.map((a) => _ActionButton(action: a)),
                if (overflow.isNotEmpty) PopupMenuButton<EdenQuickAction>(
                  icon: const Icon(Icons.more_horiz),
                  itemBuilder: (_) => overflow.map((a) => PopupMenuItem(value: a, enabled: a.onPressed != null, child: Row(children: [Icon(a.icon), const SizedBox(width: 8), Text(a.tooltip)]))).toList(),
                  onSelected: (a) => a.onPressed?.call(),
                ),
              ],
            ),
          ),
        );
      },
    );
  }
}
```

Inline action button uses `Stack` + `Badge` widget for the badge dot/count when badgeCount > 0. Use Flutter Material's built-in `Badge` widget.
