<objective>
Add `EdenConsentFlow` — explicit consent ladder above existing `eden_signature_pad` + `eden_form_wizard`. Used by medical (informed consent for procedures), legal (engagement agreements), gov (Privacy Act notices, attestation forms), fuel (hazmat acknowledgment), retail (return/refund agreements).

**Composition pattern (not a new widget tree from scratch):**
- Step 1..N: clause acceptance — Checkbox per clause + clause body text + optional 'I understand' affirmation requirement.
- Step N+1: primary signature — `eden_signature_pad`.
- Step N+2 (optional): witness signature — second `eden_signature_pad` with a witness-name TextField above.
- Step N+3: review — show all captured data + final 'Submit consent' button.

Transport-agnostic: emits a structured `EdenConsentRecord` value object via `onComplete` callback. Caller persists. Library does NOT make HTTP calls.
</objective>

## Test list (write FIRST)

**Happy path**
- Renders step 1 with 3 clauses; each has a Checkbox.
- Cannot advance to step 2 until all 3 clauses checked.
- After all clauses checked + advanced, signature step renders with eden_signature_pad.
- After signing + advancing (witness disabled), review step shows clauses + sig preview.
- 'Submit' button on review step invokes `onComplete` with an `EdenConsentRecord` containing clauses (List<EdenConsentClause>), signature (List<int> bytes), capturedAt (DateTime), and caller-supplied metadata Map.

**Witness flow**
- `requireWitness: true` adds witness step after primary signature.
- Witness step requires a non-empty witness name AND a non-empty witness signature.
- Resulting `EdenConsentRecord` includes `witnessName: String` + `witnessSignature: List<int>`.

**Edge**
- Single clause + no witness = minimal 3-step flow (clause → signature → review).
- Clause with `requireAffirmation: true` shows an extra 'I understand' confirmation under the checkbox.
- Back button on signature step returns to clauses with previous checkbox state preserved.

**Failure / safety**
- iPhone-narrow safe: clauses are scrollable; signature pad fills available width.
- Empty clauses list throws an `assert` (asserted in dev mode; ignored in release).
