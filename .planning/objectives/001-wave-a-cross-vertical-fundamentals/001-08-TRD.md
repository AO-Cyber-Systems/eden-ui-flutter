<objective>
Port trades-react `client/src/components/layout/NetworkStatusBar.tsx` to Flutter as `EdenNetworkStatusBar`. Top-of-app slim banner indicating connectivity status. **State-driven**: the library does NOT subscribe to `connectivity_plus` or any platform API; downstream apps own connectivity detection and pass the state in.

Donor inspection note: trades-react version is implemented with `useEffect` + `navigator.onLine`. Flutter version takes an `EdenNetworkStatus` enum and an optional retry-count integer + retry-callback. The widget renders nothing for `online` (no chrome cost when connection is fine).
</objective>

## Test list (write FIRST)

**Happy path**
- `status: online` → renders `SizedBox.shrink()` (no visible chrome).
- `status: offline` → renders red banner with 'No internet connection' text + Wi-Fi-off icon.
- `status: reconnecting` → renders amber banner with 'Reconnecting...' text + spinner.
- `status: syncing` → renders blue banner with 'Syncing changes...' text + optional progress indicator.

**Edge**
- `status: offline, retryButton: true, onRetry: cb` → banner has a Retry button; tap invokes cb.
- `status: reconnecting, attemptCount: 3` → text reads 'Reconnecting (attempt 3)...'.
- State transition online → offline → reconnecting → syncing → online: each transition animates in/out via SlideTransition; `tester.pump(milliseconds: 250)` advances animation.

**Failure / safety**
- iPhone-narrow (390pt): banner text + icon + retry button fit in one row without overflow.

class EdenNetworkStatusBar extends StatelessWidget {
  const EdenNetworkStatusBar({
    super.key,
    required this.status,
    this.attemptCount,
    this.retryButton = false,
    this.onRetry,
    this.height = 32.0,
  });
  final EdenNetworkStatus status;
  final int? attemptCount;
  final bool retryButton;
  final VoidCallback? onRetry;
  final double height;

  @override
  Widget build(BuildContext context) {
    if (status == EdenNetworkStatus.online) return const SizedBox.shrink();

    return AnimatedSwitcher(
      duration: const Duration(milliseconds: 200),
      transitionBuilder: (child, anim) => SlideTransition(
        position: Tween<Offset>(begin: const Offset(0, -1), end: Offset.zero).animate(anim),
        child: child,

    );
