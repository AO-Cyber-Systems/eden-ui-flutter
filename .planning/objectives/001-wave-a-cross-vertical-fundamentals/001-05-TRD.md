<objective>
Add two paired widgets:

1. `EdenPhoneInput` — international phone input with country picker (flag + ISO-3166 + dial-code) + masked text input. Format storage = E.164 (`+15551234567`). Transport-agnostic: surfaces a `verifyButton` slot and `onVerifyPressed` callback; library does NOT make HTTP/SMS calls.

2. `EdenOtpInput` — N-digit OTP code entry (default 6) with one input per digit, auto-advance focus on type, auto-back on delete, paste-spreads-across-digits behavior. Pattern donor: trades-react `client/src/components/ui/input-otp.tsx`.

Reused by: Wave C MFA (TRD outside this objective), SMS verify across all verticals, login/signup OTP flows.
</objective>

## Test list (write FIRST)

**EdenPhoneInput**
- Renders with placeholder + country picker showing default country (US 🇺🇸 +1).
- Typing '5551234567' formats as '(555) 123-4567' in US.
- Switching country to GB reformats input (+44 prefix).
- `onChanged` callback fires with E.164 string ('+15551234567').
- `verifyButton: true, onVerifyPressed: cb` shows a button; tapping invokes cb.
- `verifyButton: false` hides the button.
- iPhone-narrow (390pt): country picker collapses to flag-only (no dial code visible inline).
- Invalid number rendering (less than min digits): button (if shown) disabled OR error text below input.

**EdenOtpInput**
- Renders N=6 single-character inputs by default.
- Typing a digit auto-advances focus to next box.
- Pressing backspace on empty box moves focus back.
- Pasting '123456' fills all 6 boxes.
- `onChanged` fires with full string when all boxes are filled.
- `onSubmit` fires only when all N boxes are filled.
- Configurable length: `EdenOtpInput(length: 4)` renders 4 boxes.
