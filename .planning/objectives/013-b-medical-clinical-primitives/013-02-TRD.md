<objective>
Ship `EdenMedicationList` — a FHIR-shape medication list display widget for the left rail of medical Patient Chart screens. Per `VERTICAL_WIREFRAMES_VALIDATION_2026-05-17.md` §3.1 M1: "EdenListGroup is close but each row needs 4 metadata slots, not 2." `EdenDescriptionList` is row-per-fact (too verbose); `EdenListGroup` doesn't carry 4 metadata slots + inline badge. New widget needed.

Wave 1, parallel with 013-01, 013-03..013-05. Depends only on 013-01 for the `medical_screen.dart` file-create (serializes by appending a Section).

Outside-in test approach:
1. Single-row rendering (drug name, dose, route, frequency, prescriber visible).
2. Two-line layout test (bold line 1, caption line 2).
3. Interaction-flag rendering (EdenBadge.danger present when flag set).
4. Refill state (EdenBadge.warning when needsRefill).
5. Discontinued styling (strikethrough + neutral color).
6. Active/inactive filtering (showInactive=false excludes discontinued).
7. Multi-row realistic patient (polypharmacy elderly = 8 meds rendered, interaction warning on warfarin+aspirin).
8. Callback wiring (tap row → onMedicationTap fires with correct medication).
9. HIPAA isolation (mixed-patientId throws).
</objective>

<context>
**Design (locked):**

Value class (FHIR `MedicationStatement` shape, library-owned):
```dart
enum EdenMedicationStatus { active, paused, discontinued, completed }

enum EdenMedicationRoute { oral, injection, topical, inhaled, nasal, ophthalmic, otic, rectal, vaginal, sublingual, transdermal, other }

@immutable
class EdenMedicationStatement {
  const EdenMedicationStatement({
    required this.id,
    required this.patientId,         // HIPAA isolation key
    required this.drugName,          // 'Metformin'
    required this.doseLabel,         // '500mg' (free-form string; consumer formats)
    required this.route,
    required this.frequency,         // 'twice daily' | 'q8h' | 'PRN' — free-form
    this.prescriber,                 // 'Dr. Chen' — free-form
    this.startDate,
    this.endDate,
    this.status = EdenMedicationStatus.active,
    this.interactionWarning,         // String? — non-null triggers danger badge
    this.needsRefill = false,
    this.refillsRemaining,
    this.notes,
  });
  final String id;
  final String patientId;
  final String drugName;
  final String doseLabel;
  final EdenMedicationRoute route;
  final String frequency;
  final String? prescriber;
  final DateTime? startDate;
  final DateTime? endDate;
  final EdenMedicationStatus status;
  final String? interactionWarning;
  final bool needsRefill;
  final int? refillsRemaining;
  final String? notes;
}
```

Widget API:
```dart
EdenMedicationList({
  required List<EdenMedicationStatement> medications,
  String? patientId,
  bool showInactive = false,
  void Function(EdenMedicationStatement)? onMedicationTap,
  void Function(EdenMedicationStatement)? onDiscontinueTap,
  void Function(EdenMedicationStatement)? onRefillTap,
  EdgeInsetsGeometry? padding,
})
```

**Row layout:**
```
┌──────────────────────────────────────────────┐
│ Metformin 500mg PO                  [⚠ IXN]  │  line 1 bold; right-aligned badge
│ Twice daily · Dr. Chen · Since 2024-03-12    │  line 2 caption
│ [Refill needed]                              │  optional badge line if needsRefill
└──────────────────────────────────────────────┘
```

Route abbreviated for display: `oral → PO`, `injection → IV/IM/SC` (use 'IV' as default for injection), `topical → TOP`, `inhaled → INH`, `sublingual → SL`, `transdermal → TD`. Map in a `_routeAbbrev(EdenMedicationRoute)` private helper.

**Status styling:**
- `active` → default text color, normal weight.
- `paused` → italic, slightly faded (textTheme caption color).
- `discontinued` → strikethrough text + neutral color (Theme.disabledColor).
- `completed` → italic + neutral color.

**Filter:**
- Default (`showInactive: false`) → renders only `active` + `paused` statuses.
- `showInactive: true` → renders all statuses.

**Interaction warning:**
- `interactionWarning` is a free-form String like `'May increase bleeding risk with warfarin'`. Consumer (e.g. drug-drug interaction service in `eden-biz-flutter`) populates it.
- Renders right-aligned `EdenBadge.danger` with abbreviation `'IXN'` (interaction). On hover/long-press → tooltip with full text. (`Tooltip` widget native.)

**Refill state:**
- `needsRefill: true` → renders second-row `EdenBadge.warning` with label `'Refill needed'`. If `refillsRemaining == 0` → label becomes `'No refills left'`.

**HIPAA isolation:**
- `assert(medications.isEmpty || medications.every((m) => m.patientId == (patientId ?? medications.first.patientId)));`
- Same pattern as 013-01.

**Theme integration:**
- Compose `EdenBadge` (existing). Badge variant selection: `EdenBadge.danger` for IXN, `EdenBadge.warning` for refill.
- Use `Theme.of(context).textTheme.bodyMedium` for line 1, `.bodySmall` for line 2 caption.
- Border between rows: 1pt `Theme.of(context).dividerColor`.

**Performance:**
- Inner list uses `ListView.separated(shrinkWrap: true)` — fits inside the chart-rail Column without unbounded height.
- Long lists (≥50 meds): no virtualization in v1 — acceptable since clinical reality is rarely >20 active meds. (Note in TRD as future polish.)
</context>

## Test list (write FIRST)

**Single-row rendering**
- `EdenMedicationList(medications: [MedFixtures.metformin500])` renders 'Metformin 500mg PO' on line 1, 'Twice daily · Dr. Chen · Since 2024-03-12' on line 2.
- Drug name + dose rendered bold (TextStyle.fontWeight == FontWeight.w600 or bolder).
- Frequency + prescriber + startDate rendered in caption style (smaller font, lower contrast).

**Route abbreviation**
- `medications: [MedFixtures.metformin500]` (route: oral) → 'PO' renders, not 'oral'.
- `medications: [MedFixtures.insulinSc]` (route: injection) → 'SC' renders (consumer-set abbreviation rule: if frequency hint includes 'SC' or 'subcut', use 'SC'; else default to 'IV'). For v1: just always render 'IV' for injection. Test asserts 'IV' renders.
- `medications: [MedFixtures.albuterolInh]` (route: inhaled) → 'INH' renders.

**Interaction flag**
- `medications: [MedFixtures.aspirinWithWarfarinInteraction]` (interactionWarning='Increased bleeding risk') → finds EdenBadge with 'IXN' label OR equivalent danger badge inline.
- Tap or long-press triggers tooltip with full warning text (use `tester.longPress(find.byTooltip(...))` then assert overlay text).
- `medications: [MedFixtures.metformin500]` (no warning) → no IXN badge present.

**Refill state**
- `medications: [MedFixtures.lisinoprilNeedsRefill]` (needsRefill=true, refillsRemaining=2) → 'Refill needed' badge rendered.
- `medications: [MedFixtures.atorvastatinNoRefills]` (needsRefill=true, refillsRemaining=0) → 'No refills left' badge rendered.
- `medications: [MedFixtures.metformin500]` (needsRefill=false) → no refill badge.

**Status styling**
- `medications: [MedFixtures.discontinuedSertraline]` (status=discontinued) with `showInactive: true` → text rendered with strikethrough (TextStyle.decoration == TextDecoration.lineThrough).
- `medications: [MedFixtures.discontinuedSertraline]` with `showInactive: false` (default) → row NOT rendered (find.text('Sertraline') findsNothing).
- `medications: [MedFixtures.pausedOmeprazole]` (status=paused) → text rendered italic (TextStyle.fontStyle == FontStyle.italic).

**Multi-row realistic patient**
- `medications: MedFixtures.polypharmacyElderly` (8 active meds) → 8 rows rendered, find.byType row-widget count == 8.
- `medications: MedFixtures.t2dmHtnCombo` (3 meds: metformin + lisinopril + atorvastatin) → 3 rows; all active.
- `medications: MedFixtures.postOpPain` (2 meds: oxycodone 5mg PRN q6h + acetaminophen 650mg q6h) → 2 rows; oxycodone shows DEA controlled-substance handling via consumer-set `interactionWarning: 'Schedule II — monitor'`.

**Callback wiring**
- `onMedicationTap` fires with correct EdenMedicationStatement when row tapped: `tester.tap(find.text('Metformin 500mg PO'))` → callback invoked with `MedFixtures.metformin500`.
- `onDiscontinueTap` fires when discontinue affordance tapped (if rendered — could be in a row-action slot; defer to GREEN-phase decision).
- `onRefillTap` fires when refill badge tapped.

**Empty state**
- `medications: []` → renders 'No active medications' caption text.
- `medications: [MedFixtures.discontinuedSertraline]` with `showInactive: false` → renders empty-state text (filtered list is empty).

**HIPAA isolation**
- `medications: [MedFixtures.metforminPatient001, MedFixtures.lisinoprilPatient002]` → `expect(() => EdenMedicationList(medications: mixed), throwsA(isA<AssertionError>()))`.
- Same with explicit `patientId: 'pt-001'` → assertion fires.
- All-same-patient list → no exception, rows render.

**Catalog rendering**
- MedicalScreen smoke test: MedicationList section header visible, 4 scenarios render (polypharmacy elderly, single-med adult, post-op pain, T2DM+HTN).
