**Design (locked):**

Value class (FHIR `Condition` shape, library-owned):
```dart
enum EdenConditionStatus { active, resolved, inactive, recurrence }
enum EdenConditionVerification { provisional, differential, confirmed, refuted, enteredInError }

@immutable
class EdenCondition {
  const EdenCondition({
    required this.id,
    required this.patientId,
    required this.code,             // 'E11.9' (ICD-10)
    required this.codeSystem,       // 'ICD-10-CM' (default; SNOMED supported via string)
    required this.description,      // 'Type 2 diabetes mellitus without complications'
    required this.status,
    this.verification = EdenConditionVerification.confirmed,
    this.onsetDate,
    this.resolvedDate,
    this.diagnosedBy,               // 'Dr. Chen'
    this.severity,                  // 'mild' | 'moderate' | 'severe' — free-form
    this.notes,
  });
  final String id;
  final String patientId;
  final String code;
  final String codeSystem;
  final String description;
  final EdenConditionStatus status;
  final EdenConditionVerification verification;
  final DateTime? onsetDate;
  final DateTime? resolvedDate;
  final String? diagnosedBy;
  final String? severity;
  final String? notes;
}
```

Widget API:
```dart
EdenProblemList({
  required List<EdenCondition> conditions,
  String? patientId,
  bool showResolved = false,
  bool sortAscending = false,
  void Function(EdenCondition)? onProblemTap,
  void Function(EdenCondition)? onResolveTap,
  void Function(EdenCondition)? onRecurrenceTap,
  EdgeInsetsGeometry? padding,
})
```

**Row layout (similar to EdenMedicationList but ICD-10-first):**
```
┌──────────────────────────────────────────────┐
│ E11.9 — Type 2 diabetes mellitus  [Active]   │  line 1: code mono + description + status pill right
│ Onset 2022-08-14 · Dr. Chen                  │  line 2 caption
└──────────────────────────────────────────────┘
```

ICD-10 code rendered in monospace font (`fontFamily: 'JetBrainsMono'` with fallback). Description bold. Status pill (`EdenBadge` or fallback) right-aligned via `Spacer()` + Row.

**Status pill colors (via EdenStatusPalette):**
- `active` → warning (amber — ongoing problem demands attention).
- `recurrence` → danger (red — actively flaring).
- `resolved` → success (green — historical resolution).
- `inactive` → neutral.

**Verification status (optional sub-caption):**
- `confirmed` → no extra label.
- `provisional` → italic '(provisional)' after description.
- `differential` → italic '(differential dx)' after description.
- `refuted` → strikethrough description.
- `enteredInError` → strikethrough + neutral.

**Filtering:**
- `showResolved: false` (default) → renders only `active` + `recurrence`.
- `showResolved: true` → renders all four statuses.

**Sorting:**
- Default: sort by `onsetDate` descending (most recent first). Null `onsetDate` sorts last.
- `sortAscending: true` → reverse order.
- (No internal sort toggle in v1 — keep stateless. Sort affordance in scaffold is optional; consumer can toggle via param.)

**HIPAA isolation:** same pattern.
</context>

<gotchas>
- **ICD-10 code format:** dotted alphanumeric (`E11.9`, `I10`, `J44.9`). Don't strip dots. Render in monospace so codes align visually.
- **`EdenBadge` API:** same caveat as 013-02. If `EdenBadge.warning/.success/.neutral` exposed → use; else fall back to inline Container with palette token.
- **Verification status edge cases:** `enteredInError` is rare but real — chart-entry mistakes happen. Strikethrough + neutral handles it visually.
- **`onsetDate` null handling:** some conditions don't have known onset (e.g. chronic conditions discovered incidentally). Render line 2 as 'Onset unknown · Dr. Chen' rather than empty.
- **patientId assertion:** same pattern.
- **Empty list:** renders 'No active problems' caption text.
- **Test pairing.**
- **Fixture realism:** common ICD-10 codes — E11.9 (T2DM), I10 (essential hypertension), J44.9 (COPD), E78.5 (hyperlipidemia), F33.0 (mild recurrent MDD), M19.90 (osteoarthritis), N18.3 (CKD stage 3), G47.33 (OSA), K21.9 (GERD), Z79.4 (long-term use of insulin).
- **medical_screen.dart anchor:** append at `// ANCHOR: problem-list section`.
</gotchas>
