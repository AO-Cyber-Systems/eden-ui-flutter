<objective>
Ship `EdenAllergyList` — a FHIR-shape allergy/intolerance display for medical Patient Chart left-rail. Per `VERTICAL_WIREFRAMES_VALIDATION_2026-05-17.md` §3.1 M1: "EdenBadge.danger works for severity; the row container does not." Also: "medical wants a non-dismissible variant for allergy that EdenBlockingAlerts does not enforce."

**Distinct from `EdenMedicationList` per FHIR convention.** AllergyIntolerance is a separate FHIR resource type from MedicationStatement — same broad shape (drug/substance reference) but different display rules: severity-first (not dose-first), non-dismissible criticality banner, allergen-type icon prefix.

Wave 1, parallel with 013-01..013-05 (except sequential to 013-01 for medical_screen.dart file-create).

Outside-in test approach:
1. Single-row rendering (allergen + criticality + reaction + verified-by).
2. Severity color coding (severe = danger, moderate = warning, mild = neutral).
3. Criticality banner (renders at top when ANY criticality=high; non-dismissible).
4. Type icon prefix (medication = pill icon, food = apple, environmental = leaf).
5. Empty/NKDA state ('No known drug allergies' rendering).
6. Multi-allergy realistic patient.
7. Callback wiring.
8. HIPAA isolation.
</objective>

**Design (locked):**

Value class (FHIR `AllergyIntolerance` shape, library-owned):
```dart
enum EdenAllergenType { medication, food, environmental, biologic, other }
enum EdenAllergySeverity { mild, moderate, severe, lifeThreatening }
enum EdenAllergyCriticality { low, high, unable }
enum EdenAllergyClinicalStatus { active, inactive, resolved }
enum EdenAllergyVerificationStatus { unconfirmed, confirmed, refuted, enteredInError }

@immutable
class EdenAllergyIntolerance {
  const EdenAllergyIntolerance({
    required this.id,
    required this.patientId,
    required this.allergen,         // 'Penicillin', 'Peanuts', 'Latex'
    required this.type,
    required this.reaction,         // 'Anaphylaxis', 'Hives', 'GI upset' — free-form
    required this.severity,
    this.criticality = EdenAllergyCriticality.low,
    this.clinicalStatus = EdenAllergyClinicalStatus.active,
    this.verificationStatus = EdenAllergyVerificationStatus.confirmed,
    this.verifiedBy,                // 'Patient-reported' | 'Dr. Chen'
    this.onsetDate,
    this.notes,
  });
  final String id;
  final String patientId;
  final String allergen;
  final EdenAllergenType type;
  final String reaction;
  final EdenAllergySeverity severity;
  final EdenAllergyCriticality criticality;
  final EdenAllergyClinicalStatus clinicalStatus;
  final EdenAllergyVerificationStatus verificationStatus;
  final String? verifiedBy;
  final DateTime? onsetDate;
  final String? notes;
}
```

Widget API:
```dart
EdenAllergyList({
  required List<EdenAllergyIntolerance> allergies,
  String? patientId,
  bool showInactive = false,
  void Function(EdenAllergyIntolerance)? onAllergyTap,
  EdgeInsetsGeometry? padding,
})
```

**Top-of-widget criticality banner (non-dismissible):**
```
┌──────────────────────────────────────────────┐
│ ⚠ HIGH-CRITICALITY ALLERGIES — DO NOT GIVE   │  EdenAlert.danger (non-dismissible)
│   Penicillin (Anaphylaxis), Latex (Hives)    │
└──────────────────────────────────────────────┘
```

- Banner renders ONLY when ≥1 allergy in list has `criticality == high`.
- Banner lists allergen names + abbreviated reaction in parens.
- `EdenAlert.danger` if available with `dismissible: false` flag; else inline Container with danger surface + 1pt danger border (medical wants borders, not shadows).
- **No close button. No auto-hide. Renders as long as the criticality=high allergy is in the list.** This is the cannot-miss UX pattern.

**Row layout:**
```
┌──────────────────────────────────────────────┐
│ 💊 Penicillin                  [Anaphylaxis] │  line 1: icon + allergen bold + severity pill
│ Severe · Confirmed · Dr. Chen                │  line 2: severity + verification + verifiedBy
└──────────────────────────────────────────────┘
```

**Type icon prefix:**
- `medication` → `Icons.medication_outlined` (pill)
- `food` → `Icons.restaurant_outlined` (apple/fork)
- `environmental` → `Icons.eco_outlined` (leaf)
- `biologic` → `Icons.coronavirus_outlined` (microbe)
- `other` → `Icons.warning_amber_outlined`

**Severity pill colors:**
- `lifeThreatening` → danger (red), label 'Life-threatening'.
- `severe` → danger (red), label 'Severe'.
- `moderate` → warning (amber), label 'Moderate'.
- `mild` → neutral, label 'Mild'.

**Filtering:**
- Default (`showInactive: false`) → renders only `active` clinicalStatus.
- `showInactive: true` → renders all clinicalStatus values; inactive/resolved rendered with strikethrough.

**Verification status (line 2 prefix):**
- `confirmed` → 'Confirmed' literal.
- `unconfirmed` → 'Unconfirmed' italic.
- `refuted` → 'Refuted' strikethrough.
- `enteredInError` → 'In error' strikethrough + neutral.

**Empty / NKDA state:**
- `allergies: []` → renders 'No known drug allergies (NKDA)' caption text. This is medically standard language and significantly different from a generic 'no items' empty state.

**HIPAA isolation:** same pattern.

<gotchas>
- **NKDA is medically standard.** "No known drug allergies" — the actual phrase used in EHRs. Render verbatim. NOT a generic 'no items found.'
- **EdenAlert API:** check `lib/src/widgets/eden_alert.dart` for `dismissible: bool` flag. If `EdenAlert.danger(dismissible: false)` supported → use it. If not (e.g. all EdenAlerts are dismissible) → fall back to inline Container styled as alert. Test asserts NO close-button icon present (`find.byIcon(Icons.close)` findsNothing).
- **Criticality banner contents:** abbreviated. Don't render full reaction text — just allergen + (reaction in parens). 5+ allergies: render first 3 + '... (+N more)' to prevent banner from growing unbounded.
- **Severity vs criticality distinction:** FHIR distinguishes them. **Severity** = clinical impact of the reaction (mild/moderate/severe). **Criticality** = how dangerous this allergy is in clinical decision support (low/high/unable to assess). High-criticality drives the banner; severity drives the row pill color. They CAN differ (e.g. mild rash from penicillin = severity:mild, criticality:high if patient also has asthma making accidental exposure dangerous).
- **patientId assertion:** same pattern.
- **Empty list assert:** `find.text('No known drug allergies (NKDA)')` findsOneWidget when empty.
- **Test pairing.**
- **Fixture realism:** common drug allergies — penicillin (anaphylaxis), sulfa drugs (rash), codeine (nausea), latex (contact dermatitis), peanuts (anaphylaxis), shellfish (anaphylaxis), bee venom (anaphylaxis), iodine contrast (hives).
- **medical_screen.dart anchor:** append at `// ANCHOR: allergy-list section`.
