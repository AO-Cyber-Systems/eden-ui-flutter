<objective>
Ship `EdenVisitEncounterScaffold` — the during-appointment workflow page shell for medical Visit/Encounter screens. Per `VERTICAL_WIREFRAMES_VALIDATION_2026-05-17.md` §3.1 M2: chief complaint → SOAP composition → orders + e-prescribe → check-out. M2 was rated BLOCKED in the validation; this scaffold delivers the shell that unblocks it (3 of 4 step bodies — SOAP via 013-06, Orders via obj 012-01, Sign-off via obj 001 EdenConsentFlow — vitals capture and e-prescribe forms remain deferred per Out of Scope).

Wave 3, SECOND sequential capstone. Composes 013-06 (SOAP) + 013-08 context (the chart this visit lives within) + obj 012-01 (line items for orders/Rx) + obj 001 (consent + signature).

Per locked decision F: AI surface stays callback-driven. EdenSOAPNote already carries `aiSuggestionSlot` (013-06). This scaffold doesn't add a separate AI slot — it inherits via the SOAP step.

Outside-in test approach:
1. Full scaffold smoke (renders without exception with realistic fixture).
2. Step navigation (EdenWorkflowStepper transitions through 5 steps).
3. Chief Complaint step (EdenInput renders; onChange fires).
4. Vitals step (EdenVitalsRow visible OR fallback form).
5. SOAP step (EdenSOAPNote in compose mode visible).
6. Orders + Rx step (EdenLineItemEditor visible if obj 012 shipped; fallback form otherwise).
7. Sign-off step (EdenConsentFlow + EdenSignaturePad visible).
8. Blocking alerts rail (EdenBlockingAlerts visible across all steps).
9. Sign-off completion (onSignOff fires with full EdenVisitEncounterData).
10. HIPAA isolation across data + sub-widgets.
</objective>

Value class:
```dart
enum EdenVisitStep { chiefComplaint, vitals, soap, ordersAndRx, signOff }

@immutable
class EdenVisitOrder {
  // Generic order/Rx line item — adapts to EdenLineItemEditor (obj 012-01) when available
  const EdenVisitOrder({
    required this.id,
    required this.kind,             // 'lab' | 'imaging' | 'referral' | 'prescription' — free-form
    required this.description,      // 'CBC w/ diff' | 'Metformin 500mg' | 'Cardiology consult'
    required this.code,             // CPT/NDC/ICD-10 — consumer-supplied; library doesn't validate
    this.dose,                      // Rx only
    this.frequency,                 // Rx only
    this.quantity,                  // Rx only (qty dispensed)
    this.refills,                   // Rx only
    this.priority,                  // 'routine' | 'urgent' | 'stat'
    this.notes,
  });
  final String id;
  final String kind;
  final String description;
  final String code;
  final String? dose;
  final String? frequency;
  final int? quantity;
  final int? refills;
  final String? priority;
  final String? notes;
}

@immutable
class EdenVisitEncounterData {
  const EdenVisitEncounterData({
    required this.patientId,
    required this.encounterId,
    required this.encounterDate,
    required this.provider,         // 'Dr. Chen'
    required this.encounterType,    // 'Annual Physical' | 'URI Visit' | 'F/U T2DM'
    this.chiefComplaint = '',
    this.vitals = const <EdenVitalSign>[],   // pre-visit vitals (from triage) + re-captured
    this.soapNote,                  // EdenSoapNoteData? (013-06)
    this.orders = const <EdenVisitOrder>[],
    this.signedBy,
    this.signedAt,
    this.blockingAlerts = const [],
  });
  // ... fields
}
```
