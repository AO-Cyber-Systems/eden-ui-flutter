**Design (locked):**

Value class:
```dart
enum EdenChartEventCategory { encounter, lab, medication, note, order, vitalsCapture, allergy, problem, other }
enum EdenChartEventSeverity { routine, caution, critical, resolved }

@immutable
class EdenChartTimelineEvent {
  const EdenChartTimelineEvent({
    required this.id,
    required this.patientId,
    required this.category,
    required this.title,           // 'Annual Physical', 'CBC ordered', 'Started metformin'
    this.subtitle,                 // 'Dr. Chen', '5 results, 1 flagged H', '500mg twice daily'
    required this.occurredAt,
    this.severity = EdenChartEventSeverity.routine,
    this.provider,                 // 'Dr. Chen'
    this.relatedId,                // optional ID linking to source resource (lab result ID, etc.)
    this.notes,
  });
  final String id;
  final String patientId;
  final EdenChartEventCategory category;
  final String title;
  final String? subtitle;
  final DateTime occurredAt;
  final EdenChartEventSeverity severity;
  final String? provider;
  final String? relatedId;
  final String? notes;
}
```

Widget API:
```dart
EdenChartTimeline({
  required List<EdenChartTimelineEvent> events,
  String? patientId,
  Set<EdenChartEventCategory>? initialCategoryFilter,  // null = all categories visible
  Widget? aiInsightSlot,                                // consumer plugs in summarization widget
  void Function(EdenChartTimelineEvent)? onEventTap,
  EdgeInsetsGeometry? padding,
})
```

**Severity tinting:**
- `critical` → row background = `EdenStatusPalette.danger.surface` (red wash).
- `caution` → warning surface (amber wash).
- `resolved` → success surface (green wash, very subtle).
- `routine` → neutral surface (default — no special tinting).

**Category icons (composes EdenActivityFeedItem icon slot or wraps with prefix Icon):**
- `encounter` → `Icons.medical_services_outlined`
- `lab` → `Icons.science_outlined`
- `medication` → `Icons.medication_outlined`
- `note` → `Icons.description_outlined`
- `order` → `Icons.assignment_outlined`
- `vitalsCapture` → `Icons.monitor_heart_outlined`
- `allergy` → `Icons.warning_amber_outlined`
- `problem` → `Icons.report_problem_outlined`
- `other` → `Icons.circle_outlined`

**Category filter chips:**
- Top row of widget. `EdenChip` (existing widget, confirm `selected: bool` API) OR raw `FilterChip`.
- 'All' chip toggles all on/off. Other chips multi-select.
- State managed internally via StatefulWidget (`_activeFilters: Set<EdenChartEventCategory>`).
- `initialCategoryFilter` seeds initial state.

**Date grouping logic:**
- Group events by day (date string).
- Date header format depends on age:
  - Today → 'Today'.
  - Yesterday → 'Yesterday'.
  - Within 7 days → '{N} days ago ({date})'.
  - Within 30 days → '{N} days ago ({date})'.
  - Within 12 months → '{date}'.
  - **Older than 12 months** → quarterly bucketing: '2024 Q2', '2024 Q1', '2023 Q4', etc. Events within the same quarter clustered under one header. (Compression.)

**Multi-year compression:**
- When ANY event in list has `occurredAt < (now - 12mo)`, switches the older portion to quarterly headers.
- Recent portion (<12mo) keeps day-level headers.
- Boundary handled in `_groupByDate(events)` helper.

**EdenActivityFeedItem composition:**
- Check `lib/src/widgets/eden_activity_feed_item.dart` for API.
- If accepts `icon`, `title`, `subtitle`, `metadata` → wrap with severity tint via Container background.
- If API differs significantly → render inline 2-line row directly (don't force-compose).

**AI insight slot:**
- Rendered between filter chips and timeline list when `aiInsightSlot != null`.
- Consumer plugs in `EdenAiPanel(insights: ['Pattern: BP rising trend over 3 months', ...])` or similar from obj 003.

**Performance:**
- Use `ListView.builder` for events list — supports virtualization for long histories.
- Event count likely 100-500 for a chronic patient over 5y. Acceptable.

**HIPAA isolation:** same pattern.

**Cross-vertical note:** the widget is medical-flavored but the value class (`EdenChartTimelineEvent` with category enum) is general enough that gov caseworker case histories or legal matter timelines could re-use it. Not a v1 concern; document for future generalization.
