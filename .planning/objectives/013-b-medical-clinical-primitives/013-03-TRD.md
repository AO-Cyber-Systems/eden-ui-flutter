<objective>
Ship `EdenLabResultTable` — a compact clinical-density lab results table for medical Patient Chart Labs tab. Per `VERTICAL_WIREFRAMES_VALIDATION_2026-05-17.md` §3.1 M1: `EdenDataTable.dense` covers the table shape but lacks (a) inline trend sparkline cell type, (b) flag badge column type, (c) group-by-panel row grouping. This TRD adds all three via a dedicated widget that composes `EdenDataTable.dense` + `EdenSparkline` (obj 012-07).

Wave 1, parallel with 013-01, 013-02, 013-04, 013-05. Depends only on 013-01 for `medical_screen.dart` file-create.

**Obj 012 dependency:** `EdenSparkline` (obj 012-07) is the inline trend cell renderer. If obj 012 hasn't shipped at execution time, executor should:
1. Check `lib/src/widgets/eden_sparkline.dart` exists (look for export in eden_ui.dart).
2. If present: compose it for the trend cell.
3. If absent: render trend as numeric delta `'+5 ↑'` (mock fallback). Pair with TODO comment + tag-only test (`skip: !sparklineAvailable`) for the sparkline-specific assertions.

Outside-in test approach:
1. Single-row rendering (test name + value + unit + reference-range columns).
2. Flag column (H/L/HH/LL renders + color tinting).
3. Trend sparkline cell (or fallback numeric delta).
4. Panel grouping (groupByPanel=true renders panel-name headers).
5. Sortable columns (tap header re-orders rows).
6. Multi-panel realistic patient (CBC + CMP + Lipid panel = 18+ rows).
7. HIPAA isolation.
</objective>

<context>
**Design (locked):**

Value class (FHIR `Observation` shape, library-owned):
```dart
enum EdenLabFlag { normal, high, low, criticalHigh, criticalLow }

@immutable
class EdenLabResult {
  const EdenLabResult({
    required this.id,
    required this.patientId,        // HIPAA isolation key
    required this.testName,         // 'Hemoglobin' | 'Glucose' | 'LDL Cholesterol'
    required this.testCode,         // 'HGB' | 'GLU' | 'LDL' — short code for compact display
    required this.value,            // double
    required this.unit,             // 'g/dL' | 'mg/dL' | 'mmol/L'
    this.referenceMin,
    this.referenceMax,
    this.criticalMin,
    this.criticalMax,
    this.flag = EdenLabFlag.normal,
    required this.collectedAt,      // DateTime
    this.panelName,                 // 'CBC' | 'CMP' | 'Lipid Panel' — null for one-offs
    this.trendValues,               // List<double>? — prior values for sparkline (newest last)
    this.notes,
  });
  final String id;
  final String patientId;
  final String testName;
  final String testCode;
  final double value;
  final String unit;
  final double? referenceMin;
  final double? referenceMax;
  final double? criticalMin;
  final double? criticalMax;
  final EdenLabFlag flag;
  final DateTime collectedAt;
  final String? panelName;
  final List<double>? trendValues;
  final String? notes;
}
```

Widget API:
```dart
EdenLabResultTable({
  required List<EdenLabResult> results,
  String? patientId,
  bool groupByPanel = false,
  bool showSparkline = true,
  void Function(EdenLabResult)? onResultTap,
  EdgeInsetsGeometry? padding,
})
```

**Column layout:**
| Test (60pt) | Value (60pt mono) | Unit (60pt) | Ref Range (90pt) | Flag (40pt) | Date (80pt) | Trend (80pt sparkline) |

Total: ~470pt — fits Patient Chart Labs tab center pane. On iPhone-narrow (390pt): wrap in `SingleChildScrollView(scrollDirection: Axis.horizontal)`.

**Flag rendering:**
- `normal` → empty cell (no badge).
- `high` → `'H'` letter in `EdenStatusPalette.warning` color (amber).
- `low` → `'L'` in warning color.
- `criticalHigh` → `'HH'` in `EdenStatusPalette.danger` (red).
- `criticalLow` → `'LL'` in danger color.

Optional: auto-compute flag from value + reference range if `flag == normal` and `value` outside `[referenceMin, referenceMax]`. Prefer explicit flag from consumer.

**Trend sparkline cell:**
- Compose `EdenSparkline(values: result.trendValues + [result.value], height: 24, animate: false)` (obj 012-07 API — adapt at integration time).
- If `trendValues == null` OR `EdenSparkline` unavailable → render `'—'` (no data).
- Fallback numeric delta when sparkline unavailable: `'+5 ↑'` if last trendValue + 5 ≤ current, etc.

**Panel grouping:**
- `groupByPanel: false` (default) → flat list, sorted by collectedAt descending.
- `groupByPanel: true` → cluster by panelName; render panel-name header above each cluster (`Text('CBC', style: bodyMedium.bold)` + thin divider).
- Within panel: order by canonical lab order (CBC: WBC, RBC, Hgb, Hct, Plt; CMP: Na, K, Cl, CO2, BUN, Cr, Glu; Lipid: TC, LDL, HDL, TG). Use `_canonicalOrder(panelName, testCode)` helper map.

**Sortable columns:**
- Tap column header → toggle sort by that column (asc/desc).
- Sort state managed internally via StatefulWidget (private `_sortColumn` + `_ascending`).
- Date column default sort, descending.

**Compose `EdenDataTable.dense`:**
- Check obj 010-06's API for `EdenDataTable.dense` constructor.
- If `EdenDataTable.dense` exposes a `cellBuilder` slot → use it for Flag + Trend cells.
- If not (i.e. it requires `DataCell` widgets): wrap directly in Material `DataTable` with custom column spacing.

**HIPAA isolation:** same pattern.

**EdenStatusPalette / fallback:** same pattern as 013-01.
</context>
