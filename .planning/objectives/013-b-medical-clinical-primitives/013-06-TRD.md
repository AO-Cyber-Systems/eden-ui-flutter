<objective>
Ship `EdenSOAPNote` — the SOAP-note (Subjective / Objective / Assessment / Plan) four-section composer and viewer for medical Visit/Encounter screens. Per `VERTICAL_COVERAGE_ASSESSMENT_2026-05-15.md` §6 locked decision 5: "generic shell + template plug-in slot. Library stays transport- and domain-agnostic; downstream apps supply their own templates." Per `VERTICAL_UX_RESEARCH_2026-05-16.md` §1.4: SOAP is the unit of clinical documentation; structured form with template snippets, voice-input target zones, AI-suggested completions.

Wave 2, parallel with 013-07. Depends only on 013-01 for `medical_screen.dart` file existence. Composes obj 001 `EdenSignaturePad` for sign-off (optional; consumer can also drive via callback).

Per locked decision F (`COMPANION_UX_PATTERNS_2026-05-15.md` §0): AI surface stays **callback-driven**. Library does NOT ship `speech_to_text`, AI streaming, or template registries. Library exposes slots; consumer (medical app) plugs in concrete widgets.

Outside-in test approach:
1. Four-section rendering (compose mode: 4 editable TextField/RichTextEditor for S/O/A/P).
2. View mode (read-only render of all 4 sections + optional signed-by/signed-at caption).
3. Mode switch (compose → view via param flip).
4. Template-slot injection (sectionToolbarSlot param passes through to each section header).
5. AI suggestion slot injection (aiSuggestionSlot Widget rendered in right column when non-null).
6. Voice input slot per section.
7. Callback wiring (onChanged fires with full EdenSoapNoteData on each section edit; onSign fires with note data).
8. Sign-off composition (compose EdenSignaturePad; assert sign button → onSign fires).
9. HIPAA isolation (patientId on EdenSoapNoteData must match passed param).
</objective>

<context>
**Design (locked):**

Value class:
```dart
enum EdenSoapMode { compose, view }

@immutable
class EdenSoapNoteData {
  const EdenSoapNoteData({
    required this.patientId,
    this.subjective = '',
    this.objective = '',
    this.assessment = '',
    this.plan = '',
    this.signedBy,
    this.signedAt,
    this.encounterId,
    this.providerId,
  });
  final String patientId;
  final String subjective;
  final String objective;
  final String assessment;
  final String plan;
  final String? signedBy;        // 'Dr. Chen (NPI 1234567890)'
  final DateTime? signedAt;
  final String? encounterId;     // optional consumer-set link to backend encounter
  final String? providerId;      // optional consumer-set provider ID

  EdenSoapNoteData copyWith({...}) => EdenSoapNoteData(...);  // standard copyWith
}
```

Widget API:
```dart
EdenSOAPNote({
  required EdenSoapNoteData data,
  required String patientId,             // explicit — HIPAA isolation key (must match data.patientId)
  EdenSoapMode mode = EdenSoapMode.compose,
  void Function(EdenSoapNoteData)? onChanged,
  void Function(EdenSoapNoteData)? onSign,
  Widget? Function(String sectionName)? sectionToolbarSlotBuilder,  // template injector per section
  Widget? Function(String sectionName)? voiceInputSlotBuilder,      // speech-to-text affordance per section
  Widget? aiSuggestionSlot,             // EdenAiPanel from obj 003, plugged in by consumer
  Widget? signaturePadSlot,             // EdenSignaturePad from obj 001, plugged in by consumer (mode=view shows signed state if signedBy != null)
  EdgeInsetsGeometry? padding,
})
```

**Layout (compose mode):**
```
┌──────────────────────────────────────────────────────┐
│ Subjective                              [template ▾] │ section header + toolbar slot
│ ┌──────────────────────────────────────────────────┐ │
│ │ [TextField multiline — patient's chief complaint │ │
│ │  + HPI + ROS]                                    │ │
│ └──────────────────────────────────────────────────┘ │
│ [🎤 voice input]                                     │ voiceInputSlot
├──────────────────────────────────────────────────────┤
│ Objective                               [template ▾] │
│ ┌──────────────────────────────────────────────────┐ │
│ │ [TextField — vitals, exam findings]              │ │
│ └──────────────────────────────────────────────────┘ │
│ [🎤 voice input]                                     │
├──────────────────────────────────────────────────────┤
│ Assessment                              [template ▾] │
│ ┌──────────────────────────────────────────────────┐ │
│ │ [TextField — diagnoses, ICD-10s]                 │ │
│ └──────────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────┤
│ Plan                                    [template ▾] │
│ ┌──────────────────────────────────────────────────┐ │

│ └──────────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────┤
│              [signaturePadSlot]                      │
└──────────────────────────────────────────────────────┘
```

Right column (when `aiSuggestionSlot != null`): renders alongside main column in a Row on Expanded tier (≥840pt); stacks vertically on Compact (390pt) tier. Use `LayoutBuilder` for tier detection (don't import EdenAdaptiveLayout to avoid coupling).

**Layout (view mode):**
- Each section header + read-only text (use `SelectableText` so providers can copy values).
- 'Signed by Dr. Chen on 2026-05-17 14:32' caption below Plan section.
- No toolbar slots, no voice slots, no signature pad. Strictly read-only.

**Section toolbar slot:**
- `sectionToolbarSlotBuilder('subjective')` returns Widget for the Subjective header right side.
- Consumer plugs in `PopupMenuButton` with template list ('Cough', 'Headache HPI', 'Annual physical ROS'). Library doesn't ship templates.
- Same builder called for 'objective', 'assessment', 'plan'.

**Voice input slot:**
- `voiceInputSlotBuilder('subjective')` returns Widget below the Subjective TextField.
- Consumer plugs in mic button wired to `speech_to_text` plugin in `eden-biz-flutter`.

**AI suggestion slot:**
- Renders in right column on Expanded; below Plan section on Compact.
- Consumer (medical app) passes `EdenAiPanel(insights: ..., persona: ...)` from obj 003.

**Sign-off:**
- `signaturePadSlot` passed in by consumer. Consumer typically passes `EdenSignaturePad(onSign: (sig) => onSignCallback(...))`.
- If `mode: view` and `data.signedBy != null` → signaturePadSlot ignored; render 'Signed by {signedBy} on {signedAt}' caption.
- `onSign` callback fires when signature captured (consumer-driven).

**HIPAA isolation:**
- `assert(data.patientId == patientId);` in constructor.
- Throws AssertionError in debug if mismatched.

**TextField vs EdenRichTextEditor:**
- Check `lib/src/widgets/eden_rich_text_editor.dart` for API. If accepts `value` + `onChanged` cleanly → use it for compose mode.
- Else fall back to `TextField(maxLines: null, controller: TextEditingController(text: section.value))`.
- Use one TextEditingController per section, managed in `_EdenSOAPNoteState`.
- Don't ship a Quill / flutter_quill dep — out of scope per no-new-deps constraint.

**onChanged debouncing:**
- Don't fire `onChanged` on every keystroke. Debounce 250ms.
- Or: fire on focus loss + on explicit save action. Pick one in GREEN-phase based on `TextField.onSubmitted` vs `onChanged` Flutter behavior.
- For v1: fire on every change (simpler, consumer can debounce upstream). Document in TRD body.

## Test list (write FIRST)

**Four-section rendering (compose mode)**
- `EdenSOAPNote(data: SoapFixtures.empty, patientId: 'pt-001', mode: compose)` renders 4 section headers: 'Subjective', 'Objective', 'Assessment', 'Plan'.
- 4 TextFields rendered (`find.byType(TextField)` count == 4) OR 4 EdenRichTextEditors (`find.byType(EdenRichTextEditor)` count == 4 — pick based on availability at GREEN time).
- All 4 fields empty initially.

**Compose mode editing**
- Enter text in Subjective TextField → `onChanged` callback fires with `EdenSoapNoteData(subjective: 'entered text', objective: '', ...)`.
- Edit Objective, then Assessment → each edit fires onChanged with cumulative state preserving prior sections.

**View mode rendering**
- `EdenSOAPNote(data: SoapFixtures.annualPhysicalSigned, patientId: 'pt-001', mode: view)` renders 4 sections in read-only mode (no TextFields; find.byType(TextField) findsNothing OR finds none in EDIT state).
- Sections rendered as SelectableText.
- 'Signed by Dr. Chen on {date}' caption visible.
- `mode: view, data.signedBy == null` → 'Unsigned draft' caption visible.

**Template toolbar slot injection**
- `sectionToolbarSlotBuilder` provided: `(section) => Text('toolbar-$section')`. Each section header right side shows 'toolbar-subjective', 'toolbar-objective', etc. find.text('toolbar-subjective') findsOneWidget.
- `sectionToolbarSlotBuilder: null` → no toolbar widgets rendered.

**Voice input slot injection**
- `voiceInputSlotBuilder` provided: `(section) => Icon(Icons.mic)`. Each section renders mic icon below its TextField. find.byIcon(Icons.mic) finds 4 widgets.

**AI suggestion slot**
- `aiSuggestionSlot: Container(key: Key('ai-panel'))` provided. Wrap in SizedBox(width: 1200) (Expanded tier) → key('ai-panel') findsOneWidget, layout Row found at root with main column + ai column.
- Wrap in SizedBox(width: 390) (Compact tier) → key('ai-panel') findsOneWidget, layout Column found (stacked vertically).
- `aiSuggestionSlot: null` → no ai-panel widget present, no extra column.

**Sign-off integration**
- `signaturePadSlot: EdenSignaturePad(onSign: ...)` provided. SignaturePad widget renders below Plan section.
- Tap-and-drag signature gesture on the pad → `onSign` callback fires (driven by EdenSignaturePad).
- `mode: view` + `data.signedBy: 'Dr. Chen'` + `signaturePadSlot: <anything>` → signature pad NOT rendered; 'Signed by Dr. Chen' caption renders instead.

**Multi-scenario fixtures**
- `data: SoapFixtures.annualPhysicalDraft` (partial: S+O filled, A+P empty) → 4 TextFields, S+O pre-populated.
- `data: SoapFixtures.uriVisitSigned` (all 4 filled + signed) in view mode → 4 SelectableText with signed caption.
- `data: SoapFixtures.t2dmFollowUp` in compose mode → 4 TextFields with content.

**HIPAA isolation**
- `EdenSOAPNote(data: SoapFixtures.annualPhysicalDraft, patientId: 'pt-002', ...)` where data.patientId='pt-001' → `expect(() => ..., throwsA(isA<AssertionError>()))` in debug.
- Matching patientId → no exception.

**Catalog rendering**
- MedicalScreen smoke test: SOAPNote section renders 3 scenarios (empty compose, partial compose, signed view).
