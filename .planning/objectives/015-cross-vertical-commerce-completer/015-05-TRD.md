<anti_patterns>
- **Do NOT auto-clock-out on app close.** That's a consumer/platform concern. The library only emits events; storing the clock state is downstream.
- **Do NOT use per-frame `setState`.** Live elapsed-time uses `Timer.periodic(Duration(seconds: 30))` — battery-friendly minute-precision is the spec.
- **Do NOT block PIN retry after a failed attempt.** Clear the OTP input and let the user re-enter. Rate-limiting / lock-out is a platform concern.
- **Do NOT compose EdenApprovalQueue for the time card.** Bespoke row layout is cleaner for time-card semantics (worked-hours display, breaks, dispute states).
- **Do NOT use property-based testing** (`no_property_based_default`).
- **Do NOT emit Gherkin** (`no_gherkin_layer`).
- **Do NOT accept LLM-generated fixtures** (`no_llm_test_data`).
</anti_patterns>

<gotchas>
- **EdenOtpInput.onCompleted vs onChanged.** `onCompleted` fires once when all digits are filled. Use `onCompleted` to trigger `onResolveStaff` — not `onChanged`. This avoids racing the auth callback on every digit.
- **PIN clear after failure.** Use a `GlobalKey<EdenOtpInputState>` or `TextEditingController` reference to clear; check the existing eden_otp_input.dart API for the clear() method.
- **Timer cleanup.** Dispose the Timer in dispose(). Forgetting this leaks the widget after navigation.
- **didUpdateWidget for activeSession change.** When parent flips `activeSession` from null → non-null (clock-in succeeded), don't double-emit. Treat the prop as the source of truth post-resolve; the library emits the clockIn event ONCE on successful resolve.
- **Open-shift elapsed-time accuracy.** `DateTime.now().difference(entry.clockedInAt) - entry.breaksAccumulated` for the rendered duration. At-rest, this is 30s-precision (via Timer); not real-time.
- **staff_screen.dart APPEND anchor.** 015-04 inserts `// TRD 015-05 appends here ↓ EdenTimeClock + EdenTimeCard` BELOW the CommissionsEditor section. This TRD inserts both new Sections BEFORE the anchor; the anchor stays in place so subsequent TRDs (none in 015 — but future objectives) can append AFTER.
- **lib/eden_ui.dart Wave 2 section.** Idempotent — check for the existing Wave 2 header line; only add the section comment if absent. Then add `export 'src/widgets/eden_time_clock.dart';` and `export 'src/widgets/eden_time_card.dart';`.
</gotchas>
