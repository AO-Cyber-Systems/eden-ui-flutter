<anti_patterns>
- **Do NOT compute the report inside the widget.** The full EdenShiftReport is consumer-provided (computed from backend sales data). Library renders only.
- **Do NOT call platform print APIs.** All distribution is callback-based.
- **Do NOT block confirm when no distribution channels selected.** 'Skip distribution' is a valid path; CONFIRM accepts an empty distributedTo set.
- **Do NOT mutate reportSnapshot.** It's immutable — passed through unchanged to the result.
- **Do NOT use property-based testing** (`no_property_based_default`).
- **Do NOT emit Gherkin** (`no_gherkin_layer`).
- **Do NOT accept LLM-generated fixtures** (`no_llm_test_data`).
</anti_patterns>

<gotchas>
- **printFriendly stripping.** Iterate over the widget tree assertions carefully — Material theme injects background colors via Scaffold; the test should mount via wrap() without Scaffold, OR use `find.descendant(of: find.byType(EdenXZReport), matching: find.byType(Container))` and check that inner containers don't have non-white colors.
- **distributedTo Set ordering.** Use `Set<EdenShiftCloseDistribution>` (not List) so duplicate taps don't add duplicates. Tests assert `result.distributedTo.contains(...)`.
- **Inner widget step state.** EdenCashDrawerClose's internal step state is independent of EdenShiftClose's step state. When the inner onSubmit fires, the outer advances; the inner widget re-mounts the next time the outer revisits drawerClose (rare — only if user taps Back from REPORTPREVIEW).
- **EdenAggregateKpiStrip composition.** obj 012-02 ships this. For the XZReport Summary section, use it (4 tiles: gross/net/tax/tips). Verify import path + KPI tile shape at execute time.
