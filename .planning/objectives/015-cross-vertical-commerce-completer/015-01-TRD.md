<anti_patterns>
- **Do NOT include a 'Submit' button.** Real-time onDraftChanged emits every change. Consumer renders submit UI separately. This mirrors EdenPaymentEntry (obj 012-03) and EdenLineItemEditor (obj 012-01).
- **Do NOT validate that tipAmount > 0.** "$0 tip" is a valid state (selectedPercent=null, mode=none).
- **Do NOT format the custom-amount field as currency on every keystroke.** Cursor-jumping is unfixable when the formatter rewrites text mid-edit. Show raw decimal in the field; computed-tip preview formats via EdenCurrencyDisplay.
- **Do NOT auto-rebalance ALL rows on slider drag.** Use the locked-row pattern (last-modified row absorbs delta) per Mangomint UX. Auto-rebalance across N rows feels random to operators.
- **Do NOT bind to specific verticals.** The presets enum is salon/restaurant/retail-flavored but the widget itself never references those domains.
- **Do NOT introduce a new intl import.** Currency formatting goes through existing `EdenCurrencyDisplay` only.
- **Do NOT use property-based testing** (no rapid/gopter/Hypothesis). Per resolved constraint `no_property_based_default` — descriptive test names cover the cases.
- **Do NOT emit .feature files** (no Gherkin). Per resolved constraint `no_gherkin_layer`.
- **Do NOT accept LLM-generated test data.** Hand-built fixtures only. Per resolved constraint `no_llm_test_data`.
</anti_patterns>

<gotchas>
- **Custom-amount field focus.** When tapping a preset chip while the custom-amount field has focus, unfocus FIRST via `FocusScope.of(context).unfocus()`, then set the preset. Order matters or the keyboard re-pops.
- **Percent precision.** Store percent as double 0.0..1.0 (NOT 0..100). The label is the human-readable form; the percent is the math. EdenTipDraft.selectedPercent is 0.18 for "18%".
- **Sum-tolerance.** Use `(sum - 100.0).abs() > 0.01` for percent-mode sum check; `(sum - totalTip).abs() > 0.01` for dollar-mode. This mirrors EdenSplitTender's tolerance (obj 012-04).
- **Last-modified-row tracking.** Maintain `int? _lastModifiedIndex` in state; on slider drag of row N, the delta absorbs into the OTHER index that was last modified (default: pick the next-to-last row in initial state).
- **Theme-profile resolution.** When `Theme.of(context).extension<EdenStatusPalette>()` returns null (no profile attached), fall back to `EdenStatusPalette.commercial()` factory; this matches the pattern in `eden_split_tender.dart`.
