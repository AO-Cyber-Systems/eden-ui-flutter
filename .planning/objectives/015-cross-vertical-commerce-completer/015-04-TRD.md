<objective>
Ship `EdenCommissionsEditor` — the generic commission-rules editor that 3 verticals (salon stylists, retail employees, trades technicians) need to configure pay-out. Supports 4 modes: **percent** (flat % of qualifying sale), **fixed** (flat dollars per sale), **tiered** (% varies by sale-amount threshold), **split** (allocation across 2+ participants summing to 100%).

Per `USE_CASES_SALON_2026-05-17.md` SALON-046 `EdenCommissionStructureEditor` (PARTIAL → FULL after this TRD ships) + `USE_CASES_RETAIL_2026-05-17.md` UC-39 (`EdenCommissionRateEditor` absent; Lightspeed sells it via "Workforce" addon) + `USE_CASES_TRADES_2026-05-17.md` UC-58 BLOCKED + §5 Recommendation #6 ("commissions editor is a parity gap with ServiceTitan + Workiz").

Wave 1, parallel with 015-01 (Tipping). **This TRD bootstraps `lib/dev_app/screens/staff_screen.dart`** (NEW file). 015-05 (TimeClock+TimeCard) appends to it in Wave 2.

Outside-in test approach: widget rendering per mode → mode-switch field-clearing → field-emission → tier add/remove → split sum banner → responsive → a11y.

One test at a time per Habit 3.
</objective>

<gotchas>
- **Tier sort on emit.** When user adds tier with threshold 500 in front of an existing 1000-tier, the visible UI keeps insertion order BUT the emitted list is sorted ascending. Maintain `_displayOrder: List<EdenCommissionTier>` in state separately from the emitted order.
- **Split sharePercent representation.** Store as fraction 0..1 (0.80 for 80%). The display field shows percent×100 (so user sees "80"); convert on the boundary.
- **EdenSegmentedControl 4-segment overflow at 390pt.** 4 segments × ~70pt each = 280pt + padding overflows 390pt. Fall back to a 2x2 GridView/Wrap when LayoutBuilder constraint < 420pt.
- **home_screen.dart tile placement.** The existing list is alphabetical by category label in some sections; place StaffScreen tile near RetailScreen / SchedulerScreen for thematic grouping. Verify the surrounding tiles at execute time.
- **lib/eden_ui.dart export section.** If 015-01 runs first (parallel race), the Wave 1 section comment is already there; just append. If THIS TRD runs first, add the section comment THEN the export. Idempotent: check for the comment line before adding.
</gotchas>
