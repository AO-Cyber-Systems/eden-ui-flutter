**Graph-builder algorithm (port from donor verbatim):**
- `toCanvas(definition)`:
  1. Emit trigger node at id `'trigger-0'` with `data: {nodeType: 'trigger', triggerType, category, config}`.
  2. For each condition in `definition.conditions` (index i), emit `'condition-${i}'` node with `data: {nodeType: 'condition', field, operator, value}` + edge from previous node (sourceHandle='yes' if previous is condition, else 'right').
  3. For each action in `definition.actions` (index i), emit `'action-${i}'` node with `data: {nodeType: 'action', actionType, config}` + edge from previous node (sourceHandle='yes' if previous is condition, else 'right').
  4. Emit `'end-0'` node + edge from final node (sourceHandle='yes' if previous is condition, else 'right').
  5. If `definition.canvasLayout.edges` has user-drawn edges not already present in auto-generated edges, append them.
  6. If no saved positions, apply `EdenFreeFormLayout()` (BFS rank from obj 006) — mirrors donor's `applyDagreLayout` call.
- `fromCanvas(nodes, edges, userEdges)`:
  1. Find trigger node, extract triggerType + category + config.
  2. BFS from trigger node following edges; preferentially follow `sourceHandle='yes'` or `sourceHandle='right'` first.
  3. Walk visited order; collect condition nodes into `conditions[]`, action nodes into `actions[]`, skip trigger/end nodes.
  4. Build `canvasLayout` from `nodes[].position` keyed by `node.id`.
  5. Build `savedEdges[]` from `userEdges` (NOT auto-generated edges).

- **`EdenWorkflowSaveData` is the return type of fromCanvas, NOT a class consumers use as input.** Shape: `{triggerType, triggerConfig, category, conditions: [], actions: [], canvasLayout}`. Tests assert shape, not equality with a fixture instance.
- **`EdenDiagramNode.data` slot stores `nodeType` discriminator.** Per obj 006 TRD-04 pattern: `node.data['nodeType'] = 'trigger' | 'condition' | 'action' | 'delay' | 'branch' | 'merge' | 'end'`. Plus per-node fields: trigger has `triggerType` + `category` + `config`; condition has `field` + `operator` + `value`; action has `actionType` + `config`; delay has `delayType` + `delayMinutes` + `delayConfig`; branch/merge have only `nodeType` + label; end has only `nodeType`.
- **`EdenDiagramNode.ports` MUST be emitted per node-type** (obj 006 TRD-04 pattern):
  - trigger: 2 source ports (`right`, `bottom`) on right/bottom sides
  - condition: 2 target ports (`top`, `left`) + `yes` (right) source + `no` (bottom) source
  - action: 2 target ports (`top`, `left`) + 2 source ports (`right`, `bottom`)
  - delay: 2 target ports (`top`, `left`) + 2 source ports (`right`, `bottom`)
  - branch: 2 target ports (`top`, `left`) + 3 source ports (`right` @ offset 0.33, `right-2` @ offset 0.66, `bottom`)
  - merge: target ports (`top`, `left` @ 0.33, `left-2` @ 0.66) + 2 source ports (`right`, `bottom`)
  - end: 2 target ports (`top`, `left`); NO source ports
- **`EdenDiagramEdge` does NOT have a `sourceHandle` / `targetHandle` field today.** Per inspection of `eden_diagram/diagram_data.dart` (obj 006 — TRD-01 added EdenDiagramPort additively but EdenDiagramEdge structure may not yet have handle fields). The graph-builder MUST store the handle info via `EdenDiagramEdge.data` Map slot (e.g. `edge.data['sourceHandle'] = 'yes'`). If `EdenDiagramEdge` already has `sourceHandle: String?` / `targetHandle: String?` fields, use those. Verify by reading `lib/src/widgets/eden_diagram/diagram_data.dart` at task start — pick whichever shape obj 006 shipped. THIS GOTCHA IS HIGH PRIORITY — adjust task code per actual obj 006 shape.
- **BFS traversal in `fromCanvas` MUST prefer `sourceHandle='yes'` over `'no'` and `'right'` over `'bottom'`.** Mirror donor `flowToWorkflowData.ts:120-130` adjacency-list ordering. This preserves Yes-path priority for conditions (the "happy path" through a workflow).
</gotchas>

  /// Convert an `EdenWorkflowDefinition` into canvas nodes + edges.
  ///
  /// Algorithm (donor `useWorkflowToFlow.ts` parity):
  /// 1. Emit trigger-0 node (data: nodeType=trigger, triggerType, category, config).
  /// 2. For each condition: emit condition-{i} node + edge from previous (yes if prev is condition, else right handle).
  /// 3. For each action: emit action-{i} node + edge from previous.

  /// Convert canvas nodes + edges back to `EdenWorkflowSaveData`.
  static EdenWorkflowSaveData fromCanvas(
    List<EdenDiagramNode> nodes,
    List<EdenDiagramEdge> edges, {
    List<EdenDiagramEdge> userEdges = const [],
  }) {
    final triggerNode = nodes.firstWhere(
      (n) => n.data['nodeType'] == 'trigger',
      orElse: () => throw StateError('No trigger node in canvas'),
    );
    final triggerType = EdenWorkflowTriggerType.values.firstWhere(
      (t) => t.name == triggerNode.data['triggerType'],
      orElse: () => EdenWorkflowTriggerType.manual,
    );
    final triggerConfig = (triggerNode.data['config'] as Map?)?.cast<String, dynamic>() ?? const {};
    final category = triggerNode.data['category'] as String? ?? 'appointment';

    // BFS from trigger, preferring 'yes' / 'right' source handles
    final visited = <String>{triggerNode.id};
    final result = <EdenDiagramNode>[];
    final nodeById = {for (final n in nodes) n.id: n};

    // adjacency: source -> list of (target, sourceHandle)
    final adjacency = <String, List<({String target, String? sourceHandle})>>{};
    for (final edge in edges) {
      final handle = edge.data['sourceHandle'] as String?;
      adjacency.putIfAbsent(edge.sourceId, () => []);
      if (handle == 'yes' || handle == 'right') {
        adjacency[edge.sourceId]!.insert(0, (target: edge.targetId, sourceHandle: handle));
      } else {
        adjacency[edge.sourceId]!.add((target: edge.targetId, sourceHandle: handle));
      }
    }

    final queue = <String>[triggerNode.id];
    while (queue.isNotEmpty) {
      final currentId = queue.removeAt(0);
      final node = nodeById[currentId];
      if (node != null) {
        final nt = node.data['nodeType'];
        if (nt != 'trigger' && nt != 'end') {
          result.add(node);
        }
      }
      for (final adj in adjacency[currentId] ?? const []) {
        if (visited.add(adj.target)) queue.add(adj.target);
      }
    }

    final conditions = <EdenWorkflowCondition>[];
    final actions = <EdenWorkflowAction>[];
    for (final node in result) {
      switch (node.data['nodeType']) {
        case 'condition':
          conditions.add(EdenWorkflowCondition(
            field: node.data['field'] as String,
            operator: EdenWorkflowConditionOperator.values
              .firstWhere((o) => o.name == node.data['operator']),
            value: node.data['value'],
          ));
          break;
        case 'action':
          actions.add(EdenWorkflowAction(
            actionType: node.data['actionType'] as String,
            config: (node.data['config'] as Map?)?.cast<String, dynamic>() ?? const {},

      source: e.sourceId,
      target: e.targetId,
      sourceHandle: e.data['sourceHandle'] as String?,
      targetHandle: e.data['targetHandle'] as String?,
    )).toList();

      triggerConfig: triggerConfig,
      category: category,
      conditions: conditions,
      actions: actions,

        version: 1, nodes: layoutNodes, edges: savedEdges,
