<objective>
Ship `EdenEligibilityResultCard` — the 270/271 eligibility result display widget. Per `USE_CASES_MEDICAL_2026-05-17.md` §5 #1: "athenahealth's marquee KPI is 'patient responsibility known at check-in.' Single highest-impact differentiator for ambulatory practice ROI." Required for SKU A behavioral-health practices that bill insurance even occasionally; gate widget for SKU B Eden Clinic.

**Library renders the result; consumer fetches the 270/271 transaction.** This is critical: the library has zero knowledge of clearinghouses, payer APIs, X12 transactions, or eligibility engines. The widget displays the consumer's already-fetched eligibility data. No transport binding, no clearinghouse client.

**Cross-vertical leverage.** Shape generalizes to any "pre-flight check result" card:
- Gov benefit eligibility (SNAP / TANF / Medicaid eligibility checker for caseworker screens)
- Trades warranty eligibility (is this customer's HVAC unit still under warranty before quoting repair?)
- Fuel: hazmat-cert-still-valid pre-load check
- Retail: gift card balance check

**Coverage status alert mapping:**
- `covered` → `EdenAlert.success` text 'Covered — {planName}'
- `partiallyCovered` → `EdenAlert.warning` text 'Partial coverage — {planName}'
- `notCovered` → `EdenAlert.danger` text 'Not covered — {planName}'
- `needsAuth` → `EdenAlert.warning` text 'Coverage available — Prior authorization required'
- `unknown` → `EdenAlert` neutral text 'Coverage unknown — re-check required'

**Stale-check threshold (locked):**
- 30 days. After 30 days since `checkedAt`, render warning banner.
- Computed via `(now ?? DateTime.now()).difference(checkedAt).inDays > 30`.

**Patient-responsibility computed estimate:**
The widget does NOT compute a total estimated patient responsibility — that's a consumer concern (varies by service code / fee schedule / payer contract). It DISPLAYS the components (copay, coinsurance, deductible remaining, out-of-pocket remaining) and lets the consumer pre-compute the total elsewhere if needed.

**EdenCurrencyDisplay compose (locked):**
All dollar amounts pass through `EdenCurrencyDisplay(amount: ..., currency: result.currency)`. Composer handles formatting + locale. No hand-formatted '$25.00' strings.

**Layout variants:**
- `standard` (default): full vertical card with header alert + 4-row responsibility block + network badge row + prior auth row (if applicable) + referral row (if applicable) + footer with recheck button + checkedAt timestamp.
- `compact`: collapses to a 2-row grid: coverage status alert + 'Copay: $X | Deductible remaining: $Y' single line + recheck button.
- `kpiStrip`: horizontal 3-tile strip: [Coverage pill] [Copay] [Deductible remaining]. Used for embedding in pre-visit dashboards / KPI strips. Other fields suppressed.
