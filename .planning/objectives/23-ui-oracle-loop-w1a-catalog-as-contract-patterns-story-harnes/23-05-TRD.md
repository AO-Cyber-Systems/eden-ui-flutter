render, running through the 23-03 harness.

<anti_patterns>
- **Do NOT generate the stories from a list of state names.** Each story is hand-written with the
  `navItems` list that produces its state, and a one-line comment saying what it pins. Constraint
  `no_llm_test_data`; OBJECTIVE.md: "stories are fixtures — hand-written, one per state, never
  generated from a list of names".
- **Do NOT hand-edit `register_stories.g.dart`.** Run `flutter test tool/gen_stories.dart`. The drift
  test from 23-03 exists precisely to catch a hand-edit.
- **Do NOT bless the goldens locally.** They are produced by the CI `stories` job on Linux at the
  pinned 3.47.4. A macOS run at the local 3.41.9 skips them. eden-ui-flutter#32.
- **Do NOT add a separate `dark` story.** See the reconciliation note below — every story already gets
  a dark golden from the harness.
</anti_patterns>

## Test list

These stories are not asserted by hand-written tests — the 23-03 harness generates their assertions.
The list below is the **state list**: each entry is one hand-written story, and each must pass the
harness's three assertions (light golden, dark golden, `expectUiSane`).

**`eden_nav_item.stories.dart`** — each renders `EdenDesktopLayout` with a crafted `navItems` list
1. `nav-item/default` — a plain item, not selected.
2. `nav-item/selected` — the same item as `selectedId`, pinning the selected treatment.
3. `nav-item/expandable-collapsed` — `expandable: true, initiallyExpanded: false` with two children;
   pins that children are NOT rendered when collapsed.
4. `nav-item/expandable-expanded` — `expandable: true, initiallyExpanded: true`; **pins the containment
   rule of nav commit `b9e82bf`** — the disclosed children render inside the group, and
   `expectUiSane`'s disjointness assertion is what proves they do not spill over a sibling.
5. `nav-item/caption` — `EdenNavItem.caption('Section')`; pins that a caption has no tap target
   (`expectUiSane`'s one-tap-action rule sees zero, which is correct for a passive label).
6. `nav-item/divider` — `EdenNavItem.divider()`.
7. `nav-item/long-label` — a label long enough to exceed the 260px rail; **pins the ellipsis**. This is
   the story whose golden goes red if a future change lets the label run past the rail.
8. `nav-item/badge` — `badge: '3'`; pins badge placement relative to the label (disjointness again).

**`eden_desktop_layout.stories.dart`**
9. `desktop-layout/default` — full shell: nav items, top bar, user tile, body.
10. `desktop-layout/narrow` — the same shell rendered at a narrow width, pinning the rail's behaviour
    below the comfortable breakpoint.

**`eden_mobile_layout.stories.dart`**
11. `mobile-layout/default` — bottom bar + body at a phone width.

**Count bookkeeping (asserted, in task 3)**
12. `registry_complete_test.dart` asserts the new exact total (49 + the number registered above) and
    its comment names this TRD as the reason, matching the file's existing convention.
13. `.story-coverage.json`'s `with_story` floor is raised to the real new count and
    `test/stories/coverage_test.dart` passes.
