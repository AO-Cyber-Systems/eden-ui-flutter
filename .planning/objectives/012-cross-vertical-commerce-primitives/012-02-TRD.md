<anti_patterns>
- **Do NOT compute trend signs inside the widget.** The consumer supplies `trend` as a raw delta (-1..1 conceptual; the widget only checks `>0` / `<0` / `==0`). The widget does NOT format the trend itself into a percentage.
- **Do NOT format `displayValue` inside the widget.** Consumer pre-formats (via EdenCurrencyDisplay, NumberFormat, or whatever). Widget renders the string verbatim. This is intentional — KPI semantics are domain-specific (currency, count, percentage, duration), and the widget shouldn't fork into N format modes.
- **Do NOT bind to a specific layout direction.** Use `Directionality.of(context)` to determine LTR vs RTL for the aggregate footer pinning.
- **Do NOT use `GridView` for the tile strip.** Always horizontal-scrolling list — even on wide screens. Vertical grids hide tiles behind fold + don't match the "strip" mental model.
- **Do NOT hardcode tile width to viewport ratio.** Fixed tileWidth (default 180) is correct; consumer overrides for unusual cases.
</anti_patterns>

<gotchas>
- **Sticky aggregate footer + horizontal scroll.** Two viable layouts:
  - Stack with `Positioned(right: 0, child: aggregateCard)` overlaying scroll content. Risk: aggregate covers last tile when scrolled to far-right.
  - Row with `Expanded(child: SingleChildScrollView(...))` + `aggregateCard`. Simpler; aggregate is always pinned right (LTR) without overlap. **Prefer this approach.**
- **Trend polarity for cost-style KPIs.** Default `EdenKpiTrendPolarity.positiveIsGood` colors `trend > 0` green. For 'Cost per acquisition', 'Churn', 'Refund rate' — pass `EdenKpiTrendPolarity.negativeIsGood` to flip colors.
- **EdenCard.interactive onTap nullable.** Construct with `onTap: tile.onTap` — when null, EdenCard.interactive should still render but not be tappable. Verify behavior; if EdenCard.interactive requires non-null onTap, use plain `EdenCard` instead when tile.onTap is null.
- **Height interaction with trailingSlot.** trailingSlot widgets (typically EdenSparkline with height 24-40pt) need vertical space. Default tile height 96pt accommodates: label (16pt) + displayValue (24pt) + secondaryLabel/trend (16pt) + padding (~24pt) + trailingSlot (24pt). Tight but works.
- **Aggregate value typography.** Slightly larger than tile displayValue for visual weight. Use `Theme.of(context).textTheme.titleLarge` for aggregate vs `titleMedium` for tile values.
- **commerce_screen.dart APPEND ONLY.** Locate the `// TRD 012-02 appends: ...` placeholder comment from 012-01 and replace with a real `Section(...)` block.
</gotchas>

<error_recovery>
- **If horizontal scroll content overflows aggregate footer:** add `Padding(EdgeInsets.only(right: aggregateWidth))` to the inside of the SingleChildScrollView so the last tile can scroll fully past the pinned footer.
- **If EdenCard.interactive requires non-null onTap:** wrap with `EdenCard(...)` (the non-interactive variant) when `tile.onTap == null`; use `EdenCard.interactive(onTap: tile.onTap!, ...)` when present.
- **If `Theme.of(context).extension<EdenStatusPalette>()` returns null:** the EdenAdaptiveTheme wrapper isn't present. Fall back to `EdenColors.success` / `.error` / `.neutral`. Wrap in `_trendColor(ctx, isPositive)` helper.
- **If iPhone-narrow test reports overflow:** the trailing aggregate card is too wide for the remaining space when tiles fill the viewport. Either reduce aggregate card width OR mark aggregate as floating-on-top of the last tile when `stickyAggregate: true` AND viewport < 600pt.
</error_recovery>

```dart
import 'package:flutter/material.dart';

import '../theme/eden_status_palette.dart';
import '../tokens/colors.dart';
import '../tokens/spacing.dart';
import 'eden_card.dart';

enum EdenKpiTrendPolarity { positiveIsGood, negativeIsGood }
enum EdenKpiAggregateMode { sum, avg, max, min, custom }

class EdenKpiTile { /* full surface per <context> */ }
class EdenKpiAggregate { /* full surface per <context> */ }

class EdenAggregateKpiStrip extends StatelessWidget {
  // tiles + aggregate + tileWidth + height + stickyAggregate + emptyState
  @override
  Widget build(BuildContext context) {
    if (tiles.isEmpty) {
      return emptyState ??
          const Center(child: Padding(
            padding: EdgeInsets.all(EdenSpacing.space4),
            child: Text('No KPIs configured'),
          ));
    }

    final scroll = SingleChildScrollView(
      scrollDirection: Axis.horizontal,
      child: Row(
        children: [
          for (final tile in tiles) _buildTile(context, tile),
        ],
      ),
    );

    if (aggregate == null) {
      return SizedBox(height: height, child: scroll);
    }

    return SizedBox(
      height: height,
      child: Row(
        children: [
          Expanded(child: scroll),
          if (stickyAggregate) _buildAggregate(context, aggregate!),
        ],
      ),
    );
    // If stickyAggregate is false, embed aggregate at the END of the scroll Row instead.
  }

  Widget _buildTile(BuildContext ctx, EdenKpiTile tile) {
    final hasTap = tile.onTap != null;
    final cardChild = SizedBox(
      width: tileWidth,
      child: Padding(
        padding: const EdgeInsets.all(EdenSpacing.space3),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Row(children: [
              if (tile.leadingIcon != null) ...[tile.leadingIcon!, const SizedBox(width: 6)],
              Expanded(child: Text(tile.label, style: Theme.of(ctx).textTheme.labelMedium)),
            ]),
            const SizedBox(height: 4),
            Text(tile.displayValue, style: Theme.of(ctx).textTheme.titleMedium),
            const SizedBox(height: 4),
            Row(children: [
              if (tile.trend != null) _trendIcon(ctx, tile),
              if (tile.secondaryLabel != null) ...[const SizedBox(width: 4), Text(tile.secondaryLabel!, style: Theme.of(ctx).textTheme.labelSmall)],
              const Spacer(),
              if (tile.trailingSlot != null) tile.trailingSlot!,
            ]),
          ],
        ),
      ),
    );

    final semantics = '${tile.label}: ${tile.displayValue}${_trendSuffix(tile)}';
    return Semantics(
      label: semantics,
      button: hasTap,
      child: Padding(
        padding: const EdgeInsets.symmetric(horizontal: 4),
        child: hasTap
            ? EdenCard.interactive(onTap: tile.onTap!, child: cardChild)
            : EdenCard(child: cardChild),
      ),
    );
  }

  Widget _trendIcon(BuildContext ctx, EdenKpiTile tile) {
    final t = tile.trend!;
    final isUp = t > 0;
    final isDown = t < 0;
    final isFlat = t == 0;
    final palette = Theme.of(ctx).extension<EdenStatusPalette>();
    final goodColor = palette?.successFg ?? EdenColors.success;
    final badColor = palette?.dangerFg ?? EdenColors.error;
    final neutralColor = palette?.dangerFg ?? EdenColors.neutral; // fallback neutral
    Color color;
    IconData icon;
    if (isFlat) { color = neutralColor; icon = Icons.remove; }
    else if (isUp) {
      icon = Icons.arrow_upward;
      color = tile.polarity == EdenKpiTrendPolarity.positiveIsGood ? goodColor : badColor;
    } else {
      icon = Icons.arrow_downward;
      color = tile.polarity == EdenKpiTrendPolarity.positiveIsGood ? badColor : goodColor;
    }
    return Icon(icon, size: 14, color: color);
  }

  String _trendSuffix(EdenKpiTile tile) {
    if (tile.trend == null) return '';
    if (tile.trend! > 0) return ' trending up';
    if (tile.trend! < 0) return ' trending down';
    return ' unchanged';
  }

  Widget _buildAggregate(BuildContext ctx, EdenKpiAggregate agg) {
    return Padding(
      padding: const EdgeInsets.symmetric(horizontal: 4),
      child: SizedBox(
        width: tileWidth,
        child: Semantics(
          label: 'Aggregate ${agg.label.toLowerCase()}: ${agg.displayValue}',
          child: EdenCard(
            child: Padding(
              padding: const EdgeInsets.all(EdenSpacing.space3),
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text(agg.label, style: Theme.of(ctx).textTheme.labelMedium),
                  const SizedBox(height: 4),
                  Text(agg.displayValue, style: Theme.of(ctx).textTheme.titleLarge),
                ],
              ),
            ),
          ),
        ),
      ),
    );
  }
}
```
