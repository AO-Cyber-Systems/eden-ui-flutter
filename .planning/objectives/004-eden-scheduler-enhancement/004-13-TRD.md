<objective>
Wave 3 — Pick mode. The donor's pick mode (`DraftAppointmentBlock.tsx`, `PickModeOverlay.tsx`, `PickModeFloatingBar.tsx`, `EnhancedCalendar.tsx` pickMode/draftBlocks props at lines 185-209) is a "create multiple appointments before committing" workflow. User toggles pick mode on, drags out N draft blocks on the time grid, then commits all at once (vs creating-then-editing one by one).

Library version is the same — generic enough that any vertical can use it (trades schedule, salon multi-booking, fuel multi-delivery).

Parity row DR-4.
</objective>

- State: `bool active`, `List<EdenSchedulerDraftBlock> drafts`.
- Methods: `enter()`, `exit()`, `appendDraft(DraftBlock)`, `updateDraft(id, patch)`, `removeDraft(id)`, `clearDrafts()`.

**Draft block creation gesture:**
- When `pickMode == true`, the time-grid GestureDetector switches behavior. `onPanStart` records a draft initial position; `onPanUpdate` extends the draft block downward; `onPanEnd` commits the draft (calls appendDraft).
- Snap math: `EdenSchedulerTimeMath.yDeltaPxToMinutes` → 15-min snap.
- Draft has same data shape as event (start, end, optional resourceId from column).

**Bottom bar (PickModeFloatingBar equivalent):**
- Positioned at bottom of scheduler. Visible only when `drafts.isNotEmpty`.
- "N drafts" + "Cancel" (clear all) + "Save" (call onDraftCommit callback).

**Wiring to existing event-block conflict:** when pickMode active, EdenSchedulerEventBlock drag-to-reschedule is DISABLED. Only draft-creation gestures fire on the time grid. Otherwise a single pan could be ambiguous.
</context>

<gotchas>
- **Pan vs Tap discrimination:** when pickMode active, a quick tap (< 5pt movement) becomes a click-on-existing-event for tap-to-toggle-draft-remove. A pan becomes a new draft.
- **Draft min duration:** 15 min (one snap unit). If pan delta < 15 min minutes, snap to 15.
- **Draft positioning:** same y-offset math as events; uses the column (in WeekView) where the pan started.
- **Cross-day draft drag:** drag starting Mon-9AM ending Tue-10AM — collapse to single-day Mon 9-end-of-day (donor behavior). v1 simplification.
- **Draft ID generation:** UUID-like. Use `'draft-${DateTime.now().millisecondsSinceEpoch}-${draftIndex}'`. Library doesn't need crypto-grade ids; just unique-enough.
- **Disabled event drag:** in EventBlock, check `widget.allowDrag` flag; in pickMode, pass `allowDrag: false` to all event blocks.
- **Exit mode with drafts:** if `drafts.isNotEmpty`, show a Material `AlertDialog` asking "Discard N drafts?" before clearing.
- **Save / commit callback:** `onDraftCommit(List<EdenSchedulerDraftBlock> drafts)` is the consumer's responsibility to create real events. Library doesn't auto-convert drafts to events.
- **Visual style:** drafts are dashed-border + opacity 0.5 — distinct from real events. Use `DottedBorder` package? **No new deps** — hand-roll with `CustomPainter` for dashed border. Or use solid border + low opacity. For v1, low opacity + a "DRAFT" label is clear enough.
</gotchas>

```dart
import 'package:flutter/foundation.dart';
import 'package:flutter/material.dart';
import 'scheduler_models.dart';

@immutable
class EdenSchedulerDraftBlock {
  const EdenSchedulerDraftBlock({
    required this.id,
    required this.start,
    required this.end,
    this.resourceId,
    this.label,
  });

  final String id;
  final DateTime start;
  final DateTime end;
  final String? resourceId;
  final String? label;

  EdenSchedulerDraftBlock copyWith({DateTime? start, DateTime? end, String? resourceId, String? label}) =>
      EdenSchedulerDraftBlock(
        id: id,
        start: start ?? this.start,
        end: end ?? this.end,
        resourceId: resourceId ?? this.resourceId,
        label: label ?? this.label,
      );
}

class EdenSchedulerPickModeController extends ChangeNotifier {
  bool _active = false;
  final List<EdenSchedulerDraftBlock> _drafts = [];
  int _draftCounter = 0;

  bool get active => _active;
  List<EdenSchedulerDraftBlock> get drafts => List.unmodifiable(_drafts);

  void enter() {
    if (_active) return;
    _active = true;
    notifyListeners();
  }

  void exit() {
    if (!_active) return;
    _active = false;
    notifyListeners();
  }

  String _newDraftId() {
    _draftCounter++;
    return 'draft-${DateTime.now().millisecondsSinceEpoch}-$_draftCounter';
  }

  EdenSchedulerDraftBlock appendDraft({
    required DateTime start,
    required DateTime end,
    String? resourceId,
    String? label,
  }) {
    final draft = EdenSchedulerDraftBlock(
      id: _newDraftId(),
      start: start,
      end: end,
      resourceId: resourceId,
      label: label,
    );
    _drafts.add(draft);
    notifyListeners();
    return draft;
  }

  void updateDraft(String id, {DateTime? start, DateTime? end, String? resourceId, String? label}) {
    final idx = _drafts.indexWhere((d) => d.id == id);
    if (idx < 0) return;
    _drafts[idx] = _drafts[idx].copyWith(start: start, end: end, resourceId: resourceId, label: label);
    notifyListeners();
  }

  void removeDraft(String id) {
    final idx = _drafts.indexWhere((d) => d.id == id);
    if (idx < 0) return;
    _drafts.removeAt(idx);
    notifyListeners();
  }

  void clearDrafts() {
    if (_drafts.isEmpty) return;
    _drafts.clear();
    notifyListeners();
  }
}

class EdenSchedulerPickModeBar extends StatelessWidget {
  const EdenSchedulerPickModeBar({
    super.key,
    required this.controller,
    this.onCommit,
    this.confirmExitOnDrafts = true,
  });
  final EdenSchedulerPickModeController controller;
  final void Function(List<EdenSchedulerDraftBlock>)? onCommit;
  final bool confirmExitOnDrafts;

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: controller,
      builder: (context, _) {
        if (controller.drafts.isEmpty) return const SizedBox.shrink();
        final theme = Theme.of(context);
        return Container(
          padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 8),
          color: theme.colorScheme.primaryContainer,
          child: Row(
            children: [
              Expanded(child: Text('${controller.drafts.length} draft${controller.drafts.length == 1 ? '' : 's'}')),
              TextButton(
                onPressed: () async {
                  if (confirmExitOnDrafts && controller.drafts.isNotEmpty) {
                    final discard = await showDialog<bool>(
                      context: context,
                      builder: (_) => AlertDialog(
                        title: Text('Discard ${controller.drafts.length} drafts?'),
                        actions: [
                          TextButton(onPressed: () => Navigator.pop(context, false), child: const Text('Cancel')),
                          TextButton(onPressed: () => Navigator.pop(context, true), child: const Text('Discard')),
                        ],
                      ),
                    );
                    if (discard != true) return;
                  }
                  controller.clearDrafts();
                },
                child: const Text('Cancel'),
              ),
              const SizedBox(width: 8),
              FilledButton(
                onPressed: () {
                  onCommit?.call(controller.drafts);
                  controller.clearDrafts();
                  controller.exit();
                },
                child: Text('Save ${controller.drafts.length}'),
              ),
            ],
          ),
        );
      },
    );
  }
}
```
