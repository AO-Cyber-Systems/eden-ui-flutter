<gotchas>
- **`Duration(days: 1)` is NOT wall-clock in Dart.** Adding `Duration(days: 1)` to 2026-03-08 00:00 (US spring-forward at 2 AM) gives 24 hours later = 2026-03-09 01:00 (because Mar 9 has only 23 hours). For scheduler use, we want WALL CLOCK semantics — same hour-of-day on next calendar day. Use `DateTime(d.year, d.month, d.day + 1, d.hour, d.minute)` for "next day at same wall time".
- **`yDeltaPxToMinutes` rounding direction:** donor uses `Math.round` (banker's rounding in Dart is `.round()` which is half-away-from-zero in Dart). Test: deltaPx=20, hourHeight=60 → 20/60*60/15 = 1.333... → rounds to 1 → *15 = 15 minutes. deltaPx=22.5 → 22.5/60*60/15 = 1.5 → rounds to 2 in Dart (.round()) → *15 = 30. Match donor exactly.
- **`addMinutesToTime` clamp upper bound is `24*60 - 15 = 1425` minutes** = 23:45. If you add 30 min to 23:30 → 1440 (24:00) → clamp to 1425 → "23:45". Test this edge.
- **`formatTime` 12-hour conversion:** `hour % 12 || 12` — JS pattern. Dart: `(hour % 12 == 0) ? 12 : hour % 12`. Test hour=0 → 12 AM, hour=12 → 12 PM, hour=13 → 1 PM, hour=23 → 11 PM.
- **`formatTime` invalid input:** donor returns '' for empty / NaN. Dart: catch `int.tryParse` returning null.
- **Weekday bitmask convention:** Mon=1 (bit 0), Tue=2 (bit 1), ..., Sun=64 (bit 6). DateTime.weekday returns Mon=1..Sun=7. Bit = `1 << (weekday - 1)`.
- **Recurrence expansion bound:** when `until: null`, expand to `rangeEnd`. Never expand beyond `rangeEnd`. Never emit an occurrence whose START is before `rangeStart` (we'd render past events out-of-window).
- **Event id collisions on expansion:** each occurrence needs a unique id. Convention: `'${event.id}@${occurrenceDate.toIso8601String()}'` (e.g. `'evt-7@2026-03-16T00:00:00.000'`). The original event id is preserved in `originalId` field on the occurrence (NEW field on `EdenSchedulerEvent`? No — keep it on a wrapper class `EdenSchedulerExpandedEvent` to avoid polluting the model). Actually simpler: caller (view widgets) treats every occurrence as a standalone event and uses the suffixed id; downstream selection/move callbacks must strip the suffix to know "the original recurrence series". Document this clearly.
- **Don't import `flutter/material.dart`.** This is a pure-Dart utility. Import only `package:flutter/foundation.dart` if `@immutable` is wanted (it's not strictly necessary).
</gotchas>

```dart
import 'package:flutter/foundation.dart';

import 'scheduler_models.dart';

/// Pure-Dart time + date helpers for [EdenScheduler]. No Flutter imports
/// beyond `foundation.dart` for `@immutable`.
///
/// Wall-clock semantics: `addDays(d, 1)` returns the SAME hour/minute on the
/// next calendar day, NOT 24 hours later. Avoids DST drift.
class EdenSchedulerTimeMath {
  const EdenSchedulerTimeMath._();

  /// Convert a vertical pixel delta to a 15-minute-snapped minute count.
  /// Mirrors donor `yDeltaPxToMinutes` (`EnhancedCalendar.tsx:213`).
  static int yDeltaPxToMinutes(double deltaPx, double hourHeight) {
    if (hourHeight <= 0) return 0;
    final raw = (deltaPx / hourHeight) * 60;
    return (raw / 15).round() * 15;
  }

  /// Add minutes to an "HH:MM" time string. Clamps to [00:00, 23:45].
  /// Mirrors donor `addMinutesToTime` (`EnhancedCalendar.tsx:218`).
  static String addMinutesToTime(String time, int minutes) {
    final parts = time.split(':');
    if (parts.length != 2) {
      throw FormatException('Expected HH:MM, got: $time');
    }
    final h = int.tryParse(parts[0]) ?? 0;
    final m = int.tryParse(parts[1]) ?? 0;
    final total = h * 60 + m + minutes;
    final clamped = total.clamp(0, 24 * 60 - 15);
    final nh = clamped ~/ 60;
    final nm = clamped % 60;
    return '${nh.toString().padLeft(2, '0')}:${nm.toString().padLeft(2, '0')}';
  }

  /// Format an "HH:MM" 24-hour time string as "h:mm AM/PM" preserving minutes.
  /// Mirrors donor `formatTime` (`EnhancedCalendar.tsx:268`) — donor fix for
  /// the E11a "9 AM truncation" bug. Returns '' for null/empty/invalid input.
  static String formatTime(String? timeStr) {
    if (timeStr == null || timeStr.isEmpty) return '';
    final parts = timeStr.split(':');
    if (parts.length < 2) return '';
    final hour = int.tryParse(parts[0]);
    if (hour == null) return '';
    final mStr = parts[1].padLeft(2, '0');
    final ampm = hour >= 12 ? 'PM' : 'AM';
    final display = hour % 12 == 0 ? 12 : hour % 12;
    return '$display:$mStr $ampm';
  }

  /// DateTime with hour/min/sec/ms stripped — date-only.
  static DateTime stripTime(DateTime d) => DateTime(d.year, d.month, d.day);

  /// Returns the Monday of the week containing [d]. Wall-clock midnight.
  static DateTime startOfWeek(DateTime d) {
    final stripped = stripTime(d);
    return stripped.subtract(Duration(days: stripped.weekday - 1));
  }

  /// Wall-clock add-days. Preserves hour/min/sec on the resulting date,
  /// avoiding DST drift that `Duration(days: N)` would introduce.
  static DateTime addDays(DateTime d, int days) =>
      DateTime(d.year, d.month, d.day + days, d.hour, d.minute, d.second);

  /// Expand a recurring event into individual occurrences within
  /// [rangeStart, rangeEnd). Each occurrence preserves the original event's
  /// hour/minute/duration but uses the occurrence date for the year/month/day.
  /// Each occurrence id is suffixed with `@<iso-date>` for uniqueness.
  static List<EdenSchedulerEvent> expandRecurrence(
    EdenSchedulerEvent event,
    DateTime rangeStart,
    DateTime rangeEnd,
  ) {
    final recurrence = event.recurrence;
    if (recurrence == null ||
        recurrence.kind == EdenSchedulerRecurrenceKind.none) {
      // Single occurrence — emit only if start is within range.
      if (event.start.isBefore(rangeEnd) && event.end.isAfter(rangeStart)) {
        return [event];
      }
      return const [];
    }

    final duration = event.end.difference(event.start);
    final until = recurrence.until;
    final hardEnd = until != null && until.isBefore(rangeEnd) ? until : rangeEnd;

    final occurrences = <EdenSchedulerEvent>[];
    DateTime cursor = stripTime(event.start);

    while (cursor.isBefore(hardEnd) || cursor.isAtSameMomentAs(hardEnd)) {
      final shouldEmit = switch (recurrence.kind) {
        EdenSchedulerRecurrenceKind.daily => true,
        EdenSchedulerRecurrenceKind.weekly =>
          recurrence.matchesWeekday(cursor.weekday),
        EdenSchedulerRecurrenceKind.none => false,
      };

      if (shouldEmit && !cursor.isBefore(stripTime(rangeStart))) {
        final occStart = DateTime(
          cursor.year,
          cursor.month,
          cursor.day,
          event.start.hour,
          event.start.minute,
        );
        final occEnd = occStart.add(duration);
        occurrences.add(EdenSchedulerEvent(
          id: '${event.id}@${stripTime(cursor).toIso8601String()}',
          title: event.title,
          start: occStart,
          end: occEnd,
          color: event.color,
          description: event.description,
          assignee: event.assignee,
          status: event.status,
          type: event.type,
          resourceIds: event.resourceIds,
          location: event.location,
          dispatchIssue: event.dispatchIssue,
          allDay: event.allDay,
          recurrence: event.recurrence,
          readiness: event.readiness,
        ));
      }

      cursor = addDays(cursor, 1);
      // Hard safety bound — prevent runaway loops if hardEnd is malformed.
      if (occurrences.length > 1000) break;
    }

    return occurrences;
  }
}
```
