<context>
**Locked design inputs:**
- Donor doesn't explicitly virtualize but uses React's reconciliation. Library uses Flutter's `Stack` which renders every child — at 500 events × multiple views, this can stutter.
- Viewport math: in DayView/WeekView, the visible y-range is `(scrollOffset, scrollOffset + viewportHeight)`. Events with `bottom < scrollOffset || top > scrollOffset + viewportHeight` are off-screen and don't need positioning.
- Recurrence expansion (TRD 03) is O(N) per event per range; cache when range + event unchanged.

**Approach:**
1. `EdenSchedulerEventLayer` widget that wraps the event positioning logic. Takes events + config + ScrollController + viewportHeight. Internally:
   - Listens to ScrollController.offset.
   - Filters events to "intersects viewport y-range".
   - Calls `EdenSchedulerConflictLayout.compute(visibleEvents)`.
   - Memoizes via `_lastFingerprint` → if input event list AND visible range unchanged, reuse cached layout map.

2. **Fingerprint:** simple hash of `events.map((e) => '${e.id}:${e.start.millisecondsSinceEpoch}:${e.end.millisecondsSinceEpoch}').join(',')` + `'${visibleStart}:${visibleEnd}'`. Cheap to compute, deterministic.

3. **Recurrence cache:** static `Map<String, List<EdenSchedulerEvent>> _recurrenceCache` keyed by `'${event.id}:${rangeStart.iso}:${rangeEnd.iso}'`. Capped at 1000 entries (LRU eviction). Invalidate via `EdenSchedulerEventLayer.clearCache()` static method.

**Performance test approach:** spawn 500 fixture events, mount the EdenSchedulerDayView, measure `tester.binding.currentSystemFrameTimeStamp` before/after `pumpAndSettle()`. Assert < 200ms.

**Side-by-side parity verification:** the human-verify checkpoint requires the user to compare two screenshots manually. Plan asks the executor to capture screenshots of the dev catalog in each view mode (`flutter run` with a screenshot script), then prompt the user with side-by-side comparison cards. **Each parity-checklist row gets a yes/no/notes from the reviewer.**
</context>

<gotchas>
- **Premature optimization avoidance:** only cull when event count > 50 (a reasonable threshold). Below, the naive O(N) Stack child layout is fast enough. Add a `cullingThreshold: int = 50` parameter.
- **ScrollController listening:** rebuilds happen on every scroll tick — that's potentially 60fps × view rebuild = expensive. Throttle via `RepaintBoundary` + only re-filter on debounced offset changes (16ms = 1 frame).
- **Cache invalidation on event mutation:** if consumer adds an event to the list, the fingerprint changes → cache miss → recompute. That's correct behavior. Don't try to incremental-update.
- **Static cache lifetime:** lives for app lifetime. For tests, MUST call `EdenSchedulerEventLayer.clearCache()` in `setUp()` to avoid cross-test contamination.
- **Layout-cache + recurrence-cache interaction:** recurrence expansion produces N occurrence events; layout cache fingerprints THOSE. Cache thrashing avoided because the occurrence list is stable while range unchanged.
- **Human-verify checkpoint shape:** `type: checkpoint:human-verify` task at the END of this TRD. Block on user confirmation before marking TRD done.
</gotchas>

```dart
import 'package:flutter/foundation.dart';
import 'scheduler_conflict_layout.dart';
import 'scheduler_models.dart';
import 'scheduler_time_math.dart';

class EdenSchedulerEventLayer {
  EdenSchedulerEventLayer._();

  // ---- Layout cache ----
  static final Map<String, Map<String, EventLayout>> _layoutCache = {};
  static int _computeCalls = 0;
  @visibleForTesting
  static int get computeCalls => _computeCalls;
  static const int _maxLayoutCache = 100;

  static Map<String, EventLayout> computeLayoutCached(List<EdenSchedulerEvent> events) {
    final fp = _fingerprintEvents(events);
    if (_layoutCache.containsKey(fp)) {
      return _layoutCache[fp]!;
    }
    _computeCalls++;
    final result = EdenSchedulerConflictLayout.compute(events);
    if (_layoutCache.length >= _maxLayoutCache) {
      // LRU eviction — remove a random oldest entry (simple, deterministic enough)
      _layoutCache.remove(_layoutCache.keys.first);
    }
    _layoutCache[fp] = result;
    return result;
  }

  static String _fingerprintEvents(List<EdenSchedulerEvent> events) {
    final buf = StringBuffer();
    for (final e in events) {
      buf.write('${e.id}:${e.start.millisecondsSinceEpoch}:${e.end.millisecondsSinceEpoch};');
    }
    return buf.toString();
  }

  // ---- Recurrence cache ----
  static final Map<String, List<EdenSchedulerEvent>> _recurrenceCache = {};
  static int _recurrenceCalls = 0;
  @visibleForTesting
  static int get recurrenceCalls => _recurrenceCalls;
  static const int _maxRecurrenceCache = 500;

  static List<EdenSchedulerEvent> expandRecurrenceCached(
    EdenSchedulerEvent event,
    DateTime rangeStart,
    DateTime rangeEnd,
  ) {
    final key = '${event.id}:${rangeStart.toIso8601String()}:${rangeEnd.toIso8601String()}:${event.start.millisecondsSinceEpoch}:${event.end.millisecondsSinceEpoch}';
    if (_recurrenceCache.containsKey(key)) return _recurrenceCache[key]!;
    _recurrenceCalls++;
    final result = EdenSchedulerTimeMath.expandRecurrence(event, rangeStart, rangeEnd);
    if (_recurrenceCache.length >= _maxRecurrenceCache) {
      _recurrenceCache.remove(_recurrenceCache.keys.first);
    }
    _recurrenceCache[key] = result;
    return result;
  }

  // ---- Viewport culling ----

  /// Returns the subset of [events] whose vertical extent intersects the
  /// viewport y-range [viewportTopY, viewportBottomY] given [config] and
  /// the date's startOfDay-y-origin.
  static List<EdenSchedulerEvent> cullToViewport({
    required List<EdenSchedulerEvent> events,
    required EdenSchedulerConfig config,
    required double viewportTopY,
    required double viewportBottomY,
    required DateTime dayStart,
  }) {
    final result = <EdenSchedulerEvent>[];
    for (final e in events) {
      final yTop = _yOffsetForTime(e.start, dayStart, config);
      final yBot = _yOffsetForTime(e.end, dayStart, config);
      if (yBot < viewportTopY || yTop > viewportBottomY) continue;
      result.add(e);
    }
    return result;
  }

  static double _yOffsetForTime(DateTime t, DateTime dayStart, EdenSchedulerConfig config) {
    final hourFrac = t.difference(DateTime(dayStart.year, dayStart.month, dayStart.day, config.effectiveStartHour, 0)).inMinutes / 60.0;
    return hourFrac * config.slotHeight;
  }

  static void clearCache() {
    _layoutCache.clear();
    _recurrenceCache.clear();
    _computeCalls = 0;
    _recurrenceCalls = 0;
  }
}
```
