<gotchas>
- **Now-indicator timer disposal:** MUST cancel the Timer in `dispose()`. Forgetting = ticking timer leak. Use `late Timer _timer;` + `_timer.cancel()`.
- **Now-indicator hidden state:** when `now` is outside [startHour, endHour), DON'T render the line. Don't render at y=0 or y=totalHeight — that's a visual lie.
- **Clock injection for tests:** pass `clock: () => DateTime(2026, 5, 16, 13, 0)` to make the indicator appear at the 1 PM slot. Without injection, real wall clock is used (production behavior).
- **Slot tap precision:** when user taps the time grid, compute slot start = floor((tapY / slotHeight) * 60) / 15 * 15 minutes from startHour. So a tap at y=85pt with slotHeight=60 → 1.416 hours = 1h 25min → snap to 15-min slot = 1h 15min → 7:15 AM if startHour=6. Use `EdenSchedulerTimeMath.yDeltaPxToMinutes` if useful — but here we want absolute time, not delta. Pseudocode:
  ```
  final minutesFromStart = ((tapY / slotHeight) * 60).floor() ~/ 15 * 15;
  final tapTime = DateTime(focusedDate.year, focusedDate.month, focusedDate.day, startHour, 0).add(Duration(minutes: minutesFromStart));
  onTimeSlotTap(tapTime);
  ```
- **fullDay overrides user config silently.** Document in dartdoc: "When `fullDay == true`, `startHour` and `endHour` are ignored and forced to 0..24."
- **Event positioning math:** event start may be before startHour or end after endHour. Clip the rendered block to the visible range. `clampedStart = max(start, startOfDay + startHour)`, `clampedEnd = min(end, startOfDay + endHour)`. If clampedStart >= clampedEnd, don't render (off-screen).
- **iPhone-narrow safety:** at 390pt total width, 56pt left gutter is 14% — fine. But the event title in a single-column view should `ellipsis` overflow, not wrap into the next row. Use `Text(overflow: TextOverflow.ellipsis, maxLines: 1)`.
- **TRD 10 (event block) will replace the inline event rendering** — for now, render with a simple Container + Text. TRD 10 swaps it for `EdenSchedulerEventBlock` with drag handles.

class EdenSchedulerConfig {
  const EdenSchedulerConfig({
    this.startHour = 6,
    this.endHour = 20,
    this.slotHeight = 60.0,
    this.fullDay = false,
  });

  final int startHour;
  final int endHour;
  final double slotHeight;
  /// When true, overrides startHour=0, endHour=24 (full 24-hour grid).
  final bool fullDay;

  int get effectiveStartHour => fullDay ? 0 : startHour;
  int get effectiveEndHour => fullDay ? 24 : endHour;
  int get hourCount => effectiveEndHour - effectiveStartHour;
  double get totalHeight => hourCount * slotHeight;
}
