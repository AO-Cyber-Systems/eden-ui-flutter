<objective>
Wave 4 — Sidebar + toolbar enhancements. The donor `04-schedule-page.png` screenshot shows a desktop layout: left sidebar with mini-calendar + Trucks (resource) filter list with color dots + density legend + Show Unassigned/Maintenance toggles; top toolbar with search + 100% zoom indicator + view toggle + three-dot overflow + Today button + prev/next.

This TRD ships the supporting widgets so consumers can compose the full desktop scheduler. Each widget is independently consumable so apps that don't want the full sidebar can pick a subset.

<context>
**Locked design inputs:**
- Donor `MiniCalendarHeatMap` at `EnhancedCalendar.tsx:587-755` — small month grid with density-coded day cells.
- Donor sidebar layout in screenshot 04: mini-cal at top → "Trucks (Select)" filter with category groupings + color-dot chips → "Open / Full" legend → Show Unassigned + Show Maintenance toggles.
- Donor toolbar in screenshot: 100% zoom button, three-dot overflow.

**Approach (decompose into small widgets):**
1. `EdenSchedulerMiniCalendar(focusedDate, today, eventDensity, onDateTap)` — pure-display month grid, optional density coloring.
2. `EdenSchedulerDensityLegend()` — static legend (5 dots: low to high density colors).
3. `EdenSchedulerZoomIndicator(zoom, onZoomChange)` — chip showing percentage + +/- controls (desktop equivalent of mobile pinch-zoom).
4. `EdenSchedulerSearchField(controller)` — TextField wired to controller.setSearch with debounce 200ms.
5. `EdenSchedulerKeyboardShortcuts({required child})` — Shortcuts widget wrapping the scheduler that maps 1/2/3/4 keys.
6. `EdenSchedulerOverflowMenu(items)` — three-dot popup menu.
7. `EdenSchedulerSidebar({controller, resources, ...})` — composite that arranges 1-6 above into a Column.

**Density data shape:** `Map<DateTime, double>` where double in [0, 1]. Mini-calendar reads this to tint cells. Consumer computes density from event count vs business-hours-capacity. Library default density = none (no tint).

**Search debounce:** rapid typing shouldn't notify controller on each keystroke. Use a `Timer(Duration(milliseconds: 200))` reset on each input. On timer fire, call `controller.setSearch(value)`.

**Keyboard shortcuts:** Flutter's `Shortcuts` widget. Map intents `{LogicalKeySet(LogicalKeyboardKey.digit1): _SwitchToDayIntent()}` etc. Then `Actions` mapping intents to handlers that call `controller.setView(...)`. Apply only when focus is inside the scheduler scope.
</context>

<gotchas>
- **Mini-calendar density colors:** 5 levels (0 = empty, 0.25, 0.5, 0.75, 1.0). Match donor "Open ●●●●● Full" legend. Use `Color.lerp(theme.primary.withOpacity(0.1), theme.error.withOpacity(0.5), density)`.
- **Mini-cal cell size:** tight at 28×28pt for a 7×6 grid. Header row (S/M/T/W/T/F/S) + 6 weeks max.
- **Sidebar width 240pt at desktop:** at narrower viewports (<800pt), the sidebar should hide. Library v1: caller controls visibility via `EdenSchedulerSidebar` placement; auto-hide deferred.
- **Search debounce timer disposal:** stateful widget. Cancel timer on dispose and on text change before resetting.
- **Keyboard shortcuts focus scope:** wrap scheduler body in `Focus(autofocus: true, child: Shortcuts(...))`. Without autofocus, keys don't fire until user clicks the scheduler first.
- **Overflow menu items as builder slots:** consumer plugs in `List<PopupMenuItem<dynamic>>` directly so they can localize labels + handle actions.
- **Zoom indicator chip width:** 90pt (enough for "200%" + 2 buttons). On narrow toolbars, can collapse to icon-only.
- **Density legend dot colors:** match the heatmap colors. Ship a public `EdenSchedulerDensityColors` static class with the 5 levels.
- **Mini-cal navigation arrows:** allow prev/next month navigation independent of main view. Two arrow buttons in header.
</gotchas>

class EdenSchedulerSearchField extends StatefulWidget {
  const EdenSchedulerSearchField({super.key, required this.controller, this.debounce = const Duration(milliseconds: 200)});
  final EdenSchedulerController controller;
  final Duration debounce;
  @override
  State<EdenSchedulerSearchField> createState() => _EdenSchedulerSearchFieldState();
}
class _EdenSchedulerSearchFieldState extends State<EdenSchedulerSearchField> {
  Timer? _debounce;
  final _textController = TextEditingController();

  @override
  void dispose() {
    _debounce?.cancel();
    _textController.dispose();
    super.dispose();
  }

  void _onChanged(String v) {
    _debounce?.cancel();
    _debounce = Timer(widget.debounce, () => widget.controller.setSearch(v));
  }

  @override
  Widget build(BuildContext context) {
    return TextField(
      controller: _textController,
      onChanged: _onChanged,
      decoration: const InputDecoration(
        prefixIcon: Icon(Icons.search, size: 18),
        hintText: 'Search',
        isDense: true,
      ),
    );
  }
}
```

import 'package:flutter/material.dart';
import '../../tokens/spacing.dart';
import 'scheduler_controller.dart';
import 'scheduler_density_legend.dart';
import 'scheduler_mini_calendar.dart';
import 'scheduler_models.dart';
import 'scheduler_resource_chip_strip.dart';

class EdenSchedulerSidebar extends StatelessWidget {
  const EdenSchedulerSidebar({
    super.key,
    required this.controller,
    this.resources = const [],
    this.eventDensity = const {},
    this.showUnassigned = true,
    this.showMaintenance = true,
    this.onShowUnassignedChange,
    this.onShowMaintenanceChange,
    this.width = 240,
  });

  final EdenSchedulerController controller;
  final List<EdenSchedulerResource> resources;
  final Map<DateTime, double> eventDensity;
  final bool showUnassigned;
  final bool showMaintenance;
  final ValueChanged<bool>? onShowUnassignedChange;
  final ValueChanged<bool>? onShowMaintenanceChange;
  final double width;

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: controller,
      builder: (context, _) {
        return Container(
          width: width,
          padding: const EdgeInsets.all(EdenSpacing.space2),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              EdenSchedulerMiniCalendar(
                focusedDate: controller.focusedDate,
                today: controller.today,
                eventDensity: eventDensity,
                onDateTap: controller.setFocusedDate,
              ),
              const SizedBox(height: EdenSpacing.space3),
              const Text('Trucks (Select)', style: TextStyle(fontWeight: FontWeight.w600)),
              // Vertical-style chip strip for sidebar (one chip per row).
              ...resources.map((r) {
                final selected = controller.selectedResources.contains(r.id);
                return CheckboxListTile(
                  value: selected,
                  controlAffinity: ListTileControlAffinity.leading,
                  onChanged: (v) => controller.toggleResourceFilter(r.id),
                  title: Row(
                    children: [
                      Container(
                        width: 8,
                        height: 8,
                        decoration: BoxDecoration(
                          color: r.color ?? Theme.of(context).colorScheme.primary,
                          shape: BoxShape.circle,
                        ),
                      ),
                      const SizedBox(width: 4),
                      Expanded(child: Text(r.name, maxLines: 1, overflow: TextOverflow.ellipsis)),
                    ],
                  ),
                  dense: true,
                  contentPadding: EdgeInsets.zero,
                );
              }),
              const SizedBox(height: EdenSpacing.space2),
              const EdenSchedulerDensityLegend(),
              const SizedBox(height: EdenSpacing.space3),
              CheckboxListTile(
                value: showUnassigned,
                controlAffinity: ListTileControlAffinity.leading,
                onChanged: onShowUnassignedChange,
                title: const Row(
                  children: [Icon(Icons.warning_amber, color: Color(0xFFCA8A04), size: 16), SizedBox(width: 4), Text('Show Unassigned')],
                ),
                dense: true,
                contentPadding: EdgeInsets.zero,
              ),
              CheckboxListTile(
                value: showMaintenance,
                controlAffinity: ListTileControlAffinity.leading,
                onChanged: onShowMaintenanceChange,
                title: const Row(
                  children: [Icon(Icons.build, color: Color(0xFF22C55E), size: 16), SizedBox(width: 4), Text('Show Maintenance')],
                ),
                dense: true,
                contentPadding: EdgeInsets.zero,
              ),
            ],
          ),
        );
      },
    );
  }
}
```
