**Conflict-layout algorithm (greedy first-fit, mirrors any standard calendar event layout):**
```
Input: List<Event> sorted by start time.
For each event:
  1. Find the earliest column where the event doesn't overlap with the last event in that column.
  2. If no such column, create a new column.
  3. Record (event.id → columnIdx).
After all events placed:
  For each event, compute its "group size" = max columns used by any event in its overlap chain.
  Width = 1 / groupSize; Left = columnIdx / groupSize.
```

**Conflict detection (for banners):**
```
For each event pair (a, b):
  If a.start < b.end && b.start < a.end → conflict.
Group conflicts by (start time, resourceIds intersection). Banner shows top-level summary.
```

<gotchas>
- **Algorithm input MUST be sorted by start.** Sort at engine boundary; don't trust caller.
- **Edge case: events same start time.** Use a secondary sort by event.id for determinism.
- **Group size determination:** an event "group" = the maximal connected component of events where overlap edges connect them. Standard calendar layout algorithm. Use a Union-Find OR a sweep-line approach. For v1, simpler: after column assignment, the group size for event E = max columnIdx within E's overlap cluster + 1. Sweep events in start order; track current cluster; reset cluster when no overlap with any in current cluster.
- **Pure-Dart algorithm:** no Flutter imports in `scheduler_conflict_layout.dart`. Tests use `test(...)` not `testWidgets(...)`.
- **Modifier-key detection in tests:** use `tester.sendKeyEvent(LogicalKeyboardKey.controlLeft)` before tapping — Flutter test infra handles modifier state.
- **Mobile multi-select:** mobile has no cmd-click. Long-press is the touch equivalent. Document this for QA.
- **Banner positioning:** add a NEW widget `EdenSchedulerBanners` that sits between Toolbar and view body in `eden_scheduler.dart`. Conditionally renders zero, one, or two banners (selection precedence).
- **Layout engine output shape:** `Map<String, EventLayout>` where `EventLayout = (columnIdx, columnCount)`. The view consumes this map: `left = colIdx / count * columnWidth`, `width = columnWidth / count`.
- **Performance:** N² for overlap detection is OK for typical event counts (<200). For high counts, sweep-line is O(N log N). Defer optimization to TRD 16.
</gotchas>

```dart
import 'scheduler_models.dart';

class EventLayout {
  const EventLayout({required this.columnIdx, required this.columnCount});
  final int columnIdx;
  final int columnCount;
}

class EdenSchedulerConflictLayout {
  const EdenSchedulerConflictLayout._();

  /// Computes a column index + column count for each event, such that
  /// overlapping events render side-by-side at 1/N width.
  ///
  /// Algorithm: greedy first-fit by start time. Events that don't overlap
  /// the latest event in a column share that column. Cluster of overlapping
  /// events all get columnCount = max columns used within the cluster.
  static Map<String, EventLayout> compute(List<EdenSchedulerEvent> events) {
    if (events.isEmpty) return const {};
    final sorted = events.toList()
      ..sort((a, b) {
        final cmp = a.start.compareTo(b.start);
        if (cmp != 0) return cmp;
        return a.id.compareTo(b.id);
      });

    // Step 1: assign columns greedily.
    final columns = <DateTime>[]; // latest end per column
    final eventColumn = <String, int>{};
    for (final e in sorted) {
      var placed = false;
      for (var c = 0; c < columns.length; c++) {
        if (!columns[c].isAfter(e.start)) {
          columns[c] = e.end;
          eventColumn[e.id] = c;
          placed = true;
          break;
        }
      }
      if (!placed) {
        eventColumn[e.id] = columns.length;
        columns.add(e.end);
      }
    }

    // Step 2: compute cluster size per event.
    // A cluster is a maximal connected set of events linked by overlap.
    // For each event, find the max columnCount used by any event in its cluster.
    final clusters = _buildClusters(sorted);
    final eventCluster = <String, int>{};
    final clusterCount = <int, int>{}; // clusterId → max(col+1) seen
    for (var ci = 0; ci < clusters.length; ci++) {
      var maxCol = 0;
      for (final e in clusters[ci]) {
        final c = eventColumn[e.id]!;
        if (c > maxCol) maxCol = c;
        eventCluster[e.id] = ci;
      }
      clusterCount[ci] = maxCol + 1;
    }

    final out = <String, EventLayout>{};
    for (final e in sorted) {
      final ci = eventCluster[e.id]!;
      out[e.id] = EventLayout(
        columnIdx: eventColumn[e.id]!,
        columnCount: clusterCount[ci]!,
      );
    }
    return out;
  }

  /// Detects conflicts: returns list of (eventA, eventB) pairs that overlap.
  static List<(EdenSchedulerEvent, EdenSchedulerEvent)> detectConflicts(
    List<EdenSchedulerEvent> events,
  ) {
    final out = <(EdenSchedulerEvent, EdenSchedulerEvent)>[];
    for (var i = 0; i < events.length; i++) {
      for (var j = i + 1; j < events.length; j++) {
        final a = events[i];
        final b = events[j];
        if (a.start.isBefore(b.end) && b.start.isBefore(a.end)) {
          out.add((a, b));
        }
      }
    }
    return out;
  }

  /// Build clusters: connected components of overlap graph.
  static List<List<EdenSchedulerEvent>> _buildClusters(List<EdenSchedulerEvent> sorted) {
    final clusters = <List<EdenSchedulerEvent>>[];
    var current = <EdenSchedulerEvent>[];
    DateTime? currentMaxEnd;
    for (final e in sorted) {
      if (currentMaxEnd == null || e.start.isBefore(currentMaxEnd)) {
        current.add(e);
        if (currentMaxEnd == null || e.end.isAfter(currentMaxEnd)) {
          currentMaxEnd = e.end;
        }
      } else {
        clusters.add(current);
        current = [e];
        currentMaxEnd = e.end;
      }
    }
    if (current.isNotEmpty) clusters.add(current);
    return clusters;
  }
}
```
