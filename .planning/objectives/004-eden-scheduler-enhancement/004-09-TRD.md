<objective>
Wave 3 view — Swimlane. The donor `TruckAvailabilityView.tsx` (1761 LOC) is the swimlane view: trucks as columns, multi-day date axis, availability blocks behind events. Used for dispatcher resource planning ("which truck is available next Tuesday afternoon?").

Library version: generic resource-swimlane with simpler scope than donor (no recurrence editor inline, no drag-reorder of resources). Drag-to-reschedule between resources IS supported (key dispatch UX).

Parity row V-6.
</objective>

<context>
**Locked design inputs:**
- Donor `TruckAvailabilityView.tsx:152-186` — `TruckAvailabilityViewProps` exposes `trucks`, `appointments`, `scheduleBlocks`, `selectedDate`, `dateRange`, etc.
- Donor renders trucks-as-columns and days-as-rows (NOT days-as-columns). Each cell is `(truck, day)` showing all appointments for that combination.
- Donor `ScheduleBlock` (availability) is rendered as a colored background behind the day's events.
- Donor groups trucks by category via `categoryId`. Library: groups by `resource.group`.
- Visual: dispatcher views weeks of resource capacity at-a-glance, drags appointments between resources, sees what's blocked.

**Approach (simpler than donor):**
1. Layout: horizontal scrolling grid; each column = one resource; each row = one day; visible range = 3 weeks by default.
2. Cell content: stacked compact event bars (smaller than EdenSchedulerEventBlock; reuse it with a `compact: true` flag OR build a separate `_SwimlaneEventCell`).
3. Availability block: `Positioned.fill` Container behind events in the cell, with low-opacity color per kind.
4. Drag-to-reschedule: each cell is a DragTarget. On drop, identify the resource (from column) and date (from row), call `onEventMove(event, newStart, newEnd, newResourceIds: [colResource.id])`.

**Min width 1200pt:** below 1200pt, render fallback message + button "Switch to mobile" → calls `widget.onSwitchToMobile?.call()` or similar callback to let consumer route to the mobile view. Library MUST NOT silently overflow — better to fall back gracefully.

**Resource-grouping:** when 2+ resources share a `group.id`, render a thin vertical separator + group label above the column headers.

**Lane toggle:** clicking a resource header column toggles a `_collapsed` set state; collapsed columns render at 40pt width with just the name initial. Tap again to expand.
</context>

<gotchas>
- **Sticky date column:** the left date column should stay visible during horizontal scroll. Use a `SingleChildScrollView(scrollDirection: Axis.horizontal)` wrapping the resource columns, with the date column OUTSIDE the scroll view in a Row.
- **Vertical scroll:** date rows scroll vertically too. Wrap the whole grid in a `SingleChildScrollView(scrollDirection: Axis.vertical)`.
- **Cross-axis scroll coordination:** the date column (left) and resource columns (right) must share the vertical scroll position. Use a single ScrollController for vertical. Alternative: nested SingleChildScrollView is fine for v1 with synced via `ScrollController.addListener` (works but flickers; v2 may use `SyncScrollController` from `package:linked_scroll_controller` — that's a new dep, defer).
- **Date range default 3 weeks:** 21 days = 21 rows. Use ListView.builder for memory.
- **Resource ordering:** sort by `resource.group.sortOrder` ascending, then `resource.name`. Resources without a group come last.
- **Event filtering per cell:** `events.where((e) => sameDay(e.start, day) && e.resourceIds?.contains(resource.id))`. Pre-compute via grouped map outside the per-cell builder.
- **Drag target resource determination:** the DragTarget knows its column → knows resource. Pass `resource` to onDrop. Compute new date from row.
- **Drag preserves time-of-day:** when dropping an event in a new (date, resource) cell, keep the original hour/minute, change the date and resourceIds. Same as cross-day drag in WeekView.
- **Availability block render order:** ALL availability blocks for a (date, resource) cell render BEFORE events in the Stack. Events on top.
- **Empty grid state:** if `resources.isEmpty`, render "No resources to display."; if `events.isEmpty`, just show empty cells.
- **Lane collapse keyboard:** for v1, click-only. Keyboard support deferred.
</gotchas>

```dart
import 'package:flutter/material.dart';
import '../../tokens/colors.dart';
import '../../tokens/radii.dart';
import '../../tokens/spacing.dart';
import 'scheduler_event_block.dart';
import 'scheduler_models.dart';
import 'scheduler_time_math.dart';

class EdenSchedulerSwimlaneView extends StatefulWidget {
  const EdenSchedulerSwimlaneView({
    super.key,
    required this.focusedDate,
    required this.today,
    required this.resources,
    required this.events,
    this.availabilityBlocks = const [],
    this.dateRange = const Duration(days: 21),
    this.onEventTap,
    this.onEventMove,
    this.onSwitchToMobile,
  });

  final DateTime focusedDate;
  final DateTime today;
  final List<EdenSchedulerResource> resources;
  final List<EdenSchedulerEvent> events;
  final List<EdenSchedulerAvailabilityBlock> availabilityBlocks;
  final Duration dateRange;
  final ValueChanged<EdenSchedulerEvent>? onEventTap;
  final void Function(EdenSchedulerEvent, DateTime, DateTime, List<String> newResourceIds)? onEventMove;
  final VoidCallback? onSwitchToMobile;

  @override
  State<EdenSchedulerSwimlaneView> createState() => _EdenSchedulerSwimlaneViewState();
}

class _EdenSchedulerSwimlaneViewState extends State<EdenSchedulerSwimlaneView> {
  final Set<String> _collapsed = <String>{};
  late ScrollController _hScroll;
  late ScrollController _vScroll;

  @override
  void initState() {
    super.initState();
    _hScroll = ScrollController();
    _vScroll = ScrollController();
  }

  @override
  void dispose() {
    _hScroll.dispose();
    _vScroll.dispose();
    super.dispose();
  }

  List<DateTime> get _dates {
    final start = EdenSchedulerTimeMath.startOfWeek(widget.focusedDate);
    return List.generate(
      widget.dateRange.inDays,
      (i) => EdenSchedulerTimeMath.addDays(start, i),
    );
  }

  List<EdenSchedulerResource> get _orderedResources {
    final list = widget.resources.toList();
    list.sort((a, b) {
      final aOrder = a.group?.sortOrder ?? 999;
      final bOrder = b.group?.sortOrder ?? 999;
      if (aOrder != bOrder) return aOrder.compareTo(bOrder);
      return a.name.compareTo(b.name);
    });
    return list;
  }

  static const double _dateColumnWidth = 100;
  static const double _columnWidth = 180;
  static const double _collapsedColumnWidth = 40;
  static const double _rowHeight = 80;
  static const double _headerHeight = 56;

  double _resourceColumnWidth(EdenSchedulerResource r) =>
      _collapsed.contains(r.id) ? _collapsedColumnWidth : _columnWidth;

  List<EdenSchedulerEvent> _eventsForCell(DateTime day, EdenSchedulerResource r) =>
      widget.events.where((e) {
        final sameDay = EdenSchedulerTimeMath.stripTime(e.start) ==
            EdenSchedulerTimeMath.stripTime(day);
        final matchesResource = (e.resourceIds ?? const []).contains(r.id);
        return sameDay && matchesResource;
      }).toList();

  EdenSchedulerAvailabilityBlock? _blockForCell(DateTime day, EdenSchedulerResource r) {
    for (final b in widget.availabilityBlocks) {
      if (b.resourceId == r.id) {
        final overlap = b.start.isBefore(EdenSchedulerTimeMath.addDays(day, 1)) &&
            b.end.isAfter(day);
        if (overlap) return b;
      }
    }
    return null;
  }

  Color _blockTint(EdenSchedulerAvailabilityKind kind) {
    switch (kind) {
      case EdenSchedulerAvailabilityKind.maintenance:
        return const Color(0xFFFACC15).withOpacity(0.2);
      case EdenSchedulerAvailabilityKind.blocked:
        return const Color(0xFFEF4444).withOpacity(0.2);
      case EdenSchedulerAvailabilityKind.available:
        return Colors.transparent;
    }
  }

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(
      builder: (context, constraints) {
        if (constraints.maxWidth < 1200) {
          return _FallbackMessage(onSwitchToMobile: widget.onSwitchToMobile);
        }
        if (widget.resources.isEmpty) {
          return const Center(child: Text('No resources to display.'));
        }
        return Row(
          children: [
            _DateColumn(
              dates: _dates,
              today: widget.today,
              width: _dateColumnWidth,
              rowHeight: _rowHeight,
              headerHeight: _headerHeight,
            ),
            Expanded(
              child: SingleChildScrollView(
                controller: _hScroll,
                scrollDirection: Axis.horizontal,
                child: SizedBox(
                  width: _orderedResources.fold<double>(
                    0,
                    (sum, r) => sum + _resourceColumnWidth(r),
                  ),
                  child: Column(
                    children: [
                      _HeaderRow(
                        resources: _orderedResources,
                        height: _headerHeight,
                        widthOf: _resourceColumnWidth,
                        onTap: (r) => setState(() {
                          if (_collapsed.contains(r.id)) {
                            _collapsed.remove(r.id);
                          } else {
                            _collapsed.add(r.id);
                          }
                        }),
                      ),
                      Expanded(
                        child: ListView.builder(
                          controller: _vScroll,
                          itemCount: _dates.length,
                          itemBuilder: (context, rowIdx) {
                            final day = _dates[rowIdx];
                            return Row(
                              children: _orderedResources.map((r) {
                                final width = _resourceColumnWidth(r);
                                final cellEvents = _eventsForCell(day, r);
                                final block = _blockForCell(day, r);
                                return DragTarget<EdenSchedulerEvent>(
                                  onAcceptWithDetails: (details) {
                                    final e = details.data;
                                    final duration = e.end.difference(e.start);
                                    final newStart = DateTime(
                                      day.year, day.month, day.day,
                                      e.start.hour, e.start.minute,
                                    );
                                    final newEnd = newStart.add(duration);
                                    widget.onEventMove?.call(e, newStart, newEnd, [r.id]);
                                  },
                                  builder: (context, _, __) => Container(
                                    width: width,
                                    height: _rowHeight,
                                    decoration: BoxDecoration(
                                      color: block != null ? _blockTint(block.kind) : null,
                                      border: Border.all(color: Theme.of(context).dividerColor),
                                    ),
                                    child: ListView(
                                      padding: const EdgeInsets.all(2),
                                      children: cellEvents.map((e) =>
                                        SizedBox(
                                          height: 22,
                                          child: EdenSchedulerEventBlock(
                                            event: e,
                                            onTap: () => widget.onEventTap?.call(e),
                                            allowResize: false, // swimlane is compact
                                          ),
                                        ),
                                      ).toList(),
                                    ),
                                  ),
                                );
                              }).toList(),
                            );
                          },
                        ),
                      ),
                    ],
                  ),
                ),
              ),
            ),
          ],
        );
      },
    );
  }
}

class _DateColumn extends StatelessWidget {
  const _DateColumn({
    required this.dates,
    required this.today,
    required this.width,
    required this.rowHeight,
    required this.headerHeight,
  });
  final List<DateTime> dates;
  final DateTime today;
  final double width;
  final double rowHeight;
  final double headerHeight;
  static const _dayShort = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'];
  static const _months = ['Jan','Feb','Mar','Apr','May','Jun','Jul','Aug','Sep','Oct','Nov','Dec'];

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    return Container(
      width: width,
      decoration: BoxDecoration(border: Border(right: BorderSide(color: theme.dividerColor))),
      child: Column(
        children: [
          SizedBox(height: headerHeight),
          Expanded(
            child: ListView.builder(
              itemCount: dates.length,
              itemBuilder: (context, i) {
                final d = dates[i];
                final isToday = EdenSchedulerTimeMath.stripTime(d) ==
                    EdenSchedulerTimeMath.stripTime(today);
                return Container(
                  height: rowHeight,
                  padding: const EdgeInsets.symmetric(horizontal: EdenSpacing.space2),
                  decoration: BoxDecoration(
                    color: isToday ? theme.colorScheme.primary.withOpacity(0.08) : null,
                    border: Border(bottom: BorderSide(color: theme.dividerColor)),
                  ),
                  alignment: Alignment.centerLeft,
                  child: Text(
                    '${_dayShort[d.weekday - 1]}, ${_months[d.month - 1]} ${d.day}',
                    style: theme.textTheme.labelSmall,
                  ),
                );
              },
            ),
          ),
        ],
      ),
    );
  }
}

class _HeaderRow extends StatelessWidget {
  const _HeaderRow({
    required this.resources,
    required this.height,
    required this.widthOf,
    required this.onTap,
  });
  final List<EdenSchedulerResource> resources;
  final double height;
  final double Function(EdenSchedulerResource) widthOf;
  final ValueChanged<EdenSchedulerResource> onTap;

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    String? lastGroupId;
    final cells = <Widget>[];
    for (final r in resources) {
      final groupId = r.group?.id;
      if (groupId != lastGroupId && lastGroupId != null) {
        cells.add(Container(width: 1, height: height, color: theme.dividerColor));
      }
      lastGroupId = groupId;
      cells.add(GestureDetector(
        onTap: () => onTap(r),
        child: Container(
          width: widthOf(r),
          height: height,
          decoration: BoxDecoration(
            border: Border(
              right: BorderSide(color: theme.dividerColor),
              bottom: BorderSide(color: theme.dividerColor),
            ),
          ),
          padding: const EdgeInsets.symmetric(horizontal: EdenSpacing.space2),
          child: Row(
            children: [
              Container(
                width: 8,
                height: 8,
                decoration: BoxDecoration(color: r.color ?? theme.colorScheme.primary, shape: BoxShape.circle),
              ),
              const SizedBox(width: 4),
              Expanded(child: Text(r.name, maxLines: 1, overflow: TextOverflow.ellipsis, style: theme.textTheme.labelMedium)),
            ],
          ),
        ),
      ));
    }
    return Row(children: cells);
  }
}

        ],
      ),
    );
  }
}
```
