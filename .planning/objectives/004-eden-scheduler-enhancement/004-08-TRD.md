<context>
**Locked design inputs:**
- Donor `MobileScheduleView.tsx` exposes `mobileViewMode: 'day' | 'week' | 'month'` with a tab strip at top.
- Donor `TruckChipStrip.tsx` — horizontal scrolling row of colored truck chips; multi-select via tap.
- Donor `usePinchZoom.ts` — gesture-driven zoom level state 0.5×..2.0× applied as scale factor to slot heights.
- Donor `MobileDayView.tsx` — single-day grid with truck-chip strip pinned at top, time grid below.
- Donor `MobileWeekView.tsx` — 7-column compressed grid optimized for narrow widths (no resize handles, smaller chips).
- Donor `MobileMonthView.tsx` — heatmap dot grid; tap day → drill into day detail bottom sheet.

**Locked decision E rule 3 (responsive lock from obj 002-05):** at logical width < 1200pt, `EdenCompanionShell` forces Compact tier — which means consumers using `EdenScheduler` inside `EdenCompanionShell` get the mobile view automatically. The library's `EdenScheduler` exposes a `forceMobileView: bool` flag so consumers can route to mobile explicitly without companion shell.

**Approach — three sub-widgets:**
1. `EdenSchedulerMobileView` — top-level composite that hosts the tab strip + chip strip + body.
2. `EdenSchedulerResourceChipStrip` — horizontal scrolling Wrap of colored chips (resources). Multi-select. Tap chip → controller.toggleResourceFilter(resource.id).
3. `EdenSchedulerPinchZoom` — wrapper widget that detects pinch gestures and reports zoom level via callback.

**Pinch zoom math (Flutter):** use `GestureDetector(onScaleUpdate: ...)`. `details.scale` is cumulative factor since gesture start. Clamp result `_zoomLevel * details.scale` to [0.5, 2.0]. On `onScaleEnd`, commit the new zoom (which then applies to all subsequent layouts via slotHeight multiplier).

**Swipe-to-navigate-date (mobile day mode):** use `PageView.builder` for horizontal swipe. PageController page index maps to date offset from a fixed anchor. On `onPageChanged`, controller.setFocusedDate.
</context>

<gotchas>
- **PageView infinite scroll:** PageView.builder with `null` itemCount makes it infinite — needed for unbounded date navigation. But indexing math: `page = N` means N days after the anchor. Use a large anchor `int.maxValue ~/ 2` to allow infinite both directions.
- **Pinch + drag conflict:** the time-grid has drag-to-reschedule (TRD 10). Pinch starts with 2 fingers — Flutter's gesture arena prefers pinch over drag when 2 pointers are present. Should work out of the box; verify with a manual test.
- **Resource chip color contrast:** in companion mode at high brightness, light chips on light backgrounds disappear. Each chip MUST have a dark border (1pt) for contrast. Mirror the existing `EdenChip` widget contrast pattern.
- **Pinch + swipe-nav conflict:** PageView already handles horizontal-swipe natively. Pinch is vertical/scale. Don't conflict.
- **Mode tab strip width at 390pt:** 3 tabs of "Day"/"Week"/"Month" = ~50pt each = 150pt + padding. Fits easily.
- **Mobile week view at 390pt:** 7 cols, 56pt gutter, ~48pt per column. Use single-letter day initials (M/T/W/T/F/S/S) + day number. No expand-arrow (no room). No event titles inside chips (dots only).
- **Mobile month view:** identical to MonthView (TRD 06) but with `maxEventsPerCell: 1` and `narrow: true` forced. Reuse the existing `EdenSchedulerMonthView` widget — just pass `maxEventsPerCell: 1`.
- **Compact integration:** when `EdenAdaptiveLayout.isCompact == true` (from obj 002-02), `EdenScheduler` auto-routes to `EdenSchedulerMobileView` regardless of view enum. Document this in `EdenScheduler.forceMobileView` dartdoc. Implementation: in `eden_scheduler.dart` `_buildBody`, wrap with a `LayoutBuilder` that checks `MediaQuery.size.width < 600` OR `widget.forceMobileView == true` → return `EdenSchedulerMobileView(...)`.
- **Subwidget tests:** test each sub-widget in isolation (chip-strip, pinch-zoom) plus an integration test for the composite. Outside-in: integration first, then drill.
</gotchas>

import 'package:flutter/material.dart';

class EdenSchedulerPinchZoom extends StatefulWidget {
  const EdenSchedulerPinchZoom({
    super.key,
    required this.child,
    this.initialZoom = 1.0,
    this.minZoom = 0.5,
    this.maxZoom = 2.0,
    required this.onZoomChanged,
  });

  final Widget child;
  final double initialZoom;
  final double minZoom;
  final double maxZoom;
  final ValueChanged<double> onZoomChanged;

  @override
  State<EdenSchedulerPinchZoom> createState() => _EdenSchedulerPinchZoomState();
}

class _EdenSchedulerPinchZoomState extends State<EdenSchedulerPinchZoom> {
  late double _zoom = widget.initialZoom;
  double _baseAtGestureStart = 1.0;

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onScaleStart: (_) {
        _baseAtGestureStart = _zoom;
      },
      onScaleUpdate: (details) {
        final next = (_baseAtGestureStart * details.scale)
            .clamp(widget.minZoom, widget.maxZoom);
        if (next == _zoom) return;
        setState(() => _zoom = next);
        widget.onZoomChanged(_zoom);
      },
      child: widget.child,
    );
  }
}
```

import 'package:flutter/material.dart';
import 'scheduler_controller.dart';
import 'scheduler_day_view.dart';
import 'scheduler_models.dart';
import 'scheduler_month_view.dart';
import 'scheduler_pinch_zoom.dart';
import 'scheduler_resource_chip_strip.dart';
import 'scheduler_week_view.dart';
import 'scheduler_time_math.dart';

enum _MobileMode { day, week, month }

class EdenSchedulerMobileView extends StatefulWidget {
  const EdenSchedulerMobileView({
    super.key,
    required this.controller,
    this.resources = const [],
    this.events = const [],
    this.config = const EdenSchedulerConfig(),
    this.onEventTap,
    this.onEventMove,
    this.onTimeSlotTap,
  });

  final EdenSchedulerController controller;
  final List<EdenSchedulerResource> resources;
  final List<EdenSchedulerEvent> events;
  final EdenSchedulerConfig config;
  final ValueChanged<EdenSchedulerEvent>? onEventTap;
  final void Function(EdenSchedulerEvent, DateTime, DateTime)? onEventMove;
  final ValueChanged<DateTime>? onTimeSlotTap;

  @override
  State<EdenSchedulerMobileView> createState() => _EdenSchedulerMobileViewState();
}

class _EdenSchedulerMobileViewState extends State<EdenSchedulerMobileView> {
  _MobileMode _mode = _MobileMode.day;
  double _zoom = 1.0;
  late PageController _pageController;
  static const int _anchor = 10000;
  late DateTime _anchorDate;

  @override
  void initState() {
    super.initState();
    _anchorDate = widget.controller.focusedDate;
    _pageController = PageController(initialPage: _anchor);
  }

  @override
  void dispose() {
    _pageController.dispose();
    super.dispose();
  }

  EdenSchedulerConfig get _zoomedConfig => EdenSchedulerConfig(
    startHour: widget.config.startHour,
    endHour: widget.config.endHour,
    slotHeight: widget.config.slotHeight * _zoom,
    fullDay: widget.config.fullDay,
  );

  Widget _body() {
    switch (_mode) {
      case _MobileMode.day:
        return PageView.builder(
          controller: _pageController,
          onPageChanged: (page) {
            final delta = page - _anchor;
            widget.controller.setFocusedDate(_anchorDate.add(Duration(days: delta)));
          },
          itemBuilder: (context, page) {
            final delta = page - _anchor;
            return EdenSchedulerDayView(
              focusedDate: _anchorDate.add(Duration(days: delta)),
              today: widget.controller.today,
              events: widget.events,
              config: _zoomedConfig,
              onEventTap: widget.onEventTap,
              onEventMove: widget.onEventMove,
              onTimeSlotTap: widget.onTimeSlotTap,
            );
          },
        );
      case _MobileMode.week:
        return EdenSchedulerWeekView(
          focusedDate: widget.controller.focusedDate,
          mode: EdenSchedulerWeekMode.week,
          events: widget.events,
          config: _zoomedConfig,
          onEventTap: widget.onEventTap,
          onEventMove: widget.onEventMove,
        );
      case _MobileMode.month:
        return EdenSchedulerMonthView(
          focusedDate: widget.controller.focusedDate,
          today: widget.controller.today,
          events: widget.events,
          isDark: Theme.of(context).brightness == Brightness.dark,
          theme: Theme.of(context),
          maxEventsPerCell: 1,
          onEventTap: widget.onEventTap,
        );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        // Mode tab strip
        Padding(
          padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 8),
          child: SegmentedButton<_MobileMode>(
            segments: const [
              ButtonSegment(value: _MobileMode.day, label: Text('Day')),
              ButtonSegment(value: _MobileMode.week, label: Text('Week')),
              ButtonSegment(value: _MobileMode.month, label: Text('Month')),
            ],
            selected: {_mode},
            onSelectionChanged: (s) => setState(() => _mode = s.first),
          ),
        ),
        // Resource chip strip
        EdenSchedulerResourceChipStrip(
          resources: widget.resources,
          selectedIds: widget.controller.selectedResources,
          onToggle: widget.controller.toggleResourceFilter,
        ),
        // Body (with pinch-to-zoom on day/week)
        Expanded(
          child: _mode == _MobileMode.month
              ? _body()
              : EdenSchedulerPinchZoom(
                  initialZoom: _zoom,
                  onZoomChanged: (z) => setState(() => _zoom = z),
                  child: _body(),
                ),
        ),
      ],
    );
  }
}
```
