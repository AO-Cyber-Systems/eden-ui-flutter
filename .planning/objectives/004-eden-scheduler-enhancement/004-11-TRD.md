<objective>
Wave 3 component — `EdenSchedulerAllDayRow`. The horizontal strip above the time grid (visible as the "Notes" row in screenshot `04-schedule-page.png` line ~250pt) holds events whose `allDay == true`. Multi-day events span multiple cells. Drag-to-reschedule between days. Drag from hour-grid into all-day-row converts event to all-day.

Parity rows TG-8, DR-5.
</objective>

<context>
**Locked design inputs:**
- Donor's all-day row visible in `04-schedule-page.png` as the row labeled "Notes" between day headers and the 6 AM hour. Contains truck-group all-day cards and flexible-scheduling appointments.
- Donor `handleAllDayDragOver` + `handleAllDayDrop` at `EnhancedCalendar.tsx:3621-3622` — cross-day all-day events drag-and-drop.
- Event with `flexibleScheduling: true` (donor) or `allDay: true` (library) goes here.

**Approach:**
1. `EdenSchedulerAllDayRow` widget accepts `days: List<DateTime>`, `events: List<EdenSchedulerEvent>` (filtered to allDay), `onEventTap`, `onEventMove`.
2. Rendered as a `Row` of N cells, each cell with a fixed width = column width from parent.
3. Each cell is a `DragTarget<EdenSchedulerEvent>` (accepts cross-day moves AND hour-grid-converts).
4. Multi-day events (start.day != end.day) render as a single bar spanning multiple cells. Use a Stack overlay with absolute positioning.
5. Empty row: collapsed to ~24pt height with optional "Notes" label.

**Multi-day spanning:** an event with `start: 2026-05-11 0:00, end: 2026-05-13 23:59, allDay: true` should render as one bar spanning Mon-Wed. Layout math:
- Find the first visible day where event.start <= day < event.end.
- Width = (number of visible days the event spans) × cellWidth.
- Render via `Positioned(left: firstColIdx * cellWidth, width: span * cellWidth)` inside a Stack.

**Drag-from-hour-grid integration:** the hour grid in DayView/WeekView is a `DragTarget<EdenSchedulerEvent>`. The all-day row above is ALSO a DragTarget. When user drags an hour-grid event upward into the all-day row, the drop is captured by the all-day row's DragTarget; convert to allDay by firing `onEventMove(event, dayStart, dayStart, allDay: true)`. **For v1 the callback signature stays the same** — encode allDay as `newStart == newEnd` (zero-duration) OR add a separate `onEventConvertToAllDay(event, day)` callback. Choose: **add `onEventConvertToAllDay` for explicit semantics**.
</context>

<gotchas>
- **Multi-day spanning math:** when only PART of a multi-day event is visible (e.g. event spans Mon-Fri, view shows Wed-Sat), clip start to first visible day and end to last visible day. Don't render off-screen portions.
- **Event sort within cell:** when multiple all-day events on same day, stack vertically. Use `Column` inside the cell (or a Wrap).
- **Bar height:** 22pt is enough for one line of text. Allow the row to grow to fit multiple bars (max 3 stacked, then "+N more" like MonthView).
- **Cross-day drag:** dropping an all-day event from Mon cell to Wed cell calls `onEventMove(event, wedStart, wedEnd, allDay: true)` — keep the duration (hours) the same. For pure all-day events with no time, use day boundaries.
- **Conversion-to-all-day callback:** `onEventConvertToAllDay(EdenSchedulerEvent event, DateTime day)` is invoked when an hour-grid event is dropped into the all-day row. Library doesn't mutate the event; consumer decides whether to apply (and may show a confirmation dialog).
- **Drop target precedence:** all-day row DragTarget is above hour-grid DragTarget. Flutter resolves via hit testing — whichever target the pointer is currently over wins. As long as visual layout matches z-order, this works.
- **Empty state:** when `events.where((e) => e.allDay).isEmpty`, render a thin 24pt-high row with "Notes" label on the left (visible in screenshot). Maintains visual rhythm.
- **iPhone-narrow at 390pt:** for a 7-col Week mode, cells at ~48pt are tight. All-day event title needs `ellipsis`. Multi-day spans still work but title fits in first cell only.
- **DayView case:** allDayRow with 1 cell (just today's column). Multi-day events still render as wide bars covering the single visible day; the "rest of the event" extends conceptually but isn't shown.
</gotchas>

```dart
import 'package:flutter/material.dart';
import '../../tokens/colors.dart';
import '../../tokens/spacing.dart';
import 'scheduler_models.dart';
import 'scheduler_time_math.dart';

class EdenSchedulerAllDayRow extends StatelessWidget {
  const EdenSchedulerAllDayRow({
    super.key,
    required this.days,
    required this.events,
    this.gutterWidth = 56,
    this.maxStacked = 3,
    this.onEventTap,
    this.onEventMove,
    this.onEventConvertToAllDay,
  });

  final List<DateTime> days;
  final List<EdenSchedulerEvent> events;
  final double gutterWidth;
  final int maxStacked;
  final ValueChanged<EdenSchedulerEvent>? onEventTap;
  final void Function(EdenSchedulerEvent, DateTime newStart, DateTime newEnd)? onEventMove;
  final void Function(EdenSchedulerEvent, DateTime day)? onEventConvertToAllDay;

  List<EdenSchedulerEvent> get _allDayEvents =>
      events.where((e) => e.allDay).toList();

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final allDay = _allDayEvents;

    if (allDay.isEmpty) {
      return Container(
        height: 24,
        decoration: BoxDecoration(
          border: Border(bottom: BorderSide(color: theme.dividerColor)),
        ),
        padding: const EdgeInsets.only(left: EdenSpacing.space2),
        alignment: Alignment.centerLeft,
        child: Text(
          'Notes',
          style: theme.textTheme.labelSmall?.copyWith(color: theme.colorScheme.outline),
        ),
      );
    }

    return LayoutBuilder(
      builder: (context, constraints) {
        final cellWidth = (constraints.maxWidth - gutterWidth) / days.length;
        // Compute stacking lanes for events. Each lane is a list of non-overlapping events.
        final lanes = _computeLanes(allDay, days);
        final laneCount = lanes.length.clamp(1, maxStacked);
        final rowHeight = 24 + (laneCount * 22.0);

        return SizedBox(
          height: rowHeight,
          child: Row(
            children: [
              SizedBox(width: gutterWidth, child: Padding(
                padding: const EdgeInsets.only(left: EdenSpacing.space2),
                child: Text('Notes', style: theme.textTheme.labelSmall?.copyWith(color: theme.colorScheme.outline)),
              )),
              Expanded(
                child: Stack(
                  clipBehavior: Clip.hardEdge,
                  children: [
                    // Cell backgrounds + drag targets
                    for (var i = 0; i < days.length; i++)
                      Positioned(
                        left: i * cellWidth,
                        top: 0,
                        width: cellWidth,
                        height: rowHeight,
                        child: DragTarget<EdenSchedulerEvent>(
                          onAcceptWithDetails: (details) {
                            final e = details.data;
                            final day = days[i];
                            if (e.allDay) {
                              final dayEnd = EdenSchedulerTimeMath.addDays(day, 1).subtract(const Duration(seconds: 1));
                              onEventMove?.call(e, day, dayEnd);
                            } else {
                              onEventConvertToAllDay?.call(e, day);
                            }
                          },
                          builder: (context, _, __) => Container(
                            decoration: BoxDecoration(
                              border: Border(
                                right: BorderSide(color: theme.dividerColor),
                                bottom: BorderSide(color: theme.dividerColor),
                              ),
                            ),
                          ),
                        ),
                      ),
                    // Event bars
                    for (var laneIdx = 0; laneIdx < lanes.length && laneIdx < maxStacked; laneIdx++)
                      for (final e in lanes[laneIdx])
                        _eventBar(context, e, cellWidth, laneIdx),
                    // Overflow indicator
                    if (lanes.length > maxStacked)
                      Positioned(
                        right: 4,
                        bottom: 2,
                        child: Text(
                          '+${lanes.length - maxStacked} more',
                          style: theme.textTheme.labelSmall,
                        ),
                      ),
                  ],
                ),
              ),
            ],
          ),
        );
      },
    );
  }

  Widget _eventBar(BuildContext context, EdenSchedulerEvent e, double cellWidth, int laneIdx) {
    final theme = Theme.of(context);
    final stripped = days.map(EdenSchedulerTimeMath.stripTime).toList();
    final eStart = EdenSchedulerTimeMath.stripTime(e.start);
    final eEnd = EdenSchedulerTimeMath.stripTime(e.end);
    final firstIdx = stripped.indexWhere((d) => !d.isBefore(eStart) && !d.isAfter(eEnd));
    if (firstIdx < 0) return const SizedBox.shrink();
    // Last visible day idx
    var lastIdx = firstIdx;
    for (var i = firstIdx; i < stripped.length; i++) {
      if (!stripped[i].isAfter(eEnd)) lastIdx = i;
    }
    final span = lastIdx - firstIdx + 1;
    return Positioned(
      left: firstIdx * cellWidth + 2,
      top: laneIdx * 22.0,
      width: span * cellWidth - 4,
      height: 20,
      child: Draggable<EdenSchedulerEvent>(
        data: e,
        feedback: Material(elevation: 4, child: SizedBox(width: cellWidth * span - 4, height: 20, child: _bar(context, e))),
        childWhenDragging: Opacity(opacity: 0.3, child: _bar(context, e)),
        child: GestureDetector(
          onTap: () => onEventTap?.call(e),
          child: _bar(context, e),
        ),
      ),
    );
  }

  Widget _bar(BuildContext context, EdenSchedulerEvent e) {
    final theme = Theme.of(context);
    return Container(
      decoration: BoxDecoration(
        color: (e.color ?? theme.colorScheme.primary).withOpacity(0.85),
        borderRadius: BorderRadius.circular(4),
      ),
      padding: const EdgeInsets.symmetric(horizontal: 4),
      child: Text(
        e.title,
        style: const TextStyle(color: Colors.white, fontSize: 12, fontWeight: FontWeight.w500),
        maxLines: 1,
        overflow: TextOverflow.ellipsis,
      ),
    );
  }

  /// Group events into lanes (rows) such that no two events in the same lane overlap.
  /// Greedy first-fit.
  List<List<EdenSchedulerEvent>> _computeLanes(List<EdenSchedulerEvent> events, List<DateTime> days) {
    final sorted = events.toList()..sort((a, b) => a.start.compareTo(b.start));
    final lanes = <List<EdenSchedulerEvent>>[];
    for (final e in sorted) {
      var placed = false;
      for (final lane in lanes) {
        final last = lane.last;
        if (!e.start.isBefore(last.end)) {
          lane.add(e);
          placed = true;
          break;
        }
      }
      if (!placed) lanes.add([e]);
    }
    return lanes;
  }
}
```
