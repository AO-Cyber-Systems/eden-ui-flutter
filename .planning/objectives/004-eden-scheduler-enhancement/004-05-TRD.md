Now-indicator overlay (column-scoped):
```dart
Widget _nowIndicator(double columnWidth, BoxConstraints constraints) {
  final now = (widget.clock ?? DateTime.now)();
  final today = EdenSchedulerTimeMath.stripTime(now);
  final days = _days;
  final todayIdx = days.indexWhere((d) => EdenSchedulerTimeMath.stripTime(d) == today);
  if (todayIdx < 0) return const SizedBox.shrink();
  final cfg = widget.config;
  if (now.hour < cfg.effectiveStartHour || now.hour >= cfg.effectiveEndHour) {
    return const SizedBox.shrink();
  }
  final y = (now.hour - cfg.effectiveStartHour + now.minute / 60.0) * cfg.slotHeight;
  return Positioned(
    top: y,
    left: 56 + todayIdx * columnWidth,
    width: columnWidth,
    child: IgnorePointer(
      child: Container(height: 2, color: Colors.red),
    ),
  );
}
```
