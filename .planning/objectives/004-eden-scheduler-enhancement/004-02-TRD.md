<gotchas>
- **`visibleViews` default = null = all 7 visible.** Critical for backward compat — existing `ViewToggle(view, onChanged)` calls in test must still render all 3 of (month, week, day). Make `EdenSchedulerView.values` the default when null.
- **Title format for workWeek + week:** workWeek is Mon-Fri, week is Sun-Sat. Both use range format `'Mar 9–13, 2026'`. Use 4-day delta for workWeek, 6-day delta for week.
- **List view title:** show the current week's range (since list view is chronological, week-scoped). Format: `'Week of Mar 9, 2026'`.
- **Mobile view title:** narrow — `'Mon, Mar 9'` (no year) for narrow viewports, full `'Mon, Mar 9, 2026'` for wider. Use `LayoutBuilder` and toggle on >300pt available toolbar width.
- **Swimlane title:** donor `TruckAvailabilityView` shows multiple weeks at once (typically 3 weeks). Title: `'Mar 9 – 22, 2026'` for a 3-week swimlane. The 3-week span is the default; future TRD 09 may allow consumer override.
- **ViewToggle width:** 7 labels won't fit at 390pt. Collapse to icon-only at narrow widths via `LayoutBuilder` — icons: Day=`Icons.view_day`, WorkWeek=`Icons.business_center`, Week=`Icons.view_week`, Month=`Icons.calendar_month`, List=`Icons.view_list`, Mobile=`Icons.smartphone`, Swimlane=`Icons.view_column`. Show label text only when toolbar width >= 600pt; icon-only otherwise.
- **Tooltip on icon-only buttons:** every icon variant needs `Semantics(label: '$labelName view')` (existing pattern at line 187-190). MANDATORY for accessibility.
- **Today button:** show only when focusedDate != today (donor hides it when already on today). For now, show always — donor flicker on date change is undesirable. Document the deviation.
</gotchas>

   ```dart
   String _title(double? availableWidth) {
     switch (view) {
       case EdenSchedulerView.month:
         return '${_months[focusedDate.month - 1]} ${focusedDate.year}';
       case EdenSchedulerView.day:
         final narrow = (availableWidth ?? 800) < 300;
         final base = '${_dayShort[focusedDate.weekday - 1]}, ${_months[focusedDate.month - 1]} ${focusedDate.day}';
         return narrow ? base : '$base, ${focusedDate.year}';
       case EdenSchedulerView.mobile:
         final narrow = (availableWidth ?? 800) < 300;
         final base = '${_dayShort[focusedDate.weekday - 1]}, ${_months[focusedDate.month - 1]} ${focusedDate.day}';
         return narrow ? base : '$base, ${focusedDate.year}';
       case EdenSchedulerView.workWeek:
         return _rangeTitle(_weekStart(focusedDate), 4);
       case EdenSchedulerView.week:
         return _rangeTitle(_weekStart(focusedDate), 6);
       case EdenSchedulerView.list:
         final start = _weekStart(focusedDate);
         return 'Week of ${_months[start.month - 1]} ${start.day}, ${start.year}';
       case EdenSchedulerView.swimlane:
         return _rangeTitle(_weekStart(focusedDate), 13); // 14 days = 2 weeks span; donor shows 3 weeks, but TRD-09 may parameterize
     }
   }

   DateTime _weekStart(DateTime d) => d.subtract(Duration(days: d.weekday - 1));

   String _rangeTitle(DateTime start, int dayDelta) {
     final end = start.add(Duration(days: dayDelta));
     if (start.year == end.year) {
       if (start.month == end.month) {
         return '${_months[start.month - 1]} ${start.day}–${end.day}, ${start.year}';
       }
       return '${_months[start.month - 1]} ${start.day} – ${_months[end.month - 1]} ${end.day}, ${start.year}';
     }
     return '${_months[start.month - 1]} ${start.day}, ${start.year} – ${_months[end.month - 1]} ${end.day}, ${end.year}';
   }
   ```
