**Flutter drag API choice:**
- For drag-to-move: `LongPressDraggable<EdenSchedulerEvent>(...)` is the idiomatic Flutter approach. `DragTarget<EdenSchedulerEvent>(...)` on the time grid receives the drop. On `onAcceptWithDetails`, compute the new start/end from drop position.
- For resize: NOT `LongPressDraggable` (that's for moving). Instead use `GestureDetector` on top/bottom handle Containers with `onVerticalDragUpdate` + `onVerticalDragEnd`. Compute `deltaPx → minutes via yDeltaPxToMinutes`, then `addMinutesToTime(start/end, delta)`.

**Drag-vs-tap discrimination:**
- Naive `GestureDetector` has conflict between `onTap` and `onPanStart`. Flutter resolves via gesture arena — first to claim wins. Use `LongPressDraggable` for drag (long-press = unambiguous), `onTap` for tap-to-detail. This is the same pattern as Material's reorderable list.
- Donor uses click-without-drag = open detail; drag-without-click = move. Donor allows immediate drag (no long-press) via HTML5 dnd; Flutter needs the long-press disambiguation.
- Trade-off: a long-press is ~500ms which feels slow. Alternative: `Draggable<EdenSchedulerEvent>(...)` (no long-press) but onTap doesn't fire when drag starts. For desktop/web (mouse), Draggable is fine. For mobile (touch), LongPressDraggable. Use `kIsWeb` or `Theme.of(context).platform` to switch.

**Resize handle gesture:**
- 3pt-high `Positioned(top: -1.5, left: 0, right: 0, height: 6)` regions at top + bottom of the block.
- On hover: `MouseRegion(cursor: SystemMouseCursors.resizeRow)` — desktop only.
- On drag: `GestureDetector(onVerticalDragUpdate: ...)`.
- During drag: maintain `_resizePreview: (start, end)?` state; render preview chip overlay above the block showing the new times.
- On drag end: invoke `onResize(event, newStart, newEnd)`; clear preview.

**Preview chip during resize:** small Material chip floating above (or below — based on resize side) the block, with white text on theme.primary background, showing `formatTime(newStart)` and `formatTime(newEnd)`. Donor at `EnhancedCalendar.tsx:1368-1373`.

**Drop-target math (where does the dragged event land?):**
- DayView/WeekView's hour grid is a `DragTarget<EdenSchedulerEvent>(onAcceptWithDetails: (details) {...})`.
- `details.offset` is the pointer position when dropped. Subtract the grid origin to get local Y. `localY / slotHeight * 60` minutes from `startHour`. Round to 15-min via `yDeltaPxToMinutes`.
- Compute new date/start from drop position. Preserve original event duration. Compute `newStart`, `newEnd = newStart + originalDuration`.
- Fire `onEventMove(event, newStart, newEnd)`.
- For WeekView, the X position determines the new day column. Map drop-X to column-index (subtract gutter width, divide by columnWidth).

<gotchas>
- **LongPressDraggable on mobile + Draggable on desktop branching:** use `Theme.of(context).platform == TargetPlatform.android || TargetPlatform.iOS` to pick. Encapsulate in a `_DraggableEventWrapper` helper widget.
- **Drop target math edge case:** if user drops outside the visible hour range (e.g. above the grid), clamp to startHour or DON'T fire onEventMove (gracefully cancel). Donor cancels.
- **Drag feedback widget:** `LongPressDraggable.feedback` is the widget shown attached to the pointer during drag. Use a translucent copy of the event block (opacity 0.7). Match block dimensions so it doesn't snap-resize on drop.
- **childWhenDragging:** the original block during drag should show as a ghost (opacity 0.3) so user sees where it was. Use Draggable's `childWhenDragging` param.
- **Resize handle visual subtlety:** donor uses 6pt invisible touch area + 2pt visible bar in the middle on hover. For Flutter, render a `Container(height: 2, color: theme.primary.withOpacity(0.5))` centered in the 6pt touch region. Only visible on `MouseRegion.onHover`.
- **Touch-resize affordance:** on mobile, resize handles need to be larger (12pt touch area) since no hover-cursor. Branch by platform.
- **Onset / cleanup of `_resizePreview`:** stateful widget; clear in onVerticalDragEnd AND in onVerticalDragCancel. Don't leak preview chip if user releases off-block.
- **Snap math during resize:**
  ```dart
  final deltaMin = EdenSchedulerTimeMath.yDeltaPxToMinutes(detail.localPosition.dy - dragStartY, slotHeight);
  final newStart = original.start.add(Duration(minutes: deltaMin)); // top handle
  // or newEnd = original.end.add(Duration(minutes: deltaMin)); // bottom handle
  ```
- **Validity:** newStart must be < newEnd, newEnd must be after newStart. If resize would invert, clamp. Minimum duration = 15 min (one snap unit).
- **Event ID stability during drag:** `LongPressDraggable<EdenSchedulerEvent>` carries the event as data. The drop target gets the SAME event object — use its `.id` to identify, NOT object equality (since we'll create a new event with updated start/end).
- **Drag-cross-day in WeekView:** the X position of the drop determines new day. Compute `colIdx = ((dropX - gutter) / columnWidth).floor()`, then new date = `weekStart + colIdx days`. Time-of-day stays the same.

void _onResizeUpdate(_ResizeSide side, DragUpdateDetails d) {
  final delta = d.localPosition.dy - _resizeStartY;
  final deltaMin = EdenSchedulerTimeMath.yDeltaPxToMinutes(delta, widget.slotHeight);
  setState(() {
    if (side == _ResizeSide.top) {
      var newStart = widget.event.start.add(Duration(minutes: deltaMin));
      // Clamp: newStart can't be >= end - 15 min
      final maxStart = widget.event.end.subtract(const Duration(minutes: 15));
      if (newStart.isAfter(maxStart)) newStart = maxStart;
      _resizePreview = (newStart, widget.event.end);
    } else {
      var newEnd = widget.event.end.add(Duration(minutes: deltaMin));
      final minEnd = widget.event.start.add(const Duration(minutes: 15));
      if (newEnd.isBefore(minEnd)) newEnd = minEnd;
      _resizePreview = (widget.event.start, newEnd);
    }
  });
}

    widget.onResize?.call(widget.event, _resizePreview!.$1, _resizePreview!.$2);

    _activeSide = null;

}

  final void Function(_ResizeSide, DragStartDetails) onStart;
  final void Function(_ResizeSide, DragUpdateDetails) onUpdate;
  final void Function(_ResizeSide, DragEndDetails) onEnd;

  @override

      top: side == _ResizeSide.top ? -3 : null,
      bottom: side == _ResizeSide.bottom ? -3 : null,

          behavior: HitTestBehavior.opaque,
          onVerticalDragStart: (d) => onStart(side, d),
          onVerticalDragUpdate: (d) => onUpdate(side, d),
          onVerticalDragEnd: (d) => onEnd(side, d),

      ),
    );

}
