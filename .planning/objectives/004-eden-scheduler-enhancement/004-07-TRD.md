<objective>
Wave 2 view — List. Chronological scrolling list of events grouped under sticky date headers. The donor's "List" view in the top-level toolbar (`Schedule.tsx:2161` `viewToggle.value == 'list'`) is a flat appointment list with filters; the library version generalizes it. Used as a low-cognitive-load alternative to the calendar grid — every event in a date range, time-sorted, easy to skim.

Parity rows targeted: V-5, T-12, T-9.
</objective>

<context>
**Locked design inputs:**
- Donor list view at `Schedule.tsx:2076` filter logic + render: filtered events list with search + status filter + type filter + assignment filter + appointmentMode (service/project) filter. Library version supports: search (controller.search), resource filter (controller.selectedResources). Consumer-specific filters (status / type / mode) handled by the consumer in `events: events.where(...).toList()` before passing in.
- Sticky date headers: Material's `SliverPersistentHeader` or `StickyHeader` pattern. For v1, use a simpler approach: each date's events get a header `ListTile` followed by event rows.
- Today / Tomorrow / Yesterday formatting: relative to `controller.today`.

**Approach:**
1. Group events by `stripTime(event.start)` — dict of `Map<DateTime, List<EdenSchedulerEvent>>`.
2. Sort keys ascending.
3. For each date, render a section: `_DateHeader` followed by N `_EventRow`s.
4. Wrap the entire scroll list in `ListView.builder` for memory efficiency.
5. Date range computed from `controller.focusedDate.weekStart` to `+ 14 days` (2-week default). Configurable via `dateRange: Duration?` param.

**Filtering:**
- `controller.search` (trimmed string) — case-insensitive match against event.title, event.description, event.location.name, event.assignee.
- `controller.selectedResources` (Set<String>) — when non-empty, only show events whose resourceIds intersect.
- (Status/type filtering is consumer's responsibility — they pre-filter `events` before passing.)
</context>

<gotchas>
- **Sticky headers in plain `ListView`:** without `slivers`, headers don't truly stick (they scroll with content). For v1, ACCEPT scrolling headers (simple ListView). Mark as deferred-enhancement if downstream complains.
- **Date relative formatting:** "Today" + "Tomorrow" + "Yesterday" depend on `controller.today`. For other dates, use the same formatter as `SchedulerToolbar._title` for the day view: `'${dayShort[wd-1]}, ${months[m-1]} $d, $y'`.
- **Time format:** use `EdenSchedulerTimeMath.formatTime('HH:MM')` to render '9:30 AM'. Donor convention.
- **Multi-resource events:** an event with `resourceIds: ['r1', 'r2']` appears ONCE in the list (not duplicated per resource). The resource summary on the right shows comma-separated names.
- **Resource name lookup:** `EdenScheduler` doesn't yet know about resources as a top-level concept in the existing constructor. For v1, the list view shows `event.assignee` as the right-column text (already in event model). Resource integration is sidebar-driven (TRD 14).
- **Empty state:** when `events.isEmpty` or filtered to empty, render `Center(child: Column(children: [Icon(Icons.event_busy), Text('No events in this range.')]))`. Use `EdenEmptyState` from the existing widget library if available.
- **Recurrence expansion:** like MonthView, ListView is range-bounded — expand recurring events for the visible date range before rendering.
- **Scroll position retention:** if the consumer changes `focusedDate`, ListView scrolls back to top by default. For v1 this is fine; advanced: preserve scroll if the new range overlaps. Defer.
</gotchas>

- 1 event → 1 row visible under its date header.

- Event yesterday → 'Yesterday'.

- Event 10:30 AM-12:15 PM → '10:30 AM-12:15 PM'.
- All-day event → row left shows 'All day'.

**Sorting**
- Events at 8 AM, 9 AM, 7 AM on same day → render order 7 AM, 8 AM, 9 AM.

**Search filter**
- Controller.setSearch('coffee') → only events with 'coffee' in title/description/assignee/location visible.
- Search is case-insensitive ('COFFEE' matches 'coffee meeting').
- Empty search → all events visible.

**Resource filter**
- Controller.toggleResourceFilter('r1') → only events with 'r1' in resourceIds visible.
- Toggle off → all events visible again.
- Event with resourceIds=null → hidden when any filter is active; visible when no filter.

- Event on today, today+13 days → both visible (14-day default).
- Event on today+14 days → NOT visible.
- Custom `dateRange: Duration(days: 30)` → 30-day range applies.

**Tap event**
- Tap on event row → onEventTap(event) fires.

**Recurrence**
- Weekly Mon/Wed/Fri event for 2 weeks → 6 rows visible (Mon/Wed/Fri × 2 weeks).

**Responsive — iPhone-narrow**
- `EdenSchedulerListView` inside `SizedBox(width: 390, height: 600)` renders without `RenderFlex overflowed`; long event titles ellipsize.

```dart
import 'package:flutter/material.dart';
import '../../tokens/colors.dart';
import '../../tokens/spacing.dart';
import 'scheduler_controller.dart';
import 'scheduler_models.dart';
import 'scheduler_time_math.dart';

class EdenSchedulerListView extends StatelessWidget {
  const EdenSchedulerListView({
    super.key,
    required this.focusedDate,
    required this.today,
    required this.events,
    this.dateRange = const Duration(days: 14),
    this.searchQuery = '',
    this.selectedResources = const <String>{},
    this.onEventTap,
  });

  final DateTime focusedDate;
  final DateTime today;
  final List<EdenSchedulerEvent> events;
  final Duration dateRange;
  final String searchQuery;
  final Set<String> selectedResources;
  final ValueChanged<EdenSchedulerEvent>? onEventTap;

  static const _dayShort = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'];
  static const _months = [
    'Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun',
    'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec',
  ];

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final rangeStart = EdenSchedulerTimeMath.startOfWeek(focusedDate);
    final rangeEnd = rangeStart.add(dateRange);

    // Expand recurring events into the range
    final expanded = <EdenSchedulerEvent>[];
    for (final e in events) {
      expanded.addAll(EdenSchedulerTimeMath.expandRecurrence(e, rangeStart, rangeEnd));
    }

    // Filter by search
    final searchLower = searchQuery.trim().toLowerCase();
    final searched = searchLower.isEmpty
        ? expanded
        : expanded.where((e) {
            final hay = '${e.title} ${e.description ?? ''} ${e.assignee ?? ''} ${e.location?.name ?? ''}'
                .toLowerCase();
            return hay.contains(searchLower);
          }).toList();

    // Filter by resource
    final resourceFiltered = selectedResources.isEmpty
        ? searched
        : searched.where((e) {
            final ids = e.resourceIds ?? const <String>[];
            return ids.any(selectedResources.contains);
          }).toList();

    if (resourceFiltered.isEmpty) {
      return Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Icon(Icons.event_busy, size: 48, color: theme.colorScheme.outline),
            const SizedBox(height: EdenSpacing.space2),
            const Text('No events in this range.'),
          ],
        ),
      );
    }

    // Sort + group
    resourceFiltered.sort((a, b) => a.start.compareTo(b.start));
    final grouped = <DateTime, List<EdenSchedulerEvent>>{};
    for (final e in resourceFiltered) {
      final key = EdenSchedulerTimeMath.stripTime(e.start);
      grouped.putIfAbsent(key, () => []).add(e);
    }
    final sortedKeys = grouped.keys.toList()..sort();

    // Build flat list with date headers + rows
    final items = <_ListItem>[];
    for (final key in sortedKeys) {
      items.add(_ListItem.header(key));
      for (final e in grouped[key]!) {
        items.add(_ListItem.event(e));
      }
    }

    return ListView.builder(
      itemCount: items.length,
      itemBuilder: (context, i) {
        final item = items[i];
        if (item.isHeader) {
          return _DateHeader(date: item.date!, today: today);
        }
        return _EventRow(event: item.event!, onTap: () => onEventTap?.call(item.event!));
      },
    );
  }
}

class _ListItem {
  final bool isHeader;
  final DateTime? date;
  final EdenSchedulerEvent? event;
  _ListItem.header(this.date) : isHeader = true, event = null;
  _ListItem.event(this.event) : isHeader = false, date = null;
}

class _DateHeader extends StatelessWidget {
  const _DateHeader({required this.date, required this.today});
  final DateTime date;
  final DateTime today;
  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    String label;
    final stripped = EdenSchedulerTimeMath.stripTime(date);
    final todayStripped = EdenSchedulerTimeMath.stripTime(today);
    final diff = stripped.difference(todayStripped).inDays;
    if (diff == 0) label = 'Today';
    else if (diff == 1) label = 'Tomorrow';
    else if (diff == -1) label = 'Yesterday';
    else label = '${EdenSchedulerListView._dayShort[date.weekday - 1]}, ${EdenSchedulerListView._months[date.month - 1]} ${date.day}, ${date.year}';

    return Container(
      padding: const EdgeInsets.symmetric(horizontal: EdenSpacing.space4, vertical: EdenSpacing.space2),
      color: theme.colorScheme.surfaceVariant.withOpacity(0.4),
      child: Text(label, style: theme.textTheme.titleSmall),
    );
  }
}

class _EventRow extends StatelessWidget {
  const _EventRow({required this.event, this.onTap});
  final EdenSchedulerEvent event;
  final VoidCallback? onTap;
  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final timeLabel = event.allDay
        ? 'All day'
        : '${EdenSchedulerTimeMath.formatTime(_pad(event.start))}'
            '-${EdenSchedulerTimeMath.formatTime(_pad(event.end))}';
    final rightLabel = event.assignee ?? event.location?.name ?? '';
    return InkWell(
      onTap: onTap,
      child: Padding(
        padding: const EdgeInsets.symmetric(horizontal: EdenSpacing.space4, vertical: EdenSpacing.space2),
        child: Row(
          children: [
            SizedBox(width: 110, child: Text(timeLabel, style: theme.textTheme.bodySmall)),
            const SizedBox(width: EdenSpacing.space2),
            Expanded(child: Text(event.title, maxLines: 1, overflow: TextOverflow.ellipsis)),
            const SizedBox(width: EdenSpacing.space2),
            Flexible(
              child: Text(
                rightLabel,
                maxLines: 1,
                overflow: TextOverflow.ellipsis,
                style: theme.textTheme.bodySmall?.copyWith(color: theme.colorScheme.onSurfaceVariant),
              ),
            ),
          ],
        ),
      ),
    );
  }

  String _pad(DateTime d) => '${d.hour.toString().padLeft(2, '0')}:${d.minute.toString().padLeft(2, '0')}';
}
```
