<objective>
Ship `EdenMeterReadingEntry` — a form widget for capturing a fuel meter reading. Composes `EdenAuthenticatedImage` (from obj 001-07) for the captured photo preview. Generic — emits a value-class `EdenMeterReadingDraft` on submit; the consumer persists via their own RPC. No transport, no auth, no photo-capture plugin in the library (capture is a callback parameter).

This serves fuel-delivery drivers capturing tank readings at customer sites, but also generalizes to utility meter reads, inventory spot counts, and any photo-backed measurement workflow.

Wave 2 of objective 005 — runs in parallel with `EdenHazmatDocViewer` (TRD 005-04). No depends_on (uses existing `EdenAuthenticatedImage`). New file `lib/src/widgets/eden_meter_reading_entry.dart`.

Outside-in test approach: form-static-rendering tests first (renders fields, renders submit button disabled when empty), then validation tests (gallons numeric, operatorId required), then interaction tests (source picker selection, photo callback invocation, timestamp override), then submit emission tests (EdenMeterReadingDraft contains correct payload).
</objective>

**Validation rules:**
- `gallons`: must parse as `double`, must be `>= 0` (zero is allowed — empty tank), must not have more than 4 decimal places (heating-oil convention from `eden-biz` 100-fuel-delivery-foundation).
- `operatorId`: must not be empty/whitespace-only.
- Submit button is `enabled` only when `_gallonsValid && _operatorIdValid`.

**Photo callback contract:**
- Consumer's `onPhotoPick` returns a `Future<String?>`. The library awaits it. On non-null result, store as `_photoSignedUrl` (the URL passed straight to `EdenAuthenticatedImage`). On null (user cancelled), no state change.
- The library never opens camera/gallery itself. The consumer wires `image_picker` or `camera` package and uploads to their S3, returning the signed URL.

**Timestamp default:** initState sets `_timestamp = DateTime.now()`. Display via `_formatDateTime` (hand-rolled, no intl: `'May 16, 2026 at 2:35 PM'`-shape). Override flow opens a TimePicker dialog; user changes the time portion only (date stays today — for fuel-delivery, retroactive readings beyond a few hours are an edge case the consumer handles).

**EdenAuthenticatedImage compose:** wrap in `SizedBox(width: 120, height: 120, child: EdenAuthenticatedImage(url: _photoSignedUrl!, headersBuilder: widget.imageHeadersBuilder, width: 120, height: 120))`.

**No new pubspec deps:** TimePicker is `showTimePicker` from `flutter/material.dart` — already there.

    this.unitLabel = 'gal',

class _EdenMeterReadingEntryState extends State<EdenMeterReadingEntry> {
  late final TextEditingController _gallonsCtrl;
  late final TextEditingController _operatorCtrl;
  late final TextEditingController _notesCtrl;
  late EdenMeterReadingSource _source;
  late DateTime _timestamp;
  String? _photoSignedUrl;

  static final RegExp _gallonsRe = RegExp(r'^\d+(\.\d{0,4})?$');

  @override
  void initState() {
    super.initState();
    final d = widget.initialDraft;
    _gallonsCtrl = TextEditingController(text: d?.gallons.toString() ?? '');
    _operatorCtrl = TextEditingController(text: d?.operatorId ?? '');
    _notesCtrl = TextEditingController(text: d?.notes ?? '');
    _source = d?.source ?? EdenMeterReadingSource.manual;
    _timestamp = d?.timestamp ?? DateTime.now();
    _photoSignedUrl = d?.photoSignedUrl;
    _gallonsCtrl.addListener(_revalidate);
    _operatorCtrl.addListener(_revalidate);
  }

  @override
  void dispose() {
    _gallonsCtrl.dispose();
    _operatorCtrl.dispose();
    _notesCtrl.dispose();
    super.dispose();
  }

  void _revalidate() => setState(() {});

  bool get _gallonsValid {
    final t = _gallonsCtrl.text.trim();
    if (t.isEmpty) return false;
    return _gallonsRe.hasMatch(t);
  }

  bool get _operatorValid => _operatorCtrl.text.trim().isNotEmpty;

  bool get _formValid => _gallonsValid && _operatorValid;

  @override

    return Column(
      crossAxisAlignment: CrossAxisAlignment.stretch,
      mainAxisSize: MainAxisSize.min,
      children: [
        TextField(
          controller: _gallonsCtrl,
          keyboardType: const TextInputType.numberWithOptions(decimal: true),

String _formatDateTime(DateTime dt) {
  const months = ['Jan','Feb','Mar','Apr','May','Jun','Jul','Aug','Sep','Oct','Nov','Dec'];
  final h = dt.hour;
  final m = dt.minute;
  final am = h < 12;
  final h12 = h == 0 ? 12 : (h > 12 ? h - 12 : h);
  return '${months[dt.month - 1]} ${dt.day}, ${dt.year} at $h12:${m.toString().padLeft(2, '0')} ${am ? 'AM' : 'PM'}';
}

Future<void> _onCapturePhoto() async {
  final url = await widget.onPhotoPick?.call();
  if (!mounted) return;
  if (url != null) setState(() => _photoSignedUrl = url);
}

Future<void> _onOverrideTime() async {
  final picked = await showTimePicker(
    context: context,
    initialTime: TimeOfDay.fromDateTime(_timestamp),
  );
  if (!mounted) return;
  if (picked != null) {
    setState(() {
      _timestamp = DateTime(_timestamp.year, _timestamp.month, _timestamp.day, picked.hour, picked.minute);
    });
  }
}
