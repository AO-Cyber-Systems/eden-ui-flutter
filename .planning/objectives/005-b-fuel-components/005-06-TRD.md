<context>
**Composes (verified API):** `EdenStockLevelIndicator(currentStock: int, reorderPoint: int, showLabel: bool = true, height: double = 8)`. Constructor verified from `lib/src/widgets/eden_stock_level_indicator.dart` lines 36-46. The indicator takes **integer** stock counts (it was designed for discrete inventory like bolts), but we pass gallons rounded to nearest integer for display (3-decimal-precision-gallons is for backend storage, not the UI bar). The bar's `percent = currentStock / maxCapacity` math is accurate enough at 1-gallon resolution.

For our use case (single-fuel-type fill bar), we pass `reorderPoint: 0` so the indicator falls back to `maxCapacity = 100` internally — but that's wrong for our display (we want `maxCapacity = capacityGal`). The indicator does NOT expose a `maxCapacity` override.

**Resolution:** we compute the fill percent ourselves (`fillPct = currentGal / capacityGal`) and pass `currentStock: (fillPct * 100).round(), reorderPoint: 0` so the indicator renders the correct percent on its 0-100 scale. This is a slight workaround — we're using the indicator as a generic fill bar with our pre-computed percent. The OR alternative is to add a `maxCapacity` override to `EdenStockLevelIndicator` in this TRD; we deliberately do NOT do that because:
- It widens the indicator's API for one consumer.
- It risks regressing the 50+ existing call sites.
- The percent-pre-compute approach is clean and explicit at the call site.

**Value class:**
```dart
@immutable
class EdenTruckInventoryData {
  const EdenTruckInventoryData({
    required this.truckLabel,
    required this.fuelTypeLabel,
    required this.capacityGal,
    required this.currentGal,
  });
  final String truckLabel;     // 'Truck 47', 'Tanker A-12', etc.
  final String fuelTypeLabel;  // 'Propane', 'Diesel', etc.
  final double capacityGal;
  final double currentGal;

  double get fillRatio {
    if (capacityGal <= 0) return 0.0;
    final r = currentGal / capacityGal;
    if (r < 0) return 0.0;
    if (r > 1.0) return 1.0;
    return r;
  }

  bool get isOverfull => capacityGal > 0 && currentGal > capacityGal;
}
```

<gotchas>
- **EdenStockLevelIndicator's `showLabel: true` by default** prints `'$N in stock'` + `'Reorder at $M'` labels. We DON'T want those (our wrapper provides its own labels). Pass `showLabel: false` explicitly.
- **EdenStockLevelIndicator with `reorderPoint: 0`** triggers `maxCapacity = 100` fallback. We pre-compute percent (0-100) and pass as currentStock; consistent with passing as a percentage gauge.
- **Round-trip precision loss:** if currentGal = 320.5 and capacityGal = 500.0 → fillRatio = 0.641 → percent = 64 (rounded). Display `'64%'` is human-readable; underlying data is exact. Don't display 3-decimal percent.
- **EdenStockLevelIndicator color thresholds (red/amber/green at 25%/50%)** are inherited as-is. For fuel trucks, "low" might mean 30% empty depending on logistics; we don't tune. Consumers who need custom thresholds use `EdenTankGauge` (TRD 005-01) which has configurable thresholds. The truck card is a simpler at-a-glance variant.
- **InkWell when onTap == null:** wrap conditionally. Without it, an unnecessary InkWell ripple area is visible on hover.
- **Wrap or Row for capacity+percent inline:** `'320/500 gal  •  64%'` is a single line. Use Text concatenation OR Row of two Text widgets with a bullet separator. Single Text is cleaner; use string interp.
- **fuel-type chip:** small Container with bg=theme.colorScheme.secondaryContainer + rounded radius + small text — Material 3 chip-like idiom. Or use `Chip` widget directly (simpler). Pick Chip for simplicity.

import 'package:flutter/material.dart';

import '../tokens/radii.dart';

@immutable
class EdenTruckInventoryData {
  const EdenTruckInventoryData({
    required this.truckLabel,
    required this.fuelTypeLabel,
    required this.capacityGal,
    required this.currentGal,
  });
  final String truckLabel;
  final String fuelTypeLabel;
  final double capacityGal;
  final double currentGal;

  double get fillRatio {
    if (capacityGal <= 0) return 0.0;
    final r = currentGal / capacityGal;
    if (r < 0) return 0.0;
    if (r > 1.0) return 1.0;
    return r;
  }

  bool get isOverfull => capacityGal > 0 && currentGal > capacityGal;
}

class EdenTruckInventoryCard extends StatelessWidget {
  const EdenTruckInventoryCard({
    super.key,
    required this.data,
    this.onTap,
  });

  final EdenTruckInventoryData data;
  final VoidCallback? onTap;

  static String _fmt(double v) {
    final s = v.toStringAsFixed(1);
    return s.endsWith('.0') ? s.substring(0, s.length - 2) : s;
  }

  String get _capacityLabel {
    if (data.capacityGal <= 0) return '— / 0 gal';
    return '${_fmt(data.currentGal)}/${_fmt(data.capacityGal)} gal';
  }

  int get _percentInt => (data.fillRatio * 100).round();

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final card = Container(
      padding: const EdgeInsets.all(EdenSpacing.space3),
      decoration: BoxDecoration(
        borderRadius: EdenRadii.borderRadiusMd,
        border: Border.all(color: theme.colorScheme.outlineVariant),
      ),
      child: LayoutBuilder(builder: (context, constraints) {
        final isWide = constraints.maxWidth >= 500;
        if (isWide) {
          return Row(
            crossAxisAlignment: CrossAxisAlignment.center,
            children: [
              Expanded(child: _LeftColumn(data: data)),
              const SizedBox(width: 12),
              Expanded(child: _RightColumn(
                capacityLabel: _capacityLabel,
                percentInt: _percentInt,
                isOverfull: data.isOverfull,
              )),
            ],
          );
        }
        return Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          mainAxisSize: MainAxisSize.min,
          children: [
            _LeftColumn(data: data),
            const SizedBox(height: 12),
            _RightColumn(
              capacityLabel: _capacityLabel,
              percentInt: _percentInt,
              isOverfull: data.isOverfull,
            ),
          ],
        );
      }),
    );
    if (onTap == null) return card;
    return InkWell(
      onTap: onTap,
      borderRadius: EdenRadii.borderRadiusMd,
      child: card,
    );
  }
}

class _LeftColumn extends StatelessWidget {
  const _LeftColumn({required this.data});
  final EdenTruckInventoryData data;
  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      mainAxisSize: MainAxisSize.min,
      children: [
        Row(children: [
          Icon(Icons.local_shipping_outlined,
              size: 18, color: theme.colorScheme.onSurfaceVariant),
          const SizedBox(width: 6),
          Flexible(
            child: Text(data.truckLabel,
                style: theme.textTheme.titleSmall?.copyWith(fontWeight: FontWeight.w600),
                maxLines: 1, overflow: TextOverflow.ellipsis),
          ),
        ]),
        const SizedBox(height: 6),
        Chip(
          label: Text(data.fuelTypeLabel,
              style: const TextStyle(fontSize: 11), maxLines: 1, overflow: TextOverflow.ellipsis),
          padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 0),
          materialTapTargetSize: MaterialTapTargetSize.shrinkWrap,
          visualDensity: VisualDensity.compact,
          backgroundColor: theme.colorScheme.secondaryContainer,
        ),
      ],
    );
  }
}

class _RightColumn extends StatelessWidget {
  const _RightColumn({required this.capacityLabel, required this.percentInt, required this.isOverfull});
  final String capacityLabel;
  final int percentInt;
  final bool isOverfull;
  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      mainAxisSize: MainAxisSize.min,
      children: [
        Row(children: [
          Flexible(
            child: Text('$capacityLabel  •  $percentInt%',
                style: theme.textTheme.bodyMedium,
                maxLines: 1, overflow: TextOverflow.ellipsis),
          ),
          if (isOverfull) ...[
            const SizedBox(width: 6),
            Container(
              padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
              decoration: BoxDecoration(
                color: theme.colorScheme.errorContainer,
                borderRadius: BorderRadius.circular(4),
              ),
              child: Text('Overfull',
                  style: TextStyle(fontSize: 10, fontWeight: FontWeight.w600,
                      color: theme.colorScheme.onErrorContainer)),
            ),
          ],
        ]),
        const SizedBox(height: 6),
        EdenStockLevelIndicator(
          currentStock: percentInt,
          reorderPoint: 0,
          showLabel: false,
          height: 8,
        ),
      ],
    );
  }
}
