<objective>
Ship `EdenTankGauge` — a vertical liquid-level meter primitive for fuel tanks (and any other capacity-vs-current display: water utilities, chemical storage, beverage stock). Three rendering modes (linear / segmented / dial) selectable via constructor param OR auto-selected when the widget is in a Compact context (`EdenAdaptiveTierScope.maybeOf(context) == compact` → linear). Low-threshold visual cue (red border) signals "fill me up" to the operator.

This is a NEW design — no existing donor in trades-react or trades-flutter (verified via grep). Composes nothing; pure primitive at the lowest layer. Wave 1 of objective 005 — runs in parallel with `EdenRouteStopList` (TRD 005-02).

Outside-in test approach: static rendering tests first (renders with sample data, renders empty/low/normal/full/overfull, renders capacity label), then mode-switch tests (3 modes render their unique visuals), then adaptive-tier tests (no explicit mode + Compact context → linear), then helper unit tests (percent clamping, color threshold function).
</objective>

<context>
**Design (locked):**
- Three modes via `enum EdenTankGaugeMode { linear, segmented, dial }`.
- **Linear** — default mode. Vertical rectangle, fill color rises from bottom proportional to `currentGal / capacityGal`. Like a thermometer. Width 80pt, height 160pt at default size; respects parent constraints if smaller. Capacity label `'320/500 gal'` rendered below. Fuel-type sub-caption rendered above (if non-null). Fill color: green when >50%, amber when low%-50%, red when ≤low% (default low=20%). Optional border 2pt red when ≤low% (the low-threshold visual cue).
- **Segmented** — 5 stacked segments visualizing 20%/40%/60%/80%/100% fill. Each segment is either filled (green/amber/red per threshold) or empty (outline only). Discrete "tank quarters" feel; popular in HVAC/oil control panels. Same width/height defaults as linear.
- **Dial** — semicircle gauge (180° arc) with a needle pointing to the current percentage. Like an analog fuel gauge. 180pt wide × 100pt tall at default size. Uses `CustomPainter` for the arc + needle.
- **Compact pinning (locked decision E rule 3, obj 002-05 pattern):** widget exposes a `mode: EdenTankGaugeMode?` constructor param. If `mode != null` → use that mode. If `mode == null` → consult `EdenAdaptiveTierScope.maybeOf(context)`; if it returns `EdenAdaptiveTier.compact`, default to linear (compact-friendly). Otherwise default to linear regardless. Rationale: linear is the most narrow-screen-friendly default; dial is only chosen explicitly by consumers who have horizontal room.

**Configurable thresholds:**
- `lowThresholdPct: double = 0.20` — fill ≤20% triggers red color + border cue.
- `warningThresholdPct: double = 0.50` — fill ≤50% triggers amber color (above lowThreshold).
- Above warningThreshold → green color.
- Custom thresholds let downstream apps tune for fuel type (heating oil = 30% low common; commercial diesel = 10% low).

<gotchas>
- **Percent clamping:** `currentGal / capacityGal` can be `> 1.0` (overfull) or `< 0` (negative — shouldn't happen but defensive). Clamp to `[0.0, 1.0]` for visual fill, but track the un-clamped value to render the overflow indicator badge when actual `> 1.0`. Test both clamp directions.
- **Zero capacity edge case:** `capacityGal == 0` → division-by-zero. Treat as 0% fill + capacity label `'0/0 gal'`. Don't throw. Add a fixture for this.
- **EdenColors token names:** verify `EdenColors.danger`, `.warning`, `.success` exist. If they're `error` / `warning` / `success` instead, use those names. (Check `lib/src/tokens/colors.dart`.)
- **CustomPainter for dial:** `Path.addArc` with `Rect.fromLTWH(0, 0, 180, 200)` and `startAngle: -math.pi`, `sweepAngle: math.pi` gives a 180° upper-half semicircle. The needle is a second `Path` from center-bottom to the perimeter at angle `-math.pi + percent * math.pi`.
- **EdenAdaptiveTierScope unused-warning:** if you `import 'eden_adaptive_layout.dart'` only for type-checking `maybeOf`, no need to actually render an `EdenAdaptiveLayout` ancestor in tests — `maybeOf` returns null safely. import 'package:flutter/foundation.dart';
```dart
import 'package:flutter/material.dart';

import '../tokens/colors.dart';
import '../tokens/radii.dart';
import '../tokens/spacing.dart';
import 'eden_adaptive_layout.dart';

enum EdenTankGaugeMode { linear, segmented, dial }

@immutable
class EdenTankGaugeData {
  const EdenTankGaugeData({
    required this.capacityGal,
    required this.currentGal,
    this.fuelTypeLabel,
    this.unitLabel = 'gal',
  });
  final double capacityGal;
  final double currentGal;
  final String? fuelTypeLabel;
  final String unitLabel;

  /// Clamped fill ratio in [0.0, 1.0].
  double get fillRatio {
    if (capacityGal <= 0) return 0.0;
    final r = currentGal / capacityGal;
    if (r < 0) return 0.0;
    if (r > 1.0) return 1.0;
    return r;
  }

  bool get isOverfull => capacityGal > 0 && currentGal > capacityGal;
}

class EdenTankGauge extends StatelessWidget {
  const EdenTankGauge({
    super.key,
    required this.data,
    this.mode,
    this.lowThresholdPct = 0.20,
    this.warningThresholdPct = 0.50,
  });

  final EdenTankGaugeData data;
  /// Explicit mode override. When null, auto-selects via [EdenAdaptiveTierScope].
  final EdenTankGaugeMode? mode;
  final double lowThresholdPct;
  final double warningThresholdPct;

  EdenTankGaugeMode _resolveMode(BuildContext context) {
    if (mode != null) return mode!;
    final tier = EdenAdaptiveTierScope.maybeOf(context);
    if (tier == EdenAdaptiveTier.compact) return EdenTankGaugeMode.linear;
    return EdenTankGaugeMode.linear; // default fallback
  }

  Color _fillColor(double ratio) {
    if (ratio <= lowThresholdPct) return EdenColors.danger;     // (or .error — verify token name)
    if (ratio <= warningThresholdPct) return EdenColors.warning;
    return EdenColors.success;
  }

  String _fmt(double v) {
    final s = v.toStringAsFixed(1);
    return s.endsWith('.0') ? s.substring(0, s.length - 2) : s;
  }

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final resolved = _resolveMode(context);
    final ratio = data.fillRatio;
    final isLow = ratio <= lowThresholdPct;
    final color = _fillColor(ratio);
    final label = '${_fmt(data.currentGal)}/${_fmt(data.capacityGal)} ${data.unitLabel}';
    final body = switch (resolved) {
      EdenTankGaugeMode.linear => _LinearBody(ratio: ratio, color: color, isLow: isLow),
      EdenTankGaugeMode.segmented => _SegmentedBody(ratio: ratio, color: color),
      EdenTankGaugeMode.dial => _DialBody(ratio: ratio, color: color),
    };
    return Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        if (data.fuelTypeLabel != null) ...[
          Text(data.fuelTypeLabel!,
              style: theme.textTheme.labelSmall,
              maxLines: 1,
              overflow: TextOverflow.ellipsis),
          const SizedBox(height: EdenSpacing.space1),
        ],
        body,
        const SizedBox(height: EdenSpacing.space1),
        Text(label,
            style: theme.textTheme.labelSmall,
            maxLines: 1,
            overflow: TextOverflow.ellipsis),
        if (data.isOverfull)
          Padding(
            padding: const EdgeInsets.only(top: EdenSpacing.space1),
            child: Container(
              padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
              decoration: BoxDecoration(
                color: EdenColors.warning,
                borderRadius: BorderRadius.circular(4),
              ),
              child: const Text('Overfull',
                  style: TextStyle(fontSize: 10, fontWeight: FontWeight.w600, color: Colors.white)),
            ),
          ),
      ],
    );
  }
}

class _LinearBody extends StatelessWidget {
  const _LinearBody({required this.ratio, required this.color, required this.isLow});
  final double ratio;
  final Color color;
  final bool isLow;

  @override
  Widget build(BuildContext context) {
    return Container(
      width: 80,

      decoration: BoxDecoration(

      ),
    );
  }
```

```dart
import 'dart:math' as math;

class _DialBody extends StatelessWidget {
  const _DialBody({required this.ratio, required this.color});
  final double ratio;
  final Color color;
  @override
  Widget build(BuildContext context) {
    return SizedBox(
      width: 180,
      height: 100,
      child: CustomPaint(
        painter: _DialPainter(ratio: ratio, color: color,
            trackColor: Theme.of(context).colorScheme.outlineVariant),
      ),
    );
  }
}

class _DialPainter extends CustomPainter {
  _DialPainter({required this.ratio, required this.color, required this.trackColor});
  final double ratio;
  final Color color;
  final Color trackColor;

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height);
    final radius = size.width / 2 - 8;
    final trackPaint = Paint()
      ..color = trackColor
      ..strokeWidth = 8
      ..style = PaintingStyle.stroke
      ..strokeCap = StrokeCap.round;
    // Background arc: -π to 0 (upper semicircle).
    canvas.drawArc(
      Rect.fromCircle(center: center, radius: radius),
      -math.pi, math.pi, false, trackPaint,
    );
    // Fill arc proportional to ratio.
    final fillPaint = Paint()
      ..color = color
      ..strokeWidth = 8
      ..style = PaintingStyle.stroke
      ..strokeCap = StrokeCap.round;
    canvas.drawArc(
      Rect.fromCircle(center: center, radius: radius),
      -math.pi, math.pi * ratio, false, fillPaint,
    );
    // Needle pointing to current ratio.
    final needleAngle = -math.pi + math.pi * ratio;
    final needleEnd = Offset(
      center.dx + radius * math.cos(needleAngle),
      center.dy + radius * math.sin(needleAngle),
    );
    final needlePaint = Paint()
      ..color = color
      ..strokeWidth = 3;
    canvas.drawLine(center, needleEnd, needlePaint);
    canvas.drawCircle(center, 5, Paint()..color = color);
  }

  @override
  bool shouldRepaint(_DialPainter old) =>
      old.ratio != ratio || old.color != color || old.trackColor != trackColor;
}
```
