<objective>
Ship `EdenStoreTransfer` — multi-step inter-location inventory-transfer flow primitive. Per `USE_CASES_RETAIL_2026-05-17.md` UC-16 (L2; L1 if multi-location in scope): Square + Shopify + Lightspeed all market stock-transfers between locations as a pillar feature; Eden has zero coverage today.

Two operating modes — **dispatch** (origin store: create + send transfer; 4 steps selectLocations → selectItems → shipping → confirmDispatch) and **receive** (destination store: confirm receipt of an in-transit transfer; single-step variance + confirm).

Generic — knows nothing about retail. Consumer maps domain (`stock_transfers`, `transfer_lines`, `locations`) to `EdenStoreTransfer` + `EdenStoreTransferItem`. Cross-vertical: trades truck-to-truck inventory transfer, salon back-bar transfer, fuel parts-truck transfer, gov supply-depot transfer (all share `source → dest → items + in-transit / received` shape).

Composes obj 012 `EdenLineItemEditor` for items list (read-only in receive mode, editable in dispatch mode). Reuses obj 014-05 `EdenVarianceReason` enum for variance-reason picker on receive step — verify export at impl-time; duplicate locally if not exported.

Wave 2 multi-step flow — mirrors obj 014-05 `EdenReceivingFlow` pattern (the existing receiving flow is the closest sibling — receive existing inventory FROM a supplier; this widget receives transferred inventory FROM another internal location). Depends on 018-04 ONLY for the Wave 2 sub-header in `lib/eden_ui.dart`; no widget composition.

Outside-in test approach: mode dispatch (dispatch vs receive constructor routing) → step 1 SelectLocations + source≠dest validation → step 2 SelectItems with barcode lookup → step 3 Shipping (walk-in toggle) → step 4 ConfirmDispatch + draft emission → receive-mode step (variance picker per line + confirm) → narrow responsive → helper unit tests.
</objective>

**Dispatch-mode state machine:**
- Initial: `step = selectLocations`, `_source = null`, `_dest = null`, `_items = []`, `_carrier = ''`, `_tracking = ''`, `_isWalkIn = false`.
- Step 1 → 'Next' enabled when `_source != null && _dest != null && _source.id != _dest.id` → step = selectItems.
- Step 2 → 'Next' enabled when `_items.isNotEmpty` → step = shipping.
- Step 3 → 'Next' always enabled → step = confirmDispatch.
- Step 4 → 'Confirm dispatch' → fires `onSubmit(EdenStoreTransferDraft(status: inTransit, ...))`.

**Receive-mode flow (single step):**
- Initial: `step = receive`, `_received = Map<String, EdenStoreTransferItem>` pre-populated with `initialTransfer.items` mapped to copies with `receivedQty: item.qty` (no variance by default).
- Step 5 (Receive): list of editable per-line received-qty rows + variance reason picker shown when receivedQty != expectedQty. 'Confirm receive' → fires `onSubmit(EdenStoreTransferDraft(status: received, perLineVariance: ...))`.

**Step 1 — SelectLocations:**
- Title: 'Select locations'.
- Two `EdenSelect<EdenLocation>` widgets (Source + Destination) with the same `availableLocations` options.
- Validation: source != dest. When violated, `EdenAlert.warning('Source and destination must differ')` inline.

**Step 2 — SelectItems:**
- Title: 'Select items to transfer'.
- `EdenSearchInput` (or fallback `TextField`) + 'Scan' icon button → calls `onItemLookup(query)`. On success, adds returned `EdenStoreTransferItem` to `_items` (or increments qty if SKU already present).
- Below: list of `_items` with per-line qty edit + remove button.
- Footer: '${_items.length} item(s)' counter.

**Step 3 — Shipping:**
- 'Walk-in transfer (no carrier)' checkbox. When true, carrier + tracking fields disabled and `_carrier = ''; _tracking = ''`.
- Otherwise: `EdenInput(label: 'Shipping carrier')` + `EdenInput(label: 'Tracking #')` (both optional).

**Step 4 — ConfirmDispatch:**
- Summary: source → destination, ${items.length} items, shipping {carrier + tracking | 'Walk-in'}.
- 'Confirm dispatch' button → emits draft.

**Step 5 — Receive:**
- Title: 'Receive transfer ${id}'.
- Header: from ${sourceLocation.name} → ${destLocation.name}; dispatched ${dispatchedAt}.
- List of per-line rows: SKU + name + expected qty (read-only) + received qty input + variance reason picker (visible only when received != expected).
- 'Confirm receive' button → emits draft with `perLineVariance` map populated from rows where variance was set.

**Helpers (file-private):**
- `bool _isValidLocationPair(EdenLocation? src, EdenLocation? dst)` — both non-null AND src.id != dst.id.
- `String _stepLabel(EdenStoreTransferStep s)` — 'Select locations' / 'Select items' / 'Shipping' / 'Confirm dispatch' / 'Receive'.
- `int _itemCount(List<EdenStoreTransferItem> items)` — items.length.
- `Map<String, EdenVarianceReason> _collectVariance(Map<String, EdenStoreTransferItem> received)` — `{for (final e in received.entries) if (e.value.varianceReason != null) e.key: e.value.varianceReason!}`.

```dart
Future<void> _onScanOrSearch(String query) async {
  if (widget.onItemLookup == null) return;
  final found = await widget.onItemLookup!(query.trim());
  if (found == null) {
    setState(() => _lookupError = 'Item not found');
    return;
  }
  setState(() {
    _lookupError = null;
    final existingIdx = _items.indexWhere((i) => i.sku == found.sku);
    if (existingIdx >= 0) {
      _items[existingIdx] = _items[existingIdx].copyWith(qty: _items[existingIdx].qty + 1);
    } else {
      _items.add(found);
    }
  });
}
```

```dart
Widget _buildReceiveMode(BuildContext context) {
  final t = widget.initialTransfer!;
  return Column(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Text('Receive transfer ${t.id}', style: Theme.of(context).textTheme.titleMedium),
      Text('From ${t.sourceLocation.name} → ${t.destLocation.name}'),
      if (t.dispatchedAt != null) Text('Dispatched ${_formatDate(t.dispatchedAt!)}', style: Theme.of(context).textTheme.bodySmall),
      const SizedBox(height: 12),
      Expanded(child: ListView(
        children: t.items.map((expected) => _buildReceiveRow(expected)).toList(),
      )),
      const SizedBox(height: 12),
      ElevatedButton(
        onPressed: () {
          widget.onSubmit(EdenStoreTransferDraft(
            transferId: t.id,
            sourceLocationId: t.sourceLocation.id,
            destLocationId: t.destLocation.id,
            items: _received.values.toList(),
            status: EdenStoreTransferStatus.received,
            shippingCarrier: t.shippingCarrier,
            trackingRef: t.trackingRef,
            isWalkIn: t.isWalkIn,
            perLineVariance: _collectVariance(_received),
          ));
        },
        child: const Text('Confirm receive'),
      ),
    ],
  );
}

@override
void initState() {
  super.initState();
  if (widget.mode == _EdenStoreTransferMode.receive && widget.initialTransfer != null) {
    for (final item in widget.initialTransfer!.items) {
      _received[item.lineId] = item.copyWith(receivedQty: item.qty);
    }
  }
}
```
