<objective>
Ship `EdenLoyaltyMemberDetail` — customer loyalty profile detail surface for retail front-of-house lookup (cashier-facing during checkout-attach UX, manager-facing during customer inquiry). Was deferred from obj 014 per `OBJECTIVE.md` "out of scope" §6 as `014-future: EdenLoyaltyMemberDetail`; this TRD closes that commitment.

Renders: header (avatar + name + tier badge) → 3-KPI strip (lifetime spend / points / days-since-last-visit) → optional birthday-promo callout → recent purchases list (last N via `EdenActivityFeedItem`) → join-date footer.

Generic — knows nothing about retail. Consumer maps domain (`customers.loyalty_profile_id`, `loyalty_transactions`, `purchase_history`) to `EdenLoyaltyMember` + `EdenLoyaltyPurchase`. Cross-vertical reuse: salon membership, fuel fleet account, medical patient summary, trades customer-of-record (all share `name + tier + balance + recent-activity` shape).

Wave 1 atomic primitive — FOUNDATION TRD that bootstraps `lib/dev_app/screens/retail_polish_screen.dart` + registers `RetailPolishScreen` in `home_screen.dart`. TRDs 018-02 through 018-06 each APPEND a `Section()` at their respective anchor comments.

**Layout (top to bottom):**
1. Header: `Row([CircleAvatar, SizedBox, Expanded(Text(name)), EdenMembershipTierBadge])`. At <500pt: tier badge wraps to a second line.
2. 3-KPI strip: 3 `EdenStatCard` (or inline `Column(Text(label), Text(value))`) — lifetime spend, points, days-since-last-visit. At <500pt: wraps to vertical stack.
3. Birthday callout (conditional): `EdenAlert.info(message: 'Birthday on {Month Day} — eligible for birthday promo')` when `birthdayPromoEnabled && member.birthday != null && _isWithinBirthdayWindow(now, member.birthday, daysWindow: 14)`.
4. Recent purchases section: title row + `ListView` of up to `maxRecent` `EdenActivityFeedItem`. Empty state when `recentPurchases.isEmpty`.
5. Footer: `Text('Member since {MMM yyyy}')` when `joinedAt` set.

**Helpers (private statics or top-level fns):**
- `String _formatRelativeTime(DateTime then, DateTime now)` — "just now" (<60s), "5m ago" (<60min), "3h ago" (<24h), "yesterday" (<48h), "5d ago" (<14d), "3w ago" (<60d), "{MMM d}" (<365d), "{MMM d, yyyy}" (else). Hand-rolled, no `intl`.
- `String _formatJoinMonthYear(DateTime joined)` — `'${_months[joined.month - 1]} ${joined.year}'` with const `_months` list.
- `String _initialsFor(String name)` — first letter of each whitespace-separated token, up to 2 chars uppercase.
- `bool _isWithinBirthdayWindow(DateTime now, DateTime birthday, {int daysWindow = 14})` — compute the birthday in `now.year`; check `|now - birthdayThisYear| ≤ daysWindow`; handles year-wrap (e.g. Dec 30 birthday on Jan 5 should still match).
- `int _daysSinceLastVisit(List<EdenLoyaltyPurchase> recent, DateTime now)` — `recent.isEmpty ? -1 : now.difference(recent.first.occurredAt).inDays` (assumes recent is reverse-chronological; document on field).

```dart
bool _isWithinBirthdayWindow(DateTime now, DateTime birthday, {int daysWindow = 14}) {
  final thisYearBirthday = DateTime(now.year, birthday.month, birthday.day);
  final lastYearBirthday = DateTime(now.year - 1, birthday.month, birthday.day);
  final nextYearBirthday = DateTime(now.year + 1, birthday.month, birthday.day);
  final candidates = [lastYearBirthday, thisYearBirthday, nextYearBirthday];
  for (final c in candidates) {
    if (now.difference(c).inDays.abs() <= daysWindow) return true;
  }
  return false;
}
```

<gotchas>
- **EdenMembershipTierBadge has two constructors** — `EdenMembershipTierBadge(tier: ...)` for preset (bronze/silver/gold/platinum/vip) and `EdenMembershipTierBadge.custom(label:, backgroundColor:, foregroundColor:, icon:)` for non-preset verticals. The dispatch logic in `_tierBadge` must pick the right constructor based on which optional fields are set.
- **Birthday year-wrap edge case:** birthday is `Dec 30, 1992`, today is `Jan 5, 2026` → birthday-this-year is `Dec 30, 2026` (~360 days away). Need to also check `Dec 30, 2025` (~6 days away) → match. The 3-candidate list (last/this/next year) handles this.
- **`_daysSinceLastVisit` returns -1 when no purchases** — the test "renders '—' for days-since-last-visit when recentPurchases is empty" asserts the dash, not the number.
- **`now` injection** — use `widget.now ?? DateTime.now()` ONLY inside `build()`. Don't memoize in initState (Stateless anyway). Tests pass `now: DateTime(2026, 5, 17)` explicitly.
- **`_formatRelativeTime` thresholds:** 60s, 60m, 24h, 48h (yesterday), 14d, 60d, 365d. Hand-roll with a chain of `if (diff.inSeconds < 60) return 'just now'; if (diff.inMinutes < 60) return '${diff.inMinutes}m ago'; ...`. Test boundary cases (59s → "just now", 60s → "1m ago").

```dart
Widget _buildRecentPurchases(BuildContext context) {
  if (member.recentPurchases.isEmpty) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text('Recent purchases', style: Theme.of(context).textTheme.titleMedium),
        const SizedBox(height: 8),
        const Padding(padding: EdgeInsets.symmetric(vertical: 16), child: Text('No recent purchases')),
      ],
    );
  }
  final initials = _initialsFor(member.name);
  return Column(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Text('Recent purchases', style: Theme.of(context).textTheme.titleMedium),
      const SizedBox(height: 8),
      for (final p in member.recentPurchases.take(maxRecent))
        EdenActivityFeedItem(
          item: EdenActivityFeedItemData(

  );
}
```
