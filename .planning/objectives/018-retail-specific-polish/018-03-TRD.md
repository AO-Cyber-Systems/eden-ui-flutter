<objective>
Ship `EdenGiftCardBalanceLookup` — staff-facing gift-card balance + activity lookup surface for cashier UX. Per `USE_CASES_RETAIL_2026-05-17.md` UC-28 + UC-09: cashier needs balance-pre-apply affordance ("what's my balance?") + recent-activity audit. Square / Shopify / Lightspeed / Clover all market gift cards as a pillar; Eden's `EdenSecretField.classified` (obj 011-08) provides PCI-aware card-entry, but no balance-lookup widget shipped today.

Interactive widget: input row (card # via EdenSecretField.classified + 'Lookup' button) → on submit, fire `onLookup(cardNumber)` callback → display result (masked # + balance + status + recent activity) OR error state ('Card not found' / 'Deactivated' / 'Expired').

Generic — knows nothing about retail. Consumer wires `onLookup` to their backend (Square Gift Cards API / proprietary). Cross-vertical reuse: fuel fleet-card lookup, salon prepaid-card lookup, medical FSA/HSA card lookup, gov benefit-card lookup (all share `card # → balance + activity` shape).

obj-015 dependency strategy: when obj 015 lands with `EdenGiftCardManager` (sell + reload + balance), THIS widget remains the dedicated lookup surface. They are sibling concerns, not consumer/composer. The `_GiftCardManagerShim` clause in the orchestrator brief is a precautionary entry — at impl time, executor checks `lib/src/widgets/eden_gift_card_manager.dart`; if absent → no shim needed (this lookup widget is standalone); if present → still no composition (sibling surface). Document this in the file header.

Wave 1 atomic primitive. Depends on 018-01 ONLY for the `retail_polish_screen.dart` file-create (anchor pattern). No widget composition or runtime dependency on 018-01.

Outside-in test approach: state machine (idle → loading → result OR error) → input UI (EdenSecretField.classified composition) → lookup callback wiring → result rendering per status → activity rendering → narrow responsive → helper unit tests (card masking).
</objective>

**State machine:**
- `idle`: no lookup yet. Input + Lookup button visible.
- `loading`: lookup in flight. Spinner + 'Looking up...' text; input disabled.
- `result`: lookup returned non-null `EdenGiftCardBalanceResult`. Render result section.
- `notFound`: lookup returned null. Show `EdenAlert.warning('Card not found')`. Stay in this state until user types a new card #.

Stored as `EdenGiftCardLookupState? _lookupState`.

**Layout (top to bottom):**

1. Title: `'Gift card balance lookup'`.
2. Input row:
   - `EdenSecretField.classified(label: 'Gift card #', clipboardMode: EdenClipboardMode.disabled, onChanged: (v) => _draft = v)` for PAN entry.
   - `ElevatedButton` 'Lookup' — disabled when `_draft.length < 4` OR `_lookupState == loading`. On press: `setState(() => _lookupState = loading)` → `await widget.onLookup(_draft)` → setState with result OR notFound.
3. Result section (conditional on `_lookupState`):
   - `loading` → centered `CircularProgressIndicator` + `Text('Looking up...')`.
   - `notFound` → `EdenAlert.warning(message: 'Card not found. Check the number and try again.')`.
   - `result` → see below.
4. Result rendering:
   - Header row: masked card # (via `cardMaskFn ?? _defaultMask`) + status badge (`EdenBadge(label, color: _statusColor(status))`).
   - Balance row: `EdenCurrencyDisplay(balanceCents, large)`.
   - Status callout: when status ∈ {deactivated, expired}, `EdenAlert.warning(message)` with status-specific text below balance.
   - Last-used / expires footer: when set.
   - Activity title: `'Recent activity (last $maxRecent)'`.
   - Activity list: up to `maxRecent` `EdenActivityFeedItem` rows.
   - Empty activity: `'No recent activity'` line.

**Helpers (file-private):**
- `String _defaultMask(String full)` — if `full.length >= 4`: `'****-****-****-${full.substring(full.length - 4)}'`. Else: `'****'`.
- `Color _statusColor(EdenGiftCardStatus s, BuildContext ctx)` — green / red / grey / red per status, pulled from theme where possible.
- `String _statusLabel(EdenGiftCardStatus s)` — 'Active' / 'Deactivated' / 'Expired' / 'Not found'.
- `String _activityLabel(EdenGiftCardActivityType t)` — 'Loaded' / 'Redeemed' / 'Refunded' / 'Adjustment' / 'Expired'.
- `String _formatSignedMoney(int cents)` — same as 018-02 (file-private; duplicate is OK to avoid cross-file import).

Future<void> _doLookup() async {
  setState(() => _lookupState = _LookupState.loading);
  try {
    final res = await widget.onLookup(_draft);
    if (!mounted) return;
    setState(() {
      _result = res;
      _lookupState = res == null ? _LookupState.notFound : _LookupState.result;
    });
  } catch (e) {
    if (!mounted) return;
    setState(() {
      _lookupState = _LookupState.notFound;
      _result = null;
    });
  }
}
