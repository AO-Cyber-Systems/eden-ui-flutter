<objective>
Ship `EdenLayawayFlow` — multi-step layaway lifecycle primitive for retail cashier UX. Per `USE_CASES_RETAIL_2026-05-17.md` UC-06 (L2 — Lightspeed-marketed pillar): "Customer wants to hold item with deposit." Lightspeed lists "Deposits / Laybys / Buy now, pay later" as a marketed feature; Eden has zero coverage today.

Two operating modes — **create** (new layaway: 3-step deposit → schedule → submit) and **manage** (existing layaway: 3 actions on a known `EdenLayawayState`).

Generic — knows nothing about retail. Consumer maps domain (`layaways`, `layaway_installments`, `customer_notifications`) to `EdenLayawayState` + `EdenLayawayCartItem` + `EdenLayawayInstallment`. Cross-vertical: trades deposit-on-quote, salon prepaid-package install, medical payment-plan lifecycle (all share `deposit + installments + release/cancel` shape).

Composes obj 012 commerce primitives directly (shipped): `EdenLineItemEditor` for cart display (read-only in create-mode), `EdenPaymentEntry` for deposit + installment collection. No PCI-sensitive widget here (no PAN entry — payment method picker and amount only; consumer wires actual card capture downstream).

Wave 2 multi-step flow — mirrors obj 014-05 `EdenReceivingFlow` + 018-04 `EdenRefundFlow` patterns. Depends on 018-04 ONLY for the Wave 2 sub-header in `lib/eden_ui.dart` + the retail_polish_screen.dart anchor order; no widget composition.

Outside-in test approach: mode dispatch (create vs manage constructor routing) → create step machine + per-step rendering → manage summary + action picker + per-action sub-flow → notify-callback wiring → narrow responsive → helper unit tests (minDeposit computation, balance-due math).
</objective>

class EdenLayawayFlow extends StatefulWidget {
  /// Create-mode: new layaway from a session cart.
  const EdenLayawayFlow.create({
    super.key,
    required this.cartItems,
    required this.onSubmit,
    this.onCustomerAttach,
    this.onNotifyCustomer,

  /// Manage-mode: existing layaway from a known state.
  const EdenLayawayFlow.manage({
    super.key,
    required EdenLayawayState this.state,
    required this.onSubmit,
    this.onNotifyCustomer,
    this.minDepositPercent = 0.20,
  })  : mode = _EdenLayawayMode.manage,
        cartItems = const [],
        onCustomerAttach = null,
        customerId = null,
        customerName = null;

  final _EdenLayawayMode mode;
  final List<EdenLayawayCartItem> cartItems;        // create-mode only

  final void Function(EdenLayawayDraft draft) onSubmit;
  final VoidCallback? onCustomerAttach;
  final Future<void> Function(EdenLayawayNotifyChannel, String)? onNotifyCustomer;
  final double minDepositPercent;
  final String? customerId;
  final String? customerName;
}

**Create-mode state machine:**
- Initial: `step = create`.
- Step 1 (Create): cart summary + 'Attach customer' affordance + 'Next' → step = deposit.
- Step 2 (Deposit): EdenPaymentEntry for deposit + minDeposit validation; 'Next' → step = schedule. Disabled when depositCents < minDepositCents.
- Step 3 (Schedule): pickup-by EdenDatePicker + optional installmentCount; 'Submit' → fires onSubmit + onNotifyCustomer (channel email/sms/none, payload).

**Manage-mode:** single-screen summary + action picker + per-action sub-flow:
- Summary card: cart items list (collapsed/expanded toggle), deposit-paid: $X, installments-paid: $Y, balance-due: $Z, pickup-by countdown badge.
- `EdenSelect<EdenLayawayAction>` picker.
- 'Confirm action' button → triggers per-action sub-flow:
  - `recordInstallment`: shows `EdenPaymentEntry` for amount + method → 'Submit' fires `EdenLayawayInstallmentDraft`.
  - `releaseToCustomer`: when balance > 0 → `EdenAlert.warning('Balance due $X — collect remaining before release')` + Confirm gated. When balance = 0 → 'Confirm release' button → fires `EdenLayawayReleaseDraft` + `onNotifyCustomer(channel, 'Layaway ${id} ready for pickup')`.
  - `cancelAndRefund`: confirmation dialog ('Cancel layaway? Customer will be refunded ${depositPlusInstallments}.') → on confirm fires `EdenLayawayCancelDraft(refundCents)` + `onNotifyCustomer(channel, 'Layaway ${id} cancelled')`.

**Helpers (file-private):**
- `int _cartTotalCents(List<EdenLayawayCartItem> items)` — `items.fold(0, (acc, i) => acc + (i.unitPriceCents * i.qty).round() + i.taxCents)`.
- `int _minDepositCents(int cartTotal, double percent)` — `(cartTotal * percent).round()`.
- `int _paidSoFarCents(EdenLayawayState s)` — `s.depositCents + s.installments.fold(0, (acc, i) => acc + i.amountCents)`.
- `int _refundOnCancelCents(EdenLayawayState s)` — `_paidSoFarCents(s)` (full-paid refund; consumer policy may differ — document).
- `int _daysUntilPickup(DateTime pickupBy, DateTime now)` — `pickupBy.difference(now).inDays`. Negative when overdue.
- `String _statusLabel(EdenLayawayStatus s)` — 'Active' / 'Ready for pickup' / 'Completed' / 'Cancelled'.

**Notify-channel selection:** widget exposes a `_notifyChannel: EdenLayawayNotifyChannel _notifyChannel = EdenLayawayNotifyChannel.none` defaulting to none. UI: 3-radio picker on the schedule step (create-mode) and on each action's sub-flow (manage-mode). Consumer's `onNotifyCustomer` receives `(channel, payload)`; if `channel == none`, widget skips the callback entirely.

<gotchas>
- **Two constructors / one widget:** `EdenLayawayFlow.create` vs `EdenLayawayFlow.manage`. They cannot share `super.key` + state seamlessly — verify behavior in tests. Pattern: one State class with mode-dispatch in `build()`. Tests must cover both constructors.

Widget _buildActionSubflow(BuildContext context, EdenLayawayState s) {
  switch (_selectedAction!) {
    case EdenLayawayAction.recordInstallment: return _buildInstallmentForm(context, s);
    case EdenLayawayAction.releaseToCustomer: return _buildReleaseForm(context, s);
    case EdenLayawayAction.cancelAndRefund: return _buildCancelForm(context, s);
  }
}

Widget _buildReleaseForm(BuildContext context, EdenLayawayState s) {
  final balanceDue = s.balanceCents > 0;
  return Column(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      if (balanceDue) EdenAlert(severity: EdenAlertSeverity.warning, message: 'Balance due ${_formatMoney(s.balanceCents)} — collect remaining before release.'),
      const SizedBox(height: 12),
      _notifyChannelPicker(),
      const SizedBox(height: 12),
      ElevatedButton(
        onPressed: balanceDue ? null : () async {
          widget.onSubmit(EdenLayawayReleaseDraft(layawayId: s.id));
          if (widget.onNotifyCustomer != null && _notifyChannel != EdenLayawayNotifyChannel.none) {
            await widget.onNotifyCustomer!(_notifyChannel, 'Layaway ${s.id} ready for pickup');
          }
        },
        child: const Text('Confirm release'),
      ),
    ],
  );
}

Widget _buildCancelForm(BuildContext context, EdenLayawayState s) {
  final refund = _refundOnCancelCents(s);
  return Column(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      EdenAlert(severity: EdenAlertSeverity.danger, message: 'Cancel layaway? Customer will be refunded ${_formatMoney(refund)}.'),
      const SizedBox(height: 12),
      _notifyChannelPicker(),
      const SizedBox(height: 12),
      ElevatedButton(
        onPressed: () async {
          final confirmed = await showDialog<bool>(
            context: context,
            builder: (ctx) => AlertDialog(
              title: const Text('Cancel layaway'),
              content: Text('Refund ${_formatMoney(refund)} to customer?'),
              actions: [
                TextButton(onPressed: () => Navigator.pop(ctx, false), child: const Text('Back')),
                ElevatedButton(onPressed: () => Navigator.pop(ctx, true), child: const Text('Confirm cancel')),
              ],
            ),
          );
          if (confirmed != true) return;
          widget.onSubmit(EdenLayawayCancelDraft(layawayId: s.id, refundCents: refund));
          if (widget.onNotifyCustomer != null && _notifyChannel != EdenLayawayNotifyChannel.none) {
            await widget.onNotifyCustomer!(_notifyChannel, 'Layaway ${s.id} cancelled');
          }
        },
        child: const Text('Cancel layaway'),
      ),
    ],
  );
}
