<objective>
Ship `EdenRefundFlow` — multi-step refund flow primitive for retail cashier UX. Per `USE_CASES_RETAIL_2026-05-17.md` UC-04 (HARD BLOCKER): "Day 1 every store has a return." Currently zero coverage; was deferred from obj 014 per `OBJECTIVE.md` "out of scope" §6 as `014-future: EdenRefundFlow`. This TRD closes that commitment.

4 sequential steps: lookup sale → select lines + reasons → method picker → (conditional) manager-override approval → submit.

Generic — knows nothing about retail. Consumer maps domain (`sales`, `sale_lines`, `payments`, `customers`) to `EdenSaleRecord` + `EdenSaleLine`. Cross-vertical: trades invoice-refund, salon service-refund, fuel delivery-refund, medical claim-reversal (all share `lookup → select → method → approve` shape).

Composes obj 012 commerce primitives directly (shipped): `EdenLineItemEditor` for line selection, `EdenPaymentEntry` for method, `EdenSplitTender` not needed (single refund method per draft). Composes obj 011-08 `EdenSecretField.classified` for manager-override PIN.

Wave 2 multi-step flow — mirrors obj 014-05 `EdenReceivingFlow` state-machine pattern verbatim. Runs parallel with 018-05 + 018-06.

Outside-in test approach: state machine (step transitions) → step 1 LookupSale (search input, lookup callback) → step 2 SelectLines (line-item refund-qty editing, reason picker) → step 3 Method (refund-method picker, originalTender callout) → step 4 ManagerApprove (threshold + non-original-tender triggers, PIN entry, approval callback) → submit emits correct draft → narrow responsive → PCI constraint enforced.

**State machine:**
- Initial: `step = lookupSale`, `_sale = null`, `_refundLines: Map<String, EdenRefundLine> = {}`, `_method = null`, `_managerApproved = false`.
- Step 1 → on lookup success → `step = selectLines`, pre-populate `_refundLines` empty (user opts in per line).
- Step 2 → 'Next' → `step = method`. Disabled while `_refundLines.isEmpty` OR any selected line has no reason set.
- Step 3 → 'Next' → if `_requiresManagerApproval()` is true → `step = managerApprove`; else → `_submit()`.
- Step 4 → on approval → `_submit()`. On rejection → stay on step 4 with error message.

`bool _requiresManagerApproval()` → `totalRefundCents >= widget.managerApprovalThresholdCents || _method != EdenRefundMethod.originalTender` (assuming `widget.onManagerApprove != null`; if null, approval gate is bypassed entirely).

**Step 1 — LookupSale:**
- Title: 'Find the original sale'.
- `EdenSearchInput` with hint text 'Receipt #, phone, email, or card last 4'.
- 'Lookup' button → calls `widget.onLookupSale(query)` returning `Future<EdenSaleRecord?>`. Null → 'Sale not found' inline alert.
- On success → transition to step 2.

**Step 2 — SelectLines:**
- Renders sale header: `'Sale ${saleId} · ${_formatDate(occurredAt)} · ${_formatMoney(originalTotalCents)} on ${originalTender.name}'`.
- Composes `EdenLineItemEditor` (obj 012) in refund mode:
  - Read-only columns: SKU, name, original qty (`refundableQty`), unit price.
  - Editable column: refund qty (0 .. refundableQty).
  - Per-line `EdenSelect<EdenRefundReason>` shown only when refundQty > 0.
- Footer: `'Refund total: ${_formatMoney(_computeTotalCents())}'` live-updates.

EdenLineItemEditor refund-mode usage:
```dart
EdenLineItemEditor<EdenSaleLine>(
  items: sale.lines.map((l) => EdenLineItem<EdenSaleLine>(
    id: l.lineId,
    data: l,
    qty: _refundLines[l.lineId]?.refundQty ?? 0,
    unitPriceCents: l.unitPriceCents,
    nameLabel: l.name,
    skuLabel: l.sku,
  )).toList(),
  editable: true,
  maxQtyPerLine: (id) => sale.lines.firstWhere((l) => l.lineId == id).refundableQty,
  onQtyChanged: (id, qty) => setState(() {
    final reason = _refundLines[id]?.reason ?? EdenRefundReason.other;
    if (qty == 0) {
      _refundLines.remove(id);
    } else {
      _refundLines[id] = EdenRefundLine(lineId: id, refundQty: qty, reason: reason);
    }
  }),
  customColumns: [
    EdenLineItemColumn.custom(
      label: 'Reason',
      builder: (item) => _refundLines.containsKey(item.id)
        ? EdenSelect<EdenRefundReason>(
            value: _refundLines[item.id]!.reason,
            options: EdenRefundReason.values,
            onChanged: (r) => setState(() => _refundLines[item.id] = _refundLines[item.id]!.copyWith(reason: r!)),
          )
        : const SizedBox.shrink(),
    ),
  ],
)
```

- `bool _requiresManagerApproval()` — see state-machine description.

Example 1 — Multi-step state machine (mirror obj 014-05 verbatim):
```dart
class _State {
  EdenRefundStep _step = EdenRefundStep.lookupSale;
  EdenSaleRecord? _sale;
  final Map<String, EdenRefundLine> _refundLines = {};
  EdenRefundMethod? _method;
  bool _managerApproved = false;

  Future<void> _next() async {
    switch (_step) {
      case EdenRefundStep.lookupSale: setState(() => _step = EdenRefundStep.selectLines); break;
      case EdenRefundStep.selectLines:
        if (!_canAdvanceFromSelectLines()) return;
        setState(() => _step = EdenRefundStep.method);
        break;
      case EdenRefundStep.method:
        if (_method == null) return;
        if (_requiresManagerApproval()) {
          setState(() => _step = EdenRefundStep.managerApprove);
        } else {
          _submit();
        }
        break;
      case EdenRefundStep.managerApprove: break; // terminal; approve button handles
    }
  }
}
```

```dart
int _computeTotalCents() {
  if (_sale == null) return 0;
  int total = 0;
  for (final r in _refundLines.values) {
    final line = _sale!.lines.firstWhere((l) => l.lineId == r.lineId);
    final unitTaxCents = line.originalQty > 0 ? (line.taxCents / line.originalQty).round() : 0;
    total += (line.unitPriceCents * r.refundQty).round() + (unitTaxCents * r.refundQty).round();
  }
  return total;
}
```

<gotchas>
- **Tax allocation simplification:** v1 uses proportional unit-tax allocation (`taxCents / originalQty` per unit, rounded). Real-world tax rules vary; consumer can override by reading `_refundLines` and computing externally. Document on `_computeTotalCents` source comment.
- **`refundableQty` ≠ `originalQty`** for sales with prior partial refunds. Cap refundQty at refundableQty in `onQtyChanged`; assert in state.
- **Empty refundLines blocks advance:** `_canAdvanceFromSelectLines` returns false when no lines selected. Next button disabled.
- **Manager approval bypass:** when `widget.onManagerApprove == null`, `_requiresManagerApproval()` always returns false → step 4 never visited, submit fires from step 3.
- **`_managerApproved = false` initially**, set to true on successful onManagerApprove(). The `submit` method asserts `_managerApproved == true` when `_requiresManagerApproval()` was true.
- **Back button on each step:** step 1 → no back. Step 2 → back clears `_sale + _refundLines`. Step 3 → back keeps refund lines (user adjusting method). Step 4 → back returns to method step.

**State machine — step transitions**
- Initial step = lookupSale.
- Lookup returns EdenSaleRecord → step = selectLines.
- 'Next' on selectLines with ≥1 line + reason → step = method.
- 'Next' on selectLines with empty refundLines → button disabled.

- 'Next' on method with method != originalTender → step = managerApprove.
- 'Back' on selectLines → step = lookupSale, _sale cleared.
- 'Back' on method → step = selectLines, refund lines preserved.

- Search input renders.
- Typing + 'Lookup' fires `onLookupSale(query)` with the typed query.
- Null lookup result → stays on step 1; shows 'Sale not found' alert.

- Renders sale header (saleId + date + total + tender).
- Renders one editable row per sale line.
- Setting refundQty > 0 enables Reason picker for that row.
- Setting refundQty = 0 removes the line from _refundLines.
- Refund total updates live as qty changes.

- Renders allowedMethods (3 options by default).
- Original-tender callout shown referencing _sale.originalTender.
- Method picker updates _method state.

**Step 4 — ManagerApprove (threshold trigger)**
- $50+ refund total → step 4 entered when 'Next' on method step.
- $40 refund total + originalTender method → submit fires directly (step 4 skipped).
- $40 refund total + storeCredit method → step 4 entered (non-original-tender trigger).

- 'Approve' button fires onManagerApprove().
- Approval success → submit fires.
- Approval failure → 'Approval denied' alert; stays on step 4.

- Draft.saleId matches _sale.saleId.
- Draft.refundLines contains exactly the lines with refundQty > 0.

```dart
Widget _buildRefundLineRow(EdenSaleLine line) {

  return Padding(
    padding: const EdgeInsets.symmetric(vertical: 6),
    child: Row(
      children: [
        Expanded(flex: 3, child: Text('${line.sku} — ${line.name}')),
        Text('${line.refundableQty} avail', style: Theme.of(context).textTheme.bodySmall),
        const SizedBox(width: 8),
        SizedBox(
          width: 70,
          child: EdenInput(
            decoration: const InputDecoration(hintText: 'Qty'),
            keyboardType: const TextInputType.numberWithOptions(decimal: false),
            onChanged: (v) {
              final qty = int.tryParse(v) ?? 0;
              if (qty < 0 || qty > line.refundableQty) return;
              setState(() {
                if (qty == 0) {
                  _refundLines.remove(line.lineId);
                } else {
                  final reason = _refundLines[line.lineId]?.reason ?? EdenRefundReason.other;
                  _refundLines[line.lineId] = EdenRefundLine(lineId: line.lineId, refundQty: qty, reason: reason);
                }
              });
            },
          ),
        ),
        const SizedBox(width: 8),
        SizedBox(
          width: 140,
          child: current == null
            ? const SizedBox.shrink()
            : EdenSelect<EdenRefundReason>(
                value: current.reason,
                options: EdenRefundReason.values,
                labelBuilder: (r) => _reasonLabel(r),
                onChanged: (r) => setState(() {
                  if (r != null) _refundLines[line.lineId] = current.copyWith(reason: r);
                }),
              ),
        ),
      ],
    ),
  );
}
```

```dart
void _submit() {
  if (!_canSubmit()) return;
  widget.onSubmit(EdenRefundDraft(
    saleId: _sale!.saleId,
    refundLines: _refundLines.values.toList(),
    method: _method!,
    managerApproved: _managerApproved,
    totalRefundCents: _computeTotalCents(),
  ));
}

bool _canSubmit() => _sale != null && _refundLines.isNotEmpty && _method != null && (!_requiresManagerApproval() || _managerApproved);

String _approvalReasonText() {
  final reasons = <String>[];
  if (_computeTotalCents() >= widget.managerApprovalThresholdCents) reasons.add('refund ≥ ${_formatMoney(widget.managerApprovalThresholdCents)}');
  if (_method != EdenRefundMethod.originalTender) reasons.add('refund method is not original tender');
  return 'Manager approval required: ${reasons.join(' AND ')}.';
}

EdenRefundMethod _paymentToRefundMethod(EdenPaymentMethod p) {
  switch (p) {
    case EdenPaymentMethod.cash: return EdenRefundMethod.cash;
    default: return EdenRefundMethod.originalTender;     // card / check / other map to originalTender bucket
  }
}
```
