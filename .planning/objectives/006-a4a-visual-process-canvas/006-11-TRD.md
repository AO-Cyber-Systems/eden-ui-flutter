**Menu positioning:** mirror donor's `position: fixed; left: x; top: y; z-index: 50;`. In Flutter, use a `Stack` with `Positioned(left: x, top: y, child: Material(...))` overlaid via `OverlayEntry`. The canvas composer (TRD 14) is the consumer — it inserts the menu into a parent `Overlay` on right-click event, and removes the OverlayEntry when dismissed.

**Library convention:** the widget itself is just a `Material` card with menu items. Positioning + Overlay management is the COMPOSER'S responsibility. Tests pump the widget inside a normal `MaterialApp(home: Scaffold(body: SizedBox(child: EdenNodeContextMenu(...))))` without an Overlay.

**Click-outside dismiss:** the menu widget renders a transparent full-screen `GestureDetector` underneath itself that calls `onClose` on tap. This is the universal pattern (donor uses the same trick at `NodeContextMenu.tsx:108`).

**Submenu pattern:** when an action has `submenuItems != null`, hovering or tapping shows a nested menu to the right. Use Flutter's `MenuAnchor` + `MenuItemButton` for cleanest support; fallback to a stateful expansion (tap toggles inline expansion below the parent item). For v1: tap toggles inline expansion (mirror donor click-to-expand behavior at NodeContextMenu.tsx:65-89).
</context>

<gotchas>
- **Click-outside dismiss via GestureDetector OverlayEntry:** the widget has TWO sibling Positioned widgets in its Stack — (1) a full-screen `GestureDetector(behavior: HitTestBehavior.opaque, onTap: onClose)` and (2) the menu Material card on top. Tap on the GestureDetector → onClose. Tap inside the menu → consumed by the menu's children.
- **`destructive` action styling:** error color text + icon. Renders in `Theme.of(context).colorScheme.error`.
- **Keyboard Esc dismiss:** wrap the menu in `Focus(autofocus: true, onKeyEvent: ...)` and dismiss on `LogicalKeyboardKey.escape`.
- **Submenu inline-expansion (v1):** tapping a parent action with submenu items toggles inline expansion (renders nested items right below the parent). Donor at NodeContextMenu.tsx:74-89 shows nested items in an absolute-positioned sub-menu to the right; library v1 simplifies to inline.
- **Action `onTap` should call BOTH the user-provided callback AND `onClose`** so the menu closes after action. Implementation:
  ```dart
  GestureDetector(
    onTap: () {
      action.onTap();
      widget.onClose();
    },
    child: ...
  )
  ```
- **The canvas composer (TRD 14) builds the action list:**

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import '../../tokens/radii.dart';

class EdenNodeContextMenuAction {
  const EdenNodeContextMenuAction({
    required this.label,
    required this.icon,
    required this.onTap,
    this.destructive = false,
    this.submenuItems,
  });
  final String label;
  final IconData icon;
  final VoidCallback onTap;
  final bool destructive;
  final List<EdenNodeContextMenuAction>? submenuItems;
}

class EdenNodeContextMenu extends StatefulWidget {
  const EdenNodeContextMenu({
    super.key,
    required this.actions,
    required this.onClose,
  });
  final List<EdenNodeContextMenuAction> actions;
  final VoidCallback onClose;

  @override
  State<EdenNodeContextMenu> createState() => _State();
}

class _State extends State<EdenNodeContextMenu> {
  final Map<String, bool> _expandedSubmenus = {};

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    return Focus(
      autofocus: true,
      onKeyEvent: (node, event) {
        if (event is KeyDownEvent && event.logicalKey == LogicalKeyboardKey.escape) {
          widget.onClose();
          return KeyEventResult.handled;
        }
        return KeyEventResult.ignored;
      },
      child: Stack(children: [
        Positioned.fill(child: GestureDetector(behavior: HitTestBehavior.opaque, onTap: widget.onClose)),
        Material(
          elevation: 4,
          color: theme.colorScheme.surface,
          borderRadius: EdenRadii.borderRadiusMd,
          child: ConstrainedBox(
            constraints: const BoxConstraints(minWidth: 180, maxWidth: 240),
            child: Column(mainAxisSize: MainAxisSize.min, children: [
              for (final action in widget.actions) _buildItem(action, theme),
            ]),
          ),
        ),
      ]),
    );
  }

  Widget _buildItem(EdenNodeContextMenuAction action, ThemeData theme) {
    final hasSubmenu = action.submenuItems != null && action.submenuItems!.isNotEmpty;
    final isExpanded = _expandedSubmenus[action.label] ?? false;
    final color = action.destructive ? theme.colorScheme.error : theme.colorScheme.onSurface;
    return Column(crossAxisAlignment: CrossAxisAlignment.stretch, children: [
      InkWell(
        onTap: () {
          if (hasSubmenu) {
            setState(() => _expandedSubmenus[action.label] = !isExpanded);
          } else {
            action.onTap();
            widget.onClose();
          }
        },
        child: Padding(
          padding: const EdgeInsets.symmetric(horizontal: 8, vertical: 6),
          child: Row(children: [
            Icon(action.icon, size: 16, color: color),
            const SizedBox(width: 8),
            Expanded(child: Text(action.label, style: theme.textTheme.bodySmall?.copyWith(color: color))),
            if (hasSubmenu) Icon(isExpanded ? Icons.expand_more : Icons.chevron_right, size: 14, color: theme.colorScheme.onSurfaceVariant),
          ]),
        ),
      ),
      if (hasSubmenu && isExpanded)
        Padding(
          padding: const EdgeInsets.only(left: 16),
          child: Column(children: [
            for (final sub in action.submenuItems!) _buildItem(sub, theme),
          ]),
        ),
    ]);
  }
}
