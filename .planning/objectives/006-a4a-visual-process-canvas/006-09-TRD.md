**Free-form layout algorithm (replacing Dagre):**

The donor's Dagre LR layout assigns each node to a rank (column) based on its longest path from any root node, then positions nodes within a rank vertically to minimize edge crossings. We approximate this with:

1. **Identify roots**: nodes with no incoming edges (or specifically `start` if present, else any unreferenced node).
2. **BFS from each root**: walk outgoing edges; assign `rank[node] = max(rank[parent]) + 1`. Multiple paths → use the LONGEST path (matches Dagre rank-assignment semantics).
3. **Position nodes per rank**: nodes in the same rank stack vertically, sorted by their order of first-visit in BFS.
4. **Disconnected nodes**: handle separately — place at rank = maxRank + 1 in a "leftover" column.

This won't match Dagre's edge-crossing minimization but will produce a reasonable LR flow.

**Cycle handling:** if `phase-1 → phase-2 → phase-1` (cycle), the BFS visit order assigns `phase-1=0, phase-2=1` and on the second visit `phase-1` is already assigned so we keep its first assignment. No infinite loop.

**Constants (free-form):**
- `colSpacing = 280` (donor `nodeWidth = 250 + ranksep = 80 / 2` ≈ 290; round to 280)
- `rowSpacing = 140` (donor `nodeHeight = 100 + nodesep = 40` = 140)
- Origin offset: `(100, 100)`

**Grid + linear constants:** match donor defaults.

**Pure function discipline:** same as TRD 08 — input not mutated; returned list contains new node instances (via `copyWith`).

**Layout engine IDs:** `'free_form'`, `'grid'`, `'linear'` (already set in TRD 03 stubs; preserved).
</context>

<gotchas>
- **BFS ranking with longest-path semantics:** when a node is visited twice via different paths, the LATER visit may want to assign a HIGHER rank. Implementation:
  ```dart
  rank[node] = math.max(rank[node] ?? 0, currentRank);
  ```
  Then re-BFS from updated nodes to propagate the longer rank downstream. Simplest: repeat the BFS loop until no rank changes. Worst-case O(N*E); acceptable for v1 (process canvases are small — typically <50 nodes).
- **Root detection:** nodes with `nodeType == 'start'` are forced to rank 0. If no start node, identify roots as nodes with no incoming edges.
- **Disconnected components:** after BFS from all detected roots, any node still without a rank is disconnected. Assign these to rank = maxRank + 1 in input order.
- **Column rank to x-position:** `x = rank * colSpacing + 100`.
- **Within-rank position to y:** sort nodes in each rank by their BFS visit order; `y = (positionInRank) * rowSpacing + 100`.
- **No layout for empty input:** return `[]`.
- **Test cycle:** `[a, b, c]` + `[a→b, b→c, c→a]`. After BFS from `a`: rank a=0, b=1, c=2. Second iteration: a's rank would update to 3 (from c at 2 +1). Continue iterating until stable. Likely converges in 1-2 iterations for v1 graphs. Or simpler: detect cycle, break by ignoring back-edges. Use the iterate-until-stable approach (simpler, correct).
- **`EdenGridLayout` and `EdenLinearLayout` are stateless** — constructor params (`columns`, `spacing`, etc.) hold their config. The `applyLayout` method just maps each node's index to its position.
- **All three layouts: `copyWith` for position update.** Same pattern as TRD 08.
</gotchas>

```dart
class EdenFreeFormLayout extends EdenProcessLayoutEngine {
  const EdenFreeFormLayout({this.colSpacing = 280, this.rowSpacing = 140, this.originX = 100, this.originY = 100});
  final double colSpacing;
  final double rowSpacing;
  final double originX;
  final double originY;
  @override String get id => 'free_form';

  @override
  List<EdenDiagramNode> applyLayout(List<EdenDiagramNode> nodes, List<EdenDiagramEdge> edges) {
    if (nodes.isEmpty) return const [];

    // Build adjacency (source → targets)
    final adjacency = <String, List<String>>{};
    final allNodeIds = <String>{for (final n in nodes) n.id};
    for (final e in edges) {
      adjacency.putIfAbsent(e.sourceId, () => []).add(e.targetId);
    }

    // Roots: 'start' if present, else nodes with no incoming edges
    final incoming = <String>{};
    for (final e in edges) {
      incoming.add(e.targetId);
    }
    final roots = <String>[];
    final startNode = nodes.firstWhere((n) => n.data['nodeType'] == 'start', orElse: () => nodes.first);
    if (startNode.data['nodeType'] == 'start') {
      roots.add(startNode.id);
    } else {
      for (final n in nodes) {
        if (!incoming.contains(n.id)) roots.add(n.id);
      }
    }
    if (roots.isEmpty) roots.add(nodes.first.id);

    // BFS with longest-path-rank assignment, iterate until stable
    final ranks = <String, int>{};
    for (final r in roots) {
      ranks[r] = 0;
    }
    bool changed = true;
    int iterations = 0;
    const maxIterations = 100;
    while (changed && iterations < maxIterations) {
      changed = false;
      iterations++;
      for (final source in ranks.keys.toList()) {
        final sourceRank = ranks[source]!;
        for (final target in (adjacency[source] ?? const <String>[])) {
          final newRank = sourceRank + 1;
          if (newRank > (ranks[target] ?? -1)) {
            ranks[target] = newRank;
            changed = true;
          }
        }
      }
    }

    // Disconnected nodes → rank = maxRank + 1
    final maxRank = ranks.values.isEmpty ? 0 : ranks.values.reduce(math.max);
    final disconnectedRank = maxRank + 1;
    for (final n in nodes) {
      ranks.putIfAbsent(n.id, () => disconnectedRank);
    }

    // Group nodes by rank, preserving input order within rank
    final byRank = <int, List<String>>{};
    for (final n in nodes) {
      final r = ranks[n.id]!;
      byRank.putIfAbsent(r, () => []).add(n.id);
    }

    // Compute positions
    final positions = <String, Offset>{};
    for (final entry in byRank.entries) {
      final rank = entry.key;
      final ids = entry.value;
      for (int i = 0; i < ids.length; i++) {
        positions[ids[i]] = Offset(originX + rank * colSpacing, originY + i * rowSpacing);
      }
    }

    return nodes.map((n) {
      final pos = positions[n.id];
      return pos == null ? n : n.copyWith(x: pos.dx, y: pos.dy);
    }).toList();
  }
}

class EdenGridLayout extends EdenProcessLayoutEngine {
  const EdenGridLayout({this.columns = 3, this.spacing = 300, this.startX = 100, this.startY = 100, this.rowHeight = 200});
  final int columns;
  final double spacing;
  final double startX;
  final double startY;
  final double rowHeight;
  @override String get id => 'grid';

  @override
  List<EdenDiagramNode> applyLayout(List<EdenDiagramNode> nodes, List<EdenDiagramEdge> edges) {
    return [
      for (int i = 0; i < nodes.length; i++)
        nodes[i].copyWith(
          x: (i % columns) * spacing + startX,
          y: (i ~/ columns) * rowHeight + startY,
        ),
    ];
  }
}

class EdenLinearLayout extends EdenProcessLayoutEngine {
  const EdenLinearLayout({this.spacing = 300, this.startX = 100, this.startY = 200});
  final double spacing;
  final double startX;
  final double startY;
  @override String get id => 'linear';

  @override
  List<EdenDiagramNode> applyLayout(List<EdenDiagramNode> nodes, List<EdenDiagramEdge> edges) {
    return [
      for (int i = 0; i < nodes.length; i++)
        nodes[i].copyWith(x: startX + i * spacing, y: startY),
    ];
  }
}
```
