<objective>
Wave 1, third leg. Build the bidirectional sync layer between an `EdenProcessDefinition` (domain) and the canvas's `(nodes, edges)` representation. Two pieces:

1. **`EdenProcessGraphBuilder`** — pure function `EdenProcessDefinition → (nodes, edges)`. Mirrors donor `useProcessToFlow.ts` (294 LOC) but as a stateless static function (no React state hook). Generates `start` / `end` / `phase-N` / `group-N` / `decision-N` nodes; generates the vertical-spine edges (start→phase1, phase1→phase2, lastPhase→end) and the auto-fan edges (phase→groups dashed). Layout positions are NOT computed here — that's the layout-engine's job (TRDs 08/09).

2. **`EdenProcessController`** — extends `ChangeNotifier`. Owns the per-instance canvas state that doesn't belong on the definition: which phases are expanded, which node is selected, orphan nodes that haven't been linked to the definition yet, user-drawn edges that persist across re-renders, manual node positions (after drag), pending positions (for newly created elements). Exposes `toLayoutData()` for save and `fromLayoutData()` for restore. This is the state object `EdenVisualProcessCanvas` (TRD 14) holds.

3. **`EdenProcessLayoutEngine` abstract class** — sealed-ish base class with `applyLayout(nodes, edges) → nodes`. TRDs 08 (`EdenSwimlaneLayout`) and 09 (`EdenFreeFormLayout`, `EdenGridLayout`, `EdenLinearLayout`) ship the concrete subclasses.

After this TRD ships, Wave 2 + Wave 3 can run in full parallel: node widgets (Wave 2) consume `EdenProcessController` for their `onUpdate` / `onDelete` wiring, layout engines (Wave 3) implement the `EdenProcessLayoutEngine` interface.
</objective>

<gotchas>
- **`EdenProcessGraphBuilder.build` is a pure static function**, NOT a method on a controller. Donor `useProcessToFlow` is a hook because React needs hooks for memoization; Dart doesn't. Static function signature:
  ```dart
  class EdenProcessGraphBuilder {
    static (List<EdenDiagramNode>, List<EdenDiagramEdge>) build(
      EdenProcessDefinition definition, {
      EdenProcessController? controller,  // for manualPositions + pendingPositions lookup
      bool showAllGroups = true,           // donor showAllNodes default
    }) { ... }
  }
  ```
  The `controller` param is optional. When provided, builder reads `controller.manualPositions` and `controller.pendingPositions` to override the default `(0, 0)` position; when null, all positions are `(0, 0)` and the layout-engine fills them in.
- **Edge id stability.** Donor uses `edge-start-${phaseNodeId}`, `edge-${prevNodeId}-${phaseNodeId}`, `edge-${phaseNodeId}-${groupNodeId}`, `edge-${lastNodeId}-end`, `edge-start-end`. Library MUST match exactly for saved-layout round-trip.
- **`showAllGroups` controls whether ALL groups are emitted vs only those whose parent phase is expanded.** Donor default true; library default true. When false, the builder respects `controller.expandedPhaseIds`.
- **Auto-fan edges have dashed styling.** Donor: `style: { strokeWidth: 1.5, strokeDasharray: '4 2' }`. Library: `EdenDiagramEdge(... style: EdenEdgeStyle.dashed, color: <gray-hex>)`. Mark the edge with `data: {'edgeStyle': 'autoFan'}` so the canvas can reverse-style it.
- **Vertical spine edges have solid styling.** Donor: smoothstep default 2pt. Library: `EdenDiagramEdge(... style: EdenEdgeStyle.solid)`. Mark `data: {'edgeStyle': 'spine'}`.
- **User-drawn edges marked with `data: {'edgeStyle': 'user'}` for round-trip.** When saving via `toLayoutData`, only edges with `data['edgeStyle'] == 'user'` are serialized into `EdenProcessSavedEdge` list (auto-generated edges are regenerated from definition on load).
- **Controller dispose.** `EdenProcessController` extends ChangeNotifier; if owned by a State, MUST be disposed in `dispose()`. Document in dartdoc. Tests use `addTearDown(() => controller.dispose())`.
- **`recordManualPosition` is only called for nodes that have been DRAGGED.** Initial layout positions go through the layout engine; manual positions OVERRIDE them after user drag. The rebuild-from-definition flow:
  1. `(nodes, edges) = EdenProcessGraphBuilder.build(def, controller: ctrl)` (positions = controller.manualPositions[id] ?? Offset(0,0))
  2. If a node still has Offset(0,0) AND controller.preserveManualPositions, apply `layout.applyLayout(nodes, edges)` to fill in positions
  3. If a node has controller.manualPositions[id] set, that overrides
- **`pendingPositions` is for orphan nodes that may become real (drag-to-link).** When a consumer creates an orphan node via drag-from-toolbox at a specific Offset, they set `controller.setPendingPosition(orphanId, offset)`. After the orphan is "linked" (the consumer calls `onAddPhase()` or similar), the new phase's real id (`phase-N`) inherits the pending position via `controller.setPendingPosition('phase-N', pendingPosition); controller.clearPendingPosition(orphanId)`. Donor handles this at `VisualProcessCanvas.tsx:167` with `pendingPositions` state map.
- **`toLayoutData()` viewport optional param.** The canvas's pan/zoom state lives on `EdenDiagramState` (TRD 02). The controller doesn't track viewport. `toLayoutData(viewport: EdenProcessViewport(x: panOffset.dx, y: panOffset.dy, zoom: scale))` is called from `EdenVisualProcessCanvas` (TRD 14) which has access to both controller and canvas state.
- **Avoid emitting orphan edges to userEdges automatically.** If the user drags between two orphans and creates an edge, it goes to userEdges. If they later delete both orphans, the edge becomes dangling — the controller MUST clean up edges referencing deleted node ids in `removeOrphan`.
- **`EdenProcessLayoutEngine` stub today.** Ship `EdenSwimlaneLayout` and `EdenFreeFormLayout` as bodies-returning-input-unchanged today (no-op). TRDs 08/09 replace the bodies. The interface + ids are locked here.
- **Edge style → `EdenEdgeStyle` mapping:**
  - `EdenProcessAutoEdgeStyle.user` → `EdenEdgeStyle.solid` (eden_diagram has only solid/dashed/dotted; donor's "smoothstep curve" is the default cubic; library's `EdenEdgeStyle.solid` already draws cubic — confirmed in `diagram_painter.dart:289-325`)
  - `EdenProcessAutoEdgeStyle.autoFan` → `EdenEdgeStyle.dashed`
  - `EdenProcessAutoEdgeStyle.spine` → `EdenEdgeStyle.solid`
- **`EdenProcessEdgeStyles` helper exposes one static method:** `static EdenDiagramEdge styledEdge({required String id, required String sourceId, required String targetId, required EdenProcessAutoEdgeStyle style, EdenPortSide? sourcePort, EdenPortSide? targetPort, String? sourcePortId, String? targetPortId, String? label})` — returns a configured `EdenDiagramEdge`.
</gotchas>

**EdenProcessGraphBuilder.build — basic shape**
- Given a `processDefinitionFixture()` with 0 phases + `flowNodes: {start: true, end: true}`, builds `[startNode, endNode]` + 1 edge (start→end).

- Definition with `flowNodes: {'end': false}` → no `end` node and no lastPhase→end edge.

class EdenProcessGraphBuilder {
  EdenProcessGraphBuilder._();  // static-only class

  static (List<EdenDiagramNode>, List<EdenDiagramEdge>) build(
    EdenProcessDefinition definition, {
    EdenProcessController? controller,
    bool showAllGroups = true,
  }) {
    final nodes = <EdenDiagramNode>[];
    final edges = <EdenDiagramEdge>[];

    Offset positionFor(String nodeId) {
      // Manual takes precedence over pending; pending takes precedence over (0,0).
      final manual = controller?.manualPositionFor(nodeId);
      if (manual != null) return manual;
      final pending = controller?.pendingPositions[nodeId];
      if (pending != null) return pending;
      return Offset.zero;
    }

    final hasStart = definition.config.flowNodes?['start'] != false;
    final hasEnd = definition.config.flowNodes?['end'] != false;

    // Start node
    if (hasStart) {
      final pos = positionFor('start');
      nodes.add(EdenDiagramNode(id: 'start', x: pos.dx, y: pos.dy, width: 48, height: 48, label: 'Start', data: {'nodeType': 'start'}));
    }

    // Phases (sorted)
    final sortedPhases = [...definition.phases]..sort((a, b) => a.sortOrder.compareTo(b.sortOrder));
    for (int i = 0; i < sortedPhases.length; i++) {
      final phase = sortedPhases[i];
      final phaseNodeId = 'phase-${phase.id}';
      final pos = positionFor(phaseNodeId);
      nodes.add(EdenDiagramNode(

          sourceId: prev, targetId: phaseNodeId,
          sourcePort: EdenPortSide.bottom, targetPort: EdenPortSide.top,
          style: EdenProcessAutoEdgeStyle.spine,
        ));
      }

      // Group nodes (if showAllGroups or expanded)
      final shouldEmitGroups = showAllGroups || (controller?.expandedPhaseIds.contains(phase.id) ?? false);
      if (shouldEmitGroups) {
        final sortedGroups = [...phase.groups]..sort((a, b) => a.sortOrder.compareTo(b.sortOrder));
        for (final group in sortedGroups) {
          final groupNodeId = 'group-${group.id}';

            id: 'edge-$phaseNodeId-$groupNodeId',
            sourceId: phaseNodeId, targetId: groupNodeId,
            sourcePort: EdenPortSide.right, targetPort: EdenPortSide.left,
            style: EdenProcessAutoEdgeStyle.autoFan,
          ));
        }
      }
    }

    // Decisions
    for (final decision in definition.config.decisions) {
      final id = 'decision-${decision.id}';
      final pos = positionFor(id);
      nodes.add(EdenDiagramNode(
        id: id, x: pos.dx, y: pos.dy, width: 140, height: 140,
        label: decision.name,
        data: {'nodeType': 'decision', 'decisionId': decision.id, 'condition': decision.condition},
      ));
      // Decisions are NOT auto-connected — consumer wires via userEdges (donor matches).
    }

    // End node
    if (hasEnd) {
      final pos = positionFor('end');
      nodes.add(EdenDiagramNode(id: 'end', x: pos.dx, y: pos.dy, width: 48, height: 48, label: 'End', data: {'nodeType': 'end'}));

      // Connect last phase → end (or start → end if no phases)
      if (sortedPhases.isNotEmpty) {
        final last = 'phase-${sortedPhases.last.id}';
        edges.add(EdenProcessEdgeStyles.styledEdge(
          id: 'edge-$last-end',
          sourceId: last, targetId: 'end',
          sourcePort: EdenPortSide.bottom, targetPort: EdenPortSide.top,
          style: EdenProcessAutoEdgeStyle.spine,
        ));
      } else if (hasStart) {
        edges.add(EdenProcessEdgeStyles.styledEdge(
          id: 'edge-start-end',
          sourceId: 'start', targetId: 'end',
          sourcePort: EdenPortSide.bottom, targetPort: EdenPortSide.top,
          style: EdenProcessAutoEdgeStyle.spine,
        ));
      }
    }

    return (nodes, edges);
  }
}

class EdenProcessController extends ChangeNotifier {
  EdenProcessController({
    EdenProcessLayoutEngine? layout,
    this.preserveManualPositions = true,
  }) : _layout = layout ?? const EdenSwimlaneLayout();

  // Layout
  EdenProcessLayoutEngine _layout;
  EdenProcessLayoutEngine get layout => _layout;
  set layout(EdenProcessLayoutEngine engine) {
    if (engine.id == _layout.id) return;
    _layout = engine;
    notifyListeners();
  }
  final bool preserveManualPositions;

  // Selection
  String? _selectedNodeId;
  String? get selectedNodeId => _selectedNodeId;
  void select(String? id) {
    if (id == _selectedNodeId) return;
    _selectedNodeId = id;
    notifyListeners();
  }

  // Phase expansion
  final Set<int> _expandedPhaseIds = {};
  Set<int> get expandedPhaseIds => Set.unmodifiable(_expandedPhaseIds);
  void togglePhaseExpanded(int phaseId) {
    if (_expandedPhaseIds.contains(phaseId)) {
      _expandedPhaseIds.remove(phaseId);
    } else {
      _expandedPhaseIds.add(phaseId);
    }
    notifyListeners();
  }

  // Orphans
  int _orphanCounter = 0;
  final List<EdenDiagramNode> _orphans = [];
  List<EdenDiagramNode> get orphans => List.unmodifiable(_orphans);
  String generateOrphanId() => 'orphan-${++_orphanCounter}';
  void addOrphan(EdenDiagramNode node) {
    _orphans.add(node);
    notifyListeners();
  }
  void removeOrphan(String nodeId) {
    final initialCount = _orphans.length;
    _orphans.removeWhere((n) => n.id == nodeId);
    // Cascade: remove user edges referencing this orphan
    _userEdges.removeWhere((e) => e.sourceId == nodeId || e.targetId == nodeId);
    if (_orphans.length != initialCount) notifyListeners();
  }

  // User edges
  final List<EdenDiagramEdge> _userEdges = [];
  List<EdenDiagramEdge> get userEdges => List.unmodifiable(_userEdges);
  void addUserEdge(EdenDiagramEdge edge) {
    // Inject 'edgeStyle': 'user' marker if missing
    if (edge.data['edgeStyle'] == null) {
      edge.data['edgeStyle'] = 'user';
    }
    _userEdges.add(edge);
    notifyListeners();
  }
  void removeUserEdge(String edgeId) {
    final initialCount = _userEdges.length;
    _userEdges.removeWhere((e) => e.id == edgeId);
    if (_userEdges.length != initialCount) notifyListeners();
  }

  // Manual positions
  final Map<String, Offset> _manualPositions = {};
  Offset? manualPositionFor(String nodeId) => _manualPositions[nodeId];
  void recordManualPosition(String nodeId, Offset pos) {
    _manualPositions[nodeId] = pos;
    notifyListeners();
  }

  // Pending positions
  final Map<String, Offset> _pendingPositions = {};
  Map<String, Offset> get pendingPositions => Map.unmodifiable(_pendingPositions);
  void setPendingPosition(String nodeId, Offset pos) {
    _pendingPositions[nodeId] = pos;
    notifyListeners();
  }
  void clearPendingPosition(String nodeId) {
    if (_pendingPositions.remove(nodeId) != null) notifyListeners();
  }

  // Layout data round-trip
  EdenProcessLayoutData toLayoutData({EdenProcessViewport? viewport}) {
    final positions = <String, EdenProcessNodePosition>{
      for (final entry in _manualPositions.entries)
        entry.key: EdenProcessNodePosition(x: entry.value.dx, y: entry.value.dy),
    };
    final savedEdges = _userEdges
        .map((e) => EdenProcessSavedEdge(
              id: e.id,
              source: e.sourceId,
              target: e.targetId,
              sourceHandle: e.sourcePortId,
              targetHandle: e.targetPortId,
            ))
        .toList();
    return EdenProcessLayoutData(
      version: 1,
      autoLayout: false,
      nodes: positions,
      edges: savedEdges,
      viewport: viewport,
    );
  }

  void fromLayoutData(EdenProcessLayoutData data) {
    _manualPositions.clear();
    for (final entry in data.nodes.entries) {
      _manualPositions[entry.key] = Offset(entry.value.x, entry.value.y);
    }
    _userEdges.clear();
    for (final savedEdge in data.edges) {
      _userEdges.add(EdenDiagramEdge(
        id: savedEdge.id,
        sourceId: savedEdge.source,
        targetId: savedEdge.target,
        sourcePortId: savedEdge.sourceHandle,
        targetPortId: savedEdge.targetHandle,
        style: EdenEdgeStyle.solid,
        data: {'edgeStyle': 'user'},
      ));
    }
    notifyListeners();
  }

  // Reset
  void reset() {
    _selectedNodeId = null;
    _expandedPhaseIds.clear();
    _orphans.clear();
    _userEdges.clear();
    _manualPositions.clear();
    _pendingPositions.clear();
    _orphanCounter = 0;
    notifyListeners();
  }
}
