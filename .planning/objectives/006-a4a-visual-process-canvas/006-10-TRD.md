<objective>
Wave 4, first leg. Ship the three editor dialogs that the canvas opens via context-menu "Edit" or hover-pencil buttons: `EdenProcessPhaseEditorDialog` (195 LOC donor), `EdenProcessTaskGroupEditorDialog` (334 LOC donor), `EdenProcessTaskEditorDialog` (583 LOC donor). The last is the biggest of the three because the task has the most editable fields (15+ flags, runtime-component picker, workflow hooks).

All three dialogs follow the same shape: a `Dialog` widget with form fields wired to `onUpdate` callbacks. Debounced text saves on blur; non-text fields (checkboxes, dropdowns) save immediately. Parent owns the mutation — the dialog never mutates the value type directly.
</objective>

**Dialog opening convention:**

**Debounced text save pattern:**
```dart
class _PhaseEditorState extends State<EdenProcessPhaseEditorDialog> {
  late TextEditingController _nameCtrl;
  late TextEditingController _descCtrl;

  @override
  void initState() {
    super.initState();
    _nameCtrl = TextEditingController(text: widget.phase.displayName);
    _descCtrl = TextEditingController(text: widget.phase.description ?? '');
  }

  void _saveName() {
    final trimmed = _nameCtrl.text.trim();
    if (trimmed.isNotEmpty && trimmed != widget.phase.displayName) {
      widget.onUpdate({'displayName': trimmed});
    }
  }

  void _saveDescription() {
    final trimmed = _descCtrl.text.trim();
    final orig = widget.phase.description ?? '';
    if (trimmed != orig) {
      widget.onUpdate({'description': trimmed.isEmpty ? null : trimmed});
    }
  }

  // checkbox handlers fire onUpdate immediately
}
```

<gotchas>
- **Dialog dispose:** `TextEditingController` and `FocusNode` MUST be disposed in `dispose()`. Use `addTearDown(controller.dispose)` in tests for unit safety; in widget tests, the dialog widget's own dispose lifecycle handles it.
- **Text save on dialog close:** the donor (`PhaseEditorDialog.tsx:55-69`) saves on blur. Library matches via `TextField.onSubmitted` + `Focus.onFocusChange`. Additionally, when the dialog is dismissed (Cancel or backdrop tap), any pending un-saved text in the controller IS saved (matches donor's debounced behavior — close-without-save is a deliberate choice but parity favors save-on-close).

  Actually donor at `PhaseEditorDialog.tsx:56` saves only on blur, NOT on dialog close. Library matches — `onSubmitted` (Enter) and `Focus.onFocusChange` (blur) trigger save. Closing the dialog without blurring the field discards changes. Document in dartdoc: "Text fields save on blur (focus change). To force-save, tap outside the field BEFORE closing."
- **Approval-role and approval-user are FREE-FORM strings.** Donor allows roles like 'supervisor', 'admin' as plain strings. Library uses `TextFormField`, NOT a dropdown.
- **Blocking-behavior dropdown:** donor's `BlockingBehaviorPicker` exposes a fixed set of options (`'soft'`, `'hard'`, `'none'`). Library exposes a `DropdownButton<String>` with these 3 hard-coded options. Document as "library-default options; for custom values, use `EdenProcessTaskEditorDialog(blockingBehaviorOptions: ['custom', ...])` to override". V1: hard-code the 3 options.
- **Workflow-hook id input** is a `TextFormField` (numeric input, optional) that maps to `int?`. Empty string → null; non-empty → `int.tryParse(text)` (silently null on parse failure). Donor doesn't validate at the dialog level; library matches.
- **`materializesAsTask` defaults true** per TRD 01 value type. Checkbox initial state derives from `task.materializesAsTask`.
- **Test count expectation:** ~15-20 tests per dialog (3 dialogs × 5-7 tests = ~20).
- **Dialog tests use `tester.pumpWidget(MaterialApp(home: Builder(builder: (ctx) => ElevatedButton(onPressed: () => showDialog(context: ctx, builder: (_) => EdenProcessPhaseEditorDialog(...))))))` then `tester.tap(find.byType(ElevatedButton))` to open.** Standard Flutter dialog-test pattern.
</gotchas>

import 'package:flutter/material.dart';
import '../../../tokens/spacing.dart';

class EdenProcessPhaseEditorDialog extends StatefulWidget {
  const EdenProcessPhaseEditorDialog({super.key, required this.phase, required this.onUpdate});
  final EdenProcessPhase phase;
  final void Function(Map<String, dynamic> updates) onUpdate;

  @override
  State<EdenProcessPhaseEditorDialog> createState() => _State();
}

class _State extends State<EdenProcessPhaseEditorDialog> {
  late TextEditingController _nameCtrl;
  late TextEditingController _descCtrl;
  late FocusNode _nameFocus;
  late FocusNode _descFocus;

  static const _colors = [
    ('blue', Color(0xFF3B82F6)),
    ('green', Color(0xFF10B981)),
    ('amber', Color(0xFFF59E0B)),
    ('red', Color(0xFFEF4444)),
    ('purple', Color(0xFF8B5CF6)),
    ('pink', Color(0xFFEC4899)),
    ('cyan', Color(0xFF06B6D4)),
    ('gray', Color(0xFF6B7280)),
  ];

  @override
  void initState() {
    super.initState();
    _nameCtrl = TextEditingController(text: widget.phase.displayName);
    _descCtrl = TextEditingController(text: widget.phase.description ?? '');
    _nameFocus = FocusNode()..addListener(() { if (!_nameFocus.hasFocus) _saveName(); });
    _descFocus = FocusNode()..addListener(() { if (!_descFocus.hasFocus) _saveDescription(); });
  }

  @override
  void dispose() {
    _nameCtrl.dispose(); _descCtrl.dispose();
    _nameFocus.dispose(); _descFocus.dispose();
    super.dispose();
  }

  void _saveName() {
    final trimmed = _nameCtrl.text.trim();
    if (trimmed.isNotEmpty && trimmed != widget.phase.displayName) {
      widget.onUpdate({'displayName': trimmed});
    }
  }

  void _saveDescription() {
    final trimmed = _descCtrl.text.trim();
    final orig = widget.phase.description ?? '';
    if (trimmed != orig) {
      widget.onUpdate({'description': trimmed.isEmpty ? null : trimmed});
    }
  }

  @override
  Widget build(BuildContext context) {
    return AlertDialog(
      title: const Text('Edit Phase'),
      content: SingleChildScrollView(
        child: Column(mainAxisSize: MainAxisSize.min, crossAxisAlignment: CrossAxisAlignment.stretch, children: [
          TextField(controller: _nameCtrl, focusNode: _nameFocus, decoration: const InputDecoration(labelText: 'Name'), onSubmitted: (_) => _saveName()),
          const SizedBox(height: 12),
          TextField(controller: _descCtrl, focusNode: _descFocus, maxLines: 2, decoration: const InputDecoration(labelText: 'Description'), onSubmitted: (_) => _saveDescription()),
          const SizedBox(height: 16),
          Text('Color', style: Theme.of(context).textTheme.bodyMedium),
          const SizedBox(height: 6),
          Wrap(spacing: 8, runSpacing: 8, children: [
            for (final color in _colors)
              GestureDetector(
                onTap: () { if (widget.phase.color != color.$1) widget.onUpdate({'color': color.$1}); },
                child: Container(
                  width: 28, height: 28,
                  decoration: BoxDecoration(
                    color: color.$2,
                    shape: BoxShape.circle,
                    border: widget.phase.color == color.$1 ? Border.all(color: Theme.of(context).colorScheme.primary, width: 2.5) : null,
                  ),
                ),
              ),
          ]),
          const SizedBox(height: 16),
          _Checkbox(label: 'Required', value: widget.phase.isRequired, onChanged: (v) => widget.onUpdate({'isRequired': v})),
          _Checkbox(label: 'Milestone', value: widget.phase.isMilestone, onChanged: (v) => widget.onUpdate({'isMilestone': v})),
          _Checkbox(label: 'Can skip', value: widget.phase.canSkip, onChanged: (v) => widget.onUpdate({'canSkip': v})),
          _Checkbox(label: 'Auto-advance', value: widget.phase.autoAdvance, onChanged: (v) => widget.onUpdate({'autoAdvance': v})),
          _Checkbox(label: 'Allows scope change', value: widget.phase.allowsScopeChange, onChanged: (v) => widget.onUpdate({'allowsScopeChange': v})),
          _Checkbox(label: 'Allows ad-hoc tasks', value: widget.phase.allowsAdHocTasks, onChanged: (v) => widget.onUpdate({'allowsAdHocTasks': v})),
        ]),
      ),
      actions: [
        TextButton(onPressed: () { _saveName(); _saveDescription(); Navigator.pop(context); }, child: const Text('Close')),
      ],
    );
  }
}

class _Checkbox extends StatelessWidget {
  const _Checkbox({required this.label, required this.value, required this.onChanged});
  final String label;
  final bool value;
  final void Function(bool) onChanged;
  @override
  Widget build(BuildContext context) => Row(children: [
    Checkbox(value: value, onChanged: (v) => onChanged(v ?? false)),
    Text(label),
  ]);
}
