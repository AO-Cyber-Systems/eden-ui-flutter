**Variance computation:**

```dart
double computeVariancePct(double scheduled, double actual) {
  if (scheduled == 0) return 0; // avoid div by zero
  return (actual - scheduled) / scheduled;
}

EdenVarianceSeverity classifyVariance(double variancePct, double thresholdPct) {
  final magnitude = variancePct.abs();
  if (magnitude <= thresholdPct) return EdenVarianceSeverity.withinThreshold;
  if (magnitude <= thresholdPct * 2) return EdenVarianceSeverity.borderline;
  return EdenVarianceSeverity.exceedsThreshold;
}
```

<anti_patterns>
- **Do NOT auto-submit on threshold breach.** User reviews + confirms via Submit button; never auto-fire onSubmit.
- **Do NOT compute variance against integer values when source is float.** Always store scheduled/actual as `double`. Mixed-type math can drop precision.
- **Do NOT hardcode the unit label.** Use `EdenVarianceMetric.gallons` → 'gal'; `.hours` → 'hr'; `.minutes` → 'min'; `.fee` → '$'; `.custom` → `data.unitLabel ?? '?'`.
- **Do NOT bundle photo capture inside the library.** Callback pattern — consumer wires `image_picker` / `camera_awesome` etc.
- **Do NOT hide the variance summary in read-only mode.** Read-only hides editing affordances only; the data display stays visible.
</anti_patterns>

<gotchas>
- **Zero scheduled value (divide-by-zero).** `data.scheduled == 0` → variancePct returns 0 (no variance, no breach). Add a fixture + test.
- **Negative scheduled (shouldn't happen but defensive).** Treat as absolute value for the variance band; document.
- **EdenVarianceMetric.fee → use EdenCurrencyDisplay.** For other metrics, use plain formatted Text. Branch on metric.
- **Photo gallery state lives in the card.** `_photoUrls` accumulates; only emitted on submit via draft.
- **Disposition default.** When `initialDraft != null`, default disposition = `initialDraft.disposition`. When null, default = `unreviewed`.
- **Submit gating ambiguity.** If variance is within threshold AND user selects a reason, submit IS still enabled (reasons are optional within threshold). The constraint is: exceeds threshold → reason required.
- **lib/eden_ui.dart Wave 1 section.** Shares with 019-01 + 019-03 + 019-06.
- **fuel_screen.dart append coordination.** Shares with 019-03 + 019-04 + 019-05 + 019-06.
- **Hand-built fixtures only.** Locked header.
</gotchas>

<error_recovery>
- **If `EdenSelect<T?>` doesn't accept nullable T:** use a sentinel value (`EdenDeliveryVarianceReason.unselected`) or split into a non-null Select + a 'Clear' button.
- **If threshold band visualization is too complex to test directly:** assert on the color of a dedicated child widget (e.g. `find.byKey(Key('variance-band-color'))` returns Color with expected severity tint).
- **If iPhone-narrow side-by-side Stat cards overflow:** wrap in `Wrap` instead of `Row`; cards become full-width at <500pt.
- **If submit-gating logic causes test flakiness on borderline values:** test exact threshold boundaries (e.g. variance = thresholdPct exactly = within; variance = 2*thresholdPct exactly = borderline; +0.001 → exceeds).
</error_recovery>
