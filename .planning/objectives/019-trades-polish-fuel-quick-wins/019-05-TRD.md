**Clustering algorithm sketch:**

```dart
List<_PinOrCluster> _clusterMarkers(List<EdenFleetMapMarker> markers, EdenFleetMapViewport viewport, EdenFleetMapClusterPolicy policy) {
  if (policy == EdenFleetMapClusterPolicy.never) {
    return markers.map((m) => _PinOrCluster.pin(m)).toList();
  }
  // Project each marker's lat/lng to screen-space at current zoom level.
  // Simple agglomerative clustering: iterate; if any marker is within 50px of an existing cluster, merge.
  final clusters = <_Cluster>[];
  for (final m in markers) {
    final pt = _project(m.lat, m.lng, viewport);
    final hit = clusters.firstWhere(
      (c) => _distancePx(pt, c.centroid) < 50,
      orElse: () => _Cluster.empty(),
    );
    if (hit.isEmpty) {
      clusters.add(_Cluster.single(m, pt));
    } else {
      hit.add(m, pt);
    }
  }
  return clusters.map((c) => c.members.length == 1 ? _PinOrCluster.pin(c.members.first) : _PinOrCluster.cluster(c)).toList();
}

EdenFleetMapSeverity _worstSeverity(List<EdenFleetMapMarker> members) {
  // critical > warning > staleTelemetry > full > unknown
  final order = {
    EdenFleetMapSeverity.critical: 4,
    EdenFleetMapSeverity.warning: 3,
    EdenFleetMapSeverity.staleTelemetry: 2,
    EdenFleetMapSeverity.full: 1,
    EdenFleetMapSeverity.unknown: 0,
  };
  return members.map((m) => m.severity).reduce((a, b) => (order[a] ?? 0) >= (order[b] ?? 0) ? a : b);
}
```

<anti_patterns>
- **Do NOT bundle a real map provider.** NoOpMapProvider is the default; Google Maps / MapLibre come via separate packages (MAP-GOOGLE-01 / MAP-MAPLIBRE-01 future objectives). This widget composes the abstract `EdenMapProvider` interface.
- **Do NOT polling telemetry inside the widget.** Markers are passed in via `data.markers`. Consumer is responsible for refreshing the data (WebSocket / poll / push from Otodata / Tank Utility / Anova). Per obj 005 OBJECTIVE.md constraint 4 + obj-019 constraint 4.
- **Do NOT use `geolocator` to get user's location.** No 'Center on me' button in v1. Map starts centered on the markers' centroid (computed in widget).
- **Do NOT mutate the inbound markers list.** Treat as immutable; filter / cluster into local lists.
- **Do NOT auto-expand clusters on hover.** v1 = tap-to-expand. Hover is desktop-only and unreliable; tap works everywhere.
- **Do NOT block UI on map provider init.** NoOpMapProvider returns synchronously; for future real providers, the widget falls back to placeholder grid until provider is ready.
</anti_patterns>
