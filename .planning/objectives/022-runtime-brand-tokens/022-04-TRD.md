<objective>
Let `EdenProfileFonts` resolve a font family named by a runtime String, with a safe
fallback when the family does not exist.

Purpose: `EdenProfileFonts` already calls `GoogleFonts.getFont(family)` per profile
(022-CONTEXT.md finding 5), but only for families baked into the five `const` profile
instances. A downstream app reads `"Inter"` out of `window.APP_CONFIG` and needs that
same path to accept a String it learned at boot. This is capability 3 of 3.

Output: three additive family-taking methods plus a shared guarded resolver, and a test
suite. The existing enum-taking API is unchanged in signature and in output.
</objective>

<codebase_examples>
The existing shape (lib/src/theme/eden_profile_fonts.dart) — note the unguarded
`GoogleFonts.getFont(family)` call, which is what this TRD wraps:

```dart
  /// Returns a body [TextStyle] for the active profile.
  /// Fallback (family null) = Plus Jakarta Sans (today's default).
  static TextStyle bodyTextStyle(
    EdenThemeProfile profile, {
    double? fontSize,
    FontWeight? fontWeight,
    double? height,
    Color? color,
  }) {
    final family = bodyFontFamily(profile);
    if (family == null) {
      return GoogleFonts.plusJakartaSans(
        fontSize: fontSize, fontWeight: fontWeight, height: height, color: color,
      );
    }
    return GoogleFonts.getFont(
      family,
      fontSize: fontSize, fontWeight: fontWeight, height: height, color: color,
    );
  }
```

The class doc already states the fallback contract this TRD must preserve:

```dart
/// **Back-compat fallback contract:** when a profile has no opt-in for a
/// given style (family-string is null), the corresponding TextStyle builder
/// returns the SAME font as today's `EdenTheme` defaults:
///   - body fallback = Plus Jakarta Sans
///   - display fallback = Outfit
///   - mono fallback = JetBrains Mono
///
/// **No Roboto.** A failing fallback would silently render Material's
/// default Roboto; the test suite asserts fontFamily is never 'Roboto'.
```

That "No Roboto" rule is load-bearing for this TRD: the whole point of catching the
exception is to land on Plus Jakarta Sans / Outfit / JetBrains Mono, NOT to let Material
substitute Roboto.

The three families the five const profiles actually request today, all of which resolve
successfully: `'IBM Plex Sans'` (medicalInstitutional body), `'Public Sans'` (govFederal
body + display), `'Crimson Pro'` (legalProfessional display).

<error_recovery>
**Verified behaviour of `GoogleFonts.getFont` on an unknown family (measured
2026-08-26):**

```
GoogleFonts.getFont('Definitely Not A Real Font 9000')
  -> throws _Exception: Exception: No font family by name
     'Definitely Not A Real Font 9000' was found.

GoogleFonts.getFont('Inter')
  -> returns TextStyle(fontFamily: 'Inter_regular')
```

So the guard is a plain `try / catch` around `getFont`. Catch broadly (`catch (_)`) —
the thrown type is a private `_Exception`, so you cannot catch it by type, and a narrower
`on Exception` would still miss an `Error`. Boot survival is the requirement.

**Font files failing to DOWNLOAD is a different failure and must not be caught here.**
In an offline test environment `GoogleFonts` prints
`google_fonts was unable to load font X because the following exception occurred` but
STILL returns a valid `TextStyle` — it does not throw. Only the manifest lookup throws.
Do not try to detect or handle the download failure; it is out of scope and self-healing.

**`GoogleFonts` needs an initialized binding.** A plain `test(...)` calling these methods
fails with "Binding has not yet been initialized". Use `testWidgets(...)`, as every
objective 009 theme test does.
</error_recovery>

```dart
  // ---------------------------------------------------------------------------
  // Runtime family resolution.
  //
  // Objective 022 capability 3: a downstream Flutter web app reads a font family
  // out of `window.APP_CONFIG` at boot and passes the String straight in.
  //
  // LOCKED decision 4 (022-CONTEXT.md): no new font delivery mechanism — this
  // reuses GoogleFonts.getFont — and an unavailable family falls back to the
  // profile default rather than throwing, because a bad partner value must not
  // crash an app's boot.
  // ---------------------------------------------------------------------------

  /// Families already reported as unresolvable, so a per-frame theme rebuild
  /// does not spam the debug console. Debug-only bookkeeping.
  static final Set<String> _reportedMissingFamilies = <String>{};

  /// Resets the debug fallback-log dedupe. Tests only.
  @visibleForTesting
  static void resetMissingFamilyLog() => _reportedMissingFamilies.clear();

  /// Resolves [family] via GoogleFonts, falling back to [fallback] when the
  /// family is absent, blank, or unknown to GoogleFonts. Never throws.
  static TextStyle _resolveFamily(
    String? family, {
    required TextStyle Function() fallback,
    double? fontSize,
    FontWeight? fontWeight,
    double? height,
    Color? color,
  }) {
    if (family == null || family.trim().isEmpty) return fallback();
    try {
      return GoogleFonts.getFont(
        family,
        fontSize: fontSize,
        fontWeight: fontWeight,
        height: height,
        color: color,
      );
    } catch (_) {
      // GoogleFonts throws a private _Exception for an unknown family, so this
      // cannot be narrowed by type. Boot survival beats precision here.
      assert(() {
        if (_reportedMissingFamilies.add(family)) {
          debugPrint(
            'EdenProfileFonts: font family "$family" is not available via '
            'google_fonts — falling back to the Eden default.',
          );
        }
        return true;
      }());
      return fallback();
    }
  }

  /// Body [TextStyle] for a RUNTIME family name.
  /// Unknown / blank / null falls back to Plus Jakarta Sans.
  static TextStyle bodyTextStyleForFamily(String? family, { ...same optionals... }) =>
      _resolveFamily(family,
          fallback: () => GoogleFonts.plusJakartaSans(...), ...);

  /// Display [TextStyle] for a RUNTIME family name. Fallback = Outfit.
  static TextStyle displayTextStyleForFamily(String? family, { ... }) => ...;

  /// Mono [TextStyle] for a RUNTIME family name. Fallback = JetBrains Mono.
  static TextStyle monoTextStyleForFamily(String? family, { ... }) => ...;
```
